Manages OpenFrame authorization token storage and retrieval within the `osquery` namespace. This singleton-pattern class handles authentication tokens used for communicating with OpenFrame services.

## Key Components

| Component | Description |
|-----------|-------------|
| `OpenframeAuthorizationManager` | Non-copyable class for managing the OpenFrame auth token lifecycle |
| `updateToken(const std::string&)` | Stores a new authorization token |
| `getToken() const` | Retrieves the current authorization token |
| `OpenframeAuthorizationManagerProvider` | Friend class with exclusive access to construct/destroy the manager |

## Design Notes

- **Non-copyable**: Inherits from `boost::noncopyable` to prevent accidental token duplication
- **Access-controlled construction**: Constructor and destructor are private; only `OpenframeAuthorizationManagerProvider` can instantiate this class
- **Thread considerations**: Callers are responsible for synchronization if accessing from multiple threads

## Usage Example

```cpp
// Access is granted through OpenframeAuthorizationManagerProvider (not directly)
// Example assumes the provider exposes a singleton accessor:

osquery::OpenframeAuthorizationManager& manager = provider.getManager();

// Store a new token received from OpenFrame authentication
manager.updateToken("Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...");

// Retrieve the token when making authenticated requests
std::string token = manager.getToken();
```
