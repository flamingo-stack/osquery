Manages background token refresh for the OpenFrame authorization system, periodically re-extracting credentials at a fixed interval using a dedicated thread.

## Key Components

- **`OpenframeTokenRefresher`** — Main class that runs a background refresh loop
  - `OpenframeTokenRefresher(extractor)` — Constructor accepting a shared `OpenframeTokenExtractor` instance
  - `start()` — Launches the background refresh thread
  - `stop()` — Signals the thread to terminate and joins it
  - `process()` — Private loop body executed on the refresh thread

## Dependencies

| Dependency | Role |
|---|---|
| `OpenframeTokenExtractor` | Performs the actual token extraction/renewal |
| `OpenframeAuthorizationManager` | Manages downstream authorization state |
| `std::thread` + `std::atomic<bool>` | Thread lifecycle and safe stop signaling |

## Usage Example

```cpp
#include "openframe_token_refresher.h"
#include "openframe_token_extractor.h"

// Create shared extractor and start background refresh
auto extractor = std::make_shared<osquery::OpenframeTokenExtractor>();
osquery::OpenframeTokenRefresher refresher(extractor);

refresher.start(); // Begins periodic token renewal in background

// ... application runs ...

refresher.stop(); // Gracefully stops the refresh thread on shutdown
```

> `running_` is an `std::atomic<bool>`, ensuring the stop signal is visible to the refresh thread without requiring an explicit lock on the control path.
