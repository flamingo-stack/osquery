Manages background token refresh for the OpenFrame authorization system, running a dedicated thread to periodically re-extract and update tokens at a fixed interval.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `OpenframeTokenRefresher` | Class | Background service that continuously refreshes OpenFrame authorization tokens |
| `OpenframeTokenRefresher(extractor)` | Constructor | Accepts a shared `OpenframeTokenExtractor` instance to drive token retrieval |
| `start()` | Method | Spawns the background refresh thread and begins the periodic token refresh loop |
| `stop()` | Method | Signals the refresh thread to halt and joins it cleanly |
| `process()` | Private Method | Core loop logic — extracts tokens and updates the authorization manager on each tick |

**Dependencies:** `OpenframeTokenExtractor`, `OpenframeAuthorizationManager`

## Usage Example

```cpp
#include "openframe_token_refresher.h"
#include "openframe_token_extractor.h"

// Create the extractor and wire it into the refresher
auto extractor = std::make_shared<osquery::OpenframeTokenExtractor>();
osquery::OpenframeTokenRefresher refresher(extractor);

// Start background token refresh
refresher.start();

// ... application runs ...

// Gracefully stop the refresh thread on shutdown
refresher.stop();
```

## Thread Safety Notes

- `running_` is an `std::atomic<bool>`, making start/stop signaling lock-free
- `mutex_` guards any shared state accessed inside `process()`
- The refresh thread is a non-copyable `std::thread`; the destructor calls `stop()` to prevent dangling threads
