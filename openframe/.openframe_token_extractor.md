Declares the `OpenframeTokenExtractor` class, which reads and decrypts an authentication token from a file using an injected encryption service.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `OpenframeTokenExtractor` | Class | Main class responsible for token file reading and decryption |
| `OpenframeTokenExtractor(...)` | Constructor | Accepts a shared `OpenframeEncryptionService` instance and the path to the token file |
| `extractToken()` | Public Method | Reads the token file and returns the decrypted token as a `std::string` |
| `encryption_service_` | Private Member | Shared pointer to the encryption service used for decryption |
| `token_file_path_` | Private Member | Stores the path to the token file on disk |

## Usage Example

```c
#include "openframe_token_extractor.h"
#include "openframe_encryption_service.h"
#include <memory>
#include <iostream>

int main() {
    auto enc_service = std::make_shared<OpenframeEncryptionService>();

    OpenframeTokenExtractor extractor(enc_service, "/etc/openframe/token.enc");

    std::string token = extractor.extractToken();
    std::cout << "Decrypted token: " << token << std::endl;

    return 0;
}
```

## Notes

- The class follows RAII principles via a `std::shared_ptr`, allowing safe sharing of the encryption service across multiple components.
- The destructor is explicitly defaulted (`= default`), indicating no manual resource cleanup is required.
