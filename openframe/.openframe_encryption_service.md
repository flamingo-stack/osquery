AES-256-GCM decryption service header for the OpenFrame platform, providing secure data decryption and Base64 decoding via OpenSSL.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `OpenframeEncryptionService` | Class | Main encryption service initialized with a secret key |
| `decrypt()` | Method | Decrypts Base64-encoded AES-GCM ciphertext, returns plaintext string |
| `base64Decode()` | Method | Decodes a Base64 string into raw bytes |
| `handleOpenSSLError()` | Private Method | Translates OpenSSL error codes into `std::runtime_error` exceptions |
| `KEY_SIZE` | Constant | 32 bytes (256-bit AES key) |
| `IV_SIZE` | Constant | 12 bytes (96-bit GCM IV) |
| `TAG_SIZE` | Constant | 16 bytes (128-bit GCM authentication tag) |

## Usage Example

```cpp
#include "openframe_encryption_service.h"
#include <iostream>

int main() {
    // Initialize with a 256-bit secret key
    OpenframeEncryptionService svc("your-32-byte-secret-key-here!!");

    // Decrypt a Base64-encoded AES-256-GCM payload
    try {
        std::string plaintext = svc.decrypt("<base64-encoded-ciphertext>");
        std::cout << "Decrypted: " << plaintext << std::endl;
    } catch (const std::runtime_error& e) {
        std::cerr << "Decryption failed: " << e.what() << std::endl;
    }

    // Decode Base64 separately if needed
    std::vector<unsigned char> raw = svc.base64Decode("<base64-string>");
}
```

## Notes

- Requires OpenSSL (EVP, AES, ERR headers).
- Only decryption is exposed — no encrypt method is defined in this header.
- Throws `std::runtime_error` on decryption failure; always wrap calls in try/catch.
- Source: [`openframe_encryption_service.h`](https://github.com/flamingo-stack/osquery/blob/main/openframe_encryption_service.h)
