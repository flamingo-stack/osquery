Integration test file for the `physical_disk_performance` osquery table on Windows, verifying the table can be queried without errors.

## Key Components

- **`physicalDiskPerformance`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`test_sanity`** — Basic smoke test that executes `SELECT * FROM physical_disk_performance` and validates the result set.
