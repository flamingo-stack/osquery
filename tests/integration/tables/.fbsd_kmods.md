Integration sanity test for the `fbsd_kmods` osquery table, verifying that the FreeBSD kernel modules table can be queried without errors.

## Key Components

- **`fbsdKmods`** — Test fixture class inheriting from `testing::Test`, initializes the osquery test environment via `setUpEnvironment()`.
- **`TEST_F(fbsdKmods, test_sanity)`** — Basic integration test that executes a `SELECT *` query against the `fbsd_kmods` table to confirm it runs without failure.

## Usage Example

```cpp
// Run the sanity test (executed by the integration test runner)
TEST_F(fbsdKmods, test_sanity) {
  auto const data = execute_query("select * from fbsd_kmods");

  // Optional: enable row count assertions
  // ASSERT_GE(data.size(), 0ul);

  // Optional: enable schema validation
  ValidationMap row_map = {
    {"name",    NormalType},

    {"refs",    IntType},
```

- Targets **FreeBSD** only; corresponds to `specs/freebsd/fbsd_kmods.table`.
