## Key Components

- **`authorizationMechanisms`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`test_sanity`** — Single test case that executes a `SELECT *` query against the `authorization_mechanisms` table to confirm it runs without errors.
