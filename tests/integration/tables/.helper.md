Utility header for osquery table integration tests, providing validation primitives and helper types used to verify SQL query results against expected data constraints.

## Key Components

### Validator Classes
- **`IntMinMaxCheck`** — Functor that validates a string value falls within a specified `int64_t` [min, max] range
- **`SpecificValuesCheck`** — Functor that validates a string belongs to a predefined set of allowed values
- **`CronValuesCheck`** — Functor that validates cron-style values, accepting numeric ranges or named string tokens (e.g., `"MON"`, `"JAN"`)

### Standalone Validators
- **`verifyIpAddress`** / **`verifyEmptyStringOrIpAddress`** — Validate IPv4/IPv6 address strings
- **`verifyMacAddress`** — Validates MAC address format
- **`verifyUidGid`** — Validates UID/GID values
- **`is_valid_hex`** — Checks if a string is valid hexadecimal

### Validation Flags (Bitmask Enum)
Composable flags for column-level validation:

| Flag | Meaning |
|------|---------|
| `IntType` | Value must be an integer |
| `NonEmpty` / `NonNull` | Value must not be empty/null |
| `FileOnDisk` / `DirectoryOnDisk` | Path must exist |
| `ValidUUID`, `MD5`, `SHA256`, `SHA1` | Format validators |
| `NonNegativeInt` | Shorthand: integer, non-empty, non-null |

### Core Types
- **`ValidationMap`** — `unordered_map<string, boost::variant<int, CustomCheckerType>>` mapping column names to validation rules
- **`CustomCheckerType`** — `std::function<bool(const std::string&)>` for arbitrary validators

### Test Helpers
- **`execute_query`** — Runs a SQL query against the osquery SQLite engine
- **`validate_row`** / **`validate_rows`** — Assert all columns in one or more rows pass their `ValidationMap` rules
- **`validate_container_rows`** — Validates table output with optional SQL constraints
- **`setUpEnvironment`** — Initializes the test environment

## Usage Example

```cpp
#include "helper.h"

using namespace osquery::table_tests;

TEST_F(MyTableTest, testMyTable) {
  setUpEnvironment();

  ValidationMap row_map = {
    {"pid",      NonNegativeInt},
    {"name",     NonEmptyString},
    {"state",    SpecificValuesCheck({"R", "S", "D", "Z"})},
    {"uid",      verifyUidGid},          // CustomCheckerType
    {"address",  verifyIpAddress},
    {"checksum", IntMinMaxCheck(0, 255)},
  };

  auto rows = execute_query("SELECT * FROM my_table");
  validate_rows(rows, row_map);
}
```
