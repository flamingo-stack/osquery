Utility header for osquery table tests, providing validation helpers, type-check flags, and query execution tools used across SQL table unit tests.

## Key Components

### Validator Classes
- **`IntMinMaxCheck`** — Checks if a string value parses as an integer within `[min, max]`
- **`SpecificValuesCheck`** — Verifies a string matches one of a fixed set of allowed values
- **`CronValuesCheck`** — Validates cron-style fields: numeric range or symbolic values (e.g. `"*"`, `"@reboot"`)

### Standalone Validators
- **`verifyIpAddress`** — Returns `true` if value is a valid IPv4/IPv6 address
- **`verifyEmptyStringOrIpAddress`** — Accepts empty string or valid IP
- **`verifyMacAddress`** — Validates MAC address format
- **`verifyUidGid`** — Validates Unix UID/GID values

### Validation Flags (bitmask enum)
Composable flags for common column constraints:

| Flag | Meaning |
|------|---------|
| `IntType` | Must parse as integer |
| `NonEmpty` | Must not be empty string |
| `NonNull` | Must not be SQL NULL |
| `FileOnDisk` | Path must exist as a file |
| `ValidUUID` | Must be a valid UUID |
| `MD5` / `SHA256` / `SHA1` | Must match hash format |
| `NonNegativeInt` | Composite: int, non-empty, non-null |

### Core Functions
- **`execute_query`** — Runs a SQL query against the osquery SQLite engine
- **`validate_row`** / **`validate_rows`** — Assert all columns in a row match their `ValidationMap` entries
- **`validate_value_using_flags`** — Applies bitmask flags to a single string value
- **`validate_container_rows`** — Validates a full table with optional SQL constraints
- **`is_valid_hex`** — Checks if a string is valid hexadecimal
- **`setUpEnvironment`** — Initializes the test environment

### Types
```cpp
using CustomCheckerType  = std::function<bool(const std::string&)>;
using ValidationDataType = boost::variant<int, CustomCheckerType>;
using ValidationMap      = std::unordered_map<std::string, ValidationDataType>;
```

## Usage Example

```cpp
#include "helper.h"

TEST_F(ProcessesTableTest, test_select_all) {
  auto rows = execute_query("SELECT * FROM processes");

  ValidationMap row_map = {
    {"pid",     NonNegativeInt},
    {"name",    NonEmptyString},
    {"path",    FileOnDisk},
    {"state",   SpecificValuesCheck({"R", "S", "D", "Z", "T"})},
    {"uid",     verifyUidGid},          // CustomCheckerType
    {"cpu_time", IntMinMaxCheck(0, INT64_MAX)},
  };

  validate_rows(rows, row_map);
}
```
