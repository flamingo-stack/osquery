Utility header for osquery table integration tests, providing validation helpers, type-flag constants, and query execution utilities within the `osquery::table_tests` namespace.

## Key Components

### Validator Classes
- **`IntMinMaxCheck`** — Functor that validates a string value falls within a specified `int64_t` range
- **`SpecificValuesCheck`** — Functor that validates a string belongs to a predefined set of allowed values
- **`CronValuesCheck`** — Functor that validates cron-style fields, supporting both numeric range and named string values (e.g., `"MON"`)

### Standalone Validators
- **`verifyIpAddress`** — Validates a string as a valid IP address
- **`verifyEmptyStringOrIpAddress`** — Accepts either an empty string or a valid IP
- **`verifyMacAddress`** — Validates MAC address format
- **`verifyUidGid`** — Validates Unix UID/GID values
- **`is_valid_hex`** — Checks for valid hexadecimal string

### Validation Type Flags (Bitmask Enum)
Composable flags for column validation including `IntType`, `NonEmpty`, `NonNull`, `NonZero`, `FileOnDisk`, `DirectoryOnDisk`, `ValidUUID`, `MD5`, `SHA256`, `SHA1`, `Bool`, and convenience composites like `NonNegativeInt` and `NonEmptyString`.

### Type Aliases
- **`CustomCheckerType`** — `std::function<bool(const std::string&)>` for custom validators
- **`ValidationDataType`** — `boost::variant<int, CustomCheckerType>` (flag int or custom checker)
- **`ValidationMap`** — Maps column names to their validation rules

### Core Functions
- **`execute_query`** — Runs a SQL query and returns results as `QueryData`
- **`validate_row`** / **`validate_rows`** — Asserts row(s) conform to a `ValidationMap`
- **`validate_value_using_flags`** — Applies bitmask flag validation to a single value
- **`validate_container_rows`** — Validates all rows in a named table with optional SQL constraints
- **`setUpEnvironment`** — Initializes the test environment

## Usage Example

```c
using namespace osquery::table_tests;

ValidationMap map = {
    {"pid",     NonNegativeInt},
    {"name",    NonEmptyString},
    {"address", CustomCheckerType(verifyIpAddress)},
    {"port",    IntMinMaxCheck(0, 65535)},
    {"state",   SpecificValuesCheck({"LISTEN", "ESTABLISHED", "CLOSE_WAIT"})},
};

auto rows = execute_query("SELECT pid, name, address, port, state FROM processes");
validate_rows(rows, map);
```
