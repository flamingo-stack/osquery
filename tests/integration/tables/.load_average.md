Integration test for the `load_average` osquery table, verifying basic query execution against the POSIX `load_average` table spec.

## Key Components

- **`loadAverage`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`test_sanity`** — Sanity check that executes `SELECT * FROM load_average` and provides scaffolding for row count assertions and column validation.

## Usage Example

```cpp
// Run the sanity test (via osquery integration test runner)
// To enable full validation, uncomment and configure the ValidationMap:

ValidationMap row_map = {
    {"period",  NormalType},

```

## Notes

- Targets the POSIX table spec: `specs/posix/load_average.table`
- Row count assertions and `validate_rows` are intentionally commented out — extend these to enforce specific result sizes or column constraints.
- Follows the standard osquery integration test pattern: query → size check → validation map → validate.
