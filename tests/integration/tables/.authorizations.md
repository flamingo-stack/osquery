Integration test for the `authorizations` osquery table on Darwin (macOS), verifying basic query execution against the system authorization policies.

## Key Components

- **`authorizations` (test class)** — Inherits from `testing::Test`; sets up the test environment via `setUpEnvironment()` in `SetUp()`.
- **`TEST_F(authorizations, test_sanity)`** — Executes a `SELECT *` query against the `authorizations` table and provides a scaffolded structure for row-level validation (currently commented out).
