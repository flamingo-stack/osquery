Integration sanity test for the `docker_container_stats` osquery table, verifying that the table can be queried without errors on POSIX systems.

## Key Components

- **`dockerContainerStats`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(dockerContainerStats, test_sanity)`** — Executes a basic query against `docker_container_stats` filtered by an empty `id`, confirming the table is queryable. Full row validation is scaffolded but commented out.

## Validated Table Columns (scaffolded)

The commented `ValidationMap` documents the expected schema:

| Column | Type |
|---|---|
| `id`, `name` | `NormalType` |
| `pids`, `read`, `preread`, `interval` | `IntType` |
| `disk_read`, `disk_write`, `num_procs` | `IntType` |
| `cpu_total_usage`, `cpu_kernelmode_usage`, `cpu_usermode_usage` | `IntType` |
| `system_cpu_usage`, `online_cpus` | `IntType` |
| `memory_usage`, `memory_cached`, `memory_limit` | `IntType` |
| `network_rx_bytes`, `network_tx_bytes` | `IntType` |
