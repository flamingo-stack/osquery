Integration test file for the `docker_container_processes` osquery table, validating that the table can be queried without errors on POSIX systems.

## Key Components

- **`dockerContainerProcesses`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(dockerContainerProcesses, test_sanity)`** — Sanity check that executes a query against `docker_container_processes` with an empty `id` filter, confirming the table is queryable without crashing.
