Integration sanity test for the `signature` osquery table, validating that queries against the Darwin `signature` table execute without errors.

## Key Components

- **`signature` (test class)** — Inherits from `testing::Test`; initializes the test environment via `setUpEnvironment()` in `SetUp()`.
- **`TEST_F(signature, test_sanity)`** — Executes a basic `SELECT * FROM signature WHERE path = ''` query to verify the table is queryable. Full row count assertions and field-level validation are scaffolded but currently commented out.

// The test queries the signature table with an empty path filter
