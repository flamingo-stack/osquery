Integration test file for the `memory_device_mapped_addresses` osquery table, providing a sanity check to verify the table can be queried without errors on POSIX systems.

## Key Components

- **`memoryDeviceMappedAddresses`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`test_sanity`** — Basic integration test that executes a `SELECT *` query against the `memory_device_mapped_addresses` table to confirm it runs without crashing.
