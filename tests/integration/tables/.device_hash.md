Integration test sanity check for the `device_hash` osquery table, verifying basic query execution against the Sleuthkit-based table spec.

## Key Components

- **`deviceHash`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(deviceHash, test_sanity)`** — Executes a parameterized query against `device_hash` with empty `device`, `partition`, and `inode` filters to validate the table is queryable without errors.
