Integration test for the `ssh_configs` osquery table, validating that SSH configuration data can be queried without errors across POSIX and Windows platforms.

## Key Components

- **`sshConfigs`** — Test fixture class inheriting from `testing::Test`, with platform-specific setup/teardown for Windows user and group services via `initUsersAndGroupsServices` and `Dispatcher`.
- **`TEST_F(sshConfigs, test_sanity)`** — Sanity check that executes `SELECT * FROM ssh_configs` and provides scaffolding for row validation (currently passive — validation map is commented out).
