Integration test for the `windows_update_history` osquery table, validating query execution and column schema correctness on Windows systems.

## Key Components

- **`windows_update_history` (test class)** — Google Test fixture that initializes the osquery test environment via `setUpEnvironment()`.
- **`test_sanity` (TEST_F)** — Executes a `LIMIT 1` query against `windows_update_history` and validates the returned row schema if update history exists.
- **`ValidationMap`** — Defines expected column types for schema validation across 12 fields.

## Usage Example

```cpp
// Run via osquery integration test suite on a Windows host
TEST_F(windows_update_history, test_sanity) {
  auto const data =
      execute_query("select * from windows_update_history LIMIT 1");

  // Gracefully skips validation if no update history is present
  if (data.size() > 0) {
    validate_rows(data, row_map);
  }
}
```

> **Note:** The test is non-fatal when no update history exists on the host (e.g., clean CI build agents), making it safe for environments where Windows Update has never been run.
