Integration test file for the `autoexec` osquery table on Windows, providing a sanity check that the table can be queried without errors.

## Key Components

- **`autoexec` test class** — Inherits from `testing::Test`, initializes the test environment via `setUpEnvironment()` in `SetUp()`.
- **`test_sanity`** — Executes `SELECT * FROM autoexec` and provides a scaffolded structure for row count assertions and column validation (currently commented out).

## Notes

- Targets the Windows `autoexec` table (spec: `specs/windows/autoexec.table`), which surfaces auto-executing programs and their registry/file sources.
- Row count assertions (`ASSERT_GE`, `ASSERT_EQ`) and the `ValidationMap` are scaffolded but left commented out — activate them to enforce expected column types (`path`, `name`, `source`) during CI validation.
- Follows the standard osquery integration test pattern from `osquery/tests/integration/tables/helper.h`.
