Integration test file for the `device_partitions` osquery table, providing a sanity check that validates query execution against the table spec.

## Key Components

- **`devicePartitions`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`test_sanity`** — Core test case that executes a query against `device_partitions` with an empty device filter. Validation logic (row count assertions and schema checks) is scaffolded but commented out.
