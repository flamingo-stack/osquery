Integration test stub for the `intel_me_info` osquery table, providing a sanity check framework to validate queries against Intel Management Engine firmware version data on Linux/Windows.

## Key Components

- **`intelMeInfo`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(intelMeInfo, test_sanity)`** — Basic sanity test that executes a `SELECT *` query against the `intel_me_info` table. Validation logic (row count assertions and column type checks) is scaffolded but commented out pending implementation.
