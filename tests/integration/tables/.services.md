Integration test stub for the `services` osquery table on Windows, verifying that the `services` table can be queried without errors.

## Key Components

- **`services` (test class)** — Inherits from `testing::Test`; initializes the test environment via `setUpEnvironment()` in `SetUp()`.
- **`TEST_F(services, test_sanity)`** — Executes `SELECT * FROM services` and provides a scaffolded (commented-out) structure for size assertions and row validation.

## Usage Example

```cpp
// Extend the test by uncommenting and configuring the validation map:
ValidationMap row_map = {
    {"name",              NormalType},
    {"service_type",      NormalType},
    {"display_name",      NormalType},
    {"status",            NormalType},
    {"pid",               IntType},
    {"start_type",        NormalType},
    {"win32_exit_code",   IntType},
    {"service_exit_code", IntType},
    {"path",              NormalType},
    {"module_path",       NormalType},
    {"description",       NormalType},
    {"user_account",      NormalType},
};

validate_rows(data, row_map);
```

## Notes

- Corresponds to the osquery table spec at `specs/windows/services.table`.
- Size assertions (`ASSERT_GE`, `ASSERT_EQ`) and `validate_rows` are intentionally commented out — activate them as needed for stricter validation.
- See `osquery/tests/integration/tables/helper.h` for available type flags (`NormalType`, `IntType`, etc.) and custom `DataCheck` objects.
