Integration test file for the `ie_extensions` osquery table, providing a sanity check to verify the table can be queried without errors on Windows systems.

## Key Components

- **`ieExtensions`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`test_sanity`** — Basic integration test that executes `SELECT * FROM ie_extensions` to validate the table is queryable.

## Usage Example

```cpp
// Run the sanity test against the ie_extensions table
TEST_F(ieExtensions, test_sanity) {
  auto const data = execute_query("select * from ie_extensions");
```

- Corresponds to the table spec at `specs/windows/ie_extensions.table`.
