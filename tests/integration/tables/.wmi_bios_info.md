Integration sanity test for the `wmi_bios_info` osquery table on Windows, verifying the table can be queried without errors.

## Key Components

- **`wmiBiosInfo`** — Test fixture class inheriting from `testing::Test`, initializes the osquery environment via `setUpEnvironment()` in `SetUp()`.
- **`TEST_F(wmiBiosInfo, test_sanity)`** — Executes a `SELECT * FROM wmi_bios_info` query and provides scaffolding for row count assertions and schema validation (currently commented out).
