Integration sanity test for the `md_personalities` osquery table, verifying that the `md_personalities` virtual table can be queried without errors on Linux systems.

## Key Components

- **`mdPersonalities`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(mdPersonalities, test_sanity)`** — Executes `SELECT * FROM md_personalities` and provides a scaffold for row count assertions and schema validation (currently commented out).

## Usage Example

```cpp
// Run the integration test via osquery's test runner
// The test executes the following query internally:
auto const data = execute_query("select * from md_personalities");

// Uncomment to add row count assertions:

// Uncomment to validate schema using a ValidationMap:
```

> **Note:** The `md_personalities` table exposes Linux MD (software RAID) personality/driver types (e.g., `raid0`, `raid1`, `linear`) sourced from `/proc/mdstat`. This test targets **Linux only** — see `specs/linux/md_personalities.table` for the full schema definition.
