Integration sanity test for the `memory_info` osquery table on Linux, verifying that the table can be queried without errors.

## Key Components

- **`memoryInfo`** — Test fixture class inheriting from `testing::Test`; calls `setUpEnvironment()` in `SetUp()` to initialize the test environment.
- **`TEST_F(memoryInfo, test_sanity)`** — Executes `SELECT * FROM memory_info` and provides a scaffolded (currently commented-out) validation structure for expected integer columns.
