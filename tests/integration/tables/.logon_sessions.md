## Key Components

- **`logonSessions`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(logonSessions, test_sanity)`** — Executes a `SELECT *` query against the `logon_sessions` table to verify basic query execution.
