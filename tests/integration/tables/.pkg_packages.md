Integration test file for the `pkg_packages` osquery table, providing a sanity check that verifies the table can be queried on FreeBSD systems.

## Key Components

- **`pkgPackages`** - Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`
- **`test_sanity`** - Basic integration test that executes `SELECT * FROM pkg_packages` to verify the table is queryable

```cpp
// Run the sanity test against the pkg_packages table
```
