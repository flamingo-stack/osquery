Integration sanity test for the `prometheus_metrics` osquery table, verifying the table can be queried without errors on POSIX systems.

## Key Components

- **`prometheusMetrics`** — Test fixture class inheriting from `testing::Test`, initializes the test environment via `setUpEnvironment()`.
- **`TEST_F(prometheusMetrics, test_sanity)`** — Basic smoke test that executes `SELECT * FROM prometheus_metrics` and provides scaffolding for row count assertions and schema validation.
