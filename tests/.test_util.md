Shared test utilities header providing common constants, globals, and helper functions used across osquery's test and benchmark infrastructure.

## Key Components

### Constants & Exit Codes

| Constant | Value | Purpose |
|----------|-------|---------|
| `EXTENSION_SUCCESS_CODE` | `0x45` | Expected exit code for a successful extension child process |
| `WORKER_SUCCESS_CODE` | `0x57` | Expected exit code for a successful worker child process |
| `ERROR_COMPARE_ARGUMENT` | `-1` | Child process error: argument comparison failure |
| `ERROR_LAUNCHER_PROCESS` | `-2` | Child process error: launcher process issue |
| `ERROR_QUERY_PROCESS_IMAGE` | `-3` | Child process error: process image query failure |
| `ERROR_IMAGE_NAME_LENGTH` | `-4` | Child process error: image name length mismatch |
| `ERROR_LAUNCHER_MISMATCH` | `-5` | Child process error: launcher identity mismatch |

### Global Variables

- **`kTestDataPath`** — Path to test data, resolved at init time from source or build directory
- **`kTestWorkingDirectory`** — Sandbox directory for config, logs, and cache during tests
- **`kFakeDirectory`** — Root of the fake filesystem tree (`fstree`) used in filesystem iterator tests
- **`kProcessTestExecPath`** — Path to the currently executing test binary
- **`kOsqueryTestModuleName`** — Expected module name of the launcher process
- **`kExpectedWorkerArgs` / `kExpectedExtensionArgs`** — Expected argument arrays for worker and extension child processes

### Functions

- **`initTesting()`** — Initializes the osquery environment for tests and benchmarks
- **`shutdownTesting()`** — Tears down the test environment cleanly
- **`getOsqueryScheduledQuery()`** — Returns a sample `ScheduledQuery` for use in tests
- **`genRows(EventSubscriberPlugin*)`** — Collects all rows from a generator-based event subscriber table
- **`initUsersAndGroupsServices()`** / **`deinitUsersAndGroupsServices()`** *(Windows only)* — Manages Windows-specific user/group service lifecycle in tests

## Usage Example

```c
#include "test_util.h"

int main() {
    osquery::initTesting();

    // Access resolved test data path
    std::string dataFile = osquery::kTestDataPath + "/sample.json";

    // Use fake filesystem directory for iterator tests
    std::string fakeTree = osquery::kFakeDirectory;

    osquery::shutdownTesting();
    return 0;
}
```
