Defines the core plugin registry abstractions for osquery, providing interfaces for registering, routing, and calling plugins both internally and via external extension processes.

## Key Components

### Type Aliases
- `AddExternalCallback` / `RemoveExternalCallback` — Function signatures for managing external plugin lifecycle
- `RegistryRoutes` — Map of plugin name → `PluginResponse` for extension broadcasting
- `RouteUUID` — `uint64_t` identifier for extension registrations
- `RegistryInterfaceRef` — `shared_ptr` alias for `RegistryInterface`

### `RegistryInterface`
Abstract, non-copyable base class for all registries. Manages:
- Plugin storage (`items_`, `aliases_`, `external_`, `routes_`)
- Active plugin routing via `setActive()` / `getActive()`
- Extension UUID-based plugin registration via `addExternal()` / `removeExternal()`
- Thread-safe access using a `Mutex`

Pure virtual methods require subclasses to implement `add()`, `plugin()`, `addExternalPlugin()`, and `removeExternalPlugin()`.

### `RegistryType<PluginType>`
Templated concrete registry that enforces type safety via `dynamic_pointer_cast` on `add()`, and wires extension callbacks to the `PluginType`'s static `addExternal` / `removeExternal` methods.

### `AutoRegisterInterface`
Supports automatic plugin/registry registration at startup. Static helpers (`registries()`, `plugins()`, `autoloadRegistry()`, `autoloadPlugin()`) maintain global sets of pending registrations executed via `registryAndPluginInit()`.

## Usage Example

```cpp
// Define a typed registry for a custom plugin
class MyPlugin : public Plugin { ... };

class MyRegistry : public RegistryType<MyPlugin> {
 public:
  explicit MyRegistry() : RegistryType<MyPlugin>("my_registry", true) {}
};

// Add a plugin instance
auto registry = std::make_shared<MyRegistry>();
auto plugin = std::make_shared<MyConcretePlugin>();
registry->add("my_plugin", plugin, /* internal */ false);

// Call the plugin
PluginRequest request = {{"action", "query"}};
PluginResponse response;
registry->call("my_plugin", request, response);

// Retrieve route info for extension broadcasting
RegistryRoutes routes = registry->getRoutes();
```
