Defines the core registry abstraction layer for osquery's plugin system, providing interfaces for registering, managing, and routing calls to named plugins both internally and via external extension processes.

## Key Components

### Type Aliases
- `AddExternalCallback` / `RemoveExternalCallback` — Callbacks for managing external plugin lifecycle
- `RegistryRoutes` — Map of plugin name to optional `PluginResponse` route info
- `RouteUUID` — `uint64_t` identifier for extension registrations

### `RegistryInterface`
Abstract base class (non-copyable) for all registry types. Manages:
- Plugin registration (`add`, `remove`, `addPlugin`)
- External extension routing (`addExternal`, `removeExternal`)
- Plugin lookup (`exists`, `plugin`, `names`, `count`)
- Active plugin selection (`setActive`, `getActive`)
- Alias mapping (`addAlias`, `getAlias`)
- Route broadcasting (`getRoutes`)

### `RegistryType<PluginType>`
Typed template subclass that:
- Enforces type safety via `dynamic_pointer_cast` on `add()`
- Provides trampoline methods (`addExternalPlugin`, `removeExternalPlugin`) delegating to the concrete `PluginType`'s static callbacks

### `AutoRegisterInterface`
Supports compile-time auto-registration of registries and plugins. Static accessors (`registries()`, `plugins()`) and inserters (`autoloadRegistry`, `autoloadPlugin`) power the `registryAndPluginInit()` bootstrap function.

## Usage Example

```cpp
// Define a typed registry for a custom plugin type
class MyPluginType : public Plugin { /* ... */ };

class MyRegistry : public RegistryType<MyPluginType> {
 public:
  explicit MyRegistry() : RegistryType("my_registry", true) {}
};

// Add a plugin instance
auto registry = std::make_shared<MyRegistry>();
auto plugin = std::make_shared<MyPluginType>();
Status s = registry->add("my_plugin", plugin, /*internal=*/false);

// Call a plugin by name
PluginRequest req = {{"action", "query"}};
PluginResponse resp;
registry->call("my_plugin", req, resp);

// Inspect registered routes for extension broadcast
RegistryRoutes routes = registry->getRoutes();
```
