Convenience header that re-exports the core osquery plugin registry infrastructure through a single include.

## Key Components

Transitively includes the following headers:

| Header | Purpose |
|---|---|
| `osquery/core/plugins/plugin.h` | Base `Plugin` class and plugin lifecycle interfaces |
| `osquery/registry/registry_factory.h` | `RegistryFactory` — singleton for creating and managing plugin registries |
| `osquery/registry/registry_interface.h` | `RegistryInterface` — abstract base for all registry types |

## Usage Example

```c
// Instead of including three separate headers:
#include <osquery/registry/registry.h>

// Register a custom plugin via the factory
REGISTER(MyPlugin, "my_registry", "my_plugin");

// Access the registry factory singleton
auto& factory = RegistryFactory::get();
auto plugin = factory.plugin("my_registry", "my_plugin");
```

> **Note:** Prefer including `registry.h` over its constituent headers directly. If you only need a specific subset (e.g., just `RegistryInterface`), include the targeted header to reduce compilation overhead.
