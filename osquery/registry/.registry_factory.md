Defines the `RegistryFactory` singleton and supporting registration infrastructure for osquery's plugin system, enabling runtime registration, lookup, and invocation of plugins across named registries.

## Key Components

### `RegistryFactory` (Singleton)
The central registry manager — accessed via `RegistryFactory::get()`. Provides:

- **`call()`** — Four overloads to invoke a plugin by registry/item name, with or without a response, using the active plugin when no item name is specified
- **`setUp()`** — Initializes all non-lazy registries at startup
- **`getBroadcast()` / `addBroadcast()` / `removeBroadcast()`** — Serialize and sync registry routes for extension communication
- **`addAlias()` / `getAlias()`** — Alias support for internal plugin names
- **`setActive()` / `getActive()`** — Manage the active plugin per registry
- **`exists()` / `names()` / `count()`** — Registry and plugin introspection
- **`setExternal()` / `external()`** — Marks registry as extension-mode, forwarding internal events to osquery core

### `registries` Namespace Templates
- **`AR<R>` / `RI<R>`** — Auto-register a registry type at static init time via `CREATE_REGISTRY` or `CREATE_LAZY_REGISTRY`
- **`AP<P>` / `PI<P>`** — Auto-register a plugin into a named registry at static init time via `REGISTER` or `REGISTER_INTERNAL`

### Registration Macros

| Macro | Purpose |
|---|---|
| `CREATE_REGISTRY` | Register a new registry type (eager) |
| `CREATE_LAZY_REGISTRY` | Register a new registry type (lazy setUp) |
| `REGISTER` | Register a plugin into a registry |
| `REGISTER_INTERNAL` | Register an optional/internal plugin |

## Usage Example

```cpp
// Define and register a custom registry type
CREATE_REGISTRY(MyTableRegistry, "my_tables");

// Register a plugin into that registry
REGISTER(MyTablePlugin, "my_tables", "my_plugin");

// Call a plugin at runtime
PluginRequest req = {{"action", "query"}};
PluginResponse resp;
Status s = RegistryFactory::call("my_tables", "my_plugin", req, resp);

// Call using the active plugin
Status s2 = RegistryFactory::call("my_tables", req, resp);
```
