Singleton factory that manages all osquery plugin registries, providing a unified interface for registering, looking up, and invoking plugins across both core and extension processes.

## Key Components

**`RegistryFactory`** — Non-copyable singleton (aliased as `Registry`) that owns all registry instances and handles:
- `call()` — Four overloads to invoke plugins by registry/item name or via the active plugin
- `getBroadcast()` / `addBroadcast()` / `removeBroadcast()` — Serialize and sync registry routes with extensions via `RouteUUID`
- `addAlias()` / `getAlias()` — Alias support for internal items (only the alias name is broadcast)
- `setActive()` / `getActive()` — Manage the active plugin per registry
- `exists()`, `names()`, `count()` — Introspection helpers
- `setExternal()` — Marks the process as an extension, forwarding internal events to core

**`registries` namespace** — Auto-registration infrastructure:
- `AR<R>` — Auto-registers a registry type via `RegistryFactory::get().add()`
- `AP<P>` — Auto-registers a plugin into an existing registry
- `RI<R>` / `PI<P>` — Static initializer structs that trigger registration at program startup

**Macros** — Declarative registration at global scope:

| Macro | Purpose |
|---|---|
| `CREATE_REGISTRY` | Register a registry type (eager) |
| `CREATE_LAZY_REGISTRY` | Register a registry type (lazy `setUp`) |
| `REGISTER` | Register a plugin into a registry |
| `REGISTER_INTERNAL` | Register an optional/internal plugin |

## Usage Example

```cpp
// Define and register a custom registry type
class HashRegistry : public RegistryType<HashPlugin> {};
CREATE_REGISTRY(HashRegistry, "hash")

// Register a plugin implementation into that registry
class MD5Plugin : public HashPlugin { /* ... */ };
REGISTER(MD5Plugin, "hash", "md5")

// Invoke the plugin at runtime
PluginRequest request = {{"action", "compute"}, {"data", "hello"}};
PluginResponse response;
Status s = RegistryFactory::call("hash", "md5", request, response);

// Or call via the active plugin
RegistryFactory::get().setActive("hash", "md5");
RegistryFactory::call("hash", request, response);
```
