Declares a single utility function for dispatching serialized events within the osquery event subsystem.

## Key Components

### Function

- **`dispatchSerializedEvent(const std::string& event)`** — Dispatches a pre-serialized event string through the osquery event pipeline. Lives in the `osquery::events` namespace.

## Usage Example

```c
#include "events_stream.h"

// Dispatch a serialized event payload to the osquery event system
std::string serializedPayload = R"({"type":"process","pid":1234})";
osquery::events::dispatchSerializedEvent(serializedPayload);
```

## Notes

- Header-only declaration; the implementation resides in the corresponding `.cpp` source file.
- The function accepts the event as a `const std::string&`, so the caller is responsible for serializing the event data before dispatch.
- Part of the broader `osquery::events` subsystem used for streaming and processing host telemetry events.
