Declares a single event dispatch function within the `osquery::events` namespace for routing serialized event data through the events streaming subsystem.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `osquery::events::dispatchSerializedEvent` | Function | Dispatches a pre-serialized event string into the event stream pipeline |

## Usage Example

```c
#include "events_stream.h"

// Serialize your event payload (e.g., JSON or protobuf string)
std::string serializedPayload = R"({"action":"open","path":"/etc/passwd"})";

// Dispatch the event into the osquery event stream
osquery::events::dispatchSerializedEvent(serializedPayload);
```

## Notes

- The function accepts events as pre-serialized `std::string` values — callers are responsible for serialization before dispatch.
- Designed for internal use within the `osquery` event subsystem; typically called after an event has been captured and encoded by a platform-specific event publisher.
