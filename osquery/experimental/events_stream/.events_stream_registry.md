Declares the `EventsStreamPlugin` class and stream registry utilities for osquery's event streaming subsystem.

## Key Components

- **`EventsStreamPlugin`** — A plugin subclass that handles incoming plugin requests for the events stream registry, implementing the `call()` method to process `PluginRequest` and populate `PluginResponse`.
- **`events::streamRegistryName()`** — Returns the canonical string name used to identify the events stream registry within osquery's plugin registry.

## Usage Example

```c
// Registering and invoking the events stream plugin
PluginRequest request = {{"action", "stream"}};
PluginResponse response;

EventsStreamPlugin plugin;
Status status = plugin.call(request, response);

if (status.ok()) {
    // Process response
}

// Retrieve the registry name for lookup
const char* name = osquery::events::streamRegistryName();
// name == "events_stream" (or equivalent registry key)
```

## Notes

- Inherits from `osquery::Plugin` defined in `osquery/core/plugins/plugin.h`.
- Integrates with `numeric_monitoring` for telemetry on event stream operations.
- The `streamRegistryName()` helper is used internally to register and resolve the plugin within osquery's registry system — avoid hardcoding the name string in dependent code; always use this function.
- Source: [`osquery/events/events_stream_registry.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/events_stream_registry.h)
