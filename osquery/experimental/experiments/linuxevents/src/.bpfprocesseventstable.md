Declares the `BPFProcessEventsTable` class, an osquery `TablePlugin` that exposes Linux BPF-captured process events as a queryable SQL table.

## Key Components

- **`BPFProcessEventsTable`** — Final class inheriting from `TablePlugin`; implements the `bpf_process_events` virtual table
- **`ErrorCode`** — Scoped enum with `MemoryAllocationFailure` for factory-level error handling
- **`Ptr`** — `std::shared_ptr<BPFProcessEventsTable>` type alias for managed ownership
- **`create()`** — Static factory returning `Expected<Ptr, ErrorCode>`; preferred construction path
- **`addEvents()`** — Ingests a batch of `ILinuxEvents::EventList` events into internal storage
- **`columns()`** — Overrides `TablePlugin` to declare the table's column schema
- **`generate()`** — Overrides `TablePlugin` to produce `TableRows` for SQL query execution
- **`PrivateData`** — Opaque PIMPL struct keeping implementation details out of the header

## Usage Example

```cpp
#include "bpfprocesseventstable.h"

// Create the table plugin via the factory
auto result = osquery::BPFProcessEventsTable::create();
if (result.isError()) {
  // Handle MemoryAllocationFailure
  return;
}

osquery::BPFProcessEventsTable::Ptr table = result.take();

// Feed BPF events into the table
tob::linuxevents::ILinuxEvents::EventList events = getEventsFromBPF();
table->addEvents(std::move(events));

// osquery runtime calls generate() internally when the table is queried:
// SELECT * FROM bpf_process_events;
```

> **Note:** The copy constructor and copy assignment operator are explicitly deleted — use `Ptr` (`std::shared_ptr`) for shared ownership across components.
