Background service that runs as an osquery dispatcher thread, collecting Linux system events via BPF and feeding them into the `BPFProcessEventsTable`.

## Key Components

- **`LinuxEventsService`** — Final class inheriting from `InternalRunnable`; manages the lifecycle of the BPF-based Linux event collection loop
  - `LinuxEventsService(BPFProcessEventsTable& table)` — Constructor binding the service to a target events table
  - `start()` — Begins the event collection loop (called by the dispatcher)
  - `stop()` — Signals the service to halt gracefully
  - `PrivateData` — Opaque `pImpl` struct hiding implementation details (BPF handles, ring buffers, etc.)

## Usage Example

```cpp
#include "linuxeventsservice.h"
#include "bpfprocesseventstable.h"
#include <osquery/dispatcher/dispatcher.h>

// Instantiate the events table (registered separately with osquery)
BPFProcessEventsTable eventsTable;

// Create and launch the background service via the osquery dispatcher
auto service = std::make_shared<osquery::LinuxEventsService>(eventsTable);
osquery::Dispatcher::addService(service);

// The dispatcher calls start() internally;
// stop() is invoked on shutdown via the dispatcher teardown path
```

## Notes

- Uses the **pImpl idiom** (`PrivateData`) to keep BPF-specific includes and state out of the public header
- Marked `final` — not intended for further subclassing
- Lifecycle is managed entirely by the osquery `Dispatcher`; do not call `start()`/`stop()` directly
