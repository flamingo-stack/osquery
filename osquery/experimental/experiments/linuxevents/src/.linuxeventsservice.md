Defines the `LinuxEventsService` class, a background service that collects Linux kernel events via BPF and feeds them into the `BPFProcessEventsTable`.

## Key Components

- **`LinuxEventsService`** — A final class inheriting from `InternalRunnable` that runs as a background dispatcher thread, managing the lifecycle of BPF-based process event collection.
  - `LinuxEventsService(BPFProcessEventsTable& table)` — Constructor accepting a reference to the target events table.
  - `start()` — Begins the BPF event collection loop (overrides `InternalRunnable`).
  - `stop()` — Halts the collection loop cleanly (overrides `InternalRunnable`).
  - `PrivateData` — Opaque struct (PIMPL pattern) hiding implementation details and internal state.

## Usage Example

```cpp
#include "linuxeventsservice.h"
#include "bpfprocesseventstable.h"

// Assumes table is already registered with the osquery registry
BPFProcessEventsTable table;

// Create and dispatch the service
auto service = std::make_shared<osquery::LinuxEventsService>(table);
osquery::Dispatcher::addService(service);

// The service runs start() in the background thread.
// Call stop() or let Dispatcher manage shutdown.
```

## Notes

- Uses the **PIMPL idiom** (`std::unique_ptr<PrivateData>`) to encapsulate BPF runtime state, keeping the header clean and ABI-stable.
- Integrates with osquery's `Dispatcher` infrastructure — see [`dispatcher.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/dispatcher/dispatcher.h).
- Linux-only; depends on BPF subsystem support in the host kernel.
