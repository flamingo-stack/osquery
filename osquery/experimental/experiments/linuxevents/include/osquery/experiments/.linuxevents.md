Declares the initialization interface for Linux-specific event monitoring within the osquery framework.

## Key Components

- **`initializeLinuxEvents()`** — Function declaration that bootstraps Linux kernel event subscriptions and related event publisher infrastructure at startup.

## Usage Example

```c
#include "linuxevents.h"

// Called during osquery daemon startup to register Linux event publishers
osquery::initializeLinuxEvents();
```
