Provides hashing utilities for the osquery framework, exposing MD5, SHA1, and SHA256 digest computation over files and in-memory buffers via a streaming `Hash` class and convenience free functions.

## Key Components

### Enums
- **`HashType`** — Selects the hashing algorithm: `HASH_TYPE_MD5`, `HASH_TYPE_SHA1`, `HASH_TYPE_SHA256`
- **`HashEncodingType`** — Controls output encoding: `HASH_ENCODING_TYPE_HEX`, `HASH_ENCODING_TYPE_BASE64`

### Structs
- **`MultiHashes`** — Holds simultaneous results for multiple algorithms; includes `mask`, `md5`, `sha1`, and `sha256` string fields

### Class: `Hash`
Non-copyable, move-aware streaming hash context.

| Method | Description |
|---|---|
| `Hash(HashType)` | Constructs with hex encoding |
| `Hash(HashType, HashEncodingType)` | Constructs with explicit encoding |
| `update(buffer, size)` | Feeds a chunk of data into the hash context |
| `digest()` | Finalizes computation and returns the encoded digest string |

### Free Functions
- **`hashFromFile(hash_type, path)`** — Returns a hex digest string from a file on disk
- **`hashMultiFromFile(mask, path)`** — Computes multiple algorithm digests in a single file pass, returned as `MultiHashes`
- **`hashFromBuffer(hash_type, buffer, size)`** — Returns a hex digest string from a raw memory buffer

## Usage Example

```cpp
#include "hashing.h"

// Streaming hash over chunks
osquery::Hash h(osquery::HASH_TYPE_SHA256);
h.update(data_chunk, chunk_size);
std::string result = h.digest();

// Single-call file hash
std::string md5 = osquery::hashFromFile(osquery::HASH_TYPE_MD5, "/etc/hosts");

// Multiple algorithms in one pass
osquery::MultiHashes hashes = osquery::hashMultiFromFile(
    osquery::HASH_TYPE_MD5 | osquery::HASH_TYPE_SHA256,
    "/etc/hosts"
);

// Buffer hash
std::string sha1 = osquery::hashFromBuffer(
    osquery::HASH_TYPE_SHA1, buffer, buffer_size
);
```
