Provides hashing utilities for the osquery framework, supporting MD5, SHA1, and SHA256 algorithms with hex or Base64 encoding for files and in-memory buffers.

## Key Components

**Enums**
- `HashType` — Algorithm selector: `HASH_TYPE_MD5`, `HASH_TYPE_SHA1`, `HASH_TYPE_SHA256`
- `HashEncodingType` — Output encoding: `HASH_ENCODING_TYPE_HEX`, `HASH_ENCODING_TYPE_BASE64`

**Struct**
- `MultiHashes` — Holds concurrent results for MD5, SHA1, and SHA256 alongside a bitmask indicating which were computed

**Class**
- `Hash` — Stateful, non-copyable (move-only) hasher; supports incremental `update()` calls for streaming large content, finalized via `digest()`

**Free Functions**
- `hashFromFile()` — Computes a single hash digest from a file path
- `hashMultiFromFile()` — Computes multiple hashes from a file in one pass using a bitmask
- `hashFromBuffer()` — Computes a single hash digest from a raw memory buffer

## Usage Example

```cpp
#include "hashing.h"

// Incremental hashing of chunked data
osquery::Hash hasher(osquery::HASH_TYPE_SHA256);
hasher.update(chunk1, chunk1_size);
hasher.update(chunk2, chunk2_size);
std::string result = hasher.digest(); // hex-encoded SHA256

// Hash a file directly
std::string md5 = osquery::hashFromFile(osquery::HASH_TYPE_MD5, "/etc/passwd");

// Compute MD5 + SHA1 + SHA256 in a single file read
osquery::MultiHashes hashes = osquery::hashMultiFromFile(
    osquery::HASH_TYPE_MD5 | osquery::HASH_TYPE_SHA1 | osquery::HASH_TYPE_SHA256,
    "/etc/passwd"
);

// Hash from a buffer
std::string digest = osquery::hashFromBuffer(
    osquery::HASH_TYPE_SHA1, buffer_ptr, buffer_len
);
```
