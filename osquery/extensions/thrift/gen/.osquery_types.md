Autogenerated Thrift header defining the core data types, enumerations, and type aliases used by the osquery extensions IPC layer (`osquery::extensions` namespace).

## Key Components

### Enum
- **`ExtensionCode`** — Status codes for extension operations: `EXT_SUCCESS` (0), `EXT_FAILED` (1), `EXT_FATAL` (2)

### Classes
- **`InternalOptionInfo`** — Holds an option's current `value`, `default_value`, and `type` strings
- **`InternalExtensionInfo`** — Describes a registered extension: `name`, `version`, `sdk_version`, `min_sdk_version`
- **`ExtensionStatus`** — Operation result with integer `code`, `message` string, and route `uuid`
- **`ExtensionResponse`** — Combines an `ExtensionStatus` with an `ExtensionPluginResponse` payload
- **`ExtensionException`** — Thrift exception type mirroring `ExtensionStatus` fields; implements `what()`

All classes extend `apache::thrift::TBase` (or `TException`) and support Thrift `read()`/`write()` serialization.
