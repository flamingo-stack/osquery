Autogenerated Thrift (0.13.0) header defining the `Extension` service interface for osquery's IPC extension protocol within the `osquery::extensions` namespace.

## Key Components

- **`ExtensionIf`** — Pure virtual interface declaring the three service methods all extension handlers must implement:
  - `ping()` — Health check returning `ExtensionStatus`
  - `call()` — Invoke a plugin by registry/item name with a request payload, returning `ExtensionResponse`
  - `shutdown()` — Signal the extension to terminate

- **`ExtensionIfFactory` / `ExtensionIfSingletonFactory`** — Factory abstractions for creating/releasing handler instances per connection; singleton variant wraps a shared handler

- **`ExtensionNull`** — No-op implementation of `ExtensionIf`; useful as a stub or base class

- **`Extension_*_args` / `Extension_*_pargs`** — Thrift-generated argument containers for each RPC method, with `read()`/`write()` for protocol serialization

- **`Extension_*_result` / `Extension_*_presult`** — Result containers holding return values and `__isset` bitmask structs for optional field tracking

- **`ExtensionClient`** — Concrete Thrift client implementing `ExtensionIf`; wraps input/output `TProtocol` instances and exposes split `send_*/recv_*` async-style calls

- **`ExtensionProcessor`** — `TDispatchProcessor` subclass that routes incoming RPC calls by method name to the appropriate `process_*` handler via a `ProcessMap`

## Usage Example

```cpp
#include "Extension.h"
#include <thrift/transport/TSocket.h>
#include <thrift/protocol/TBinaryProtocol.h>

// Connect to a running osquery extension
auto socket    = std::make_shared<apache::thrift::transport::TSocket>("localhost", 9090);
auto transport = std::make_shared<apache::thrift::transport::TBufferedTransport>(socket);
auto protocol  = std::make_shared<apache::thrift::protocol::TBinaryProtocol>(transport);

osquery::extensions::ExtensionClient client(protocol);
transport->open();

// Health check
osquery::extensions::ExtensionStatus status;
client.ping(status);

// Invoke a plugin
osquery::extensions::ExtensionResponse response;
osquery::extensions::ExtensionPluginRequest req;
client.call(response, "table", "processes", req);

transport->close();
```
