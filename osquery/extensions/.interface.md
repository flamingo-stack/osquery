Defines the C++ abstract interfaces, server handlers, runner threads, and client classes for the osquery Extension IPC system, bridging extension processes and the core osquery manager via Thrift RPC over UNIX domain sockets.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `ExtensionAPI` | Abstract class | Base interface requiring `ping()`, `call()`, and `shutdown()` |
| `ExtensionManagerAPI` | Abstract class | Base interface for manager-side operations: `extensions()`, `options()`, `registerExtension()`, `deregisterExtension()`, `query()`, `getQueryColumns()` |
| `ExtensionInterface` | Class | Concrete Thrift server handler implementing `ExtensionAPI` for extension processes |
| `ExtensionManagerInterface` | Class | Combines `ExtensionInterface` + `ExtensionManagerAPI`; manages extension registry, options, and SQL passthrough |
| `ExtensionRunnerInterface` | Class | PIMPL wrapper around the Thrift server lifecycle (`serve`, `connect`, `init`, `stopServer`) |
| `ExtensionRunnerCore` | Class | `InternalRunnable` base for dispatcher-managed Thrift server threads |
| `ExtensionRunner` | Class | Dispatcher thread that serves a single extension's Thrift endpoint |
| `ExtensionManagerRunner` | Class | Dispatcher thread that serves the extension manager Thrift endpoint |
| `ExtensionClientCore` | Class | UNIX socket client base with timeout control |
| `ExtensionClient` | Class | Client for calling into an extension (`ping`, `call`, `shutdown`) |
| `ExtensionManagerClient` | Class | Client for calling into the extension manager |
| `Option` | Struct | Holds a flag's current value, default, and type string |
| `ExtensionCode` | Enum | `EXT_SUCCESS`, `EXT_FAILED`, `EXT_FATAL` |

## Usage Example

```cpp
// Start an extension manager server thread
auto manager_runner = std::make_shared<ExtensionManagerRunner>(
    "/var/osquery/osquery.em");
Dispatcher::addService(manager_runner);

// From an extension: connect to the manager and register
ExtensionManagerClient client("/var/osquery/osquery.em");
RouteUUID uuid;
ExtensionInfo info;         // populated with extension metadata
ExtensionRegistry registry; // populated with plugin routes
Status s = client.registerExtension(info, registry, uuid);
if (!s.ok()) {
  // handle registration failure
}

// Call a plugin on a remote extension from core
ExtensionClient ext_client("/var/osquery/ext.uuid.sock");
PluginRequest  req  = {{"action", "query"}};
PluginResponse resp;
Status cs = ext_client.call("table", "processes", req, resp);
```
