Defines the abstract interfaces, data structures, and server/client classes for osquery's Thrift-based extension communication layer, enabling extensions to register, communicate with, and be managed by the osquery core process.

## Key Components

### Data Structures
- **`Option`** — Holds a flag's current value, default value, and type string
- **`ExtensionCode`** — Enum for extension response codes (`EXT_SUCCESS`, `EXT_FAILED`, `EXT_FATAL`)
- **Type aliases** — `OptionList`, `ExtensionRouteTable`, `ExtensionRegistry`

### Abstract API Interfaces
- **`ExtensionAPI`** — Pure virtual base requiring `ping()`, `call()`, and `shutdown()`
- **`ExtensionManagerAPI`** — Pure virtual base requiring `extensions()`, `options()`, `registerExtension()`, `deregisterExtension()`, `query()`, and `getQueryColumns()`

### Server-Side Classes
- **`ExtensionInterface`** — Implements `ExtensionAPI`; serves the extension's Thrift endpoint with an assigned `RouteUUID`
- **`ExtensionManagerInterface`** — Combines `ExtensionInterface` + `ExtensionManagerAPI`; manages extension registration, route tracking, and SQL passthrough
- **`ExtensionRunnerInterface`** — PIMPL wrapper around the Thrift server lifecycle (`serve`, `connect`, `init`, `stopServer`)
- **`ExtensionRunnerCore`** — Dispatcher-integrated runnable base with start/stop thread safety
- **`ExtensionRunner`** — Runs a single extension's Thrift server
- **`ExtensionManagerRunner`** — Runs the extension manager's Thrift server

### Client-Side Classes
- **`ExtensionClientCore`** — PIMPL wrapper managing the UNIX socket client connection and timeouts
- **`ExtensionClient`** — Client for calling into an extension (`ping`, `call`, `shutdown`)
- **`ExtensionManagerClient`** — Client for calling into the extension manager

## Usage Example

```cpp
// Start an extension manager server
auto manager_runner = std::make_shared<ExtensionManagerRunner>("/var/osquery/osquery.em");
Dispatcher::addService(manager_runner);

// Connect a client from an extension process
ExtensionManagerClient client("/var/osquery/osquery.em");
RouteUUID uuid;
ExtensionRegistry registry;
ExtensionInfo info;

Status s = client.registerExtension(info, registry, uuid);
if (s.ok()) {
  // Extension registered; begin serving ExtensionRunner
  auto runner = std::make_shared<ExtensionRunner>("/var/osquery/osquery.em", uuid);
  Dispatcher::addService(runner);
}

// Query osquery core SQL from an extension
QueryData results;
client.query("SELECT * FROM users", results);
```
