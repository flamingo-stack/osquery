Declares the core extension management interface for osquery, providing types, utilities, and function signatures for loading, communicating with, and managing osquery extensions over UNIX domain sockets.

## Key Components

### Flags
| Flag | Description |
|------|-------------|
| `extensions_socket` | UNIX socket path for extension communication |
| `extensions_autoload` | Path for auto-discovering extension binaries |
| `extensions_timeout` | Timeout duration for extension operations |
| `disable_extensions` | Toggle to disable the extension subsystem |

### Types & Structs

- **`ExtensionInfo`** — Metadata struct holding an extension's `name`, `version`, `sdk_version`, and `min_sdk_version`
- **`ExtensionList`** — `std::map<RouteUUID, ExtensionInfo>` mapping route UUIDs to extension metadata

### Key Functions

| Function | Description |
|----------|-------------|
| `getExtensionSocket()` | Resolves the socket path for a given extension UUID |
| `getExtensions()` | Retrieves the list of currently active extensions |
| `pingExtension()` | Health-checks an extension or extension manager |
| `callExtension()` | Dispatches a plugin request to an extension via its route UUID or socket path |
| `loadExtensions()` | Reads autoload paths and returns a set of extension file paths |
| `applyExtensionDelay()` | Runs a predicate in a loop until timeout or predicate signals stop |
| `startExtension()` | Starts the extension runloop and `ExtensionRunner` thread |
| `startExtensionWatcher()` | Starts a watcher thread to monitor extension manager liveness |
| `startExtensionManager()` | Starts the `ExtensionManagerRunner` thread |
| `initShellSocket()` | Initializes a unique socket path for `osqueryi` shell sessions |

### Class: `ExternalSQLPlugin`

Implements `SQLPlugin` for routing SQL queries through the extension registry rather than the local SQLite engine.

## Usage Example

```c
// Load and start extensions at osquery startup
std::set<std::string> ext_paths = loadExtensions();

// Start the extension manager to accept connections
Status s = startExtensionManager();

// Query active extensions
ExtensionList extensions;
getExtensions(extensions);
for (auto& [uuid, info] : extensions) {
    // info.name, info.version, etc.
}

// Call a plugin exposed by a remote extension
PluginRequest req = {{"action", "query"}};
PluginResponse resp;
callExtension(uuid, "table", "my_table", req, resp);

// Resolve socket path for a specific extension UUID
std::string socket = getExtensionSocket(42);
// → "/var/osquery/osquery.em.42"
```
