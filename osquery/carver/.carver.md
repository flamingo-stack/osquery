Defines the file carving subsystem for osquery, enabling collection and exfiltration of files from disk to a remote endpoint via compressed archives.

## Key Components

### `CarverRunnable`
Abstract base class extending `InternalRunnable`. Serially processes pending carve requests from the dispatcher queue. Tracks global running state via `static std::atomic<bool> running_`.

- `start()` — Scans and executes all pending carve requests
- `doCarve()` — Pure virtual; performs the actual carve for a given set of paths, GUID, and request ID
- `running()` — Static check for whether a carver is currently dispatched

### `CarverRunner<T>`
Concrete template subclass of `CarverRunnable`. Instantiates a carver of type `T` per request, enabling test fakes via template substitution.

- `doCarve()` — Constructs `T(paths, guid, requestId)` and calls `carve()`
- `carves()` — Returns the count of carves attempted in the current runner lifetime

### `Carver`
Core carving implementation. Manages the full lifecycle: file copy → tar archive → zstd compression → HTTP POST.

- `carve()` — End-to-end orchestration method
- `createPaths()` — Initializes temp directory, archive, and compress paths
- `carveAll()` — Copies source files into the temp carve directory
- `blockwiseCopy()` — Block-level file copy (default 8KB blocks via `FLAGS_carver_block_size`)
- `postCarve()` — POSTs the compressed archive to configured TLS endpoints

### `scheduleCarves()`
Free function that dispatches a `CarverRunner` if one is not already active. Intended to be called periodically by the osquery scheduler.

## Usage Example

```cpp
// Dispatch carving from the scheduler
osquery::scheduleCarves();

// Direct carver instantiation (e.g., in tests)
std::set<std::string> paths = {"/etc/hosts", "/etc/passwd"};
osquery::Carver carver(paths, "guid-1234", "req-5678");
osquery::Status status = carver.carve();

if (!status.ok()) {
  LOG(ERROR) << "Carve failed: " << status.getMessage();
}
```
