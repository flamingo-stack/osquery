A header file defining the `GLOGLogger` class, a singleton GLOG-backed implementation of the `Logger` interface for use within osquery's worker logging subsystem.

## Key Components

- **`GLOGLogger`** — Final class inheriting from `Logger`, implementing GLOG-based logging for worker processes.
- **`instance()`** — Static method returning the singleton `GLOGLogger` instance.
- **`log(int severity, const std::string& message)`** — Logs a message at the specified severity level.
- **`vlog(int severity, const std::string& message)`** — Logs a verbose message at the specified severity level.

## Usage Example

```c
#include <osquery/worker/logging/glog_logger.h>

// Retrieve the singleton instance and log a message
auto& logger = osquery::GLOGLogger::instance();
logger.log(1, "Worker process started successfully");

// Log a verbose diagnostic message
logger.vlog(2, "Detailed worker state diagnostics");
```

## Notes

- Declared `final` — not intended for further subclassing.
- Follows the singleton pattern; use `instance()` rather than constructing directly.
- Depends on [`osquery/worker/logging/logger.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/worker/logging/logger.h) for the base `Logger` interface.
- Part of the `osquery` namespace.
