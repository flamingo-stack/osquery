IPC coordination layer for querying osquery tables inside Linux containers, managing worker process lifecycle and pipe-based communication between the host and containerized environments.

## Key Components

### `LinuxTableContainerIPC` (class)
Drives the full lifecycle of container-based table queries: connecting to the container worker, sending query jobs, and retrieving results over pipe channels.

| Method | Description |
|--------|-------------|
| `connectToContainer()` | Spawns/connects to a container worker process for a given table |
| `retrieveQueryDataFromContainer()` | Sends a `QueryContext` and collects the resulting `QueryData` |
| `executeQueryJobs()` | Worker-side loop that processes incoming query jobs (non-returning) |
| `stopContainerWorker()` | Terminates the container worker process and cleans up resources |
| `handleLog()` | `TableIPCMessageHandler` override; relays log messages from the worker |
| `handleJob()` | `TableIPCMessageHandler` override; executes a query job in the worker |

### `CleanupWorkerOnError` (inner RAII guard)
Automatically calls `stopContainerWorker()` on destruction unless `dismiss()` is called, ensuring cleanup on error paths.

### Free Functions

| Function | Description |
|----------|-------------|
| `hasNamespaceConstraint()` | Returns `true` if the query context includes a `pid_with_namespace` constraint |
| `generateInNamespace()` | Runs a table generator inside the appropriate Linux namespace using the container IPC path |

### Type Alias
- **`TableGeneratePtr`** — function pointer type `QueryData(*)(QueryContext&, Logger&)` representing a table's generate function.

## Usage Example

```cpp
#include "osquery/worker/ipc/linux/linux_table_container_ipc.h"

// Host side: query a table inside a container namespace
QueryData results;
PipeChannelFactory factory;
LinuxTableContainerIPC ipc(factory);

Status s = ipc.connectToContainer("processes", false, &generateProcesses);
if (s.ok()) {
    s = ipc.retrieveQueryDataFromContainer(context, results);
}

// Convenience wrapper for namespace-constrained queries
QueryData rows = generateInNamespace(context, "processes", &generateProcesses);
```
