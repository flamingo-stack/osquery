POSIX pipe-based IPC channel factory for osquery's worker process communication system. Provides utilities for creating and managing bidirectional pipe channels between parent and child worker processes.

## Key Components

### `PipeChannelTicket`
A move-only RAII wrapper that holds pre-allocated pipe file descriptors before a `PipeChannel` is constructed. Ensures safe ownership transfer of raw file descriptors between factory methods.

- **`getAndUseReadFd(index)`** — Transfers ownership of a read-end file descriptor (invalidates after use)
- **`getAndUseWriteFd(index)`** — Transfers ownership of a write-end file descriptor (invalidates after use)
- **Destructor** — Automatically closes any unclaimed file descriptors

### `PipeChannelFactory`
Concrete factory extending `TableChannelFactoryBase<PipeChannelFactory>` that manages `PipeChannel` lifecycle.

| Method | Description |
|--------|-------------|
| `createChannelTicket()` | Allocates pipe pairs and returns a `PipeChannelTicket` |
| `createChildChannel(name, ticket)` | Constructs the child-side `PipeChannel` from a ticket |
| `createParentChannel(name, ticket, pid)` | Constructs the parent-side `PipeChannel`, associating the child PID |
| `getTableNameFromPid(pid)` | Resolves a table name from a known child process PID |

### `GetChannelType<PipeChannelFactory>`
Template specialization associating `PipeChannelFactory` with its concrete channel type `PipeChannel`.

## Usage Example

```cpp
osquery::PipeChannelFactory factory;

// Pre-allocate pipe descriptors before fork()
auto ticket = factory.createChannelTicket();

pid_t child_pid = fork();
if (child_pid == 0) {
  // Child process: consume child side of ticket
  auto& child_channel = factory.createChildChannel("my_table",
                                                    std::move(ticket));
} else {
  // Parent process: consume parent side of ticket
  auto& parent_channel = factory.createParentChannel("my_table",
                                                      std::move(ticket),
                                                      child_pid);
}
```

> **Note:** `PipeChannelTicket` is non-copyable and move-only. Attempting to move a ticket that has already been consumed will throw `std::logic_error`.
