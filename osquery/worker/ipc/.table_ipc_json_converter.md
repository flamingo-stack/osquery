Defines the `TableIPCJSONConverter` utility class and `JSONMessageType` enum for serializing and deserializing IPC messages between osquery table processes and the core daemon using JSON.

## Key Components

**`JSONMessageType` (enum class)**
Identifies the type of an IPC JSON message:
- `None` — unrecognized/unset
- `QueryData` — table query results
- `Log` — log message
- `Job` — job/task message

**`TableIPCJSONConverter` (class)**

All methods are static:

| Method | Description |
|---|---|
| `JSONToQueryData` | Deserializes a JSON object into a `QueryData` result set |
| `queryDataToJSON` | Serializes a `QueryData` result set into a JSON object |
| `JSONToLogMessage` | Deserializes a JSON object into log fields (`priority`, `log_type`, `message`) |
| `logMessageToJSON` | Serializes log fields into a JSON object |
| `JSONTypeToMessageType` | Inspects a JSON object and resolves its `JSONMessageType` |

## Usage Example

```c
#include <osquery/core/sql/query_data.h>
#include <osquery/utils/json/json.h>
#include "table_ipc_json_converter.h"

using namespace osquery;

// Serialize QueryData to JSON for IPC transmission
QueryData results = {/* populated rows */};
JSON json_helper;
Status s = TableIPCJSONConverter::queryDataToJSON(results, json_helper);

// Deserialize incoming IPC JSON message
JSON incoming;
JSONMessageType msg_type;
TableIPCJSONConverter::JSONTypeToMessageType(incoming, msg_type);

if (msg_type == JSONMessageType::QueryData) {
    QueryData query_data;
    TableIPCJSONConverter::JSONToQueryData(incoming, query_data);
}
```
