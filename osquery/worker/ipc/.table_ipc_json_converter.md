Defines the `TableIPCJSONConverter` utility class for serializing and deserializing IPC messages between JSON and osquery's internal data types (query results and log messages) used in inter-process communication for table extensions.

## Key Components

**Enum**
- `JSONMessageType` — Discriminates IPC message kinds: `None`, `QueryData`, `Log`, `Job`

**Class: `TableIPCJSONConverter`** (all methods static)

| Method | Direction | Description |
|---|---|---|
| `JSONToQueryData` | JSON → `QueryData` | Deserializes a JSON payload into query result rows |
| `queryDataToJSON` | `QueryData` → JSON | Serializes query result rows into a JSON payload |
| `JSONToLogMessage` | JSON → log fields | Extracts `priority`, `log_type`, and `message` string from JSON |
| `logMessageToJSON` | log fields → JSON | Packs log fields into a JSON payload |
| `JSONTypeToMessageType` | JSON → enum | Reads the message type discriminator from a JSON envelope |

## Usage Example

```c
#include <osquery/utils/table_ipc_json_converter.h>

// Serialize query results for IPC transport
QueryData results = getTableRows();
JSON json_helper;
Status s = TableIPCJSONConverter::queryDataToJSON(results, json_helper);

// On the receiving end, detect message type then deserialize
JSONMessageType msg_type;
TableIPCJSONConverter::JSONTypeToMessageType(json_helper, msg_type);

if (msg_type == JSONMessageType::QueryData) {
    QueryData received;
    TableIPCJSONConverter::JSONToQueryData(json_helper, received);
}

// Serialize a log message for IPC transport
JSON log_json;
TableIPCJSONConverter::logMessageToJSON(
    /*priority=*/2, /*log_type=*/1, "Extension loaded", log_json);
```
