Utility header defining serialization/deserialization helpers for converting osquery IPC messages between JSON and native C++ types.

## Key Components

### `JSONMessageType` (enum class)
Identifies the type of an incoming IPC JSON message:

| Value | Description |
|-------|-------------|
| `None` | Unknown or unset type |
| `QueryData` | SQL query result payload |
| `Log` | Log message payload |
| `Job` | Job/task payload |

### `TableIPCJSONConverter` (class)
A static-only utility class providing bidirectional JSON ↔ native type conversions for IPC communication.

| Method | Direction | Description |
|--------|-----------|-------------|
| `JSONToQueryData` | JSON → native | Deserializes a JSON object into a `QueryData` result set |
| `queryDataToJSON` | native → JSON | Serializes a `QueryData` result set into a JSON object |
| `JSONToLogMessage` | JSON → native | Extracts `priority`, `log_type`, and `message` string from JSON |
| `logMessageToJSON` | native → JSON | Packs log fields into a JSON object for IPC transport |
| `JSONTypeToMessageType` | JSON → enum | Inspects a JSON payload and returns its `JSONMessageType` |

All methods return `Status` to surface parsing or conversion errors to the caller.

## Usage Example

```cpp
#include <osquery/core/sql/query_data.h>
#include <osquery/utils/json/json.h>
#include "table_ipc_json_converter.h"

using namespace osquery;

// Determine message type before dispatching
JSON incoming;
JSONMessageType msg_type;
auto status = TableIPCJSONConverter::JSONTypeToMessageType(incoming, msg_type);

if (msg_type == JSONMessageType::QueryData) {
    QueryData results;
    status = TableIPCJSONConverter::JSONToQueryData(incoming, results);
} else if (msg_type == JSONMessageType::Log) {
    int priority, log_type;
    std::string message;
    status = TableIPCJSONConverter::JSONToLogMessage(
        incoming, priority, log_type, message);
}
```
