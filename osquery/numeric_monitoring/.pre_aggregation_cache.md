Cache layer for numeric monitoring data that buffers and pre-aggregates monitoring points before they are dispatched, reducing redundant data by merging values with matching paths and aggregation types.

## Key Components

### `Point` (class)
The fundamental monitoring unit representing a single observed value.

| Member | Type | Description |
|--------|------|-------------|
| `path_` | `std::string` | Unique name identifying the metric sequence |
| `value_` | `ValueType` | The observed numeric value |
| `pre_aggregation_type_` | `PreAggregationType` | How values are merged (sum, min, max, etc.) |
| `time_point_` | `TimePoint` | When the value was observed |

**Key method:**
- `tryToAggregate(const Point& new_point)` — Merges `new_point` into `this` if both share the same `path_` and `pre_aggregation_type_`. Returns `true` on success, `false` if incompatible.

### `PreAggregationCache` (class)
Maintains an indexed buffer of `Point` objects, automatically collapsing duplicates on insertion.

| Method | Description |
|--------|-------------|
| `addPoint(Point)` | Inserts a point, aggregating into an existing entry if one matches |
| `takePoints()` | Drains and returns all buffered points |
| `size()` | Returns current number of buffered points |

Internally uses `points_index_` (`unordered_map<string, size_t>`) for O(1) lookup into the `points_` vector by path.

## Usage Example

```cpp
using namespace osquery::monitoring;

PreAggregationCache cache;

// Add two points for the same metric path
cache.addPoint(Point("cpu.usage", 45.0, PreAggregationType::Sum, now()));
cache.addPoint(Point("cpu.usage", 30.0, PreAggregationType::Sum, now()));
// Cache now holds one aggregated point (value = 75.0)

// Flush all points for dispatch
auto points = cache.takePoints();
```
