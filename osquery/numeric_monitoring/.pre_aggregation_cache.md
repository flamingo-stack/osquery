Pre-aggregation cache for the osquery numeric monitoring system. Provides in-memory buffering and aggregation of monitoring data points before they are flushed to the monitoring backend.

## Key Components

### `Point`
Represents a single monitoring observation unit with the following public members:
- `path_` — Unique name/identifier for the metric sequence
- `value_` — The observed numeric value
- `pre_aggregation_type_` — Aggregation strategy (e.g., sum, min, max)
- `time_point_` — Timestamp of the observation

**Key method:**
- `tryToAggregate(const Point& new_point)` — Attempts to merge `new_point` into this point. Returns `true` and updates `value_` if `path_` and `pre_aggregation_type_` match; otherwise returns `false` unchanged.

### `PreAggregationCache`
Manages a collection of `Point` objects, deduplicating and aggregating by path using an internal index.

| Method | Description |
|--------|-------------|
| `addPoint(Point point)` | Inserts a new point or aggregates it into an existing one with the same path |
| `takePoints()` | Drains and returns all buffered points |
| `size()` | Returns the current number of cached points |

## Usage Example

```cpp
using namespace osquery::monitoring;

PreAggregationCache cache;

// Add monitoring points - same path will be aggregated
cache.addPoint(Point("cpu.usage", 42.0, PreAggregationType::Sum, now()));
cache.addPoint(Point("cpu.usage", 18.0, PreAggregationType::Sum, now()));

// Flush all aggregated points for dispatch
std::vector<Point> points = cache.takePoints();
// points contains one entry: cpu.usage = 60.0
```
