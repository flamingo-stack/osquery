Defines the public interface for osquery's numeric monitoring system, providing types and functions to record numeric data points and flush aggregation buffers via a plugin-based architecture.

## Key Components

### Structs
- **`RecordKeys`** — Field name descriptors (`path`, `value`, `timestamp`, `pre_aggregation`, `sync`) used when serializing monitoring records
- **`HostIdentifierKeys`** — Descriptor keys (`name`, `scheme`) for host identity metadata

### Type Aliases
- **`Clock`** / **`TimePoint`** — Aliases for `std::chrono::system_clock` and its `time_point`
- **`ValueType`** — `long long int`, the numeric type for all recorded values

### Enum
- **`PreAggregationType`** — Aggregation strategy applied before data is sent: `None`, `Sum`, `Min`, `Max`, `Avg`, `Stddev`, `P10`, `P50`, `P95`, `P99`

### Functions
| Function | Description |
|---|---|
| `record(path, value, pre_aggregation, sync, time_point)` | Records a numeric data point to the monitoring system |
| `flush()` | Forces a flush of the pre-aggregation buffer |
| `hostIdentifierKeys()` | Returns canonical host identifier field keys |
| `recordKeys()` | Returns canonical record field keys |
| `registryName()` | Returns the plugin registry name for monitoring |

### Templates
- **`to<std::string>(PreAggregationType)`** — Converts a `PreAggregationType` to its string representation
- **`tryTo<PreAggregationType>(std::string)`** — Parses a `PreAggregationType` from a string, returning `Expected<T, ConversionError>`

## Usage Example

```cpp
#include "osquery/utils/monitoring/numeric_monitoring.h"

// Record a summed metric at the current time
osquery::monitoring::record(
    "workers.query.execution_ms",
    42LL,
    osquery::monitoring::PreAggregationType::Sum
);

// Record synchronously (blocks until sent)
osquery::monitoring::record(
    "workers.query.count",
    1LL,
    osquery::monitoring::PreAggregationType::None,
    /* sync = */ true
);

// Convert enum to string for logging
std::string label = osquery::to<std::string>(
    osquery::monitoring::PreAggregationType::P95
);

// Parse enum from config string
auto result = osquery::tryTo<osquery::monitoring::PreAggregationType>("Sum");
if (result) {
    osquery::monitoring::flush();
}
```
