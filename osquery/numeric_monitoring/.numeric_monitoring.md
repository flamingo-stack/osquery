Defines the public API for osquery's numeric monitoring subsystem, providing types and functions for recording time-series metric data points to pluggable monitoring backends.

## Key Components

### Structs
- **`RecordKeys`** — String field names used as keys when serializing monitoring records (`path`, `value`, `timestamp`, `pre_aggregation`, `sync`)
- **`HostIdentifierKeys`** — Keys for host identity fields (`name`, `scheme`)

### Type Aliases
- **`Clock`** / **`TimePoint`** — `std::chrono::system_clock` and its `time_point`, used for timestamping records
- **`ValueType`** — `long long int`; the numeric type for all monitored values

### Enum: `PreAggregationType`
Controls how the monitoring plugin pre-aggregates points before flushing:

| Value | Description |
|-------|-------------|
| `None` | No aggregation |
| `Sum`, `Min`, `Max`, `Avg`, `Stddev` | Standard statistics |
| `P10`, `P50`, `P95`, `P99` | Percentile estimates |

### Functions
- **`record(path, value, pre_aggregation, sync, time_point)`** — Submits a new metric data point
- **`flush()`** — Forces the pre-aggregation buffer to emit immediately
- **`hostIdentifierKeys()`** / **`recordKeys()`** — Return canonical key name constants
- **`registryName()`** — Returns the plugin registry name string

### Conversion Templates
- **`to<std::string>(PreAggregationType)`** — Serializes enum to string
- **`tryTo<PreAggregationType>(std::string)`** — Parses string to enum, returning `Expected<T, ConversionError>`

## Usage Example

```cpp
#include <osquery/numeric_monitoring/numeric_monitoring.h>

// Record a simple counter with sum pre-aggregation
osquery::monitoring::record(
    "worker.tasks.completed",
    42LL,
    osquery::monitoring::PreAggregationType::Sum
);

// Record a latency measurement, flushing immediately
osquery::monitoring::record(
    "worker.latency.ms",
    150LL,
    osquery::monitoring::PreAggregationType::P95,
    /* sync = */ true
);

// Convert enum to string for logging
std::string label = osquery::to<std::string>(
    osquery::monitoring::PreAggregationType::P95
); // → "P95"

// Force flush when shutting down
osquery::monitoring::flush();
```
