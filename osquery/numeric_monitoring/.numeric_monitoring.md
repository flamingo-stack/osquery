Defines the public API for osquery's numeric monitoring system, providing types and functions for recording time-series metric data points with optional pre-aggregation support.

## Key Components

### Structs
- **`RecordKeys`** — Field name descriptors (`path`, `value`, `timestamp`, `pre_aggregation`, `sync`) used by monitoring plugins
- **`HostIdentifierKeys`** — Host identity descriptors (`name`, `scheme`) for metric attribution

### Type Aliases
- **`Clock`** / **`TimePoint`** — `std::chrono::system_clock` wrappers for consistent time handling
- **`ValueType`** — `long long int` for all numeric metric values

### Enum: `PreAggregationType`
Controls how values are aggregated before dispatch:

| Value | Description |
|-------|-------------|
| `None` | No aggregation |
| `Sum` / `Min` / `Max` / `Avg` / `Stddev` | Statistical aggregations |
| `P10` / `P50` / `P95` / `P99` | Percentile estimates |

### Functions
- **`record()`** — Submits a new metric data point with optional aggregation and sync control
- **`flush()`** — Forces the pre-aggregation buffer to drain immediately
- **`hostIdentifierKeys()`** / **`recordKeys()`** — Accessor functions for key name constants
- **`registryName()`** — Returns the plugin registry name for this monitoring system

### Conversion Templates
- **`to<std::string>()`** — Serializes a `PreAggregationType` to string
- **`tryTo<PreAggregationType>()`** — Parses a `PreAggregationType` from string, returning `Expected<T, ConversionError>`

## Usage Example

```cpp
#include "numeric_monitoring.h"

// Record a simple summed metric (fire-and-forget)
osquery::monitoring::record(
    "workers.query.executions",
    42LL,
    osquery::monitoring::PreAggregationType::Sum
);

// Record with sync=true to block until the plugin confirms delivery
osquery::monitoring::record(
    "workers.query.latency_ms",
    150LL,
    osquery::monitoring::PreAggregationType::P95,
    true
);

// Convert enum to string for logging
std::string label = osquery::to<std::string>(
    osquery::monitoring::PreAggregationType::Sum
); // "Sum"

// Force flush before shutdown
osquery::monitoring::flush();
```
