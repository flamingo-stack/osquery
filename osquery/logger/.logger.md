Lightweight logging utility header for the osquery framework, providing convenience macros that wrap Google's `glog` library for table-level and reference-tagged log output.

## Key Components

| Macro | Description |
|-------|-------------|
| `TLOG` | Verbose log macro (`VLOG(1)`) intended for table-generated log lines — parsing edge cases, non-critical warnings |
| `RLOG(n)` | Prepends a bracketed reference number (e.g., `[Ref #42]`) to a log message for external searchability |

## Usage Example

```c
#include "logger.h"

// Table developer logging a non-critical parsing edge case
TLOG << "Unexpected value encountered in column 'pid'; skipping row.";

// Logging a confusing or critical-looking line with a searchable reference
LOG(WARNING) << RLOG(101) << "Registry key not found; defaulting to empty.";
```

**Output examples:**

```text
VLOG(1): Unexpected value encountered in column 'pid'; skipping row.
WARNING: [Ref #101] Registry key not found; defaulting to empty.
```

## Notes

- `TLOG` respects the verbosity level set via CLI flags or osquery config — users control whether verbose table logs are emitted.
- `RLOG(n)` is a pure string-prepend macro and can be composed with any `glog` severity level (`LOG(INFO)`, `LOG(WARNING)`, etc.).
- Both macros live in the `osquery` namespace.
