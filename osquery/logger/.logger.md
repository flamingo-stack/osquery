Logging utility header for the `osquery` namespace, providing convenience macros that wrap Google's `glog` library for consistent log output across the codebase.

## Key Components

| Macro | Description |
|-------|-------------|
| `TLOG` | Verbose log alias (`VLOG(1)`) intended for table-generated log lines such as parsing edge-cases |
| `RLOG(n)` | Prepends a formatted reference number string (e.g., `[Ref #42]`) to a log message for external lookup |

## Usage Example

```c
#include "logger.h"

// Table-level verbose logging (only shown at verbosity level 1+)
TLOG << "Unexpected value encountered while parsing row data";

// Log with a reference number for documentation cross-linking
LOG(WARNING) << RLOG(99) << "Suspicious process path detected";
// Output: [Ref #99] Suspicious process path detected
```

## Notes

- Requires `glog` (`<glog/logging.h>`) as a dependency.
- `TLOG` output is suppressed unless the user enables verbosity via CLI flag or config, keeping default output clean.
- `RLOG(n)` expands at compile time using token stringification (`#n`), so `n` must be a literal token — not a variable.
