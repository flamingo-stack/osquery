Brief header defining the core entry-point and service management interface for the osquery daemon (`osqueryd`).

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `installService` | `Status` function | Registers `osqueryd` as a platform service (currently Windows-only) |
| `uninstallService` | `Status` function | Removes a previously installed `osqueryd` service |
| `startOsquery` | `int` function | Platform-agnostic entry point that bootstraps both the shell and daemon |

## Usage Example

```c
#include "main.h"

int main(int argc, char* argv[]) {
    // Bootstrap osquery shell or daemon
    return osquery::startOsquery(argc, argv);
}

// Windows-specific service installation
osquery::Status status = osquery::installService("C:\\osquery\\osqueryd.exe");
if (!status.ok()) {
    // Handle installation failure
}

// Remove the service when no longer needed
osquery::Status uninstall = osquery::uninstallService();
```

## Notes

- `installService` / `uninstallService` are **Windows-only** at the platform implementation level. POSIX systems rely on external tooling (`osqueryctl`) and init system scripts (systemd, launchd) instead.
- The asymmetry between Windows and POSIX install flows is a [known limitation](https://github.com/flamingo-stack/osquery/blob/main/main.h); POSIX paths are candidates for future refactoring into these same methods.
- All symbols live in the `osquery` namespace.
- Depends on `osquery/utils/status/status.h` for the `Status` return type used in service lifecycle calls.
