Provides a fuzzing utility interface for osquery, offering an initialization function to reduce statefulness during fuzz testing by disabling core features.

## Key Components

- **`osqueryFuzzerInitialize(int* argc, char*** argv)`** — Disables core osquery features to minimize statefulness during fuzzing sessions. Intended to be called within `LLVMFuzzerInitialize`.

## Usage Example

```c
#include "fuzz_utils.h"

extern "C" int LLVMFuzzerInitialize(int* argc, char*** argv) {
    return osquery::osqueryFuzzerInitialize(argc, argv);
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
    // Fuzz target logic here
    return 0;
}
```

> **Note:** This header is designed exclusively for use with LLVM's libFuzzer. Always call `osqueryFuzzerInitialize` before executing any fuzz target logic to ensure core subsystems are properly suppressed.
