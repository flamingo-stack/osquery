Provides fuzzing utility declarations for osquery, offering a helper to initialize osquery in a reduced-state mode suitable for fuzz testing.

## Key Components

- **`osqueryFuzzerInitialize(int* argc, char*** argv)`** — Disables core osquery features to minimize statefulness during fuzz testing. Intended to be called from within `LLVMFuzzerInitialize`.

## Usage Example

```c
#include "fuzz_utils.h"

extern "C" int LLVMFuzzerInitialize(int* argc, char*** argv) {
  return osquery::osqueryFuzzerInitialize(argc, argv);
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  // Your fuzz target logic here
  return 0;
}
```

## Notes

- Must be called before any fuzz input processing to ensure osquery internals are in a clean, low-state configuration.
- Designed for use with **libFuzzer** (`LLVMFuzzerInitialize` entry point).
- Reduces side effects from osquery's logging, eventing, and other subsystems during corpus-driven testing.
