Utility header providing a generic initialization function for osquery fuzz testing targets, designed to minimize statefulness by disabling core features during fuzzing runs.

## Key Components

### `osqueryFuzzerInitialize`

```text
int osqueryFuzzerInitialize(int* argc, char*** argv)
```

- **Namespace:** `osquery`
- **Purpose:** Disables core osquery features to reduce statefulness during fuzz testing
- **Parameters:** Standard argument pointers (`argc`, `argv`) matching the LLVM fuzzer init signature
- **Returns:** `int` status code

## Usage Example

Call `osqueryFuzzerInitialize` inside your `LLVMFuzzerInitialize` entry point before the fuzzer begins feeding input:

```c
#include "fuzz_utils.h"

extern "C" int LLVMFuzzerInitialize(int* argc, char*** argv) {
  return osquery::osqueryFuzzerInitialize(argc, argv);
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  // fuzz target logic here
  return 0;
}
```

## Notes

- This header is intended exclusively for fuzz test targets, not production code
- Stripping core features reduces side effects and improves fuzzer reproducibility
- Source lives at [`tools/fuzz/fuzz_utils.h`](https://github.com/flamingo-stack/osquery/blob/main/tools/fuzz/fuzz_utils.h)
