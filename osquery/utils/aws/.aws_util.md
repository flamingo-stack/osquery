Utility header providing AWS SDK integration for osquery, including custom HTTP client implementations, credential providers, region management, and client factory helpers for EC2, Kinesis, Firehose, and STS services.

## Key Components

### Constants
- `kEc2MetadataUrl` — EC2 instance metadata endpoint URL
- `kImdsTokenResource`, `kImdsTokenHeader`, `kImdsTokenTtlHeader`, `kImdsTokenTtlDefaultValue` — IMDSv2 token request constants

### Enumerations
- `AWSServiceType` — Supported service targets: `EC2`, `Firehose`, `Kinesis`, `STS`
- `AWSRegionError` — Region validation error types: `Generic`, `NotFIPSCompliant`

### Classes
| Class | Purpose |
|-------|---------|
| `AWSRegion` | Validated AWS region wrapper; constructed via `AWSRegion::make()` |
| `OsqueryHttpClientFactory` | Custom AWS HTTP client factory (avoids libcurl dependency) |
| `OsqueryHttpClient` | osquery-native AWS HTTP client implementation |
| `OsqueryFlagsAWSCredentialsProvider` | Reads credentials from osquery config flags |
| `OsquerySTSAWSCredentialsProvider` | Obtains temporary credentials via STS assume-role |
| `OsqueryAWSCredentialsProviderChain` | Ordered credential resolution chain (STS → flags → profile → env → EC2 metadata) |

### Free Functions
- `initAwsSdk()` — One-time SDK initialization with custom HTTP factory
- `getIMDSToken()` — Fetches IMDSv2 session token with retry logic
- `getInstanceIDAndRegion()` — Returns EC2 instance ID and region from metadata service
- `setAWSProxy()` — Applies proxy settings from osquery flags to client config
- `setAwsClientConfig()` — Configures an `Aws::Client::ClientConfiguration` for a given service and region
- `appendLogTypeToJson()` — Injects a `log_type` key into a JSON log string
- `enableFIPSInClientConfig()` — Enables FIPS-compliant endpoints on a client configuration

### Template Function

```cpp
template <class Client>
Status makeAWSClient(std::shared_ptr<Client>& client,
                     const AWSRegion& region,
                     bool use_sts_credentials = true,
                     const std::string& endpoint_override = "");
```

Instantiates a typed AWS client (`KinesisClient`, `FirehoseClient`, `STSClient`, or `EC2Client`) with resolved credentials and configuration. Unsupported client types produce a compile-time error via `static_assert`.

## Usage Example

```cpp
// Initialize the SDK once at plugin startup
osquery::initAwsSdk();

// Build a validated region
auto region_result = osquery::AWSRegion::make("us-east-1");
if (!region_result) {
  return Status::failure("Invalid region");
}

// Instantiate a Kinesis client with STS credentials
std::shared_ptr<Aws::Kinesis::KinesisClient> client;
Status s = osquery::makeAWSClient(client, region_result.get());
if (!s.ok()) {
  return s;
}

// Fetch EC2 instance metadata
auto metadata = osquery::getInstanceIDAndRegion();
if (metadata) {
  auto [instance_id, region] = *metadata;
}
```
