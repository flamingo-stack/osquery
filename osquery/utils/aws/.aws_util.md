Utility header providing AWS SDK integration for osquery, including custom HTTP client implementations, credentials providers, region management, and client factory helpers for EC2, Kinesis, Firehose, and STS services.

## Key Components

### Constants
- `kEc2MetadataUrl` — EC2 instance metadata endpoint URL
- `kImdsTokenResource`, `kImdsTokenHeader`, `kImdsTokenTtlHeader`, `kImdsTokenTtlDefaultValue` — IMDSv2 token request configuration

### Enumerations
- `AWSServiceType` — Identifies supported services: `EC2`, `Firehose`, `Kinesis`, `STS`
- `AWSRegionError` — Region validation error kinds: `Generic`, `NotFIPSCompliant`

### Classes
- `AWSRegion` — Validated AWS region wrapper; constructed via `AWSRegion::make()`
- `OsqueryHttpClientFactory` — Custom `HttpClientFactory` replacing libcurl with the osquery HTTP client
- `OsqueryHttpClient` — AWS-compatible HTTP client backed by osquery's native HTTP stack
- `OsqueryFlagsAWSCredentialsProvider` — Reads credentials from `aws_access_key_id` / `aws_secret_access_key` config flags
- `OsquerySTSAWSCredentialsProvider` — Acquires temporary credentials via STS AssumeRole
- `OsqueryAWSCredentialsProviderChain` — Ordered credential resolution: STS → flags → profile → env vars → default profile → EC2 IMDS

### Functions
| Function | Description |
|---|---|
| `initAwsSdk()` | One-time SDK initialization using the custom HTTP factory |
| `getIMDSToken()` | Retrieves an IMDSv2 session token via HTTP PUT |
| `getInstanceIDAndRegion()` | Returns EC2 instance ID and region from metadata service |
| `setAWSProxy()` | Applies proxy settings to a `ClientConfiguration` from flags |
| `setAwsClientConfig()` | Configures a `ClientConfiguration` for a given region and service |
| `makeAWSClient<Client>()` | Template factory; instantiates a typed AWS client with full osquery config |
| `appendLogTypeToJson()` | Appends a `log_type` field to a JSON log string |
| `enableFIPSInClientConfig()` | Enables FIPS-compliant endpoints in a `ClientConfiguration` |

## Usage Example

```cpp
#include <osquery/utils/aws/aws_util.h>

// Initialize the AWS SDK once at plugin startup
osquery::initAwsSdk();

// Create a validated region
auto region_result = osquery::AWSRegion::make("us-east-1");
if (!region_result) {
  // handle error
}

// Instantiate a Kinesis client using osquery credentials and config
std::shared_ptr<Aws::Kinesis::KinesisClient> kinesis_client;
osquery::Status s = osquery::makeAWSClient(kinesis_client, region_result.get());
if (!s.ok()) {
  LOG(ERROR) << "Failed to create Kinesis client: " << s.getMessage();
}

// Retrieve EC2 instance metadata
auto meta = osquery::getInstanceIDAndRegion();
if (meta) {
  auto [instance_id, region] = *meta;
}
```
