Windows ETW (Event Tracing for Windows) utility functions for extracting metadata from ETW event records within the osquery framework.

## Key Components

| Function | Description |
|---|---|
| `sidStringFromEtwRecord` | Extracts the user SID string from an ETW `EVENT_RECORD`'s extended header data |
| `processImagePathFromProcessId` | Resolves the full image file path of a process given its PID |

## Usage Example

```c
#include <osquery/utils/system/etw_helpers.h>

// Extract SID from an ETW event callback
VOID WINAPI MyEventCallback(PEVENT_RECORD pEventRecord) {
    std::string sid = osquery::sidStringFromEtwRecord(*pEventRecord);
    // e.g. "S-1-5-21-3623811015-3361044348-30300820-1013"
}

// Resolve process image path from a known PID
uint32_t pid = 1234;
std::string imagePath = osquery::processImagePathFromProcessId(pid);
// e.g. "C:\Windows\System32\svchost.exe"
```

> **Note:** These helpers are Windows-only and depend on `evntcons.h`. They are intended for use within ETW-based osquery event publishers targeting Windows platforms.
