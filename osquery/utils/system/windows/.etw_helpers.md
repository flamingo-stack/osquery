Windows ETW (Event Tracing for Windows) utility header providing helper functions for extracting security and process information from ETW event records within the osquery framework.

## Key Components

| Function | Description |
|---|---|
| `sidStringFromEtwRecord` | Extracts the user SID string from an ETW `EVENT_RECORD`'s extended header data |
| `processImagePathFromProcessId` | Resolves a process image file path from a given process ID |

## Usage Example

```c
#include "etw_helpers.h"

// ETW event callback context
void WINAPI OnEventRecord(PEVENT_RECORD record) {
    // Extract the SID of the user associated with the event
    std::string userSid = osquery::sidStringFromEtwRecord(*record);

    // Resolve the full image path for a given process
    uint32_t pid = 1234;
    std::string imagePath = osquery::processImagePathFromProcessId(pid);
}
```

## Notes

- **Windows-only**: Depends on `<evntcons.h>` and `osquery/utils/system/system.h`, making this header exclusive to Windows builds.
- Both functions return empty strings on failure or when the requested information is unavailable.
- Intended for use within ETW-based osquery table implementations that consume live kernel or user-mode event streams.
