Windows platform compatibility header that bridges POSIX system APIs with Windows equivalents for the osquery codebase.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `SIGHUP` | Macro | Defined as `1`, mirroring POSIX behavior |
| `SIGUSR1` | Macro | Mapped to `SIGILL` (Windows has no native `SIGUSR1`) |
| `SIGALRM` | Macro | Aliased to `SIGUSR1` |
| `gmtime_r()` | Function | Thread-safe `gmtime` wrapper matching POSIX signature |
| `localtime_r()` | Function | Thread-safe `localtime` wrapper matching POSIX signature |
| `alarm()` | Function | No-op stub satisfying POSIX `alarm()` call sites |
| `pid_t` | Type alias | Maps to `unsigned long` (`DWORD`) — Windows process ID type |
| `PlatformPidType` | Type alias | `void*` — platform-agnostic process handle type |

**Preprocessor guards applied:**
- `NOMINMAX` — prevents Windows min/max macro collisions
- `WIN32_LEAN_AND_MEAN` — reduces Windows header bloat
- `_WIN32_DCOM` — enables COM support
- `#undef GetObject` / `#undef GetMessage` — resolves conflicts with RapidJSON and other libraries

## Usage Example

```c
#include "system.h"

// Use POSIX-style time functions on Windows
time_t now = time(nullptr);
struct tm result;
osquery::gmtime_r(&now, &result);

// Use portable process ID type
osquery::pid_t pid = GetCurrentProcessId();

// Signal constants work cross-platform
int sig = SIGHUP; // == 1
```

## Notes

- Requires `NTDDI_VERSION` and `_WIN32_WINNT` to be defined at build time (enforced via `#error`); these are set in [`tools/build_defs/oss/osquery/cxx.bzl`](https://github.com/flamingo-stack/osquery/blob/main/tools/build_defs/oss/osquery/cxx.bzl)
- Warning `C4067` is suppressed around `sddl.h` inclusion due to a known MSVC preprocessor quirk
