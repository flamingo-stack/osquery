Windows-specific helper header providing RAII memory management and SID/account utility functions for querying user and group information via the Windows Net API.

## Key Components

### `NetApiObjectPtr<T>`
A move-only RAII smart pointer that automatically calls `NetApiBufferFree()` on destruction, preventing leaks of buffers allocated by Windows Net API calls. Supports move semantics, pointer access via `->`, equality comparison, and safe buffer reacquisition via `get_new_ptr()`.

**Convenience type aliases:**

| Alias | Wrapped Type |
|---|---|
| `user_info_0_ptr` | `USER_INFO_0` |
| `user_info_2_ptr` | `USER_INFO_2` |
| `user_info_3_ptr` | `USER_INFO_3` |
| `user_info_4_ptr` | `USER_INFO_4` |
| `localgroup_users_info_0_ptr` | `LOCALGROUP_USERS_INFO_0` |
| `localgroup_info_1_ptr` | `LOCALGROUP_INFO_1` |

### Free Functions

| Function | Description |
|---|---|
| `psidToString(PSID)` | Converts a binary SID to its string representation |
| `getSidFromAccountName(...)` | Looks up a SID by username (wide string or `LPCWSTR`) |
| `getRidFromSid(PSID)` | Extracts the Relative Identifier (RID) from a SID |
| `getGidFromUserSid(PSID)` | Returns the primary group ID for a user SID |
| `getGidFromUsername(LPCWSTR)` | Returns the primary group ID for a username |
| `getGroupSidFromUserSid(PSID)` | Returns the group SID string from a user SID |
| `getGroupSidFromUsername(...)` | Returns the group SID string from a username |
| `getUserHomeDir(string)` | Returns the home directory path for a given SID string |

## Usage Example

```c
// RAII-safe Net API buffer usage
osquery::user_info_3_ptr user_info;
NetUserGetInfo(nullptr, L"jdoe", 3,
               reinterpret_cast<LPBYTE*>(user_info.get_new_ptr()));

// Convert user SID to string
std::string sid_str = osquery::psidToString(user_info->usri3_user_sid);

// Resolve primary group ID
auto gid = osquery::getGidFromUserSid(user_info->usri3_user_sid);
if (gid.has_value()) {
    // use gid.value()
}

// Get home directory
std::string home = osquery::getUserHomeDir(sid_str);
```
