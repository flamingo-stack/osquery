Provides a type-safe C++ wrapper around POSIX `errno` values within the osquery namespace, mapping raw integer error codes to a strongly-typed enum.

## Key Components

### `PosixError` enum class
A scoped enum mapping common POSIX error constants (e.g., `EPERM`, `ENOENT`, `EINVAL`) to named, type-safe variants. Includes an `Unknown = 0` sentinel for unrecognized errors.

### `impl::toPosixSystemError(int from_errno)`
Internal conversion function that translates a raw `errno` integer into a `PosixError` enum value. Declared in the `impl` namespace to discourage direct use.

### `to<PosixError>(int from_errno)`
A template conversion helper constrained via `std::enable_if` to only participate in overload resolution when `ToType` is `PosixError`. Provides the public API for converting raw errno values.

## Usage Example

```cpp
#include "errno.h"  // osquery errno wrapper

int result = some_syscall();
if (result < 0) {
  osquery::PosixError err = osquery::to<osquery::PosixError>(errno);

  switch (err) {
    case osquery::PosixError::NOENT:
      // Handle file not found
      break;
    case osquery::PosixError::ACCES:
      // Handle permission denied
      break;
    case osquery::PosixError::Unknown:
    default:
      // Handle unexpected error
      break;
  }
}
```

## Notes

- The `#pragma once` guard and inclusion of system `<errno.h>` ensure platform POSIX constants are available before the enum is defined.
- The `impl` namespace signals that `toPosixSystemError` is an internal detail; prefer `to<PosixError>()` in consuming code.
