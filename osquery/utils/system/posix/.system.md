Defines the `DropPrivileges` RAII class for temporarily lowering process privileges in osquery, supporting drops by path ownership, explicit UID/GID, or username.

## Key Components

**Type Aliases**
- `PlatformPidType` — Platform-agnostic process ID type (`pid_t`)
- `DropPrivilegesRef` — `shared_ptr` alias for `DropPrivileges`

**`DropPrivileges` Class**
A non-copyable RAII guard that drops and automatically restores effective process privileges on destruction.

| Member | Description |
|--------|-------------|
| `get()` | Factory method returning a `DropPrivilegesRef` instance |
| `dropToParent(path)` | Drops privileges to match the owner of the parent directory of `path` |
| `dropTo(uid, gid)` | Drops to explicit numeric UID/GID |
| `dropTo(uid_str, gid_str)` | Drops to string-parsed UID/GID |
| `dropTo(user)` | Drops to a named user's UID/GID |
| `dropped()` | Returns `true` if effective credentials differ from real credentials |
| `~DropPrivileges()` | Restores original effective privileges on destruction |

**Private State**
- `dropped_` — tracks whether a drop is active
- `to_user_`, `to_group_` — target credentials
- `original_groups_` / `group_size_` — saved supplemental groups for full restoration

## Usage Example

```cpp
#include <osquery/core/system.h>

void readSensitiveFile(const boost::filesystem::path& filePath) {
    // Drop privileges to the file's parent directory owner
    auto dropper = osquery::DropPrivileges::get();
    if (dropper->dropToParent(filePath)) {
        // Operate with reduced privileges
        // ...
    }
    // Privileges are automatically restored when 'dropper' goes out of scope
}

// Explicit UID/GID drop
void dropExplicit() {
    auto dropper = osquery::DropPrivileges::get();
    dropper->dropTo(uid_t(65534), gid_t(65534)); // e.g., nobody:nogroup
}
```
