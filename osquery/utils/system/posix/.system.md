Provides POSIX privilege-dropping utilities for osquery, enabling temporary reduction of process permissions to a specified user, group, or path owner, with automatic restoration on object destruction.

## Key Components

### `PlatformPidType`
Type alias for `pid_t` — platform-agnostic process identifier.

### `DropPrivileges`
RAII-style class for safely lowering process privileges. Non-copyable; manages a single active privilege drop at a time and restores original effective UID/GID on destruction.

| Method | Description |
|--------|-------------|
| `get()` | Factory method returning a `DropPrivilegesRef` (`shared_ptr`) |
| `dropToParent(path)` | Drops to the UID/GID of the parent directory owner |
| `dropTo(uid, gid)` | Drops to explicit numeric UID and GID |
| `dropTo(uid_str, gid_str)` | Drops to string-specified UID and GID |
| `dropTo(user)` | Drops to a named user's UID and GID |
| `dropped()` | Returns `true` if effective IDs differ from real IDs |
| `~DropPrivileges()` | Restores original effective privileges on destruction |

### `DropPrivilegesRef`
Type alias for `std::shared_ptr<DropPrivileges>`.

## Usage Example

```c
#include <osquery/core/system.h>

// Drop privileges to the owner of a specific path
auto dropper = osquery::DropPrivileges::get();
if (dropper->dropToParent("/var/osquery/data")) {
    // Operating with reduced privileges
    // ...
} // Privileges automatically restored when dropper goes out of scope

// Drop to a specific user
auto dropper2 = osquery::DropPrivileges::get();
if (dropper2->dropTo("nobody")) {
    // Running as 'nobody'
}

// Check if currently dropped
if (dropper2->dropped()) {
    // Effective UID/GID differ from real UID/GID
}
```
