Reads the system boot time on Linux by parsing the `btime` field from `/proc/stat`, returning the result as a Unix timestamp.

## Key Components

- **`getBootTime()`** — Reads `/proc/stat`, locates the `btime` entry, extracts and parses the boot timestamp as a `uint64_t`. Returns `0` on any failure (file unreadable, field missing, or parse error).

## Usage Example

```cpp
#include <osquery/utils/system/boottime.h>

uint64_t bootTime = osquery::getBootTime();

if (bootTime == 0) {
    std::cerr << "Failed to retrieve boot time." << std::endl;
} else {
    std::cout << "System booted at Unix timestamp: " << bootTime << std::endl;
}
```

## Notes

- **Linux-specific** — Relies on `/proc/stat`, which is only available on Linux systems.
- **Error handling** — All failure paths (file read error, missing `btime` field, integer conversion failure) silently return `0`; callers should treat `0` as an error sentinel.
- **Dependencies** — Uses `osquery::readFile` for file I/O and `osquery::tryTo<T>` for safe string-to-integer conversion.
