Provides a utility function for reading process command-line information on Linux/Unix systems within the osquery `proc` namespace.

## Key Components

- **`cmdline(pid_t pid)`** — Returns the full command-line string for the given process ID, typically sourced from `/proc/<pid>/cmdline`.

## Usage Example

```c
#include <osquery/utils/linux/proc.h>

// Retrieve the command line for a running process
pid_t target_pid = 1234;
std::string cmd = osquery::proc::cmdline(target_pid);

if (!cmd.empty()) {
    // Process the command line string
    printf("Process %d command: %s\n", target_pid, cmd.c_str());
}
```

## Notes

- Located in the `osquery::proc` namespace.
- Depends on [`boost::filesystem::path`](https://www.boost.org/doc/libs/release/libs/filesystem/).
- Intended for Linux environments where `/proc` is available.
- Returns an empty string if the PID does not exist or the command line cannot be read.
