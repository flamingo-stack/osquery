Provides a utility interface for querying process information on the system, specifically for retrieving command-line arguments of running processes.

## Key Components

- **`cmdline(pid_t pid)`** — Returns the full command-line string for the process identified by the given `pid`.

## Usage Example

```c
#include "proc.h"
#include <iostream>

int main() {
    pid_t target_pid = 1234;
    std::string cmd = osquery::proc::cmdline(target_pid);
    std::cout << "Command line: " << cmd << std::endl;
    return 0;
}
```

## Notes

- Lives within the `osquery::proc` namespace.
- Depends on `boost::filesystem` and the standard `<string>` library.
- Typically used in osquery table implementations that expose process metadata (e.g., `processes` table).
