Linux CPU topology utilities for querying CPU state information via the sysfs interface, providing both raw string and decoded bitmask representations of CPU sets.

## Key Components

### Types & Constants

| Symbol | Description |
|--------|-------------|
| `Error` | Enum with `IOError` (1) and `IncorrectRange` (2) error codes |
| `kMaskSize` | Constant `128`, matching `NR_CPUS` from `linux/cpumask.h` |
| `Mask` | `std::bitset<128>` representing a set of CPUs |

### Functions

| Function | Description |
|----------|-------------|
| `decodeMaskFromString()` | Decodes a sysfs CPU mask string into a `Mask` bitset |
| `getOfflineRaw()` / `getOffline()` | CPUs that are hotplugged off or exceed kernel config limits |
| `getOnlineRaw()` / `getOnline()` | CPUs currently online and being scheduled |
| `getPossibleRaw()` / `getPossible()` | CPUs allocated resources and bringable online |
| `getPresentRaw()` / `getPresent()` | CPUs physically identified in the system |

Each query is available in two forms: raw string (`*Raw`) and decoded `Mask` bitset.

## Usage Example

```c
#include <osquery/utils/cpu.h>

using namespace osquery::cpu;

// Get online CPUs as a bitset
auto online = getOnline();
if (online) {
    Mask mask = online.get();
    for (std::size_t i = 0; i < kMaskSize; i++) {
        if (mask.test(i)) {
            // CPU i is online
        }
    }
}

// Decode a mask string directly (e.g. from /sys/devices/system/cpu/online)
auto decoded = decodeMaskFromString("0-3,7");
if (!decoded) {
    // Handle Error::IOError or Error::IncorrectRange
}
```
