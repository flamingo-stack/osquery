Provides a single utility function for retrieving system uptime within the osquery framework.

## Key Components

- **`getUptime()`** — Returns the system uptime as a `long` value (in seconds) within the `osquery` namespace.

## Usage Example

```c
#include "uptime.h"

// Retrieve current system uptime in seconds
long uptimeSeconds = osquery::getUptime();
```
