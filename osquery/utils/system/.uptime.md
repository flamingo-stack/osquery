Declares a single utility function for retrieving system uptime within the `osquery` namespace.

## Key Components

- **`getUptime()`** — Returns the system uptime as a `long` value (in seconds).

## Usage Example

```c
#include "uptime.h"

long uptimeSeconds = osquery::getUptime();
```
