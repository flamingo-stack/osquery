Brief header providing cross-platform time utility functions for the osquery framework, including UNIX epoch conversion and human-readable ASCII time formatting.

## Key Components

| Function | Description |
|----------|-------------|
| `platformAsctime()` | Converts a `struct tm*` to a C++ string using platform-safe ASCII representation |
| `toUnixTime()` | Converts a `struct tm*` to a `uint64_t` UNIX epoch timestamp |
| `getUnixTime()` | Returns the current time as a `uint64_t` UNIX epoch value |
| `toAsciiTime()` | Converts a UTC `struct tm*` to a human-readable string (e.g., `"Wed Sep 21 10:27:52 2011"`) |
| `toAsciiTimeUTC()` | Converts a local `struct tm*` to a UTC ASCII string via epoch round-trip |
| `getAsciiTime()` | Returns the current date/time as a human-readable ASCII string |

All functions reside in the `osquery` namespace.

## Usage Example

```c
#include "osquery/utils/system/time.h"

// Get current UNIX timestamp
uint64_t now = osquery::getUnixTime();

// Get current time as a readable string
std::string readable = osquery::getAsciiTime();
// → "Wed Sep 21 10:27:52 2011"

// Convert a struct tm to UNIX epoch
struct tm tm_time = {};
// ... populate tm_time ...
uint64_t epoch = osquery::toUnixTime(&tm_time);

// Convert local struct tm to UTC ASCII string
std::string utcStr = osquery::toAsciiTimeUTC(&tm_time);
```

## Notes

- `toAsciiTime()` expects the `struct tm` to **already be in UTC**.
- `toAsciiTimeUTC()` handles local-to-UTC conversion internally via `gmtime()`.
- All timestamp functions return `uint64_t` to safely represent post-2038 dates.
