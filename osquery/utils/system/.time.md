Cross-platform time utility header for the `osquery` namespace, providing helpers to retrieve, convert, and format time values as UNIX epochs or human-readable ASCII strings.

## Key Components

| Function | Description |
|---|---|
| `platformAsctime` | Converts a `struct tm*` to a C++ `std::string` using the platform's `asctime` equivalent |
| `toUnixTime` | Converts a `struct tm*` to a `uint64_t` UNIX epoch timestamp |
| `getUnixTime` | Returns the current time as a `uint64_t` UNIX epoch (seconds since epoch) |
| `toAsciiTime` | Converts a UTC `struct tm*` to a human-readable string (e.g. `"Wed Sep 21 10:27:52 2011"`) |
| `toAsciiTimeUTC` | Converts a local `struct tm*` to UTC, then formats it as the same human-readable string |
| `getAsciiTime` | Returns the current UTC time as a human-readable string |

## Usage Example

```c
#include <osquery/utils/time/time.h>
#include <iostream>

// Get current time as UNIX epoch
uint64_t epoch = osquery::getUnixTime();

// Get current time as readable string
std::string now = osquery::getAsciiTime();
// now == "Wed Sep 21 10:27:52 2011"

// Convert a struct tm to UTC ASCII
struct tm tm_time = {};
// ... populate tm_time ...
std::string utcStr = osquery::toAsciiTimeUTC(&tm_time);

// Convert a struct tm to UNIX epoch
uint64_t ts = osquery::toUnixTime(&tm_time);
```

> **Note:** `toAsciiTime` expects the `struct tm` to already be in UTC. Use `toAsciiTimeUTC` when starting from local time, as it internally applies `gmtime()` conversion.
