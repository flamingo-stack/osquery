Simple ROT13 string decoding utility header for the osquery namespace, providing a single function to decode ROT13-encoded strings.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `osquery::rotDecode` | Function | Decodes a ROT13-encoded string and returns the plaintext result |

## Usage Example

```c
#include "rot13.h"
#include <iostream>

// Decode a ROT13-encoded string
std::string encoded = "Uryyb, Jbeyq!"; // ROT13 for "Hello, World!"
std::string decoded = osquery::rotDecode(encoded);

std::cout << decoded; // Output: Hello, World!
```

> **Note:** ROT13 is a symmetric cipher — encoding and decoding use the same operation. Calling `rotDecode` on an already-decoded string will re-encode it.
