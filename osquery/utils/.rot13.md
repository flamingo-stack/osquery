Provides a ROT13 decoding utility within the `osquery` namespace for transforming ROT13-encoded strings back to their original form.

## Key Components

- **`rotDecode(const std::string& rot_string)`** — Decodes a ROT13-encoded string, returning the plaintext result.

## Usage Example

```c
#include "rot13.h"

// Decode a ROT13-encoded string
std::string encoded = "Uryyb, Jbeyq!";
std::string decoded = osquery::rotDecode(encoded);
// decoded == "Hello, World!"
```

> **Note:** ROT13 is a simple symmetric cipher — encoding and decoding are the same operation. Calling `rotDecode` on a plaintext string will also produce its ROT13 equivalent.
