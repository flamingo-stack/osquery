Provides a ROT13 string decoding utility within the `osquery` namespace.

## Key Components

- **`rotDecode(const std::string& rot_string)`** — Decodes a ROT13-encoded string and returns the plaintext result.

## Usage Example

```c
#include "rot13.h"

// Decode a ROT13-encoded string
std::string encoded = "Uryyb, Jbeyq!";
std::string decoded = osquery::rotDecode(encoded);
// decoded == "Hello, World!"
```

> **Note:** ROT13 is a symmetric cipher — encoding and decoding use the same operation. Calling `rotDecode` on a plaintext string will also produce the ROT13-encoded output.
