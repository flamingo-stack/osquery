Utility header for fetching and parsing Yandex Cloud (YCloud) instance metadata within the osquery framework.

## Key Components

| Symbol | Description |
|--------|-------------|
| `getYCloudKey` | Extracts a named key from a YCloud metadata JSON document |
| `getVendorKey` | Extracts a named key from the vendor-specific section of a YCloud JSON document |
| `getYCloudSshKey` | Retrieves the SSH public key from YCloud instance metadata |
| `getSerialPortEnabled` | Returns whether the serial port is enabled on the YCloud instance |
| `getZoneId` | Parses and normalizes a zone identifier string |
| `fetchYCloudMetadata` | Performs an HTTP request to a given endpoint and populates a `JSON` document with YCloud instance metadata |

All symbols are declared within the `osquery` namespace.

## Usage Example

```c
#include "ycloud_util.h"
#include <osquery/utils/json/json.h>
#include <osquery/utils/status/status.h>

osquery::JSON doc;

// Fetch metadata from the YCloud IMDS endpoint
osquery::Status status = osquery::fetchYCloudMetadata(
    doc, "http://169.254.169.254/latest/meta-data/");

if (status.ok()) {
    std::string instanceId = osquery::getYCloudKey(doc, "instance-id");
    std::string sshKey     = osquery::getYCloudSshKey(doc);
    std::string zone       = osquery::getZoneId(
        osquery::getYCloudKey(doc, "placement/availability-zone"));
}
```
