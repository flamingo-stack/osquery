Windows Shell Item parsing header that declares data structures and helper functions for deserializing various Windows Shell Item (LNK/Jump List) binary formats within the osquery framework.

## Key Components

### `ShellFileEntryData` struct
Holds parsed metadata from a file entry shell item:

| Field | Type | Description |
|-------|------|-------------|
| `path` | `std::string` | File system path |
| `dos_created/accessed/modified` | `long long` | DOS timestamps |
| `version` | `int` | Shell item version |
| `extension_sig` | `std::string` | Extension block signature |
| `identifier` | `std::string` | Item identifier |
| `mft_entry` / `mft_sequence` | `long long` / `int` | NTFS MFT reference |
| `string_size` | `int` | Internal string block size |

### Parser Functions

| Function | Returns | Parses |
|----------|---------|--------|
| `fileEntry()` | `ShellFileEntryData` | File entry shell items |
| `propertyStore()` | `std::string` | Windows Property Store GUIDs |
| `networkShareItem()` | `std::string` | Network share paths |
| `zipContentItem()` | `std::string` | ZIP archive content names |
| `rootFolderItem()` | `std::string` | Root folder/Desktop GUIDs |
| `driveLetterItem()` | `std::string` | Drive letters (e.g. `C:\`) |
| `controlPanelItem()` / `controlPanelCategoryItem()` | `std::string` | Control Panel entries |
| `ftpItem()` | `std::vector<std::string>` | FTP hostnames and paths |
| `guidParse()` | `std::string` | Little-endian GUID bytes → formatted GUID string |
| `propertyViewDrive()` | `std::string` | User property drive data |
| `variableGuid()` / `variableFtp()` | `std::string` | Variable-length GUID/FTP data |
| `mtpDevice()` / `mtpFolder()` / `mtpRoot()` | `std::string` | MTP device/folder/root names |

## Usage Example

```c
#include "shellitem.h"
#include <string>

// Parse a raw shell item binary blob read from a LNK or Jump List file
std::string raw_data = readShellItemBlob();

// Extract file entry metadata
osquery::ShellFileEntryData entry = osquery::fileEntry(raw_data);
// entry.path, entry.mft_entry, entry.dos_modified now populated

// Parse an embedded GUID (little-endian on disk)
std::string guid = osquery::guidParse(raw_data.substr(4, 16));
// Returns: "{XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}"

// Identify a network share item
std::string share = osquery::networkShareItem(raw_data);
```

All functions are defined in the `osquery` namespace. Source: [`shellitem.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/shell/shellitem.h)
