Header defining the LZXpress Huffman decompression interface for osquery on Windows systems.

## Key Components

- **`ExpectedDecompressData`** — Type alias for `Expected<std::vector<UCHAR>, ConversionError>`, representing either decompressed bytes or a conversion error.
- **`decompressLZxpress()`** — Decompresses LZ Xpress Huffman-encoded data, returning the raw bytes or an error.

## Usage Example

```c
#include <osquery/utils/compression/lzxpress.h>

std::vector<UCHAR> compressed = getCompressedBlob(); // your compressed input
unsigned long uncompressed_size = 4096;              // known output size

auto result = osquery::decompressLZxpress(compressed, uncompressed_size);

if (result.isError()) {
    // handle ConversionError
    LOG(ERROR) << result.getError().getMessage();
} else {
    std::vector<UCHAR> data = result.take();
    // use decompressed data
}
```

## Notes

- Windows-only: depends on `osquery/utils/system/system.h` which exposes `UCHAR` via the Windows SDK.
- Uses osquery's `Expected<T, E>` pattern (similar to `std::expected`) for error propagation without exceptions.
- The caller must supply the correct **uncompressed size** (`size`) ahead of time — typically read from a metadata header in the compressed stream.
