Header file declaring a utility function for decompressing LZ Xpress Huffman-compressed data within the osquery framework (Windows-targeted, using `UCHAR`).

## Key Components

- **`ExpectedDecompressData`** — Type alias for `Expected<std::vector<UCHAR>, ConversionError>`, representing either decompressed byte data or a conversion error.
- **`decompressLZxpress()`** — Decompresses LZ Xpress Huffman-encoded data, returning the raw bytes or an error on failure.

## Usage Example

```c
#include <osquery/utils/system/lzxpress.h>

std::vector<UCHAR> compressed = getCompressedBlob(); // your compressed input
unsigned long originalSize = 4096;                   // known uncompressed size

osquery::ExpectedDecompressData result =
    osquery::decompressLZxpress(compressed, originalSize);

if (result) {
    std::vector<UCHAR> data = result.take();
    // use decompressed data...
} else {
    LOG(ERROR) << "Decompression failed: " << result.getError().getMessage();
}
```

## Notes

- Only available on Windows (`UCHAR` is a Windows type from `<osquery/utils/system/system.h>`).
- The `size` parameter must reflect the **total uncompressed** output size; incorrect values will produce errors or truncated output.
- Returns an `Expected` type — always check for errors before accessing the decompressed vector.
