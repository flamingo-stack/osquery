Manages a PID file for a running osquery process, providing safe creation, locking, reading, and cleanup of process ID files to prevent duplicate daemon instances.

## Key Components

### `Pidfile` Class
A non-copyable, move-only RAII wrapper for PID file lifecycle management.

**Error Enum**
| Value | Meaning |
|---|---|
| `Busy` | Another process holds the lock |
| `NotRunning` | No active process found |
| `AccessDenied` | Insufficient file permissions |
| `IOError` | Filesystem read/write failure |
| `InvalidProcessID` | PID value is malformed |

**Static Methods**

| Method | Description |
|---|---|
| `create(path)` | Creates, locks, and writes the current PID to the file |
| `read(path)` | Reads and returns the PID from an existing file |
| `createFile(path)` | Opens/creates the file, returns a raw handle |
| `lockFile(handle)` | Applies an exclusive lock to the file handle |
| `readFile(handle)` | Reads raw content from a locked file handle |
| `writeFile(handle)` | Writes the current PID into the file |
| `closeFile(handle)` | Closes the file handle |
| `destroyFile(handle, path)` | Closes and removes the file from disk |

**`operator<<`** — Stream-formats a `Pidfile::Error` for logging.

## Usage Example

```c
#include <osquery/utils/pidfile/pidfile.h>

// Create and lock a PID file on daemon start
auto pidfile = osquery::Pidfile::create("/var/run/osquery.pid");
if (pidfile.isError()) {
  if (pidfile.getError() == osquery::Pidfile::Error::Busy) {
    // Another instance is already running
  }
  return;
}

// Read PID from an existing file (e.g., from another process)
auto pid = osquery::Pidfile::read("/var/run/osquery.pid");
if (pid.isValue()) {
  std::cout << "osquery PID: " << pid.get() << std::endl;
}

// pidfile destructor cleans up automatically on scope exit
```

## Notes

- Copy construction and assignment are **deleted**; use `std::move` to transfer ownership.
- All public factory methods return `Expected<T, Error>` — check before use.
- Implementation details are hidden via the `PrivateData` pimpl pattern.
