Provides a lightweight string trimming utility within the `osquery` namespace, removing leading and trailing whitespace from a `std::string_view` without allocating a new string.

## Key Components

| Symbol | Description |
|--------|-------------|
| `osquery::trim` | Trims leading and trailing spaces from a `std::string_view`, returning an adjusted view into the original buffer |

## Usage Example

```c
#include "trim.h"
#include <string_view>
#include <cassert>

int main() {
    std::string_view raw = "  hello world  ";
    std::string_view result = osquery::trim(raw);

    // result == "hello world"
    assert(result == "hello world");

    // Works on already-trimmed input
    std::string_view clean = osquery::trim("no spaces");
    assert(clean == "no spaces");

    return 0;
}
```

> **Note:** `trim` returns a `std::string_view` — a non-owning view into the original string's memory. Ensure the source string outlives the returned view to avoid dangling references.
