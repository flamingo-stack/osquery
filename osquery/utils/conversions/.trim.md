Provides a utility function for trimming leading and trailing whitespace from a `std::string_view` within the `osquery` namespace.

## Key Components

- **`osquery::trim(std::string_view input)`** — Returns a `std::string_view` with all leading and trailing spaces removed from the input. Non-owning; no heap allocation.

## Usage Example

```c
#include "trim.h"
#include <iostream>

int main() {
    std::string_view raw = "   hello world   ";
    std::string_view trimmed = osquery::trim(raw);
    std::cout << trimmed; // "hello world"
}
```

> **Note:** The returned `std::string_view` references the original string's memory. Ensure the source string outlives the returned view.
