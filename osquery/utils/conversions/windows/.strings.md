Windows-specific string utility header providing conversion functions between narrow/wide strings, Windows-specific types, and various encoding formats used throughout osquery's Windows platform layer.

## Key Components

| Function | Description |
|----------|-------------|
| `stringToWstring()` | Converts `std::string` → `std::wstring` |
| `wstringToString()` | Converts `std::wstring` or `wchar_t*` → `std::string` (overloaded) |
| `cimDatetimeToUnixtime()` | Converts WMI CIM datetime string → Unix timestamp (`LONGLONG`) |
| `bstrToString()` | Converts Windows `BSTR` type → `std::string` |
| `swapEndianess()` | Swaps byte order of a string (little ↔ big endian) |
| `errorDwordToString()` | Converts Windows error `DWORD` → human-readable `std::string` |

All functions reside in the `osquery` namespace.

## Usage Example

```c
#include "strings.h"

// Narrow <-> Wide string conversion
std::wstring wide = osquery::stringToWstring("C:\\Windows\\System32");
std::string narrow = osquery::wstringToString(wide);

// Convert a WMI CIM datetime to Unix timestamp
std::string cimTime = "20231015120000.000000+000";
LONGLONG unixTime = osquery::cimDatetimeToUnixtime(cimTime);

// Convert a Windows error code to readable string
DWORD err = GetLastError();
std::string errMsg = osquery::errorDwordToString(err);

// Convert BSTR from a WMI query result
BSTR bstrValue = SysAllocString(L"WMI Result");
std::string result = osquery::bstrToString(bstrValue);
SysFreeString(bstrValue);
```

## Notes

- **Windows-only** — depends on `<comutil.h>` and Windows types (`BSTR`, `DWORD`, `LONGLONG`). Not portable to Linux/macOS.
