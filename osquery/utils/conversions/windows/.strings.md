Windows-specific string utility header providing conversion functions between narrow/wide strings and Windows-native types within the osquery framework.

## Key Components

| Function | Description |
|----------|-------------|
| `stringToWstring()` | Converts `std::string` → `std::wstring` |
| `wstringToString(const std::wstring&)` | Converts `std::wstring` → `std::string` |
| `wstringToString(const wchar_t*)` | Converts wide C-string → `std::string` |
| `cimDatetimeToUnixtime()` | Converts WMI CIM datetime string → Unix timestamp (`LONGLONG`) |
| `bstrToString()` | Converts Windows `BSTR` type → `std::string` |
| `swapEndianess()` | Swaps byte order of a string (little ↔ big endian) |
| `errorDwordToString()` | Converts a Windows `DWORD` error code → human-readable `std::string` |

## Usage Example

```c
#include "strings.h"

// Narrow <-> Wide string conversion
std::wstring wide = osquery::stringToWstring("Hello, Windows!");
std::string narrow = osquery::wstringToString(wide);

// Convert WMI CIM datetime to Unix timestamp
std::string cimTime = "20240101120000.000000+000";
LONGLONG unixTime = osquery::cimDatetimeToUnixtime(cimTime);

// Convert Windows BSTR (e.g., from WMI query result)
BSTR bstr = SysAllocString(L"WMI Result");
std::string result = osquery::bstrToString(bstr);
SysFreeString(bstr);

// Decode a Windows API error code
DWORD err = GetLastError();
std::string errMsg = osquery::errorDwordToString(err);

// Swap endianness of a raw byte string
std::string swapped = osquery::swapEndianess(rawBytes);
```

> **Note:** This header is Windows-only. It depends on `<comutil.h>` and links against Windows COM utilities. All functions reside in the `osquery` namespace.
