Windows-specific utility header providing timestamp conversion functions that transform various Windows time formats into Unix epoch timestamps.

## Key Components

| Function | Input | Description |
|----------|-------|-------------|
| `filetimeToUnixtime` | `const FILETIME&` | Converts a Windows `FILETIME` structure to Unix epoch |
| `longIntToUnixtime` | `LARGE_INTEGER&` | Converts a Windows `LARGE_INTEGER` timestamp to Unix epoch |
| `littleEndianToUnixTime` | `const std::string&` | Converts a little-endian encoded `FILETIME` (as used in the Windows Registry) to Unix epoch |
| `parseFatTime` | `const std::string&` | Parses and converts FAT/DOS filesystem time to Unix epoch |

All functions return `LONGLONG` representing seconds since the Unix epoch.

## Usage Example

```c
#include <osquery/utils/system/windows/time/windows_time.h>

namespace osquery {

// Convert a FILETIME (e.g., from file metadata) to Unix epoch
FILETIME ft;
GetSystemTimeAsFileTime(&ft);
LONGLONG unixTime = filetimeToUnixtime(ft);

// Convert a LARGE_INTEGER timestamp (e.g., from NtQuerySystemInformation)
LARGE_INTEGER li;
LONGLONG unixTimeLi = longIntToUnixtime(li);

// Convert a little-endian FILETIME from the Windows Registry
std::string regTimeData = readRegistryBinaryValue();
LONGLONG unixTimeReg = littleEndianToUnixTime(regTimeData);

// Convert FAT time from a filesystem entry
std::string dosTime = readFatEntry();
LONGLONG unixTimeFat = parseFatTime(dosTime);

} // namespace osquery
```

## Notes

- Windows-only header; guarded by inclusion of `osquery/utils/system/system.h`
- All functions are declared within the `osquery` namespace
- Handles three distinct Windows time formats: `FILETIME`, `LARGE_INTEGER`, and FAT/DOS time — covering file system, registry, and legacy storage sources
