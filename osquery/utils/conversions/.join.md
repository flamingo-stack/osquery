Provides a string joining utility within the `osquery` namespace, wrapping Boost's `algorithm::join` to concatenate sequence elements with a delimiter token.

## Key Components

- **`join<SequenceType>(s, tok)`** — Template function that joins any sequence of strings (e.g., `std::vector<std::string>`) into a single `std::string`, inserting `tok` between each element. Delegates to `boost::algorithm::join`.

## Usage Example

```c
#include "join.h"
#include <vector>
#include <string>

// Join a vector of strings with a comma delimiter
std::vector<std::string> parts = {"alpha", "beta", "gamma"};
std::string result = osquery::join(parts, ", ");
// result == "alpha, beta, gamma"

// Works with any compatible sequence type
std::list<std::string> flags = {"--verbose", "--json", "--output"};
std::string cmd = osquery::join(flags, " ");
// cmd == "--verbose --json --output"
```

## Notes

- Accepts any sequence type (`std::vector`, `std::list`, etc.) via the `SequenceType` template parameter.
- Thin wrapper — all behavior is governed by `boost::algorithm::join`.
- Defined as `inline` to avoid multiple-definition issues across translation units.
