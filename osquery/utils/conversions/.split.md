String splitting utility header providing three functions for tokenizing strings by delimiter or whitespace within the `osquery` namespace.

## Key Components

### Functions

| Function | Description |
|----------|-------------|
| `split(s, delim)` | Splits a string by a delimiter string (defaults to `"\t "` whitespace) |
| `split(s, delim, occurrences)` | Splits a string by a char delimiter up to `occurrences` times |
| `vsplit(source, delimiter)` | High-performance split returning `string_view` tokens — at least 2x faster than `split` |

**Key distinction:** `vsplit` avoids string allocation by returning `std::vector<std::string_view>`, making it preferred when only a subset of tokens is needed and the source string's lifetime is guaranteed.

## Usage Example

```c
#include "split.h"

// Whitespace split (default delimiter)
auto tokens = osquery::split("foo  bar\tbaz");
// tokens → ["foo", "bar", "baz"]

// Custom string delimiter
auto parts = osquery::split("a,b,c", ",");
// parts → ["a", "b", "c"]

// Limited splits by char delimiter
auto limited = osquery::split("a:b:c:d", ':', 2);
// limited → ["a", "b", "c:d"]

// High-performance split using string_view (no allocation)
std::string_view csv = "col1,col2,col3";
auto views = osquery::vsplit(csv, ',');
// views → ["col1", "col2", "col3"] as string_views
```

## Notes

- **Lifetime caution:** `vsplit` returns `string_view` tokens — ensure the source string outlives the returned vector.
- **Source:** [`osquery/utils/chars/split.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/chars/split.h)
