Utility header providing string splitting functions within the `osquery` namespace, offering delimiter-based and whitespace tokenization for `std::string` and `std::string_view` types.

## Key Components

| Function | Description |
|----------|-------------|
| `split(s, delim)` | Splits a string by a delimiter string (defaults to tab/space whitespace) |
| `split(s, delim, occurrences)` | Splits a string by a char delimiter up to a maximum number of splits |
| `vsplit(source, delimiter)` | High-performance split returning `string_view` slices — at least 2× faster than `split` |

## Usage Example

```cpp
#include "split.h"

// Whitespace split (default)
auto tokens = osquery::split("foo  bar\tbaz");
// tokens → ["foo", "bar", "baz"]

// Delimiter string split
auto parts = osquery::split("a,b,c", ",");
// parts → ["a", "b", "c"]

// Limited occurrences split
auto limited = osquery::split("a:b:c:d", ':', 2);
// limited → ["a", "b", "c:d"]

// Fast string_view split (no allocations per element)
std::string_view line = "col1|col2|col3";
auto views = osquery::vsplit(line, '|');
// views → ["col1", "col2", "col3"] (string_views into original buffer)
```

> **Note:** Prefer `vsplit` for performance-critical paths where only a subset of elements is needed, as it avoids string copies by returning `std::string_view` slices into the original buffer. Ensure the source string outlives the returned views.
