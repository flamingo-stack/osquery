Utility header providing string splitting functions within the `osquery` namespace.

## Key Components

| Function | Signature | Description |
|----------|-----------|-------------|
| `split` | `(string, string)` | Splits a string by a delimiter (defaults to whitespace/tab) |
| `split` | `(string, char, size_t)` | Splits a string by a char delimiter, limited to N occurrences |
| `vsplit` | `(string_view, char)` | Fast split returning `string_view` slices — at least 2× faster than `split` |

## Usage Example

```cpp
#include "split.h"

// Default whitespace split
std::vector<std::string> tokens = osquery::split("foo bar  baz");
// → ["foo", "bar", "baz"]

// Custom delimiter
std::vector<std::string> parts = osquery::split("a,b,c,d", ",");
// → ["a", "b", "c", "d"]

// Limited occurrences (splits at most 2 times)
std::vector<std::string> limited = osquery::split("a:b:c:d", ':', 2);
// → ["a", "b", "c:d"]

// Zero-copy split via string_view (preferred for performance)
std::string_view data = "col1|col2|col3";
std::vector<std::string_view> cols = osquery::vsplit(data, '|');
// → ["col1", "col2", "col3"]
```

> **Performance note:** Prefer `vsplit` when parsing large strings or high-frequency paths — it avoids heap allocations by returning `string_view` slices into the original buffer. Ensure the source string outlives the returned views.
