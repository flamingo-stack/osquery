Provides IOKit utility declarations for querying and parsing macOS hardware device properties via the IOKit framework within the osquery namespace.

## Key Components

**Device Class Name Constants**
- `kIOUSBDeviceClassName_` — USB devices
- `kIOPCIDeviceClassName_` — PCI devices
- `kIOPlatformExpertDeviceClassName_` — Platform expert devices
- `kIOACPIPlatformDeviceClassName_` — ACPI platform devices
- `kIOPlatformDeviceClassName_` — Generic platform devices
- `kAppleARMIODeviceClassName_` — Apple ARM I/O devices

**`IOKitPCIProperties` struct**
Holds parsed PCI device metadata: `vendor_id`, `model_id`, `pci_class`, and `driver`. Constructed from the raw `"compatible"` property string returned by IOKit.

**Functions**
- `getIOKitProperty()` — Extracts a string value from a `CFMutableDictionaryRef` by key
- `getNumIOKitProperty()` — Extracts a numeric (`long long int`) value from a `CFMutableDictionaryRef` by key
- `idToHex()` — Converts a device ID string to its hexadecimal representation in-place

## Usage Example

```c
#include "iokit.h"

// Retrieve a string property from an IOKit device dictionary
std::string vendor = osquery::getIOKitProperty(deviceDetails, "vendor-id");

// Retrieve a numeric property
long long int revisionId = osquery::getNumIOKitProperty(deviceDetails, "revision-id");

// Convert a raw ID to hex format
std::string deviceId = "8086";
osquery::idToHex(deviceId); // modifies in-place

// Parse PCI compatible string into structured properties
osquery::IOKitPCIProperties props("pci8086,1502");
// props.vendor_id == "8086", props.model_id == "1502"
```
