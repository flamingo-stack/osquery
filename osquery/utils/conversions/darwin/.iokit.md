Utility header for interacting with macOS IOKit framework to enumerate and inspect hardware devices via the IOKit registry.

## Key Components

### Constants

| Constant | Description |
|----------|-------------|
| `kIOUSBDeviceClassName_` | IOKit class name for USB devices |
| `kIOPCIDeviceClassName_` | IOKit class name for PCI devices |
| `kIOPlatformExpertDeviceClassName_` | IOKit class name for platform expert devices |
| `kIOACPIPlatformDeviceClassName_` | IOKit class name for ACPI platform devices |
| `kIOPlatformDeviceClassName_` | IOKit class name for generic platform devices |
| `kAppleARMIODeviceClassName_` | IOKit class name for Apple ARM I/O devices |

### `IOKitPCIProperties` Struct

Holds parsed PCI device properties extracted from the IOKit registry:

- `vendor_id` — PCI vendor identifier
- `model_id` — PCI model/device identifier
- `pci_class` — PCI device class
- `driver` — Associated driver name

Constructed by parsing the `"compatible"` property string from an IOKit PCI device entry.

### Functions

| Function | Description |
|----------|-------------|
| `getIOKitProperty()` | Retrieves a string property value from a `CFMutableDictionaryRef` by key |
| `getNumIOKitProperty()` | Retrieves a numeric (`long long int`) property value from a `CFMutableDictionaryRef` by key |
| `idToHex()` | Converts a device ID string to its hexadecimal representation in-place |

## Usage Example

```c
#include "iokit.h"

// Parse PCI device properties from the "compatible" string
osquery::IOKitPCIProperties props("pci8086,1234");
// props.vendor_id == "8086", props.model_id == "1234"

// Read a string property from an IOKit device dictionary
CFMutableDictionaryRef details = /* IOKit registry entry properties */;
std::string name = osquery::getIOKitProperty(details, "IOClass");

// Read a numeric property
long long int vendor = osquery::getNumIOKitProperty(details, "vendor-id");

// Convert numeric ID to hex string
std::string id = "32902";
osquery::idToHex(id); // id becomes "0x8086"
```

> **Platform Note:** This header is macOS-only and depends on `CoreServices` and the IOKit framework. See the full implementation in the [osquery repository](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/darwin/iokit.h).
