Utility header for converting macOS CoreFoundation `CFNumberRef` values to C++ `std::string` objects within the osquery framework.

## Key Components

### Functions

- **`stringFromCFNumber(const CFDataRef& cf_number)`** — Converts a `CFDataRef` to a `std::string`, automatically inferring the numeric type.
- **`stringFromCFNumber(const CFDataRef& cf_number, CFNumberType type)`** — Converts a `CFDataRef` to a `std::string` using an explicitly specified `CFNumberType` (e.g., `kCFNumberIntType`, `kCFNumberDoubleType`).

## Usage Example

```c
#include "cfnumber.h"
#include <CoreFoundation/CoreFoundation.h>

// Auto-inferred type conversion
int value = 42;
CFNumberRef cf_num = CFNumberCreate(kCFAllocatorDefault, kCFNumberIntType, &value);
std::string result = osquery::stringFromCFNumber((CFDataRef)cf_num);
// result == "42"

// Explicit type conversion
double dval = 3.14;
CFNumberRef cf_dbl = CFNumberCreate(kCFAllocatorDefault, kCFNumberDoubleType, &dval);
std::string result2 = osquery::stringFromCFNumber((CFDataRef)cf_dbl, kCFNumberDoubleType);
// result2 == "3.14"

CFRelease(cf_num);
CFRelease(cf_dbl);
```

## Notes

- macOS/Darwin only — depends on the `CoreFoundation` framework.
- Both functions are defined in the `osquery` namespace.
- Prefer the explicit-type overload when the `CFNumberType` is known ahead of time to avoid potential type inference mismatches.
