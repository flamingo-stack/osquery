Provides utility functions for converting Core Foundation `CFNumberRef` values to `std::string` on macOS.

## Key Components

### Functions

- **`stringFromCFNumber(const CFDataRef& cf_number)`** — Converts a `CFDataRef` (representing a `CFNumber`) to a `std::string`, automatically inferring the numeric type.
- **`stringFromCFNumber(const CFDataRef& cf_number, CFNumberType type)`** — Converts a `CFDataRef` to a `std::string` using an explicitly specified `CFNumberType` (e.g., `kCFNumberIntType`, `kCFNumberDoubleType`).

## Usage Example

```c
#include "cfnumber.h"

// Auto-infer numeric type
CFNumberRef num = CFNumberCreate(kCFAllocatorDefault, kCFNumberIntType, &myInt);
std::string result = osquery::stringFromCFNumber((CFDataRef)num);

// Explicit numeric type
std::string result2 = osquery::stringFromCFNumber(
    (CFDataRef)num,
    kCFNumberIntType
);

CFRelease(num);
```

> **Note:** This header is macOS-only and requires linking against the `CoreFoundation` framework. It is part of osquery's platform abstraction layer for parsing Apple property lists and system data structures.
