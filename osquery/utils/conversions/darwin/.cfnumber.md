Utility header for converting CoreFoundation `CFNumberRef` values to standard C++ strings on macOS/Apple platforms.

## Key Components

### Functions

- **`stringFromCFNumber(const CFDataRef& cf_number)`** — Converts a `CFDataRef` (representing a CF number) to a `std::string`, auto-detecting the number type.
- **`stringFromCFNumber(const CFDataRef& cf_number, CFNumberType type)`** — Converts a `CFDataRef` to a `std::string` using an explicitly specified `CFNumberType` (e.g., `kCFNumberIntType`, `kCFNumberDoubleType`).

Both overloads live in the `osquery` namespace.

## Usage Example

```c
#include "cfnumber.h"

// Auto-detect number type
CFNumberRef num = ...; // obtained from CF API
std::string value = osquery::stringFromCFNumber((CFDataRef)num);

// Explicit type conversion
std::string intValue = osquery::stringFromCFNumber(
    (CFDataRef)num,
    kCFNumberSInt32Type
);
```

## Notes

- **macOS only** — depends on `CoreFoundation/CoreFoundation.h`; not available on Linux/Windows builds.
- Accepts `CFDataRef` rather than `CFNumberRef` directly, so callers may need to cast appropriately.
- Part of osquery's Apple platform utility layer for bridging CoreFoundation types into osquery's string-based table results.
