Utility header for extracting string values from macOS CoreFoundation `CFDictionaryRef` objects within the osquery framework.

## Key Components

### Functions

- **`getPropertiesFromDictionary`** — Retrieves a value from a `CFDictionaryRef` by key and returns it as a `std::string`. Internally leverages the `cfdata`, `cfnumber`, and `cfstring` conversion utilities to handle various underlying CoreFoundation value types.

### Dependencies

- `cfdata.h`, `cfnumber.h`, `cfstring.h` — osquery CoreFoundation type converters
- `CoreFoundation/CoreFoundation.h` — macOS system framework
- `namespace osquery` — all symbols are scoped to the osquery namespace

## Usage Example

```c
#include "cfdictionary.h"
#include <CoreFoundation/CoreFoundation.h>

// Assume `properties` is a CFDictionaryRef obtained from a system API
CFDictionaryRef properties = getSystemProperties();

std::string value = osquery::getPropertiesFromDictionary(properties, "DeviceName");

if (!value.empty()) {
    // Use the extracted string value
    LOG(INFO) << "Device name: " << value;
}
```

## Notes

- macOS only — depends on the CoreFoundation framework, which is not available on Linux or Windows
- Part of osquery's broader CoreFoundation abstraction layer alongside `cfdata.h`, `cfnumber.h`, and `cfstring.h`
