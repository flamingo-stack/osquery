Utility header for converting Apple CoreFoundation `CFStringRef` types to C++ `std::string` within the osquery framework.

## Key Components

- **`stringFromCFString(const CFStringRef& cf_string)`** — Converts a CoreFoundation `CFStringRef` to a `std::string`. Declared inside the `osquery` namespace.

## Usage Example

```c
#include "cfstring.h"
#include <CoreFoundation/CoreFoundation.h>

// Convert a CFStringRef to std::string
CFStringRef cf_str = CFSTR("Hello, macOS!");
std::string result = osquery::stringFromCFString(cf_str);
```

## Notes

- macOS only — depends on `CoreFoundation` framework.
- Handles the encoding bridge between CF's internal string representation and `std::string`.
