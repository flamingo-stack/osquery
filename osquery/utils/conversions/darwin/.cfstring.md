Utility header providing a conversion function between CoreFoundation string types and C++ standard strings within the osquery namespace.

## Key Components

- **`stringFromCFString(const CFStringRef& cf_string)`** — Converts a CoreFoundation `CFStringRef` to a `std::string`. Declared in the `osquery` namespace.

## Usage Example

```c
#include "cfstring.h"
#include <CoreFoundation/CoreFoundation.h>

// Convert a CFStringRef to std::string
CFStringRef cf_str = CFSTR("Hello, osquery!");
std::string result = osquery::stringFromCFString(cf_str);
```

## Notes

- macOS/Darwin only — depends on `CoreFoundation` framework.
- Header-only declaration; implementation lives in the corresponding `.cpp` source file.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
