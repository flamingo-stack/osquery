Utility header for converting CoreFoundation `CFAbsoluteTime` values to standard C++ strings on macOS/Apple platforms.

## Key Components

- **`stringFromCFAbsoluteTime(const CFDataRef& cf_abstime)`** — Converts a `CFDataRef` containing a `CFAbsoluteTime` value into a human-readable `std::string`.

## Usage Example

```c
#include "cftime.h"
#include <CoreFoundation/CoreFoundation.h>

// Assume cf_data is a CFDataRef containing a CFAbsoluteTime
CFDataRef cf_data = /* ... obtain from system API ... */;

std::string timeStr = osquery::stringFromCFAbsoluteTime(cf_data);
// timeStr now contains a formatted time string
```

## Notes

- macOS/Apple only — depends on `CoreFoundation` framework.
- Lives within the `osquery` namespace.
- Typical use case: parsing macOS plist or system data where timestamps are stored as `CFAbsoluteTime` (seconds since Jan 1, 2001).
