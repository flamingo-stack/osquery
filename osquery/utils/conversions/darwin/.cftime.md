Converts a CoreFoundation `CFAbsoluteTime` value (wrapped in a `CFDataRef`) to a human-readable `std::string`, scoped within the `osquery` namespace.

## Key Components

- **`stringFromCFAbsoluteTime(const CFDataRef& cf_abstime)`** — Takes a `CFDataRef` containing a `CFAbsoluteTime` and returns it as a formatted `std::string`.

## Usage Example

```c
#include "cftime.h"
#include <CoreFoundation/CoreFoundation.h>

// Assume cf_data holds a CFAbsoluteTime value
CFDataRef cf_data = /* ... obtained from a CF API ... */;

std::string timeStr = osquery::stringFromCFAbsoluteTime(cf_data);
// timeStr now contains a human-readable timestamp
```

## Notes

- **macOS only** — depends on `CoreFoundation`, so this header is platform-specific to Apple platforms.
