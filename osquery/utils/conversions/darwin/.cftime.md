Utility header for converting CoreFoundation `CFAbsoluteTime` values to standard C++ strings within the osquery macOS platform layer.

## Key Components

- **`stringFromCFAbsoluteTime(const CFDataRef& cf_abstime)`** — Converts a `CFDataRef` containing a `CFAbsoluteTime` value into a human-readable `std::string`.

## Usage Example

```c
#include "cftime.h"

// Given a CFDataRef containing a CFAbsoluteTime value:
CFDataRef cf_time_data = /* ... obtained from CoreFoundation API ... */;

std::string time_str = osquery::stringFromCFAbsoluteTime(cf_time_data);
// time_str now holds a human-readable timestamp string
```

## Notes

- macOS/Darwin only — depends on `CoreFoundation/CoreFoundation.h`
- `CFAbsoluteTime` measures seconds since January 1, 2001 00:00:00 UTC; this utility handles that epoch conversion automatically
- Lives in the `osquery` namespace
