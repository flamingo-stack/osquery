Utility header for converting CoreFoundation `CFDataRef` objects to C++ `std::string` on macOS/Apple platforms.

## Key Components

- **`stringFromCFData(const CFDataRef& cf_data)`** — Converts a CoreFoundation `CFDataRef` binary data reference into a `std::string`, enabling interoperability between Apple's CoreFoundation C APIs and standard C++ string handling within the `osquery` namespace.

## Usage Example

```c
#include "cfdata.h"
#include <CoreFoundation/CoreFoundation.h>

// Example: converting raw CFData to std::string
const char* raw = "hello";
CFDataRef cfData = CFDataCreate(kCFAllocatorDefault,
                                (const UInt8*)raw,
                                strlen(raw));

std::string result = osquery::stringFromCFData(cfData);
CFRelease(cfData);
```

> **Note:** This header is macOS-only due to its dependency on `<CoreFoundation/CoreFoundation.h>`. It is typically guarded by platform preprocessor checks in cross-platform builds.
