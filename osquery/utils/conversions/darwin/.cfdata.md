Utility header for converting Core Foundation `CFDataRef` objects to C++ `std::string` values on macOS/Apple platforms.

## Key Components

### Functions

| Function | Description |
|----------|-------------|
| `stringFromCFData(const CFDataRef&)` | Converts a Core Foundation `CFDataRef` to a `std::string` |

## Usage Example

```c
#include "cfdata.h"
#include <CoreFoundation/CoreFoundation.h>

// Example: Convert CFDataRef to std::string
CFDataRef cf_data = /* ... obtained from a CF API ... */;
std::string result = osquery::stringFromCFData(cf_data);
```

## Notes

- Defined within the `osquery` namespace
- macOS/Apple platform only — depends on `CoreFoundation`
- Source: [`osquery/utils/darwin/cfdata.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/darwin/cfdata.h)
