Provides a type-safe string conversion utility for `boost::variant` types used within the osquery framework, ensuring consistent serialization of numeric and string values — particularly preserving floating-point notation (e.g., `0.0` instead of `0`).

## Key Components

### `CastVisitor` (class)
A `boost::static_visitor<std::string>` that handles conversion of each supported variant type:

| Overload | Behavior |
|---|---|
| `operator()(const long long&)` | Converts integer via `std::to_string` |
| `operator()(const double&)` | Formats with SQLite-compatible 15-digit precision; appends `.0` if no decimal point is present |
| `operator()(const std::string&)` | Returns string unchanged |

### `castVariant` (inline function)
Applies `CastVisitor` to a `boost::variant<long long, double, std::string>`, returning a `std::string` representation.

## Usage Example

```c
#include "castvariant.h"

boost::variant<long long, double, std::string> v1 = 42LL;
boost::variant<long long, double, std::string> v2 = 3.14;
boost::variant<long long, double, std::string> v3 = 0.0;
boost::variant<long long, double, std::string> v4 = std::string("hello");

osquery::castVariant(v1); // "42"
osquery::castVariant(v2); // "3.14"
osquery::castVariant(v3); // "0.0"  (not "0")
osquery::castVariant(v4); // "hello"
```

> **Note:** The double precision is capped at `std::numeric_limits<double>::digits10` (15 significant digits) to align with SQLite's precision constraints.
