Provides type-safe conversion utilities for transforming values between types (same-type passthrough, string-to-integer, and string-to-boolean) using the `Expected` error-handling pattern to avoid exceptions in calling code.

## Key Components

- **`ConversionError` enum** — Error codes returned on failed conversions: `InvalidArgument`, `OutOfRange`, `Unknown`
- **`tryTo<ToType>(from)`** — Primary conversion template with three specializations:
  - **Same-type passthrough** — Returns the value directly via perfect forwarding when source and target types match
  - **String → Integer** — Converts `std::string`/`std::wstring` to any integer type (`int`, `long`, `long long`, `unsigned` variants) with optional numeric base; wraps `std::stoi`/`stol`/`stoll`/`stoul`/`stoull`
  - **String → Bool** — Parses common boolean representations (`"1"`, `"0"`, `"y"`, `"yes"`, `"n"`, `"no"`, etc.) via `impl::stringToBool`
- **`impl::IsStlString<T>`** — Trait detecting `std::string` or `std::wstring`
- **`impl::IsInteger<T>`** — Trait detecting integral types excluding `bool`
- **`impl::throwingStringToInt<ToType>`** — Internal dispatcher selecting the correct `std::stox` overload via SFINAE
- **`operator"" _sz`** — User-defined literal converting `unsigned long long` to `uint64_t`

## Usage Example

```cpp
#include <osquery/utils/conversions/tryto.h>

// String to integer (base 10)
auto result = osquery::tryTo<int>("42");
if (result) {
    int value = result.get(); // 42
}

// String to integer (hex)
auto hexResult = osquery::tryTo<unsigned long>("FF", 16);

// String to bool
auto boolResult = osquery::tryTo<bool>("yes");
if (boolResult) {
    bool flag = boolResult.get(); // true
}

// Handle errors
auto bad = osquery::tryTo<int>("not_a_number");
if (!bad) {
    // bad.getError() == ConversionError::InvalidArgument
}

// Same-type passthrough
auto passthrough = osquery::tryTo<std::string>(std::string("hello"));
```
