A utility header providing safe, exception-free type conversion functions within the osquery framework, wrapping standard C++ conversions in `Expected`-based error handling.

## Key Components

### `ConversionError` Enum
Error codes returned on failed conversions:
- `InvalidArgument` — input string cannot be converted
- `OutOfRange` — parsed value exceeds target type range
- `Unknown` — unexpected exception during conversion

### `tryTo<ToType>(from)` — Identity Overload
No-op passthrough when source and destination types are identical. Returns the forwarded value wrapped in `Expected<ToType, ConversionError>`.

### `tryTo<ToType>(from, base)` — String-to-Integer Overload
Converts `std::string` or `std::wstring` to any integer type (`int`, `long`, `long long`, `unsigned int`, `unsigned long`, `unsigned long long`). Accepts an optional numeric base (default `10`). Maps standard exceptions to `ConversionError` values instead of propagating them.

### `tryTo<bool>(from)` — String-to-Bool Overload
Parses common boolean string representations (`"1"`, `"0"`, `"y"`, `"yes"`, `"n"`, `"no"`, etc.) via `impl::stringToBool`.

### `operator"" _sz`
User-defined literal converting `unsigned long long` to `uint64_t` for size expressions (e.g., `4_sz`).

### `impl` Namespace
Internal helpers: `IsStlString`, `IsInteger` type traits, and `throwingStringToInt` overloads dispatched by return type.

## Usage Example

```cpp
#include <osquery/utils/conversions/tryto.h>

// String to integer
auto result = osquery::tryTo<int>("42");
if (result) {
  int val = result.get(); // 42
}

// String to integer with custom base
auto hex = osquery::tryTo<unsigned long>("FF", 16);

// String to bool
auto flag = osquery::tryTo<bool>("yes");
if (flag && flag.get()) {
  // condition is true
}

// Error handling
auto bad = osquery::tryTo<int>("not_a_number");
if (!bad) {
  // bad.getError() == ConversionError::InvalidArgument
}

// Size literal
uint64_t bufSize = 1024_sz;
```
