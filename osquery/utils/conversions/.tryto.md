Provides type-safe conversion utilities for transforming values between compatible types, with structured error handling via the `Expected` monad instead of exceptions.

## Key Components

### `ConversionError` (enum class)
Error codes returned on failed conversions:
- `InvalidArgument` — input string could not be parsed
- `OutOfRange` — parsed value exceeds the target type's range
- `Unknown` — unexpected error during conversion

### `tryTo<ToType>(from)` (function templates)
Three overloads:

| Overload | Behavior |
|---|---|
| Same-type identity | Returns the value forwarded as-is |
| `[w]string → integer` | Wraps `std::stoi`/`stol`/`stoll`/`stoul`/`stoull`; accepts optional `base` (default `10`) |
| `string → bool` | Delegates to `impl::stringToBool`; accepts `"1"`, `"y"`, `"yes"`, `"0"`, `"n"`, `"no"`, etc. |

### `impl::throwingStringToInt<ToType>` (internal)
SFINAE-dispatched helpers that select the correct `std::sto*` function based on the exact integer target type.

### `operator"" _sz`
User-defined literal converting `unsigned long long` to `uint64_t` for size expressions (e.g., `4_sz`).

## Usage Example

```cpp
#include <osquery/utils/expected/tryto.h>

// String to integer
auto result = osquery::tryTo<int>("42");
if (result) {
    int value = result.get(); // 42
}

// String to integer with base
auto hex = osquery::tryTo<unsigned long>("FF", 16);

// String to bool
auto flag = osquery::tryTo<bool>("yes");
if (flag) {
    bool b = flag.get(); // true
}

// Error handling
auto bad = osquery::tryTo<int>("not_a_number");
if (bad.isError()) {
    // bad.getError() == ConversionError::InvalidArgument
}
```
