A utility base class that enforces move-only semantics for derived types, preventing accidental copying while explicitly allowing move construction and move assignment.

## Key Components

### `osquery::only_movable`

A base class similar to Boost's `noncopyable`, but designed to permit move semantics. It achieves this by:

- **Deleting copy constructor** and **copy assignment operator** (public, to produce clear compiler errors)
- **Defaulting move constructor** and **move assignment operator** (protected, allowing derived classes to expose them)
- **Defaulting constructor and destructor** (protected, for standard subclass use)

## Usage Example

Inherit from `only_movable` to make a class move-only:

```cpp
#include "only_movable.h"

namespace osquery {

class ResourceHandle : public only_movable {
 public:
  ResourceHandle() = default;

  // Explicitly expose move semantics from the base
  ResourceHandle(ResourceHandle&&) noexcept = default;
  ResourceHandle& operator=(ResourceHandle&&) = default;
};

} // namespace osquery

// Usage:
ResourceHandle a;
ResourceHandle b = std::move(a);  // OK: move allowed

// ResourceHandle c = b;           // Error: copy deleted
// ResourceHandle d; d = b;        // Error: copy assignment deleted
```

## Notes

- Intended as a **mixin base class** — not used directly.
- The copy operations are deleted in the `public` scope deliberately, so compiler errors on accidental copies are clear and descriptive.
- Move operations are `protected` so derived classes control whether they surface them publicly.
- Part of the [`osquery`](https://github.com/flamingo-stack/osquery) core utility headers.
