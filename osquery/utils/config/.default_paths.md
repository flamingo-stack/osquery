Defines platform-specific default filesystem paths used by osquery for configuration, storage, logging, and runtime files across Linux, Windows, FreeBSD, and other Unix-like systems.

## Key Components

| Macro | Purpose |
|---|---|
| `OSQUERY_HOME` | Base directory for config, flagfiles, extensions, and module autoload |
| `OSQUERY_DB_HOME` | RocksDB persistent storage location |
| `OSQUERY_SOCKET` | IPC socket or named pipe path |
| `OSQUERY_PIDFILE` | PID file directory |
| `OSQUERY_LOG_HOME` | Log output directory (used by the filesystem logger plugin) |
| `OSQUERY_CERTS_HOME` | TLS certificate storage |

## Platform Path Summary

| Macro | Linux | Windows | FreeBSD | Default (macOS/other) |
|---|---|---|---|---|
| `OSQUERY_HOME` | `/etc/osquery/` | `\Program Files\osquery\` | `/var/db/osquery/` | `/var/osquery/` |
| `OSQUERY_DB_HOME` | `/var/osquery/` | *(same as HOME)* | *(same as HOME)* | *(same as HOME)* |
| `OSQUERY_SOCKET` | `/var/osquery/` | `\\.\pipe\` | `/var/run/` | *(same as DB_HOME)* |
| `OSQUERY_LOG_HOME` | `/var/log/osquery/` | `\Program Files\osquery\log\` | `/var/log/osquery/` | `/var/log/osquery/` |
| `OSQUERY_CERTS_HOME` | `/opt/osquery/share/osquery/certs/` | `\Program Files\osquery\certs\` | `/etc/ssl/` | `/var/osquery/certs/` |

## Usage Example

```c
#include "default_paths.h"
#include <stdio.h>

int main() {
    printf("Config home:  %s\n", OSQUERY_HOME);
    printf("Database:     %s\n", OSQUERY_DB_HOME);
    printf("Logs:         %s\n", OSQUERY_LOG_HOME);
    printf("Certificates: %s\n", OSQUERY_CERTS_HOME);
    return 0;
}
```

> **Note:** These macros are compile-time constants resolved via preprocessor guards. To override default paths at runtime, use osquery's flagfile or `--flagfile` CLI option rather than modifying this header.
