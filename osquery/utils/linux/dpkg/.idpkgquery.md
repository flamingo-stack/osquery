Defines the `IDpkgQuery` interface for querying Debian package (dpkg) metadata from a specified admin directory.

## Key Components

### `IDpkgQuery` (Abstract Class)
- **`ErrorCode`** — Enum covering failure cases: `MemoryAllocationFailure`, `InvalidAdminDirPath`, `NotADpkgAdminDir`, `NoPackagesFound`, `PermissionError`
- **`Package`** — POD struct holding package metadata fields: `name`, `version`, `source`, `size`, `arch`, `revision`, `status`, `status_string`, `maintainer`, `section`, `priority`
- **`PackageList`** — Alias for `std::vector<Package>`

### Static Methods
- **`create(const std::string& dpkg_admindir)`** — Factory that returns an `Expected<Ptr, ErrorCode>` owning instance; validates the admin directory before constructing
- **`getErrorCodeDescription(const ErrorCode&)`** — Returns a human-readable string for a given `ErrorCode`

### Virtual Methods
- **`getPackageList()`** — Pure virtual; implementations return `Expected<PackageList, ErrorCode>` populated from the dpkg database

## Usage Example

```cpp
#include "idpkgquery.h"

auto result = osquery::IDpkgQuery::create("/var/lib/dpkg");

if (result.isError()) {
  auto desc = osquery::IDpkgQuery::getErrorCodeDescription(result.getError());
  LOG(ERROR) << "Failed to init dpkg query: " << desc;
  return;
}

auto query = std::move(result.get());
auto packages = query->getPackageList();

if (packages.isValue()) {
  for (const auto& pkg : packages.get()) {
    LOG(INFO) << pkg.name << " " << pkg.version << " (" << pkg.arch << ")";
  }
}
```

## Notes
- Non-copyable by design; use `Ptr` (`std::unique_ptr<IDpkgQuery>`) for ownership
- Pairs with a concrete implementation via the `create()` factory — see [`https://github.com/flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery) for the dpkg plugin source
