Abstract interface for querying dpkg package information from a Debian-based system's package database directory.

## Key Components

### `IDpkgQuery` (Abstract Class)
- **`ErrorCode`** — Enum of failure modes: `MemoryAllocationFailure`, `InvalidAdminDirPath`, `NotADpkgAdminDir`, `NoPackagesFound`, `PermissionError`
- **`Package`** — Plain struct holding package metadata fields: `name`, `version`, `source`, `size`, `arch`, `revision`, `status`, `status_string`, `maintainer`, `section`, `priority`
- **`PackageList`** — Alias for `std::vector<Package>`

### Static Methods
- **`create(dpkg_admindir)`** — Factory method returning an `Expected<Ptr, ErrorCode>`; constructs a concrete implementation pointed to a given dpkg admin directory (typically `/var/lib/dpkg`)
- **`getErrorCodeDescription(error_code)`** — Returns a human-readable string for a given `ErrorCode`

### Virtual Methods
- **`getPackageList()`** — Pure virtual; returns `Expected<PackageList, ErrorCode>` with all installed packages found in the admin directory

## Usage Example

```cpp
#include "idpkgquery.h"

auto result = osquery::IDpkgQuery::create("/var/lib/dpkg");

if (result.isError()) {
  auto desc = osquery::IDpkgQuery::getErrorCodeDescription(result.getError());
  LOG(ERROR) << "Failed to initialize dpkg query: " << desc;
  return;
}

auto& query = result.get();

auto packages = query->getPackageList();
if (packages.isError()) {
  LOG(ERROR) << "Failed to list packages";
  return;
}

for (const auto& pkg : packages.get()) {
  std::cout << pkg.name << " " << pkg.version << " (" << pkg.arch << ")\n";
}
```

> **Note:** The class is non-copyable by design. Always interact through the `IDpkgQuery::Ptr` (`unique_ptr`) returned by `create()`.
