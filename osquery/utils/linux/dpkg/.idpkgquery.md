Interface definition for querying dpkg (Debian package manager) package information within the osquery framework.

## Key Components

### `IDpkgQuery` (Abstract Class)
The primary interface for dpkg package queries. Non-copyable, uses unique_ptr ownership semantics.

**`ErrorCode` Enum**
| Value | Description |
|-------|-------------|
| `MemoryAllocationFailure` | Failed to allocate required memory |
| `InvalidAdminDirPath` | Provided path is invalid |
| `NotADpkgAdminDir` | Path exists but is not a dpkg admin directory |
| `NoPackagesFound` | Directory contains no package data |
| `PermissionError` | Insufficient permissions to read directory |

**`Package` Struct**
Holds metadata for a single installed package:

```text
name · version · source · size · arch
revision · status · status_string · maintainer · section · priority
```

**Static Methods**
- `create(dpkg_admindir)` — Factory method; returns `Expected<Ptr, ErrorCode>`
- `getErrorCodeDescription(error_code)` — Returns human-readable error string

**Virtual Methods**
- `getPackageList()` — Returns `Expected<PackageList, ErrorCode>` of all installed packages

## Usage Example

```cpp
#include "idpkgquery.h"

auto result = osquery::IDpkgQuery::create("/var/lib/dpkg");

if (result.isError()) {
  auto desc = osquery::IDpkgQuery::getErrorCodeDescription(
      result.getErrorCode()
  );
  LOG(ERROR) << "Failed to initialize dpkg query: " << desc;
  return;
}

auto query = std::move(result.get());
auto packages = query->getPackageList();

if (packages.isValue()) {
  for (const auto& pkg : packages.get()) {
    LOG(INFO) << pkg.name << " @ " << pkg.version
              << " [" << pkg.arch << "]";
  }
}
```
