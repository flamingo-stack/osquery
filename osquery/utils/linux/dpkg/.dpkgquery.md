Concrete implementation of the `IDpkgQuery` interface for querying installed Debian packages using the native `libdpkg` C library.

## Key Components

### `DpkgQuery` (class)
Final implementation of `IDpkgQuery` within the `osquery` namespace.

| Member | Type | Description |
|--------|------|-------------|
| `getPackageList()` | `virtual` public | Returns an `Expected<PackageList, ErrorCode>` containing all installed dpkg packages |
| `~DpkgQuery()` | `virtual` destructor | Cleans up libdpkg resources |
| `DpkgQuery(const std::string&)` | private constructor | Initializes with a custom `dpkg_admindir` path (typically `/var/lib/dpkg`) |
| `validateAdminDir(const std::string&)` | private | Validates the dpkg admin directory before use |
| `packageIteratorCallback(...)` | static private | Callback used during `pkg_array` iteration to populate the `PackageList` |

### Notable Details
- Defines `LIBDPKG_VOLATILE_API` to acknowledge the unstable libdpkg API contract
- Wraps the C-style `<dpkg/pkg-array.h>` header inside `extern "C"` for C++ compatibility
- Instantiated via the `IDpkgQuery` factory pattern (`friend class IDpkgQuery`)

## Usage Example

```cpp
#include <osquery/utils/linux/idpkgquery.h>

// Instantiate via factory; DpkgQuery's constructor is private
auto query = IDpkgQuery::create("/var/lib/dpkg");

auto result = query->getPackageList();
if (result) {
    for (const auto& pkg : result.get()) {
        // process each installed package
    }
}
```
