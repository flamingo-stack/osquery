Defines the `osquery::Status` class, a lightweight utility for expressing operation success or failure with an integer code and descriptive message throughout the osquery codebase.

## Key Components

**Class: `Status`**

| Member | Description |
|--------|-------------|
| `Status(int c, std::string m)` | Primary constructor — code `0` = success, non-zero = failure |
| `Status(const ErrorBase&)` | Constructs a failure status directly from an `ErrorBase` error |
| `ok()` | Returns `true` if code equals `kSuccessCode` (0) |
| `getCode()` | Returns the raw integer status code |
| `getMessage()` / `toString()` / `what()` | Returns the descriptive message string |
| `Status::success()` | Static factory for a successful status |
| `Status::failure(message)` | Static factory for a failed status with message |
| `operator bool()` | Enables direct use in `if` conditions |
| `operator==` / `operator!=` | Equality comparisons, useful with gtest assertions |

**Free Function: `to<Status>(...)`**

Converts an `Expected<ValueType, ErrorCodeEnumType>` to a `Status`, bridging the two result-type idioms.

## Usage Example

```cpp
#include <osquery/core/core.h>

// Returning status from a function
osquery::Status doWork() {
  if (workSucceeded()) {
    return osquery::Status::success();
  }
  return osquery::Status::failure("work failed: resource unavailable");
}

// Checking status
auto s = doWork();
if (s.ok()) {
  LOG(INFO) << "Success";
} else {
  LOG(ERROR) << s.getMessage(); // "work failed: resource unavailable"
}

// Implicit bool conversion
if (doWork()) {
  LOG(INFO) << "Also works!";
}

// Converting from Expected<>
auto result = someExpectedReturningFn();
osquery::Status status = osquery::to<osquery::Status>(result);
```
