Defines the `osquery::Status` class, a lightweight result type used throughout osquery to express success or failure of operations, along with a template conversion utility from `Expected` types.

## Key Components

**`Status` class**
- `Status(int c, std::string m)` — constructs with a numeric code and message; code `0` = success
- `Status(const ErrorBase&)` — constructs a failure status directly from an error object
- `ok()` — returns `true` when code equals `kSuccessCode` (0)
- `getCode()` — returns the integer status code
- `getMessage()` / `toString()` / `what()` — return the status message string
- `operator bool()` — allows direct use in `if` statements
- `Status::success()` — static factory for a successful status
- `Status::failure(message)` / `Status::failure(code, message)` — static factories for failure statuses
- `operator==` / `operator!=` / `operator<<` — comparison and stream operators for gtest compatibility

**`to<Status>(Expected<V, E>)` template**
Converts an `Expected<ValueType, ErrorCodeEnumType>` into a `Status`, mapping success to `Status::success()` and failure to `Status::failure(message)`.

## Usage Example

```cpp
#include <osquery/core/core.h>
#include <osquery/utils/status/status.h>

osquery::Status doWork() {
  if (someCondition) {
    return osquery::Status::success();
  }
  return osquery::Status::failure("something went wrong");
}

void caller() {
  auto s = doWork();

  // Boolean check via operator bool()
  if (!s) {
    LOG(ERROR) << "Failed: " << s.getMessage();
    return;
  }

  // Or explicit ok() check
  if (s.ok()) {
    LOG(INFO) << "Success";
  }

  // Converting an Expected<> to Status
  Expected<std::string, MyError> result = getExpected();
  osquery::Status converted = osquery::to<osquery::Status>(result);
}
```
