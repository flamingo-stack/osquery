Defines the `osquery::Status` class, a lightweight utility for expressing success or failure of operations with an integer code and descriptive message.

## Key Components

| Member | Description |
|--------|-------------|
| `Status(int c, std::string m)` | Primary constructor; code `0` = success, non-zero = failure |
| `Status(const ErrorBase&)` | Constructs a failure status directly from an `ErrorBase` error |
| `ok()` | Returns `true` if code equals `kSuccessCode` (0) |
| `getCode()` | Returns the raw integer status code |
| `getMessage()` / `toString()` / `what()` | Returns the associated status message string |
| `Status::success()` | Static factory for a success status |
| `Status::failure(message)` | Static factory for a failure status with code `1` |
| `operator bool()` | Implicit bool conversion; enables direct use in `if` conditions |
| `to<Status>(Expected<V,E>)` | Template helper converting an `Expected` value to a `Status` |

## Usage Example

```cpp
#include <osquery/core/status.h>

// Return status from a function
osquery::Status doWork() {
  if (/* success condition */) {
    return osquery::Status::success();
  }
  return osquery::Status::failure("Something went wrong");
}

// Check status with ok()
auto s = doWork();
if (s.ok()) {
  LOG(INFO) << "Success";
} else {
  LOG(ERROR) << s.getMessage();
}

// Use implicit bool conversion
if (doWork()) {
  LOG(INFO) << "Also works!";
}

// Convert an Expected<> to Status
osquery::Expected<int, MyError> result = computeValue();
osquery::Status s = osquery::to<osquery::Status>(result);
```

## Notes

- Default-constructed `Status` represents success (`code = 0`, message `"OK"`).
- `==` and `!=` operators and `operator<<` support straightforward use with **gtest** assertions.
