Utility header for fetching and parsing Azure instance metadata within the osquery framework.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `getAzureKey` | Function | Extracts a string value from a parsed Azure metadata JSON document by key |
| `fetchAzureMetadata` | Function | Fetches Azure instance metadata from the IMDS endpoint and populates a `JSON` document |

## Usage Example

```c
#include <osquery/utils/azure/azure_util.h>

namespace osquery {

void exampleAzureMetadataUsage() {
  JSON doc;

  // Fetch metadata from the Azure IMDS endpoint
  Status status = fetchAzureMetadata(doc);

  if (!status.ok()) {
    // Handle fetch error
    return;
  }

  // Extract a specific key from the metadata document
  std::string vmId = getAzureKey(doc, "vmId");
  std::string location = getAzureKey(doc, "location");
}

} // namespace osquery
```

## Notes

- Both functions operate within the `osquery` namespace.
- `fetchAzureMetadata` uses osquery's `Status` type to signal success or failure, consistent with the broader osquery error-handling pattern.
- Depends on [`osquery/utils/json/json.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/json/json.h) for the `JSON` wrapper and [`osquery/utils/status/status.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/status/status.h) for the `Status` type.
- Primarily used to power Azure-specific virtual table implementations that surface cloud instance metadata to osquery users.
