Utility header for fetching and parsing Azure instance metadata within the osquery framework.

## Key Components

- **`getAzureKey(JSON& doc, const std::string& key)`** — Extracts a string value from a parsed Azure metadata JSON document by key name.
- **`fetchAzureMetadata(JSON& doc)`** — Queries the Azure Instance Metadata Service (IMDS) endpoint and populates the provided JSON document with the response. Returns a `Status` indicating success or failure.

## Usage Example

```c
#include <osquery/utils/azure/azure_util.h>

osquery::JSON doc;
osquery::Status status = osquery::fetchAzureMetadata(doc);

if (status.ok()) {
    std::string vmId = osquery::getAzureKey(doc, "vmId");
    std::string location = osquery::getAzureKey(doc, "location");
}
```

## Notes

- Both functions operate within the `osquery` namespace.
- `fetchAzureMetadata` is typically called once to populate the `JSON` document before using `getAzureKey` to read individual fields.
- Designed for use on Azure-hosted virtual machines where the IMDS endpoint (`169.254.169.254`) is accessible.
