Utility header for fetching and parsing Azure instance metadata within the osquery framework.

## Key Components

- **`getAzureKey(JSON& doc, const std::string& key)`** — Extracts a string value from a parsed Azure metadata JSON document by key name.
- **`fetchAzureMetadata(JSON& doc)`** — Queries the Azure Instance Metadata Service (IMDS) and populates the provided `JSON` document with the response. Returns a `Status` indicating success or failure.

## Usage Example

```c
#include <osquery/utils/azure/azure_util.h>

osquery::JSON doc;
osquery::Status status = osquery::fetchAzureMetadata(doc);

if (status.ok()) {
    std::string region = osquery::getAzureKey(doc, "location");
    std::string vmId   = osquery::getAzureKey(doc, "vmId");
}
```

## Notes

- Both functions operate within the `osquery` namespace.
- `fetchAzureMetadata` is expected to call the Azure IMDS endpoint (`http://169.254.169.254/metadata/instance`) internally.
- Returns an empty string from `getAzureKey` if the key is not present in the document.
- Depends on `osquery/utils/json/json.h` for JSON parsing and `osquery/utils/status/status.h` for error handling.
