Provides Base64 encoding and decoding utilities within the `osquery::base64` namespace.

## Key Components

| Function | Signature | Description |
|----------|-----------|-------------|
| `decode` | `std::string decode(std::string encoded)` | Decodes a Base64-encoded string and returns the original plaintext |
| `encode` | `std::string encode(const std::string_view unencoded)` | Encodes a raw string into its Base64 representation |

## Usage Example

```cpp
#include <osquery/utils/base64.h>

// Encode a plaintext string
std::string encoded = osquery::base64::encode("hello world");
// encoded == "aGVsbG8gd29ybGQ="

// Decode back to original
std::string decoded = osquery::base64::decode(encoded);
// decoded == "hello world"
```

> Both functions operate on standard C++ `std::string` / `std::string_view` types, requiring no external dependencies beyond the STL.
