Provides Base64 encoding and decoding utilities within the `osquery::base64` namespace.

## Key Components

| Function | Description |
|----------|-------------|
| `decode(std::string encoded)` | Decodes a Base64-encoded string and returns the original plaintext |
| `encode(std::string_view unencoded)` | Encodes a raw string into its Base64 representation |

## Usage Example

```cpp
#include "base64.h"

// Encode a plain string
std::string encoded = osquery::base64::encode("hello world");
// encoded == "aGVsbG8gd29ybGQ="

// Decode it back
std::string decoded = osquery::base64::decode(encoded);
// decoded == "hello world"
```

## Notes

- Both functions operate on standard C++ `std::string`; `encode` accepts a `std::string_view` to avoid unnecessary copies.
- Defined under the `osquery::base64` nested namespace to avoid naming conflicts with third-party Base64 implementations.
- Source: [`osquery/include/osquery/utils/base64.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/base64.h)
