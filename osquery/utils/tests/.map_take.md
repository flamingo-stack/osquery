Unit test file for the `map_take` utility, validating the `tryTake` and `tryTakeCopy` functions from `osquery/utils/map_take.h` against both `std::map` and `std::unordered_map` container types.

## Key Components

- **`testTryTake<MapType>()`** — Template helper verifying that `tryTake` extracts and **removes** an entry from the map on success, returns the correct value, and returns a `MapTakeError::NoSuchKey` error (without mutating the map) when the key is absent.
- **`testTryTakeCopy<MapType>()`** — Template helper verifying that `tryTakeCopy` returns a copy of the value **without removing** the entry, and likewise returns `MapTakeError::NoSuchKey` for missing keys.
- **`GetTests/tryTake_on_map`** — Runs `testTryTake` against `std::map<std::string, std::string>`.
- **`GetTests/tryTake_on_unordered_map`** — Runs `testTryTake` against `std::unordered_map<std::string, std::string>`.
- **`GetTests/tryTakeCopy_on_map`** — Runs `testTryTakeCopy` against `std::map<std::string, std::string>`.
- **`GetTests/tryTakeCopy_on_unordered_map`** — Runs `testTryTakeCopy` against `std::unordered_map<std::string, std::string>`.

## Usage Example

```cpp
#include <osquery/utils/map_take.h>

std::map<std::string, std::string> m = {
    {"dev", "/dev/"},
    {"etc", "/etc/"},
};

// Moves value out and erases key from map
auto result = tryTake(m, "dev");
if (!result.isError()) {
    std::string value = result.get(); // "/dev/"
    // m no longer contains "dev"
}

// Returns a copy; map is unchanged
auto copy = tryTakeCopy(m, "etc");
if (copy.isValue()) {
    std::string value = copy.get(); // "/etc/"
    // m still contains "etc"
}

// Missing key returns MapTakeError::NoSuchKey
auto missing = tryTake(m, "usr");
if (missing.isError()) {
    assert(missing.getErrorCode() == MapTakeError::NoSuchKey);
}
```
