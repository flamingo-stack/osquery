Brief utility header providing character and string encoding helpers within the `osquery` namespace, covering ASCII printability checks, UTF-8 string length calculation, and Unicode unescaping.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `isPrintable` | Function | Returns `true` if every character in the given `string_view` is ASCII printable |
| `incUtf8StringIterator` | Template Function | Advances an iterator past a single UTF-8 multi-byte sequence; returns bytes consumed |
| `utf8StringSize` | Function | Returns the number of Unicode code points (not raw bytes) in a UTF-8 `std::string` |
| `unescapeUnicode` | Function | Converts Unicode escape sequences (e.g. `\uXXXX`) in a string to their UTF-8 representations |

## Usage Example

```c
#include "chars.h"
#include <iostream>

int main() {
    // Check if a string contains only printable ASCII characters
    std::string_view raw = "Hello, world!";
    if (osquery::isPrintable(raw)) {
        std::cout << "String is printable\n";
    }

    // Get the character length of a UTF-8 string
    std::string utf8 = "caf\xC3\xA9"; // "café"
    size_t len = osquery::utf8StringSize(utf8);
    // len == 4 (code points), not 5 (raw bytes)

    // Unescape Unicode sequences
    std::string escaped = "caf\\u00E9";
    std::string result  = osquery::unescapeUnicode(escaped);
    // result == "café"
}
```

> **Note:** `incUtf8StringIterator` is a low-level inline helper intended for internal use by `utf8StringSize`. Prefer `utf8StringSize` for measuring string length in consuming code.
