A thin RAII wrapper around RapidJSON that simplifies safe construction, manipulation, and serialization of JSON objects and arrays within the osquery framework.

## Key Components

### `JSON` Class
Move-only wrapper (`only_movable`) around a `rapidjson::Document`, providing memory-safe JSON operations.

**Factory Methods**
- `newObject()` — creates a JSON wrapper for an object (map)
- `newArray()` — creates a JSON wrapper for an array (list)
- `newFromValue()` — creates a wrapper from an existing `rapidjson::Value`

**Mutation Methods**
- `add(key, value[, obj])` — adds typed key-value pairs (`string`, `char*`, `int`, `long`, `long long`, `unsigned` variants, `double`, `bool`, `rapidjson::Value`) to the document or a sub-object
- `addCopy()` / `addRef()` — explicit copy vs. reference semantics for string values
- `push(value[, arr])` — appends values to an array (`rapidjson::Value`, `size_t`, `string`)
- `pushCopy()` — appends a string copy to an array
- `copyFrom()` — deep-copies a value into the document or a target node
- `mergeObject()` / `mergeArray()` — merges members from one object/array into another

**Serialization / Parsing**
- `toString(str)` — serializes to compact JSON string
- `toPrettyString(str, indent)` — serializes to formatted JSON string
- `fromString(str, ParseMode)` — parses JSON from a string; supports `Iterative` (stack-safe) or `Recursive` modes

**Accessors**
- `doc()` — returns reference to the underlying `rapidjson::Document`
- `getObject()` / `getArray()` — creates new empty document of the respective type
- `valueToSize()` — extracts a `uint64_t` from a value

## Usage Example

```cpp
#include <osquery/utils/json/json.h>

// Build a JSON object
auto doc = osquery::JSON::newObject();
doc.add("hostname", "myhost");
doc.add("port", 8080);
doc.add("enabled", true);

// Serialize to string
std::string output;
doc.toString(output);
// output: {"hostname":"myhost","port":8080,"enabled":true}

// Parse from string
osquery::JSON parsed;
auto status = parsed.fromString(output, osquery::JSON::ParseMode::Iterative);
if (!status.ok()) {
  // handle error
}

// Build a JSON array
auto arr = osquery::JSON::newArray();
arr.push(std::size_t{42});
arr.pushCopy(std::string{"item"});
```

> **Note:** Iterative parse mode (`kParseIterativeFlag`) is set as the default to prevent stack overflows on deeply nested JSON input.
