A lightweight RAII wrapper around RapidJSON that simplifies safe construction, mutation, and serialization of JSON objects and arrays within the osquery framework.

## Key Components

### `JSON` Class
A move-only (`only_movable`) wrapper around `rapidjson::Document` providing memory-safe JSON manipulation.

**Factory Methods**
- `JSON::newObject()` — Creates a JSON object (map) wrapper
- `JSON::newArray()` — Creates a JSON array (list) wrapper
- `JSON::newFromValue()` — Creates a wrapper from an existing `rapidjson::Value`

**Mutation Methods**
- `add(key, value[, obj])` — Adds typed key-value pairs (`std::string`, `char*`, `int`, `long`, `long long`, `unsigned` variants, `double`, `bool`, `rapidjson::Value`) to the document or a target object
- `addCopy()` / `addRef()` — Explicit copy vs. reference semantics for string values
- `push(value[, arr])` — Appends values (`rapidjson::Value`, `size_t`, `std::string`) to the document or a target array
- `pushCopy()` — Appends a copied string to an array
- `copyFrom()` — Deep-copies a `rapidjson::Value` into the document or a target
- `mergeObject()` / `mergeArray()` — Merges members from a source into a target

**Serialization / Parsing**
- `toString(str)` — Serializes to a compact JSON string
- `toPrettyString(str, indentCharCount)` — Serializes to formatted JSON
- `fromString(str, parseMode)` — Parses a JSON string; supports `Iterative` (stack-safe) or `Recursive` mode

**Utilities**
- `getObject()` / `getArray()` — Creates a new blank `rapidjson::Document`
- `doc()` — Direct access to the underlying `rapidjson::Document`
- `valueToSize(value)` — Extracts a `uint64_t` from a `rapidjson::Value`

## Usage Example

```cpp
#include <osquery/utils/json/json.h>

// Build a JSON object
auto j = osquery::JSON::newObject();
j.add("hostname", "my-host");
j.add("pid", 1234);
j.add("active", true);

// Serialize to string
std::string output;
auto status = j.toString(output);
if (status.ok()) {
  LOG(INFO) << output; // {"hostname":"my-host","pid":1234,"active":true}
}

// Parse from string
auto parsed = osquery::JSON::newObject();
parsed.fromString(R"({"key":"value"})", osquery::JSON::ParseMode::Iterative);
```
