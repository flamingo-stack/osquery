Defines versioning constants and utilities for the osquery framework, exposing the build version, SDK version, and a helper for version comparisons.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `kVersion` | `extern const std::string` | The current osquery runtime version |
| `kSDKVersion` | `extern const std::string` | The osquery SDK version string |
| `OSQUERY_SDK_VERSION` | Macro | Stringified form of `OSQUERY_BUILD_SDK_VERSION` |
| `versionAtLeast()` | Function | Checks if a given version string meets a minimum version threshold |

**Required build definitions:**
- `OSQUERY_VERSION` — must be defined at build time (error if missing)
- `OSQUERY_BUILD_SDK_VERSION` — must be defined at build time (error if missing)
- `OSQUERY_BUILD_VERSION` — should be defined; falls back to `1.0.0-unknown` with a warning

## Usage Example

```c
#include <osquery/core/version.h>
#include <iostream>

namespace osquery {

void checkCompatibility() {
  // Print current versions
  std::cout << "osquery version: " << kVersion << std::endl;
  std::cout << "SDK version:     " << kSDKVersion << std::endl;

  // Gate logic on a minimum version requirement
  if (versionAtLeast("5.0.0")) {
    std::cout << "Running osquery 5.0.0 or later" << std::endl;
  }

  // Check against a specific SDK version instead of kVersion
  if (versionAtLeast("4.9.0", kSDKVersion)) {
    std::cout << "SDK is at least 4.9.0" << std::endl;
  }
}

} // namespace osquery
```

> `versionAtLeast()` expects `major.minor.patch[-commit-hash]` format. The optional second argument defaults to `kVersion`, enabling both runtime and SDK compatibility checks.
