Defines version constants and comparison utilities for the osquery binary and SDK within the `osquery` namespace.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `kVersion` | `const std::string` | The current osquery binary version string |
| `kSDKVersion` | `const std::string` | The osquery SDK version string |
| `OSQUERY_SDK_VERSION` | Macro | Stringified form of `OSQUERY_BUILD_SDK_VERSION` |
| `versionAtLeast()` | Function | Compares a version string against the running osquery version |

**Required build-time definitions:**
- `OSQUERY_VERSION` — must be defined; build fails otherwise
- `OSQUERY_BUILD_SDK_VERSION` — must be defined; build fails otherwise
- `OSQUERY_BUILD_VERSION` — optional; defaults to `1.0.0-unknown` with a warning

## Usage Example

```c
#include <osquery/version/version.h>

// Check the running osquery version
void checkCompatibility() {
  // Compare against the default kVersion
  if (osquery::versionAtLeast("5.0.0")) {
    // Feature available in 5.0.0 or later
  }

  // Compare a specific version string against kVersion
  bool compatible = osquery::versionAtLeast("4.9.0", osquery::kVersion);

  // Access version strings directly
  LOG(INFO) << "osquery version: " << osquery::kVersion;
  LOG(INFO) << "SDK version:     " << osquery::kSDKVersion;
}
```

Version strings follow `major.minor.patch[-commit-hash]` format. `versionAtLeast()` returns `true` if the provided version `v` is **at least** the reference version, enabling runtime compatibility gating across extensions and core components.
