Defines version constants and comparison utilities for the osquery runtime, enforcing that required build-time version macros are present at compile time.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `kVersion` | `const std::string` | The runtime osquery version string |
| `kSDKVersion` | `const std::string` | The runtime osquery SDK version string |
| `OSQUERY_SDK_VERSION` | Macro | Stringified compile-time SDK version |
| `versionAtLeast()` | Function | Compares a version string against the SDK or a provided version |

**Required build defines:**
- `OSQUERY_VERSION` — must be set; compile error if missing
- `OSQUERY_BUILD_SDK_VERSION` — must be set; compile error if missing
- `OSQUERY_BUILD_VERSION` — recommended; defaults to `1.0.0-unknown` with a warning

## Usage Example

```c
#include <osquery/core/version.h>
#include <iostream>

namespace osquery {

void checkCompatibility(const std::string& extensionVersion) {
    // Check if the extension meets the minimum SDK version
    if (!versionAtLeast(extensionVersion, kSDKVersion)) {
        std::cerr << "Extension version " << extensionVersion
                  << " is below required SDK version " << kSDKVersion
                  << std::endl;
        return;
    }

    std::cout << "Running osquery v" << kVersion << std::endl;
}

} // namespace osquery
```

> **Note:** Version strings follow `major.minor.patch-commit-hash` format. `versionAtLeast(v)` returns `true` if `v` is greater than or equal to `kVersion` (or the optionally supplied version string).
