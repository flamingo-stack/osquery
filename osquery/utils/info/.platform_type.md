Defines platform detection types and compile-time constants for identifying the target OS at both build time and runtime within the osquery framework.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `PlatformType` | `enum class` | Bitmask enum for platform identification (`TYPE_POSIX`, `TYPE_WINDOWS`, `TYPE_BSD`, `TYPE_LINUX`, `TYPE_OSX`, `TYPE_FREEBSD`) |
| `kPlatformType` | `constexpr` | Compile-time bitmask constant built from preprocessor defines (`POSIX`, `WINDOWS`, `BSD`, `LINUX`, `DARWIN`, `FREEBSD`) |
| `isPlatform()` | Function | Runtime check whether a given `PlatformType` flag is active |
| `operator\|` | Operator | Bitwise OR for combining `PlatformType` values |
| `kSDKPlatform` | `extern const std::string` | String identifier of the build platform, mirrors `OSQUERY_BUILD_PLATFORM` |
| `OSQUERY_PLATFORM` | `#define` | Macro alias for `OSQUERY_BUILD_PLATFORM` |

> **Note:** `OSQUERY_BUILD_PLATFORM` and `OSQUERY_BUILD_DISTRO` **must** be defined by the build system — the header enforces this with `#error` directives.

## Usage Example

```c
#include <osquery/utils/info/platform_type.h>

// Runtime platform check
if (osquery::isPlatform(osquery::PlatformType::TYPE_LINUX)) {
    // Linux-specific logic
}

// Combining platform flags
osquery::PlatformType combined =
    osquery::PlatformType::TYPE_POSIX | osquery::PlatformType::TYPE_LINUX;

if (osquery::isPlatform(osquery::PlatformType::TYPE_POSIX, combined)) {
    // Runs if combined mask includes POSIX
}

// Accessing build-time platform string
std::cout << osquery::kSDKPlatform; // e.g. "linux", "darwin", "windows"
```
