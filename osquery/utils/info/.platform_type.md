Defines the `PlatformType` enumeration and related utilities for compile-time and runtime platform detection within the osquery framework.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `PlatformType` | `enum class` | Bitmask-capable enum representing supported platforms (`TYPE_POSIX`, `TYPE_WINDOWS`, `TYPE_BSD`, `TYPE_LINUX`, `TYPE_OSX`, `TYPE_FREEBSD`) |
| `kPlatformType` | `constexpr PlatformType` | Compile-time constant built from preprocessor defines (`POSIX`, `WINDOWS`, `BSD`, `LINUX`, `DARWIN`, `FREEBSD`) |
| `isPlatform()` | `bool` | Runtime check whether a given `PlatformType` flag is set in the current platform mask |
| `operator\|` | `PlatformType` | Bitwise OR operator enabling combination of `PlatformType` values |
| `kSDKPlatform` | `const std::string` | String identifier of the build platform, sourced from `OSQUERY_BUILD_PLATFORM` |
| `OSQUERY_PLATFORM` | `#define` | Alias macro for `OSQUERY_BUILD_PLATFORM` |

> **Note:** `OSQUERY_BUILD_PLATFORM` and `OSQUERY_BUILD_DISTRO` are **required** build definitions — the header will emit a `#error` if either is missing.

## Usage Example

```c
#include <osquery/utils/info/platform_type.h>

// Compile-time platform check via constexpr
if (isPlatform(PlatformType::TYPE_LINUX)) {
    // Linux-specific logic
}

// Combine platform flags for multi-platform checks
PlatformType target = PlatformType::TYPE_LINUX | PlatformType::TYPE_BSD;
if (isPlatform(PlatformType::TYPE_POSIX, target)) {
    // Runs if target mask includes POSIX
}

// Access the build platform string
std::cout << "Platform: " << osquery::kSDKPlatform << std::endl;
```

## Notes

- Prefer runtime detection via `isPlatform()` over preprocessor `#ifdef` guards where possible.
- Platform values are exposed through the `osquery_info` table — avoid changing enum numeric values.
