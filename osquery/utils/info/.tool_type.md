Defines the `ToolType` enumeration and related utility functions used to identify and query the running osquery process type at runtime.

## Key Components

### `ToolType` Enum
| Value | Description |
|-------|-------------|
| `UNKNOWN` | Default undetected type |
| `SHELL` | Interactive osquery shell (`osqueryi`) |
| `DAEMON` | Background daemon (`osqueryd`) |
| `TEST` | Test harness execution |
| `EXTENSION` | osquery extension process |
| `SHELL_DAEMON` | Combined shell/daemon mode |

### Functions

- **`setToolType(ToolType tool)`** — Sets the global tool type, typically called during `Initializer` startup
- **`getToolType()`** — Returns the currently registered `ToolType`
- **`isDaemon()`** — Convenience check; returns `true` if tool type is `DAEMON`
- **`isShell()`** — Convenience check; returns `true` if tool type is `SHELL`

## Usage Example

```c
#include <osquery/core/tool_type.h>

// Set during initialization
osquery::setToolType(osquery::ToolType::DAEMON);

// Branch on runtime tool type
if (osquery::isDaemon()) {
    // daemon-specific logic
} else if (osquery::isShell()) {
    // interactive shell logic
}

// Direct enum comparison
if (osquery::getToolType() == osquery::ToolType::EXTENSION) {
    // extension-specific behavior
}
```

> **Note:** The `ToolType` is typically set automatically by the `Initializer` class using the process name and compile-time flags. Manual calls to `setToolType()` should only be made during early program initialization.
