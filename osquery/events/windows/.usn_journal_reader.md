Windows NTFS USN (Update Sequence Number) Journal reader interface for osquery's file change event monitoring system.

## Key Components

### `USNFileReferenceNumber`
A portable wrapper around Windows file reference numbers supporting 64-bit (`DWORDLONG`), 128-bit (`FILE_ID_128`), and GUID formats. Implements full comparison operators and `std::hash` specialization for use in unordered containers.

### `USNJournalEventRecord`
Event record struct representing a single NTFS journal change, containing:
- `Type` enum — 32 distinct event types covering file/directory creation, deletion, rename, write, truncation, and attribute changes
- Metadata fields: `drive_letter`, `update_sequence_number`, `node_ref_number`, `parent_ref_number`, `record_timestamp`, `attributes`, `name`

### `USNJournalReaderContext`
Shared state between the reader thread and `FileChangePublisher`, holding the processed record list, synchronization primitives (`Mutex`, `ConditionVariable`), and a termination flag.

### `USNJournalReader` (`InternalRunnable`)
Background service thread that drives the journal read loop via `initialize()`, `acquireRecords()`, `processAcquiredRecords()`, and `dispatchEventRecords()`. Key static methods:
- `DecompressRecord()` — expands a compound reason bitmask into discrete event records
- `ProcessAndAppendUSNRecord()` — parses a raw `USN_RECORD*` and appends typed events

### `USNParsers` Namespace
Low-level parser helpers that extract individual fields from raw `USN_RECORD*` pointers: `GetUpdateSequenceNumber`, `GetFileReferenceNumber`, `GetParentFileReferenceNumber`, `GetTimeStamp`, `GetAttributes`, `GetReason`, `GetEventType`, `GetEventString`.

## Usage Example

```cpp
// Create shared context for a drive
auto ctx = std::make_shared<osquery::USNJournalReaderContext>();
ctx->drive_letter = 'C';

// Start the reader service
auto reader = std::make_shared<osquery::USNJournalReader>(ctx);
reader->run();

// Publisher side: consume processed records
{
    std::unique_lock<osquery::Mutex> lock(ctx->processed_records_mutex);
    ctx->processed_records_cv.wait(lock, [&] {
        return !ctx->processed_record_list.empty() || ctx->terminate;
    });

    for (const auto& record : ctx->processed_record_list) {
        std::cout << record << "\n"; // uses operator<< overload
    }
    ctx->processed_record_list.clear();
}

// Parse a raw record manually
std::vector<osquery::USNJournalEventRecord> out;
osquery::USNPerFileLastRecordType lastTypeMap;
osquery::USNJournalReader::ProcessAndAppendUSNRecord(
    out, rawUsnRecord, lastTypeMap, 'C');
```
