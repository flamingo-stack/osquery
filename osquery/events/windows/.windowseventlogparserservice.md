Background service that parses raw Windows Event Log subscription data into structured property trees, organized by event channel.

## Key Components

**`WindowsEventLogParserService`** — Inherits from `InternalRunnable`; runs as a background dispatcher thread within the osquery framework.

**Type Aliases**
- `PropertyTreeList` — `std::vector<boost::property_tree::ptree>`: a list of parsed event objects
- `ChannelEventObjects` — `std::unordered_map<std::string, PropertyTreeList>`: parsed events keyed by channel name

**Public Methods**

| Method | Description |
|--------|-------------|
| `start()` / `stop()` | Lifecycle controls inherited from `InternalRunnable` |
| `addEventList(channel, event_list)` | Enqueues raw `EvtSubscription::EventList` data for a given channel |
| `getChannelEventObjects()` | Returns all accumulated parsed event objects, grouped by channel |

**`PrivateData` (PIMPL)** — Internal implementation details hidden via `std::unique_ptr<PrivateData>` to minimize header dependencies and ABI exposure.

## Usage Example

```cpp
#include <osquery/events/windows/windowseventlogparserservice.h>

// Instantiate and register with the dispatcher
auto parser = std::make_shared<osquery::WindowsEventLogParserService>();

// Feed raw events from a subscription callback
parser->addEventList("Security", subscription.drainEvents());

// Retrieve structured results after processing
auto channelEvents = parser->getChannelEventObjects();

for (const auto& [channel, treeList] : channelEvents) {
  for (const auto& tree : treeList) {
    // Access parsed event fields via Boost property_tree
    auto eventId = tree.get<std::string>("Event.System.EventID", "");
  }
}
```

> **Note:** `addEventList` and `getChannelEventObjects` are intended to be called from the event subscription thread and consumer thread respectively. Thread safety is handled internally via the `PrivateData` PIMPL.
