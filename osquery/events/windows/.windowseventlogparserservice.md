Background service that parses raw Windows Event Log entries and organizes them into structured property trees, grouped by channel.

## Key Components

### Class: `WindowsEventLogParserService`

Extends `InternalRunnable` to run as a background dispatcher thread within the osquery framework.

**Type Aliases**
- `PropertyTreeList` — `std::vector<boost::property_tree::ptree>`: A list of parsed event property trees
- `ChannelEventObjects` — `std::unordered_map<std::string, PropertyTreeList>`: Maps channel names to their parsed event collections

**Public Methods**

| Method | Description |
|--------|-------------|
| `WindowsEventLogParserService()` | Constructor; initializes internal private state |
| `~WindowsEventLogParserService()` | Destructor; cleans up resources |
| `start()` | Begins the background parsing loop (called by dispatcher) |
| `stop()` | Signals the service to halt |
| `addEventList(channel, event_list)` | Queues a raw `EvtSubscription::EventList` for a given channel to be parsed |
| `getChannelEventObjects()` | Returns all currently parsed events grouped by channel |

**Private Implementation**
- Uses a `PrivateData` PIMPL struct (held via `std::unique_ptr<PrivateData> d_`) to hide implementation details

## Usage Example

```cpp
#include <osquery/events/windows/windowseventlogparserservice.h>

// Instantiate and register with the dispatcher
auto parser = std::make_shared<osquery::WindowsEventLogParserService>();

// Feed raw events from a subscription callback
parser->addEventList("Security", std::move(event_list));

// Retrieve parsed results grouped by channel
auto parsed = parser->getChannelEventObjects();
for (const auto& [channel, events] : parsed) {
    for (const auto& tree : events) {
        // Process each boost::property_tree::ptree event
    }
}
```

## Notes

- Windows-only component; relies on `EvtSubscription` and Win32 event APIs
- Thread-safe event ingestion is expected via `addEventList` feeding the background `start()` loop
