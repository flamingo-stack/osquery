Background service class for parsing raw Windows Event Log subscription data into structured property trees, organized by channel.

## Key Components

### `WindowsEventLogParserService`
Extends `InternalRunnable` (osquery dispatcher thread) to run as a background service.

**Type Aliases**
- `PropertyTreeList` — `std::vector<boost::property_tree::ptree>` — ordered list of parsed event objects
- `ChannelEventObjects` — `std::unordered_map<std::string, PropertyTreeList>` — maps channel names to their parsed event lists

**Public Methods**

| Method | Description |
|--------|-------------|
| `start()` | Begins the background parsing loop |
| `stop()` | Signals the service to halt |
| `addEventList(channel, event_list)` | Enqueues raw `EvtSubscription::EventList` data for a given channel |
| `getChannelEventObjects()` | Returns all parsed events grouped by channel name, consuming the internal buffer |

**Private Implementation**
Uses the [Pimpl idiom](https://en.cppreference.com/w/cpp/language/pimpl) (`PrivateData` via `std::unique_ptr<PrivateData>`) to hide threading primitives and internal state.

## Usage Example

```cpp
#include <osquery/events/windows/windowseventlogparserservice.h>

// Instantiate and register with the osquery dispatcher
auto parser = std::make_shared<osquery::WindowsEventLogParserService>();
Dispatcher::addService(parser);

// Feed raw subscription events from a Windows Event Log channel
parser->addEventList("Security", subscriptionHandle.drainEvents());

// Retrieve all parsed property trees grouped by channel
auto parsedEvents = parser->getChannelEventObjects();
for (const auto& [channel, trees] : parsedEvents) {
  for (const auto& tree : trees) {
    // Process each boost::property_tree::ptree event object
  }
}
```

> **Note:** `getChannelEventObjects()` is intended to be called from the consumer side (e.g., an event publisher) after the service has processed incoming raw events. Thread safety is managed internally via the hidden `PrivateData` struct.
