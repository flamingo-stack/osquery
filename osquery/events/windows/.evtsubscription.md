Windows Event Log subscription wrapper that provides a C++ interface for subscribing to and consuming Windows Event Log channels via the `EvtSubscribe` API.

## Key Components

### Free Function

- **`EvtSubscriptionCallbackDispatcher`** — Windows callback (`WINAPI`) invoked by the Event Log API on new events; dispatches to the owning `EvtSubscription` instance via the `context` pointer.

### `EvtSubscription` Class

| Member | Description |
|--------|-------------|
| `Ref` | `unique_ptr<EvtSubscription>` — sole ownership handle |
| `Event` | `std::wstring` — a single rendered event (XML/text) |
| `EventList` | `std::vector<Event>` — batch of collected events |
| `create(Ref&, channel)` | Factory; subscribes to the named Windows Event Log channel, returns `Status` |
| `channel()` | Returns the subscribed channel name |
| `getEvents()` | Drains and returns all buffered events since last call |
| `~EvtSubscription()` | Closes the `EVT_HANDLE` subscription cleanly |

The class uses the **Pimpl idiom** (`PrivateData`) to hide Win32 handle details, and is non-copyable by design.

## Usage Example

```cpp
#include "evtsubscription.h"

osquery::EvtSubscription::Ref sub;

auto status = osquery::EvtSubscription::create(sub, "System");
if (!status.ok()) {
    // handle subscription failure
    return;
}

// Poll for new events
osquery::EvtSubscription::EventList events = sub->getEvents();
for (const auto& evt : events) {
    // evt is a std::wstring containing the rendered event XML
    processEvent(evt);
}
```

> **Platform note:** This header is Windows-only (`<winevt.h>`). It is part of the osquery Windows Event Log table implementation. For the full context, see [`osquery/tables/events/windows/`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/events/windows/) in the repository.
