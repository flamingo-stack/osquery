Windows Event Log event publisher that subscribes to and distributes Windows Event Log entries to osquery event subscribers via the publisher-subscriber pattern.

## Key Components

### Structs

- **`WindowsEventLogSubscriptionContext`** — Subscription context holding a set of Windows Event Log channel names (`channel_list`) and a character frequency map (`character_frequency_map`) used for anomaly detection.
- **`WindowsEventLogEC`** (Event Context) — Carries the event payload: the source `channel` name and a list of parsed property trees (`event_objects`) from `WindowsEventLogParserService`.

### Type Aliases

- **`WindowsEventLogECRef`** — `shared_ptr<WindowsEventLogEC>`
- **`WindowsEventLogSCRef`** — `shared_ptr<WindowsEventLogSubscriptionContext>`

### Class: `WindowsEventLogPublisher`

Inherits from `EventPublisher<WindowsEventLogSubscriptionContext, WindowsEventLogEC>`.

| Method | Description |
|---|---|
| `configure()` | Sets up channel subscriptions based on registered subscriber contexts |
| `run()` | Main polling loop that reads and dispatches Windows Event Log entries |
| `tearDown()` | Cleans up handles and resources |
| `shouldFire()` | Filters events against a subscription's channel list |
| `cosineSimilarity()` | Static utility comparing a buffer's character frequency against a reference vector for anomaly scoring |

Private implementation details are hidden via a `PrivateData` PIMPL struct.

## Usage Example

```cpp
// Define a subscriber with a channel subscription context
auto sc = std::make_shared<WindowsEventLogSubscriptionContext>();
sc->channel_list.insert("Security");
sc->channel_list.insert("System");

// Cosine similarity check for anomaly detection
std::string buffer = "suspicious log content";
std::vector<double> baseline_freqs = getBaselineFrequencies();
double score = WindowsEventLogPublisher::cosineSimilarity(buffer, baseline_freqs);

if (score < threshold) {
  // Flag as anomalous
}
```
