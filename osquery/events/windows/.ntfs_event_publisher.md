Windows NTFS filesystem event publisher for osquery that monitors drive volumes via the USN (Update Sequence Number) journal, translating raw journal records into structured file change events for subscribers.

## Key Components

### Structs

| Name | Purpose |
|------|---------|
| `NTFSEventSubscriptionContext` | Defines subscriber interest — write/access paths and file reference numbers (FRNs) per category |
| `NTFSEventRecord` | Normalized single NTFS event with path, timestamps, USN, FRNs, drive letter, and rename support |
| `NTFSEventContext` | Batch container holding a vector of `NTFSEventRecord` entries emitted to subscribers |
| `VolumeData` | Holds volume/root folder HANDLEs and root FRN for a monitored drive |
| `USNJournalReaderInstance` | Tracks a running reader service, its shared context, FRN path cache, and rename merge map |

### Class

**`NTFSEventPublisher`** — core publisher inheriting `EventPublisher<NTFSEventSubscriptionContext, NTFSEventContext>`:

- `setUp()` — initializes the publisher
- `configure()` — reads drive configuration on startup or config reload
- `run()` — main loop acquiring and dispatching journal records
- `tearDown()` — cleanup routine
- `restartJournalReaderServices()` — spawns/restarts `USNJournalReader` per active drive
- `acquireJournalRecords()` — pulls raw events from reader services
- `getPathFromReferenceNumber()` / `getPathFromParentFRN()` — resolves full paths from FRNs
- `getVolumeData()` — retrieves volume handle and root FRN
- `releaseDriveHandleMap()` — releases cached drive handles

### Type Aliases

- `NTFSEventPublisherConfiguration` — `unordered_set<char>` of monitored drive letters
- `ParentFRNCache` — `unordered_map<USNFileReferenceNumber, string>` for path resolution

### Free Function

- `GetNativeFileIdFromUSNReference()` — converts a `USNFileReferenceNumber` to `FILE_ID_DESCRIPTOR` for `OpenFileById`

## Usage Example

```cpp
// Subscribing to NTFS write events on C:\sensitive
auto sc = NTFSEventPublisher::createSubscriptionContext();
sc->category = "sensitive_writes";
sc->write_paths.insert("C:\\sensitive");

// The publisher is registered and driven by osquery's event framework
// NTFSEventPublisher::setUp() → configure() → run() loop
// Subscribers receive NTFSEventContextRef batches containing NTFSEventRecord entries
```
