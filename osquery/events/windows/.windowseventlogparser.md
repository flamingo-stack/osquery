Header defining data structures and parsing utilities for Windows Event Log entries within the osquery framework.

## Key Components

### `WELEvent` Struct
A plain data container representing a parsed Windows Event Log entry with the following fields:

| Field | Type | Description |
|-------|------|-------------|
| `osquery_time` | `std::time_t` | Timestamp when osquery captured the event |
| `datetime` | `std::string` | Event datetime string |
| `source` | `std::string` | Event log source channel |
| `provider_name` | `std::string` | Event provider name |
| `provider_guid` | `std::string` | Event provider GUID |
| `computer_name` | `std::string` | Originating computer name |
| `event_id` | `int64_t` | Windows Event ID |
| `task_id` | `int64_t` | Task category ID |
| `level` | `int64_t` | Severity level |
| `pid` / `tid` | `int64_t` | Process and thread IDs |
| `keywords` | `std::string` | Event keywords bitmask string |
| `data` | `std::string` | Raw event data payload |

### Functions

- **`parseWindowsEventLogXML`** — Parses a raw Windows Event Log XML string (`std::wstring`) into a Boost `property_tree::ptree` object. Returns an osquery `Status` indicating success or failure.

- **`parseWindowsEventLogPTree`** — Converts a populated `ptree` into a `WELEvent` struct. Intended as a second-stage parser after `parseWindowsEventLogXML`.

## Usage Example

```cpp
#include "windowseventlogparser.h"

boost::property_tree::ptree event_tree;
osquery::WELEvent wel_event;

// Stage 1: Parse raw XML from the Windows Event Log API
auto status = osquery::parseWindowsEventLogXML(event_tree, raw_xml_wstring);
if (!status.ok()) {
    LOG(ERROR) << "XML parse failed: " << status.getMessage();
    return;
}

// Stage 2: Populate the WELEvent struct
status = osquery::parseWindowsEventLogPTree(wel_event, event_tree);
if (status.ok()) {
    LOG(INFO) << "Event ID: " << wel_event.event_id
              << " Source: "  << wel_event.source;
}
```
