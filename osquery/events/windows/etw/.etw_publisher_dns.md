ETW (Event Tracing for Windows) publisher header for collecting and dispatching DNS-related ETW events within the osquery framework on Windows.

## Key Components

### Structs

- **`EtwDNSEventSubContext`** — Subscription context for DNS ETW events; friend-restricted to `EtwPublisherDNS`
- **`EtwDNSEventContext`** — Event context carrying a reference to parsed ETW event data (`EtwEventDataRef`)

### Type Aliases

- **`EtwDNSEventContextRef`** — `std::shared_ptr<EtwDNSEventContext>`
- **`EtwDNSEventSubContextRef`** — `std::shared_ptr<EtwDNSEventSubContext>`

### Constants

- **`kEtwDNSPublisherName`** — Publisher identifier string `"etw_dns_publisher"`

### Class: `EtwPublisherDNS`

Inherits from `EtwPublisherBase` and `EventPublisher<EtwDNSEventSubContext, EtwDNSEventContext>`.

| Member | Description |
|---|---|
| `setUp()` | Configures ETW providers, parameters, and processing callbacks |
| `providerPreProcessor()` | Static C-function callback; lightweight entry point for raw ETW events from the OS |
| `providerPostProcessor()` | Post-processing callback for enriching/aggregating event data before dispatch |
| `hardVolumeDrives_` | Maps hard volume paths to drive letters |
| `usernamesBySIDs_` | Caches SID-to-username resolutions |

**Event ID constants:**

| Constant | Value | Purpose |
|---|---|---|
| `etwDefaultKernelID` | `0` | Default kernel event |
| `etwDNSStartID` | `1` | DNS query start |
| `etwDNSStopID` | `2` | DNS query stop |

**Supported event versions:** Start (v0–v3), Stop (v0–v2), Kernel (v3–v4)

## Usage Example

```c
// Subscriber registration pattern
auto sub_ctx = EtwPublisherDNS::createSubscriptionContext();
auto callback = [](const EtwDNSEventContextRef& ctx, const EtwDNSEventSubContextRef&) {
  // Access parsed DNS event data
  auto& data = ctx->data;
  // Process DNS event...
};

EventFactory::registerEventSubscriber<EtwPublisherDNS>(sub_ctx, callback);
```
