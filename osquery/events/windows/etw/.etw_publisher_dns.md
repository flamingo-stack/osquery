ETW (Event Tracing for Windows) publisher header for capturing and dispatching DNS resolution events from the Windows kernel and user-mode ETW providers.

## Key Components

### Structs
- **`EtwDNSEventSubContext`** — Subscription context for DNS event subscribers; access restricted to `EtwPublisherDNS`
- **`EtwDNSEventContext`** — Event payload container holding an `EtwEventDataRef` data reference dispatched to subscribers

### Type Aliases
- **`EtwDNSEventContextRef`** — `std::shared_ptr<EtwDNSEventContext>`
- **`EtwDNSEventSubContextRef`** — `std::shared_ptr<EtwDNSEventSubContext>`

### Constants
- **`kEtwDNSPublisherName`** — Publisher identifier string: `"etw_dns_publisher"`

### Class: `EtwPublisherDNS`
Inherits `EtwPublisherBase` and `EventPublisher<EtwDNSEventSubContext, EtwDNSEventContext>`.

| Member | Description |
|---|---|
| `setUp()` | Registers ETW providers, configuration, and processing callbacks |
| `providerPreProcessor()` | Static C-function callback; lightweight entry point for raw `EVENT_RECORD` data from the OS |
| `providerPostProcessor()` | Post-processing callback; enriches and aggregates event data before subscriber dispatch |
| `hardVolumeDrives_` | Maps hard volume paths to drive letters |
| `usernamesBySIDs_` | Caches SID-to-username resolutions |

**Supported ETW Event IDs/Versions:**

| Event | IDs / Versions |
|---|---|
| Kernel DNS | Versions 3–4 |
| User DNS Start | Versions 0–3 (ID: 1) |
| User DNS Stop | Versions 0–2 (ID: 2) |

## Usage Example

```cpp
#include <osquery/events/windows/etw/etw_publisher_dns.h>

// Subscribe to DNS events
auto sub_ctx = std::make_shared<EtwDNSEventSubContext>();

EventFactory::registerEventPublisher<EtwPublisherDNS>();

// Access event data in a subscriber callback
void onDNSEvent(const EtwDNSEventContextRef& ctx,
                const EtwDNSEventSubContextRef& sub) {
  auto& data = ctx->data;
  // Process DNS resolution event data
}
```
