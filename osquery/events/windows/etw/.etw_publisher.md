Header file defining the `EtwPublisherBase` abstract class, which provides a standardized interface for ETW (Event Tracing for Windows) event publishers within the osquery event framework.

## Key Components

### Macros

- **`REGISTER_ETW_PUBLISHER(class_name, plugin_name)`** — Registers a class as an `event_publisher` plugin in the osquery registry.
- **`REGISTER_ETW_SUBSCRIBER(class_name, plugin_name)`** — Registers a class as an `event_subscriber` plugin.
- **`getPreProcessorCallback()`** — Generates a lambda that wraps `providerPreProcessor()` with structured exception handling, logging errors with the ETW Provider ID and Event ID on failure.

### Class: `EtwPublisherBase`

Abstract base class for ETW event publishers.

| Member | Description |
|--------|-------------|
| `EtwPublisherBase(name)` | Constructor accepting the provider name |
| `EtwEngine()` | Returns a reference to the global `EtwController` instance |
| `run()` | Signals the dispatcher that no dedicated thread is needed |
| `getPostProcessorCallback()` | Returns a `std::function` wrapping the publisher's post-processor |
| `updateUserInfo(userSid, username)` | Resolves a SID to a username using an internal cache |
| `updateHardVolumeWithLogicalDrive(path)` | Converts device paths (e.g., `\Device\HarddiskVolume1`) to logical drive letters (e.g., `C:`) |
| `providerPostProcessor(data)` | **Pure virtual** — must be implemented by derived publishers |

## Usage Example

```c
class MyEtwPublisher : public EtwPublisherBase {
 public:
  MyEtwPublisher() : EtwPublisherBase("MyProvider") {}

 private:
  void providerPostProcessor(const EtwEventDataRef& data) override {
    // Process and dispatch ETW event data to subscribers
  }
};

REGISTER_ETW_PUBLISHER(MyEtwPublisher, "my_etw_publisher");
```
