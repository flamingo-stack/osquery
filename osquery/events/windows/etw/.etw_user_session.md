Manages the ETW (Event Tracing for Windows) user-space trace session as a dedicated thread, enabling osquery to listen for and process user-mode ETW provider events.

## Key Components

### `UserEtwSessionRunnable` (class)
Inherits from `InternalRunnable` to run the ETW user-space session on a dedicated thread. Uses the KrabsETW library (`krabs::user_trace`) under the hood.

**Type Aliases**
- `EtwUserProvider` — `shared_ptr<krabs::user_trace>`
- `UserProviderRef` — `shared_ptr<krabs::provider<>>`
- `UserProvidersCollection` — vector of `UserProviderRef`

**Public Methods**
- `UserEtwSessionRunnable(const std::string& runnableName)` — Constructor; names the runnable thread.
- `addProvider(const EtwProviderConfig&)` — Registers a new user-space ETW provider with its preprocessor/postprocessor callbacks.

**Protected Methods (thread lifecycle)**
- `start()` — Starts the InternalRunnable thread.
- `stop()` — Stops the InternalRunnable thread.

**Private Methods**
- `pause()` / `resume()` — Suspends and resumes event listening.
- `initUserTraceSession(const std::string&)` — Best-effort session initialization.
- `stopUserTraceSession(const std::string&)` — Best-effort session teardown.

**Private Members**
- `userTraceSession_` — KrabsETW user trace session object.
- `runningProviders_` — Cache of active provider instances.
- `mutex_` — Guards concurrent access to session state.
- `endTraceSession_` — Atomic flag signaling session shutdown.
- `traceSessionStopped_` — Atomic flag indicating session has stopped.
- `condition_` — Condition variable for pause/resume coordination.

## Usage Example

```cpp
#include "etw_user_session.h"
#include <osquery/events/windows/etw/etw_provider_config.h>

// Create and start a named ETW user session thread
osquery::UserEtwSessionRunnable session("my-etw-user-session");

osquery::EtwProviderConfig config;
// ... configure provider GUID, callbacks, etc.

osquery::Status result = session.addProvider(config);
if (!result.ok()) {
  LOG(ERROR) << "Failed to add ETW provider: " << result.getMessage();
}

// Thread lifecycle managed via InternalRunnable (start/stop called by Dispatcher)
```
