Manages an ETW (Event Tracing for Windows) user-space trace session, running it on a dedicated thread via osquery's `InternalRunnable` abstraction to listen for and process user-space ETW events.

## Key Components

### `UserEtwSessionRunnable` (class)
A thread-safe, final class extending `InternalRunnable` that owns and controls a KrabsETW `user_trace` session.

**Type Aliases**
| Alias | Underlying Type |
|---|---|
| `EtwUserProvider` | `std::shared_ptr<krabs::user_trace>` |
| `UserProviderRef` | `std::shared_ptr<krabs::provider<>>` |
| `UserProvidersCollection` | `std::vector<UserProviderRef>` |

**Public Methods**
- `UserEtwSessionRunnable(name)` — Constructs the runnable with a given thread name
- `addProvider(configData)` — Registers a user-space ETW provider along with its pre/post processor callbacks

**Protected Methods**
- `start()` — Starts the underlying `InternalRunnable` thread
- `stop()` — Stops the underlying `InternalRunnable` thread

**Private Helpers**
- `pause()` / `resume()` — Suspend or continue event listening
- `initUserTraceSession(name)` — Best-effort initialization of the KrabsETW user trace
- `stopUserTraceSession(name)` — Best-effort teardown of the trace session

**Key Members**
- `userTraceSession_` — KrabsETW `user_trace` instance
- `runningProviders_` — Cache of active provider references
- `endTraceSession_` / `traceSessionStopped_` — Atomic flags for lifecycle control
- `mutex_` / `condition_` — Thread-safety and pause/resume synchronization

## Usage Example

```cpp
// Instantiate and start the ETW user session thread
auto session = std::make_shared<osquery::UserEtwSessionRunnable>("etw-user-session");

// Register a provider with preprocessing/postprocessing callbacks
osquery::EtwProviderConfig config; // populate with GUID, callbacks, etc.
osquery::Status status = session->addProvider(config);

if (!status.ok()) {
  LOG(ERROR) << "Failed to add ETW provider: " << status.getMessage();
}

// Thread lifecycle is managed via InternalRunnable
session->start(); // begins listening for user-space ETW events
// ...
session->stop();  // signals the trace session to terminate
```
