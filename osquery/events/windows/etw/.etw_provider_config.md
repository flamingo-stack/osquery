Defines the `EtwProviderConfig` class, which encapsulates all configurable parameters for an ETW (Event Tracing for Windows) provider, including event filtering options, pre/post-processing callbacks, and kernel/user provider settings.

## Key Components

### Enum
- **`EtwKernelProviderType`** — Identifies supported kernel providers: `File`, `ImageLoad`, `Network`, `Process`, `Registry`, `ObjectManager`, `Invalid`

### Type Aliases
| Alias | Underlying Type |
|---|---|
| `EtwProviderName` | `std::string` |
| `EtwBitmask` | `boost::optional<uint64_t>` |
| `EtwLevel` | `boost::optional<uint8_t>` |
| `EventProviderPreProcessor` | `krabs::c_provider_callback` |
| `EventProviderPostProcessor` | `std::function<void(const EtwEventDataRef&)>` |
| `EtwProviderConfigRef` | `std::shared_ptr<EtwProviderConfig>` |

### Key Methods
- **`setPreProcessor` / `getPreProcessor`** — Manages the raw `krabs` callback for initial event ingestion
- **`setPostProcessor` / `getPostProcessor`** — Manages the `std::function` callback for structured post-processing
- **`setEventTypes` / `addEventTypeToHandle`** — Configures which `EtwEventType` values this provider handles
- **`isValid()`** — Validates the configuration before provider registration
- **`isAnyBitmaskSet`, `isAllBitmaskSet`, `isLevelSet`** — Optional flag presence checks

## Usage Example

```cpp
auto config = std::make_shared<osquery::EtwProviderConfig>();

config->setName("Microsoft-Windows-Kernel-Process");
config->setKernelProviderType(
    EtwProviderConfig::EtwKernelProviderType::Process);
config->setLevel(boost::optional<uint8_t>(4));
config->setAnyBitmask(boost::optional<uint64_t>(0x10));

config->setPreProcessor(myKrabsCallback);
config->setPostProcessor([](const EtwEventDataRef& event) {
    // structured post-processing logic
});

config->addEventTypeToHandle(EtwEventType::ProcessStart);

auto status = config->isValid();
if (!status.ok()) {
    LOG(ERROR) << "Invalid ETW provider config: " << status.getMessage();
}
```
