Defines the `EtwProviderConfig` class, which encapsulates configuration for an ETW (Event Tracing for Windows) provider, including optional filtering parameters and pre/post-processing callbacks for event handling.

## Key Components

### `EtwProviderConfig` Class
- **`EtwKernelProviderType`** — Enum listing supported kernel providers: `File`, `ImageLoad`, `Network`, `Process`, `Registry`, `ObjectManager`
- **Type Aliases** — `EtwBitmask`, `EtwLevel`, `EtwInteger` (all `boost::optional`-wrapped), plus `EventProviderPreProcessor` (`krabs::c_provider_callback`) and `EventProviderPostProcessor` (`std::function<void(const EtwEventDataRef&)>`)
- **Callback accessors** — `getPreProcessor()` / `setPreProcessor()`, `getPostProcessor()` / `setPostProcessor()`
- **Event type management** — `getEventTypes()`, `setEventTypes()`, `addEventTypeToHandle()`
- **Optional filter flags** — `anyBitmask`, `allBitmask`, `level`, `traceFlags`, `tag` with corresponding `is*Set()` checkers and getters/setters
- **`isValid()`** — Validates that the config contains expected, well-formed data
- **`EtwProviderConfigRef`** — `std::shared_ptr<EtwProviderConfig>` alias for shared ownership

## Usage Example

```cpp
#include <osquery/events/windows/etw/etw_provider_config.h>

auto config = std::make_shared<osquery::EtwProviderConfig>();

// Configure a user-mode provider
config->setName("Microsoft-Windows-Security-Auditing");
config->setAnyBitmask(0x8000000000000000ULL);
config->setLevel(4); // Informational

// Attach a pre-processor (raw krabs callback)
config->setPreProcessor([](const EVENT_RECORD& record, const krabs::trace_context& ctx) {
    // low-level event filtering
});

// Attach a post-processor (structured EtwEventData)
config->setPostProcessor([](const osquery::EtwEventDataRef& event) {
    // enrich or dispatch the parsed event
});

// Add specific event types to handle
config->addEventTypeToHandle(osquery::EtwEventType::ProcessStart);

// Validate before registering
auto status = config->isValid();
```
