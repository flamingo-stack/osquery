ETW publisher header that defines the `EtwPublisherProcesses` class for capturing and dispatching Windows ETW (Event Tracing for Windows) process start and stop events within the osquery framework.

## Key Components

**Structs / Type Aliases**
- `EtwProcEventSubContext` — Subscription context for process ETW events (friend-restricted to `EtwPublisherProcesses`)
- `EtwProcessEventContext` — Event context carrying an `EtwEventDataRef` payload
- `EtwProcessEventContextRef` / `EtwProcEventSubContextRef` — `shared_ptr` aliases for the above

**Constants**
- `kEtwProcessPublisherName` — Publisher identifier string (`"etw_process_publisher"`)

**Class: `EtwPublisherProcesses`**
Inherits `EtwPublisherBase` and `EventPublisher<EtwProcEventSubContext, EtwProcessEventContext>`.

| Member | Description |
|---|---|
| `setUp()` | Configures ETW providers, parameters, and processing callbacks |
| `providerPreProcessor()` | Static C-function callback; lightweight entry point called by the OS per ETW event |
| `providerPostProcessor()` | Post-processing: enriches, aggregates, and dispatches event data to subscribers |
| `cleanOldAggregationCacheEntries()` | Purges stale cache entries |
| `updateTokenInfo()` | Resolves token type metadata |
| `updateImagePath()` | Resolves process image path by composite key |
| `isSupportedEvent()` / `isKernelEvent()` / etc. | Inline header-level event classification helpers |
| `processStartAggregationCache_` | Maps composite key → `EtwProcStartDataRef` |
| `processImageCache_` | Maps composite key → image path string |

**Supported ETW Event Versions**

| Enum | Versions |
|---|---|
| `etwUserProcStartVersion` | 0–3 |
| `etwUserProcStopVersion` | 0–2 |
| `etwKernelProcVersion` | 3–4 |

## Usage Example

```c
// Register a subscriber to process events
auto sub_ctx = std::make_shared<EtwProcEventSubContext>();

EventSubscriber<EtwPublisherProcesses>::subscribe(
    [](const EtwProcessEventContextRef& event_ctx,
       const EtwProcEventSubContextRef& sub_ctx) -> Status {

        auto& data = event_ctx->data;
        // Inspect process start/stop data
        return Status::success();
    },
    sub_ctx
);
```
