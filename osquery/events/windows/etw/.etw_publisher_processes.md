Windows ETW (Event Tracing for Windows) publisher header that defines the `EtwPublisherProcesses` class for collecting and dispatching process start/stop events from the Windows kernel and user-mode ETW providers.

## Key Components

### Structs
- **`EtwProcEventSubContext`** — Subscription context for process ETW events; restricted to `EtwPublisherProcesses` via friend declaration
- **`EtwProcessEventContext`** — Event context carrying an `EtwEventDataRef` payload for each process event

### Type Aliases
- **`EtwProcessEventContextRef`** — `shared_ptr<EtwProcessEventContext>`
- **`EtwProcEventSubContextRef`** — `shared_ptr<EtwProcEventSubContext>`

### Constants
- **`kEtwProcessPublisherName`** — Publisher identifier string: `"etw_process_publisher"`

### Class: `EtwPublisherProcesses`
Inherits from `EtwPublisherBase` and `EventPublisher<EtwProcEventSubContext, EtwProcessEventContext>`.

| Member | Description |
|---|---|
| `setUp()` | Configures ETW providers, parameters, and processing callbacks |
| `providerPreProcessor()` | Static C-function callback; lightweight entry point for raw `EVENT_RECORD` data from the OS |
| `providerPostProcessor()` | Enriches and aggregates event data before subscriber dispatch |
| `processStartAggregationCache_` | Cache for in-flight process start events keyed by composed ID |
| `processImageCache_` | Cache mapping composed keys to image paths |

**Supported ETW event versions:**
- User process start: `v0–v3`
- User process stop: `v0–v2`
- Kernel process: `v3–v4`

## Usage Example

```cpp
#include <osquery/events/windows/etw/etw_publisher_processes.h>

// Registration happens via DECLARE_PUBLISHER macro using kEtwProcessPublisherName.
// Subscribers bind using EtwProcEventSubContext:

auto sub_ctx = std::make_shared<EtwProcEventSubContext>();

// The publisher is initialized and started by the osquery event framework:
auto publisher = std::make_shared<EtwPublisherProcesses>();
publisher->setUp(); // Registers ETW providers for process start/stop events
```
