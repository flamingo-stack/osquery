Manages an ETW (Event Tracing for Windows) kernel-space trace session as a dedicated runnable thread, enabling osquery to listen for and process kernel-level ETW events via the KrabsETW library.

## Key Components

### `KernelEtwSessionRunnable` (class)
Extends `InternalRunnable` to run an ETW kernel trace session on a dedicated thread. Handles provider registration, session lifecycle, and thread-safe event processing.

| Member | Description |
|--------|-------------|
| `KernelEtwSessionRunnable(name)` | Constructor; accepts a runnable thread name |
| `addProvider(configData)` | Registers a kernel ETW provider with pre/post-processor callbacks |
| `start()` | Starts the managed thread (override) |
| `stop()` | Stops the managed thread (override) |
| `pause()` | Suspends active event listening |
| `resume()` | Resumes suspended event listening |
| `initKernelTraceSession(name)` | Best-effort initialization of the kernel trace session |
| `stopKernelTraceSession(name)` | Best-effort teardown of the kernel trace session |

**Private Members:**
- `kernelTraceSession_` — `krabs::kernel_trace` session object
- `runningProviders_` — Cache of active `krabs::kernel_provider` instances
- `mutex_` — Thread-safety guard
- `endTraceSession_` — Atomic stop signal
- `traceSessionStopped_` — Atomic session-stopped flag
- `condition_` — Condition variable for pause/resume coordination

## Usage Example

```cpp
#include <osquery/events/windows/etw/etw_kernel_session.h>

// Create and start the kernel ETW session thread
auto kernelSession = std::make_shared<osquery::KernelEtwSessionRunnable>(
    "KernelEtwSession");

// Register a kernel provider with its event config
osquery::EtwProviderConfig config = /* ... */;
osquery::Status status = kernelSession->addProvider(config);

if (status.ok()) {
    kernelSession->start(); // begins listening for kernel ETW events
}
```

## Notes

- Windows-only; depends on the [KrabsETW](https://github.com/microsoft/krabsetw) library (`krabs::kernel_trace`, `krabs::kernel_provider`)
- Thread safety enforced via `std::mutex` and `std::atomic` flags
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/windows/etw/etw_kernel_session.h)
