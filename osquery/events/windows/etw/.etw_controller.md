Singleton controller that manages Windows ETW (Event Tracing for Windows) sessions and event processing pipelines, abstracting low-level ETW API details behind a session-agnostic provider subscription interface.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `instance()` | `static EtwController&` | Singleton accessor — returns the single global `EtwController` instance |
| `addProvider()` | `Status` | Registers an ETW provider via `EtwProviderConfig`, attaching pre/post-processor callbacks |
| `dispatchETWEvents()` | `void` | Forwards pre-processor-captured events into the downstream processing pipeline |
| `startProcessing()` | `Status` (private) | Launches userspace and kernel ETW sessions plus the post-processing pipeline |
| `initialize()` | `Status` (private) | One-time engine bootstrap; guards re-entry via `initialized_` atomic flag |

### Internal Session Runnables

- `etwUserSession_` — manages the `OsqueryUserETWSession` trace session
- `etwKernelSession_` — manages the `OsqueryKernelETWSession` trace session
- `etwPostProcessingEngine_` — drives the `EtwPostProcessingEngine` post-processor runnable
- `concurrentQueue_` — thread-safe queue bridging event capture and post-processing

## Usage Example

```cpp
#include <osquery/events/windows/etw/etw_controller.h>

// Obtain singleton instance
EtwController& controller = EtwController::instance();

// Configure and register an ETW provider
EtwProviderConfig config;
// ... populate config with provider GUID and callbacks ...

Status status = controller.addProvider(config);
if (!status.ok()) {
    LOG(ERROR) << "Failed to add ETW provider: " << status.getMessage();
}

// Dispatch an event from within a pre-processor callback
controller.dispatchETWEvents(eventDataRef);
```

## Notes

- Inherits `boost::noncopyable` — copy and assignment are explicitly deleted
- Thread-safe initialization via `std::atomic<bool> initialized_` and `std::mutex mutex_`
