Syslog event publisher header defining types, classes, and utilities for ingesting rsyslog-forwarded syslog entries into the osquery event framework.

## Key Components

### Structs
- **`SyslogSubscriptionContext`** — Empty subscription context for syslog events; reserved for future filtering logic
- **`SyslogEventContext`** — Holds a tokenized syslog message as a `std::map<std::string, std::string>` of field name-to-value pairs

### Type Aliases
- `SyslogEventContextRef` — `shared_ptr<SyslogEventContext>`
- `SyslogSubscriptionContextRef` — `shared_ptr<SyslogSubscriptionContext>`

### Classes
- **`NonBlockingFStream`** — Non-blocking pipe reader with an internal pre-allocated buffer (default 2048 bytes). Provides `openReadOnly()`, `close()`, and a non-blocking `getline()` that only writes to output when a complete line is available
- **`SyslogEventPublisher`** — Core event publisher that reads JSON syslog entries from a named pipe (written by rsyslog), parses them, and fires events to subscribers. Handles pipe creation, locking (to prevent multiple osquery instances from reading simultaneously), and error threshold enforcement
- **`RsyslogCsvSeparator`** — Boost `TokenizerFunction` functor for parsing rsyslog-specific CSV output, handling `""`-escaped quotes and unescaped backslashes

## Usage Example

```cpp
// Subscribing to syslog events
class MySyslogSubscriber
    : public EventSubscriber<SyslogEventPublisher> {
 public:
  Status init() override {
    auto sc = createSubscriptionContext();
    subscribe(&MySyslogSubscriber::handleEvent, sc);
    return Status::success();
  }

  Status handleEvent(const SyslogEventContextRef& ec,
                     const SyslogSubscriptionContextRef& sc) {
    // Access parsed syslog fields
    auto msg = ec->fields["message"];
    auto host = ec->fields["hostname"];
    return Status::success();
  }
};
```
