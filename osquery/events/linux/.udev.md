Defines the Linux `udev` event publisher interface for osquery, enabling hardware device event monitoring (add/remove/change) via the `libudev` kernel device management subsystem.

## Key Components

### Enumerations
- **`udev_event_action`** — Device event action types: `ADD`, `REMOVE`, `CHANGE`, `UNKNOWN`, and `ALL` (subscriber catch-all)

### Structs
- **`UdevSubscriptionContext`** — Subscription filter criteria: action type, subsystem, devnode, devtype, and driver name
- **`UdevEventContext`** — Event payload: raw `udev_device*` pointer, action enum, action string, and device metadata fields

### Type Aliases
- **`UdevEventContextRef`** — `std::shared_ptr<UdevEventContext>`
- **`UdevSubscriptionContextRef`** — `std::shared_ptr<UdevSubscriptionContext>`

### Class: `UdevEventPublisher`
Extends `EventPublisher<UdevSubscriptionContext, UdevEventContext>`.

| Method | Description |
|--------|-------------|
| `setUp()` | Initializes the udev handle and monitor |
| `tearDown()` | Releases udev resources |
| `run()` | Main event loop; polls the udev monitor socket |
| `getValue(device, property)` | Returns a udev property string for a device |
| `getAttr(device, attr)` | Returns a udev sysattr string for a device |
| `shouldFire(...)` | Matches subscription filters against incoming events |
| `createEventContextFrom(device)` | Builds an `UdevEventContext` from a raw `udev_device*` |

## Usage Example

```cpp
// Define a subscription context to watch USB block device additions
auto sc = createSubscriptionContext<UdevSubscriptionContext>();
sc->action = UDEV_EVENT_ACTION_ADD;
sc->subsystem = "block";
sc->devtype = "disk";

// Subscribe and handle the event
subscribe(&MySubscriber::Callback, sc);

// Inside callback — read device metadata from context
void Callback(const UdevEventContextRef& ec) {
  auto vendor = UdevEventPublisher::getValue(ec->device, "ID_VENDOR");
  auto sysfs_path = UdevEventPublisher::getAttr(ec->device, "size");
}
```
