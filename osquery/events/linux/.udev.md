Linux udev event publisher interface for osquery, providing hardware device event monitoring through the `libudev` subsystem.

## Key Components

### Enumerations

- **`udev_event_action`** — Device event action types: `ADD`, `REMOVE`, `CHANGE`, `UNKNOWN`, and `ALL` (subscriber catch-all).

### Structs

- **`UdevSubscriptionContext`** — Subscription filter criteria (action, subsystem, devnode, devtype, driver).
- **`UdevEventContext`** — Event payload containing the `udev_device*` pointer plus parsed action, subsystem, devnode, devtype, and driver strings.

### Class: `UdevEventPublisher`

Extends `EventPublisher<UdevSubscriptionContext, UdevEventContext>`. Core lifecycle and utility methods:

| Method | Description |
|--------|-------------|
| `setUp()` | Initializes udev handle and monitor socket |
| `tearDown()` | Releases udev resources |
| `run()` | Polls for udev events and fires subscribers |
| `getValue(device, property)` | Returns a udev property string (empty if null) |
| `getAttr(device, attr)` | Returns a udev sysattr string (empty if null) |
| `shouldFire(...)` | Filters events against subscription context |
| `createEventContextFrom(device)` | Builds an `UdevEventContext` from a raw device pointer |

## Usage Example

```cpp
// Subscribe to USB device add events
auto sub_ctx = UdevEventPublisher::createSubscriptionContext();
sub_ctx->action    = UDEV_EVENT_ACTION_ADD;
sub_ctx->subsystem = "usb";

// In an event subscriber callback
void eventCallback(const UdevEventContextRef& ec,
                   const UdevSubscriptionContextRef&) {
  auto vendor = UdevEventPublisher::getValue(ec->device, "ID_VENDOR");
  auto model  = UdevEventPublisher::getAttr(ec->device, "idProduct");
  LOG(INFO) << "USB device added: " << vendor << " / " << model;
}
```

## Notes

- Linux-only; requires `libudev` (`-ludev`).
- Internal state (`handle_`, `monitor_`) is protected by a `Mutex` for thread safety.
- Source: [`osquery/events/linux/udev.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/linux/udev.h)
