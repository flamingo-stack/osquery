Header defining the BPF-based event publisher for Linux, which captures kernel-level system call events using eBPF and translates them into osquery events for process, file, and network activity tracking.

## Key Components

### Structs

- **`BPFEventSC`** — Subscription context for BPF events (friend of `BPFEventPublisher`; no public fields)
- **`BPFEventEC`** — Event context carrying a list of `ISystemStateTracker::Event` objects emitted per BPF event batch

### Class: `BPFEventPublisher`

Inherits from `EventPublisher<BPFEventSC, BPFEventEC>`. Manages eBPF tracing lifecycle and dispatches syscall events to subscribers.

**Lifecycle Methods**

| Method | Description |
|--------|-------------|
| `setUp()` | Initializes eBPF tracers and perf event readers |
| `configure()` | Applies subscriber configuration |
| `run()` | Main event loop; reads perf events and fires callbacks |
| `tearDown()` | Cleans up eBPF resources |

**Static Event Processors** — one per tracked syscall:

- **Process lifecycle:** `processForkEvent`, `processVforkEvent`, `processCloneEvent`, `processExecveEvent`, `processExecveatEvent`
- **File descriptors:** `processCloseEvent`, `processDupEvent`, `processDup2Event`, `processDup3Event`, `processFcntlEvent`
- **File system:** `processOpenEvent`, `processOpenatEvent`, `processOpenat2Event`, `processCreatEvent`, `processMknodatEvent`, `processChdirEvent`, `processFchdirEvent`, `processNameToHandleAtEvent`, `processOpenByHandleAtEvent`
- **Networking:** `processSocketEvent`, `processConnectEvent`, `processAcceptEvent`, `processAccept4Event`, `processBindEvent`, `processListenEvent`

**Utility Template**

- **`getEventMapValue<T>(value, field_map, key)`** — Type-safe helper to extract a typed value from an `IFunctionTracer::Event::FieldMap` using `std::variant`

## Usage Example

```cpp
// Retrieve a typed field from a BPF event's field map
uint64_t pid = 0;
bool ok = BPFEventPublisher::getEventMapValue(
    pid,
    event.field_map,
    "pid"
);

// Each syscall processor updates system state from raw BPF events
if (BPFEventPublisher::processExecveEvent(state_tracker, bpf_event)) {
    // state_tracker now reflects the new process execution
}
```
