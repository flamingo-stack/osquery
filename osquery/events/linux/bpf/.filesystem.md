Concrete implementation of the `IFilesystem` interface providing real filesystem operations for Linux BPF event processing within osquery.

## Key Components

**`Filesystem`** — Final class implementing `IFilesystem` with the following methods:

| Method | Description |
|--------|-------------|
| `open()` | Opens a file by path with specified flags, returning a unique fd |
| `openAt()` | Opens a file relative to a directory fd (`dirfd`) |
| `readLinkAt()` | Resolves a symbolic link path relative to a directory fd |
| `read()` | Reads up to `max_size` bytes from an open fd into a buffer |
| `enumFiles()` | Enumerates files in a directory, invoking a callback per entry |
| `fileExists()` | Checks whether a named file exists within a directory fd |

The constructor is private — instantiation is controlled exclusively by `IFilesystem` (factory pattern via `friend class IFilesystem`).

## Usage Example

```cpp
#include <osquery/events/linux/bpf/filesystem.h>

// Obtain instance through the IFilesystem factory
auto fs = osquery::IFilesystem::create();

// Open a file and read its contents
tob::utils::UniqueFd fd;
if (fs->open(fd, "/proc/self/status", O_RDONLY)) {
    std::vector<char> buffer;
    if (fs->read(buffer, fd.get(), 4096)) {
        // process buffer
    }
}

// Check if a file exists relative to a directory fd
bool exists = false;
fs->fileExists(exists, AT_FDCWD, "config.json");

// Enumerate directory entries
fs->enumFiles(AT_FDCWD, [](const std::string& name) {
    // handle each entry
});
```

> **Note:** This class is Linux-only and intended for use within osquery's BPF event subsystem. Direct instantiation is not permitted — always obtain instances via the `IFilesystem` interface factory.
