Concrete implementation of the `IFilesystem` interface for Linux BPF event processing, providing real filesystem operations used by osquery's BPF-based event system.

## Key Components

**`Filesystem`** — A `final` class inheriting from `IFilesystem` with private constructor (instantiated via `IFilesystem` factory friend):

| Method | Description |
|--------|-------------|
| `open()` | Opens a file by path with given flags, returns a `UniqueFd` |
| `openAt()` | Opens a file relative to a directory fd (`dirfd`) |
| `readLinkAt()` | Resolves a symlink relative to a directory fd |
| `read()` | Reads up to `max_size` bytes from an fd into a buffer |
| `enumFiles()` | Enumerates files in a directory fd via callback |
| `fileExists()` | Checks whether a named file exists within a directory fd |

## Usage Example

```cpp
#include <osquery/events/linux/bpf/filesystem.h>

// Obtain instance through the IFilesystem factory
auto fs = osquery::IFilesystem::create();

tob::utils::UniqueFd fd;
if (fs->open(fd, "/proc/self/status", O_RDONLY)) {
    std::vector<char> buffer;
    fs->read(buffer, fd.get(), 4096);
}

bool exists = false;
fs->fileExists(exists, AT_FDCWD, "somefile.txt");
```

## Notes

- Construction is private; instances must be created through the `IFilesystem` factory (`IFilesystem` is a `friend`).
- Designed for Linux only (BPF event subsystem).
- Source: [`osquery/events/linux/bpf/filesystem.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/linux/bpf/filesystem.h)
