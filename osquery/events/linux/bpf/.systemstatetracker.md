Concrete implementation of `ISystemStateTracker` that tracks Linux process and file descriptor state via BPF event hooks within the osquery eventing subsystem.

## Key Components

### Class: `SystemStateTracker`

| Member | Description |
|--------|-------------|
| `create()` | Factory methods returning a `Ref`; overload accepts a custom `IProcessContextFactory` |
| `restart()` | Resets tracker state and re-enumerates existing processes |
| `Context` | Inner struct holding the `ProcessContextMap`, `EventList`, and file handle index/map |
| `PrivateData` | Pimpl struct owning internal state behind a `unique_ptr` |
| `FileHandleStruct` / `FileHandleStructMap` | Stores `name_to_handle_at` results for later `open_by_handle_at` resolution |

### Virtual Event Handlers (override `ISystemStateTracker`)

| Method | Syscall Tracked |
|--------|----------------|
| `createProcess` | `fork` / `clone` |
| `executeBinary` | `execveat` / `execve` |
| `setWorkingDirectory` | `chdir` / `fchdir` |
| `openFile` / `duplicateHandle` / `closeHandle` | `open`, `dup2`, `close` |
| `createSocket` / `bind` / `listen` / `connect` / `accept` | Socket lifecycle |
| `nameToHandleAt` / `openByHandleAt` | File handle open |

### Static Helpers

- `getProcessContext` — lazily creates a `ProcessContext` for a PID
- `expireProcessContexts` — prunes stale entries against the filesystem
- `parseUnixSockaddr` / `parseInetSockaddr` / `parseInet6Sockaddr` / `parseNetlinkSockaddr` — deserialize raw `sockaddr` bytes into address/port
- `parseSocketAddress` — dispatches to the correct parser and populates `SocketData`
- `saveFileHandle` / `expireFileHandleEntries` — manage the bounded file handle cache

## Usage Example

```cpp
// Create tracker with default process context factory
auto tracker = osquery::SystemStateTracker::create();

// Handle a fork event received from BPF
tracker->createProcess(event_header, parent_pid, child_pid);

// Retrieve and process accumulated events
auto events = tracker->eventList();
for (const auto& ev : events) {
    // dispatch ev to osquery table publishers
}

// Inject a custom factory for testing
auto mock_factory = std::make_shared<MockProcessContextFactory>();
auto test_tracker = osquery::SystemStateTracker::create(mock_factory);
```
