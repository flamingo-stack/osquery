Concrete implementation of `ISystemStateTracker` that tracks Linux process state via BPF events, maintaining a map of process contexts, file descriptors, and socket data derived from intercepted syscalls.

## Key Components

### Class: `SystemStateTracker`

| Member | Description |
|--------|-------------|
| `create()` | Static factory methods (default or with custom `IProcessContextFactory`) |
| `restart()` | Resets and re-initializes tracked state |
| `Context` | Internal state struct holding `ProcessContextMap`, `EventList`, and file handle maps |
| `FileHandleStruct` / `FileHandleStructMap` | Stores `nameToHandleAt` data keyed by a serialized handle index |
| `PrivateData` | Opaque pImpl struct holding the live `Context` and factory reference |

### Virtual Instance Methods (from `ISystemStateTracker`)

| Method | Tracked syscall |
|--------|----------------|
| `createProcess` | `fork` / `clone` |
| `executeBinary` | `execveat` / `execve` |
| `setWorkingDirectory` | `chdir` / `fchdir` |
| `openFile` / `duplicateHandle` / `closeHandle` | `open`, `dup`, `close` |
| `createSocket` / `bind` / `listen` / `connect` / `accept` | socket lifecycle |
| `nameToHandleAt` / `openByHandleAt` | file handle APIs |

### Static Helper Methods

| Method | Purpose |
|--------|---------|
| `getProcessContext` | Looks up or creates a `ProcessContext` by PID |
| `expireProcessContexts` | Removes stale process entries |
| `parseUnixSockaddr` / `parseInetSockaddr` / `parseInet6Sockaddr` / `parseNetlinkSockaddr` | Decode raw `sockaddr` bytes into address/port |
| `parseSocketAddress` | Dispatches to the correct parser and populates `SocketData` |
| `createFileHandleIndex` / `saveFileHandle` / `expireFileHandleEntries` | Manage the file handle cache |

## Usage Example

```cpp
// Create tracker with default process context factory
auto tracker = osquery::SystemStateTracker::create();

// Notify tracker of a fork event
tracker->createProcess(event_header, parent_pid, child_pid);

// Notify tracker of an execve
tracker->executeBinary(event_header, pid, AT_FDCWD, 0, "/usr/bin/curl", argv);

// Notify tracker of a socket connection
tracker->connect(event_header, pid, sockfd, raw_sockaddr_bytes);

// Retrieve buffered events for table population
auto events = tracker->eventList();

// Inspect a copy of internal state (for testing/debugging)
auto ctx = tracker->getContextCopy();
```
