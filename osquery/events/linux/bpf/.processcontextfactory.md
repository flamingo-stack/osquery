Concrete implementation of the `IProcessContextFactory` interface for capturing Linux process context data via BPF event handling.

## Key Components

**Class: `ProcessContextFactory`**
Final implementation of `IProcessContextFactory` that reads process information from the Linux `/proc` filesystem.

| Method | Description |
|--------|-------------|
| `captureSingleProcess(process_context, pid)` | Instance method — captures context for a single process by PID |
| `captureAllProcesses(process_map)` | Instance method — captures context for all running processes |
| `captureSingleProcess(fs, process_context, pid)` | Static — captures single process context using a provided filesystem ref |
| `captureAllProcesses(fs, process_map)` | Static — captures all process contexts using a provided filesystem ref |
| `getArgvFromCmdlineFile(fs, argv, fd)` | Static — parses command-line arguments from a `/proc/[pid]/cmdline` file descriptor |
| `getParentPidFromStatFile(fs, parent_pid, fd)` | Static — extracts parent PID from a `/proc/[pid]/stat` file descriptor |

**Private Members:**
- `fs` — an `IFilesystem::Ref` used for `/proc` filesystem access (injected via private constructor)
- Constructor is private; instantiation is delegated to `IProcessContextFactory` (friend class)

## Usage Example

```cpp
// Instantiate via the factory interface (friend class handles construction)
auto factory = IProcessContextFactory::create(filesystem_ref);

// Capture a single process by PID
ProcessContext ctx;
if (factory->captureSingleProcess(ctx, 1234)) {
    // ctx is populated with process data
}

// Capture all running processes
ProcessContextMap process_map;
if (factory->captureAllProcesses(process_map)) {
    // process_map contains all process contexts
}

// Use static helpers directly with a filesystem reference
std::vector<std::string> argv;
ProcessContextFactory::getArgvFromCmdlineFile(fs, argv, cmdline_fd);
```
