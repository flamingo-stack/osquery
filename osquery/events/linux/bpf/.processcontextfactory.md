Concrete implementation of `IProcessContextFactory` for capturing Linux process context data via BPF event handling in osquery.

## Key Components

### `ProcessContextFactory` (class)
Final class implementing `IProcessContextFactory`, providing both instance and static methods for process context capture.

**Instance Methods**
- `captureSingleProcess(ProcessContext&, pid_t)` — Captures context for a single process by PID
- `captureAllProcesses(ProcessContextMap&)` — Enumerates and captures context for all running processes

**Static Utility Methods**
- `captureSingleProcess(IFilesystem&, ProcessContext&, pid_t)` — Filesystem-injected variant for single process capture
- `captureAllProcesses(IFilesystem&, ProcessContextMap&)` — Filesystem-injected variant for bulk capture
- `getArgvFromCmdlineFile(IFilesystem&, std::vector<std::string>&, int fd)` — Parses `/proc/<pid>/cmdline` into an argv vector
- `getParentPidFromStatFile(IFilesystem&, pid_t&, int fd)` — Extracts parent PID from `/proc/<pid>/stat`

**Private Members**
- `fs` (`IFilesystem::Ref`) — Injected filesystem abstraction used by instance methods
- Private constructor — instantiation is controlled via `IProcessContextFactory` (friend class)

## Usage Example

```cpp
// Factory instantiation is managed by IProcessContextFactory
auto factory = IProcessContextFactory::create(fs);

// Capture a single process by PID
osquery::ProcessContext ctx;
if (factory->captureSingleProcess(ctx, 1234)) {
    // ctx is populated with argv, parent PID, etc.
}

// Capture all running processes
osquery::ProcessContextMap process_map;
factory->captureAllProcesses(process_map);

// Static helper: parse cmdline directly
std::vector<std::string> argv;
osquery::ProcessContextFactory::getArgvFromCmdlineFile(fs, argv, fd);
```

> **Note:** Construction is restricted via a private constructor and `friend class IProcessContextFactory`, enforcing factory-pattern instantiation. The `IFilesystem` abstraction enables testability by allowing mock filesystem injection.
