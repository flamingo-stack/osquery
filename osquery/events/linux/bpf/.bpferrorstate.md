Defines the `BPFErrorState` structure and related utilities for tracking and reporting error conditions in osquery's BPF (Berkeley Packet Filter) publisher subsystem.

## Key Components

### `BPFErrorState` (struct)

A container aggregating all error counters used by the BPF event publisher:

| Field | Type | Description |
|-------|------|-------------|
| `perf_error_counters` | `IPerfEventReader::ErrorCounters` | Errors from `perf_output` event reading |
| `probe_error_counter` | `std::size_t` | Count of BPF probe failures (e.g., failed string/buffer capture) |
| `errored_tracer_list` | `std::unordered_set<uint64_t>` | IDs of tracers that produced unprocessable events |

### Functions

- **`updateBpfErrorState`** — Merges incoming `perf_output` error counters into an existing `BPFErrorState` instance.
- **`reportAndClearBpfErrorState`** — Logs all accumulated errors and resets the state for the next collection cycle.

## Usage Example

```c
#include "bpferrorstate.h"

osquery::BPFErrorState error_state;

// After reading perf events, update with any new errors
tob::ebpfpub::IPerfEventReader::ErrorCounters counters = reader->getErrorCounters();
osquery::updateBpfErrorState(error_state, counters);

// Periodically report and clear accumulated errors
osquery::reportAndClearBpfErrorState(error_state);
```

## Notes

- `probe_error_counter` captures failures such as an inability to read syscall arguments (e.g., path strings for `open`, or `sockaddr_in` buffers for socket calls).
- `errored_tracer_list` helps correlate unprocessable events to specific tracers, which may indicate lost events or persistent probe failures.
- Lives in the `osquery` namespace; source available at [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery).
