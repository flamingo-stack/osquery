Declares a utility function for configuring BPF (Berkeley Packet Filter) memory resource limits within the osquery framework.

## Key Components

- **`configureBPFMemoryLimits()`** — Sets system resource limits (`rlimit`) required for BPF operations. Returns an osquery `Status` object indicating success or failure.

## Usage Example

```c
#include <osquery/utils/system/linux/setrlimit.h>

using namespace osquery;

Status s = configureBPFMemoryLimits();
if (!s.ok()) {
  LOG(ERROR) << "Failed to configure BPF memory limits: " << s.getMessage();
}
```

## Notes

- Linux-specific utility; lives under the `linux/` platform path.
- Must be called before initializing BPF-dependent subsystems (e.g., eBPF event publishers).
- Returns `Status::success()` on successful limit configuration; wraps OS-level errors otherwise.
