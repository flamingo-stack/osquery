Declares the `ParameterListMap` type alias and exports the `kParameterListMap` constant, mapping syscall/function names to their eBPF parameter list definitions used during event serialization.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ParameterListMap` | Type alias | `unordered_map<string, IFunctionTracer::ParameterList>` mapping function names to their parameter lists |
| `kParameterListMap` | `extern const` | Global map of known function/syscall names to their eBPF parameter descriptors |

## Usage Example

```c
#include "serializers.h"

// Look up parameter list for a traced syscall
auto it = osquery::kParameterListMap.find("openat");
if (it != osquery::kParameterListMap.end()) {
    const auto& paramList = it->second;
    // Use paramList to deserialize eBPF event data
}
```

## Notes

- Depends on [`ebpfpub/ifunctiontracer.h`](https://github.com/flamingo-stack/osquery/blob/main/libraries/cmake/source/ebpfpub) from the `tob::ebpfpub` namespace.
- `kParameterListMap` is defined in the corresponding `.cpp` file, where concrete parameter descriptors (name, type, in/out direction) are registered per traced function.
- Used by the eBPF-based event publisher subsystem to correctly parse and serialize raw kernel event data into osquery row format.
