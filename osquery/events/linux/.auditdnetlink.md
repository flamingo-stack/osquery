Header defining the audit netlink interface for osquery's Linux audit subsystem integration, providing structures and services for reading, parsing, and accessing kernel audit events via the Netlink socket.

## Key Components

### Enums & Type Aliases
- **`NetlinkStatus`** — Enum indicating handle state: `ActiveMutable`, `ActiveImmutable`, `Disabled`, `Error`
- **`AuditRuleDataObject`** — `std::vector<uint8_t>` wrapping raw `audit_rule_data`
- **`AuditdContextRef`** — `shared_ptr<AuditdContext>` for shared ownership between services

### Structs
- **`AuditEventRecord`** — A parsed audit record containing `type`, `time`, `audit_id`, `fields` map, and `raw_data` for SELinux/AppArmor records
- **`AuditdContext`** — Thread-safe shared state between reader and parser services, holding unprocessed/processed queues, mutexes, condition variables, and throttling counters

### Classes
- **`AuditdNetlinkReader`** (`InternalRunnable`) — Background service that acquires the netlink handle, configures audit rules, reads raw `audit_reply` messages, and manages rule lifecycle
- **`AuditdNetlinkParser`** (`InternalRunnable`) — Background service that parses raw `audit_reply` structs into `AuditEventRecord` objects; exposes static `ParseAuditReply()` and `AdjustAuditReply()` helpers
- **`AuditdNetlink`** — Public-facing, non-copyable consumer class; call `getEvents()` to drain processed records

### Inline Utility
- **`DecodeAuditPathValues()`** — Strips surrounding quotes or hex-decodes audit field values via Boost

## Usage Example

```cpp
#include "auditdnetlink.h"

// Instantiate the netlink interface (starts reader/parser internally)
osquery::AuditdNetlink netlink;

// Poll for parsed audit events in a publisher loop
while (running) {
    auto events = netlink.getEvents();
    for (const auto& record : events) {
        // record.type    -> AUDIT_SYSCALL, AUDIT_PATH, etc.
        // record.fields  -> key/value pairs from the audit record
        auto path_it = record.fields.find("name");
        if (path_it != record.fields.end()) {
            auto decoded = osquery::DecodeAuditPathValues(path_it->second);
        }
    }
}
```
