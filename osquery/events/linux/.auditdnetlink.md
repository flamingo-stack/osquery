Header file defining the Linux audit netlink interface for osquery, providing classes and data structures to read, parse, and manage audit events from the kernel via the netlink socket.

## Key Components

### Enums & Type Aliases
- **`NetlinkStatus`** — Enum indicating netlink handle state: `ActiveMutable`, `ActiveImmutable`, `Disabled`, or `Error`
- **`AuditRuleDataObject`** — Alias for `std::vector<uint8_t>` holding raw audit rule data
- **`AuditdContextRef`** — Shared pointer to `AuditdContext`

### Structs
- **`AuditEventRecord`** — A parsed audit event containing record type, timestamp, audit ID, field map, and raw data
- **`AuditdContext`** — Thread-safe shared state between reader/parser services; holds unprocessed record queues, processed event queues, mutexes, condition variables, and throttling counters

### Classes
- **`AuditdNetlinkReader`** (`InternalRunnable`) — Background service that reads raw `audit_reply` records from the kernel netlink socket, configures audit rules, and manages the netlink handle lifecycle
- **`AuditdNetlinkParser`** (`InternalRunnable`) — Background service that parses raw `audit_reply` structs into `AuditEventRecord` objects; exposes static helpers `ParseAuditReply()` and `AdjustAuditReply()`
- **`AuditdNetlink`** — Public interface for consumers; calls `getEvents()` to retrieve a batch of fully parsed `AuditEventRecord` objects

### Free Functions
- **`DecodeAuditPathValues()`** — Decodes audit field values that are either quote-wrapped strings or hex-encoded byte sequences

## Usage Example

```cpp
#include "auditdnetlink.h"

// Create the shared context and netlink interface
osquery::AuditdNetlink netlink;

// Retrieve parsed audit events in a polling loop
while (running) {
  std::vector<osquery::AuditEventRecord> events = netlink.getEvents();

  for (const auto& record : events) {
    // Access event type, ID, timestamp, and fields
    auto path_it = record.fields.find("name");
    if (path_it != record.fields.end()) {
      std::string decoded = osquery::DecodeAuditPathValues(path_it->second);
    }
  }
}
```
