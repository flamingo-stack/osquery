Linux `inotify` filesystem event publisher interface for osquery, defining the subscription context, event context, and publisher class used to monitor file and directory changes via the kernel's inotify API.

## Key Components

### Structs

- **`INotifySubscriptionContext`** — Subscription configuration for a watched path. Holds the target path, event mask, recursive flag, category, and internal descriptor/status-change-time maps. Provides `requireAction()` to map string action names to inotify mask bits.
- **`INotifyEventContext`** — Carries a fired inotify event, including the raw `inotify_event` struct, resolved path string, action string, transaction ID, and a back-reference to the originating subscription context.

### Class: `INotifyEventPublisher`

Extends `EventPublisher<INotifySubscriptionContext, INotifyEventContext>`. Manages the inotify file descriptor lifecycle, watch descriptor bookkeeping, recursive directory monitoring, and event dispatch.

**Key public methods:**

- `setUp()` — Initializes the inotify handle
- `configure()` — Applies updated config to active watches
- `tearDown()` — Releases the inotify handle and cleans up
- `run()` — Main event loop; reads and dispatches inotify events
- `addSubscription()` — Deduplicates and registers a new subscription
- `removeSubscriptions()` — Lazily marks subscriptions for removal

**Key private methods:**

- `addMonitor()` / `needMonitoring()` — Add inotify watches with optional recursive enumeration
- `monitorSubscription()` — Resolves a subscription context to actual watches
- `shouldFire()` — Matches an event against a subscription's path and mask
- `buildExcludePathsSet()` — Populates the path exclusion set from config
- `handleOverflow()` — Recovers from `IN_Q_OVERFLOW` by reading extra events

### Global Constants

- `kMaskActions` — Maps inotify mask bits to human-readable action strings
- `kFileDefaultMasks` / `kFileAccessMasks` — Preset mask combinations for common monitoring scenarios

## Usage Example

```cpp
// Subscribe to write events on a directory
auto sc = std::make_shared<INotifySubscriptionContext>();
sc->path = "/etc/";
sc->recursive = true;
sc->requireAction("UPDATED");  // sets IN_CLOSE_WRITE bit in mask

auto sub = Subscription::create("my_subscriber", sc, callback);
EventFactory::addSubscription("inotify", sub);
```
