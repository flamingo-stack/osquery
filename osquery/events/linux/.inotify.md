Linux `inotify`-based filesystem event publisher for osquery, providing event subscription and monitoring infrastructure for file and directory change detection.

## Key Components

### Structures

- **`INotifySubscriptionContext`** — Defines what to monitor: path, action mask, recursive flag, category, and lazy-deletion support. Includes `requireAction()` to map string action names to inotify bitmask values.
- **`INotifyEventContext`** — Carries event details when fired: raw `inotify_event`, resolved path, string action, transaction ID, and a reference to the originating subscription context.

### Class

- **`INotifyEventPublisher`** — Core publisher implementing the osquery event framework lifecycle (`setUp`, `configure`, `tearDown`, `run`). Manages inotify watch descriptors, recursive directory monitoring, subscription deduplication, path exclusion sets, and overflow handling.

### Key Type Aliases

| Type | Description |
|------|-------------|
| `PathDescriptorMap` | Path → inotify watch descriptor |
| `DescriptorPathMap` | inotify watch descriptor → path |
| `DescriptorINotifySubCtxMap` | Descriptor → subscription context |
| `ExcludePathSet` | Paths excluded from event propagation |

### Global Constants

- `kMaskActions` — Maps inotify mask bits to string action names
- `kFileDefaultMasks` / `kFileAccessMasks` — Preset action mask configurations

## Usage Example

```cpp
// Create and register a subscription for a directory
auto sc = std::make_shared<INotifySubscriptionContext>();
sc->path = "/etc/";
sc->recursive = true;
sc->category = "config_watch";
sc->requireAction("UPDATED"); // Maps string to inotify bitmask

// The publisher matches events via shouldFire() and
// delivers INotifyEventContext to subscribers:
auto ec = std::make_shared<INotifyEventContext>();
// ec->path  => "/etc/hosts"
// ec->action => "UPDATED"
```
