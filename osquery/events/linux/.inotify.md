Linux `inotify`-based filesystem event publisher for osquery, providing watch descriptor management, subscription context handling, and event routing for file/directory monitoring.

## Key Components

### Constants & Type Aliases
- `kMaskActions` — maps `inotify` bitmask values to human-readable action strings
- `kFileDefaultMasks` / `kFileAccessMasks` — predefined event mask groups
- `PathDescriptorMap` / `DescriptorPathMap` — bidirectional path ↔ watch descriptor lookups
- `DescriptorINotifySubCtxMap` — maps watch descriptors to subscription contexts
- `ExcludePathSet` — patterned path set for suppressing unwanted events

### `INotifySubscriptionContext`
Subscription configuration struct. Fields include:
- `path` / `opath` — resolved and original config paths
- `mask` — `inotify` event filter bitmask (0 = all events)
- `recursive` — enables recursive directory watching
- `category` — config-originating category label
- `mark_for_deletion` — lazy subscription removal flag
- `requireAction(action)` — maps a string action name to the appropriate bitmask bit

### `INotifyEventContext`
Event payload struct carrying the raw `inotify_event`, resolved `path`, string `action`, and a reference back to the originating `INotifySubscriptionContextRef`.

### `INotifyEventPublisher`
Core publisher class inheriting `EventPublisher<INotifySubscriptionContext, INotifyEventContext>`. Key methods:

| Method | Purpose |
|---|---|
| `setUp()` | Opens the `inotify` file descriptor |
| `configure()` | Applies updated subscription config |
| `tearDown()` | Releases the `inotify` handle and scratch buffer |
| `run()` | Main event loop thread entry point |
| `addMonitor()` | Registers an `inotify` watch on a path, optionally recursive |
| `removeMonitor()` | Deregisters a watch descriptor |
| `shouldFire()` | Matches an event context against a subscription context |
| `handleOverflow()` | Recovers from `IN_Q_OVERFLOW` by increasing read batch size |

## Usage Example

```cpp
// Define a subscriber using inotify contexts
class MySubscriber
    : public EventSubscriber<INotifyEventPublisher> {
 public:
  Status init() override {
    auto sc = createSubscriptionContext();
    sc->path = "/etc/hosts";
    sc->recursive = false;
    sc->requireAction("UPDATED");  // Filter to write/modify events only
    subscribe(&MySubscriber::handleEvent, sc);
    return Status::success();
  }

  Status handleEvent(const INotifyEventContextRef& ec,
                     const INotifySubscriptionContextRef& sc) {
    LOG(INFO) << "File changed: " << ec->path
              << " Action: "      << ec->action;
    return Status::success();
  }
};
```
