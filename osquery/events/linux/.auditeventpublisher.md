Header defining the Linux audit event publisher for osquery, providing data structures and interfaces for processing kernel audit events (syscalls, AppArmor, seccomp, user events) via the Linux audit netlink subsystem.

## Key Components

### Event Data Structures
- **`UserAuditEventData`** — Holds a user-space audit event ID
- **`SyscallAuditEventData`** — Captures syscall metadata: number, success, PID, UID/GID sets, and executable path
- **`AppArmorAuditEventData`** — Key/value fields for AppArmor audit records (profile, operation, masks, capabilities)
- **`SeccompAuditEventData`** — Key/value fields for seccomp audit records (PID, syscall, arch, signal, instruction pointer)
- **`AuditEvent`** — Top-level descriptor combining a `Type` enum (`UserEvent`, `Syscall`, `SELinux`, `AppArmor`, `Seccomp`), a `boost::variant` data payload, and a raw record list

### Publisher Class
- **`AuditEventPublisher`** — Core publisher implementing `setUp()`, `configure()`, `tearDown()`, and `run()` lifecycle methods; owns the `AuditdNetlink` reader and the `AuditTraceContext` assembly map
- **`ProcessEvents()`** — Static method aggregating raw `AuditEventRecord` lists into structured `AuditEvent` objects

### Helper Functions
| Function | Purpose |
|---|---|
| `GetEventRecord()` | Extracts a record by type from an `AuditEvent` |
| `GetStringFieldFromMap()` | Safe string field extraction with default |
| `GetIntegerFieldFromMap()` | Safe integer field extraction with base/default |
| `CopyFieldFromMap()` | Copies a named field into an osquery `Row` |
| `StripQuotes()` | Removes surrounding quotes from a string value |
| `parseSeccompEvent()` | Parses a raw seccomp record into `SeccompAuditEventData` |

## Usage Example

```cpp
#include <osquery/events/linux/auditeventpublisher.h>

// Process incoming audit records into structured events
AuditEventContextRef ctx = std::make_shared<AuditEventContext>();
AuditTraceContext traceCtx;
std::set<int> allowedFailures = {59}; // e.g., execve

AuditEventPublisher::ProcessEvents(
    ctx, rawRecordList, traceCtx, allowedFailures);

for (const auto& event : ctx->audit_events) {
    if (event.type == AuditEvent::Type::Syscall) {
        const auto& data = boost::get<SyscallAuditEventData>(event.data);
        std::cout << "Syscall " << data.syscall_number
                  << " by PID " << data.process_id << "\n";
    }
}

// Extract a specific field from a parsed record
std::string path;
GetStringFieldFromMap(path, record.fields, "exe", "/unknown");
```
