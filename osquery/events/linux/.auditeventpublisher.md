Defines the Linux audit event publisher for osquery, providing data structures and interfaces for processing kernel audit events including syscalls, AppArmor, Seccomp, and user-space audit events via the Linux audit netlink socket.

## Key Components

### Event Data Structures

| Struct | Purpose |
|--------|---------|
| `UserAuditEventData` | User-space audit events (login, auth, etc.) |
| `SyscallAuditEventData` | Syscall events with full process identity (PID, UID, GID, executable path) |
| `AppArmorAuditEventData` | AppArmor policy violation events with profile/operation fields |
| `SeccompAuditEventData` | Seccomp filter events (arch, syscall, signal, instruction pointer) |
| `AuditEvent` | Top-level descriptor wrapping a typed `boost::variant` of the above data + raw record list |

### Publisher Class: `AuditEventPublisher`

Extends `EventPublisher<AuditSubscriptionContext, AuditEventContext>` and manages the full lifecycle of audit event collection:

- `setUp()` / `configure()` / `tearDown()` / `run()` — standard osquery publisher lifecycle
- `ProcessEvents()` — static method aggregating raw `AuditEventRecord` lists into structured `AuditEvent` objects using an `AuditTraceContext` map

### Utility Functions

- `GetEventRecord()` — extracts a specific record type from an `AuditEvent`
- `GetStringFieldFromMap()` / `GetIntegerFieldFromMap()` — safe field extraction from parsed audit maps
- `CopyFieldFromMap()` — copies a parsed field directly into an osquery `Row`
- `StripQuotes()` — strips surrounding quotes from audit field values
- `parseSeccompEvent()` — parses raw seccomp audit records into `SeccompAuditEventData`

## Usage Example

```cpp
// Aggregating raw audit records into structured events
AuditEventContextRef ctx = std::make_shared<AuditEventContext>();
AuditTraceContext trace;
std::set<int> allowed_failures = {257}; // e.g., openat allowed to fail

AuditEventPublisher::ProcessEvents(
    ctx, incoming_records, trace, allowed_failures);

// Extracting a field from a syscall record
std::string exe;
GetStringFieldFromMap(exe, record.fields, "exe", "/unknown");

// Extracting an integer field
std::uint64_t syscall_num = 0;
GetIntegerFieldFromMap(syscall_num, record.fields, "syscall", 10);
```
