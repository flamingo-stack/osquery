Declares a utility function for retrieving the set of system call numbers relevant to socket event monitoring in osquery's event subsystem.

## Key Components

- **`getSocketEventsSyscalls()`** — Returns a `std::set<int>` containing the syscall identifiers that should be monitored for socket-related events (e.g., `connect`, `bind`, `accept`).

## Usage Example

```c
#include "socket_events.h"
#include <iostream>

// Retrieve monitored syscalls for socket events
std::set<int> syscalls = osquery::getSocketEventsSyscalls();

for (int syscall : syscalls) {
    std::cout << "Monitoring syscall: " << syscall << std::endl;
}
```

## Notes

- Lives within the `osquery` namespace.
- Typically consumed by the event publisher/subscriber layer to configure kernel-level audit or eBPF filters for network socket activity.
- See the implementation file for the actual syscall list, which may vary by platform (Linux audit syscalls differ from macOS BSM events).
