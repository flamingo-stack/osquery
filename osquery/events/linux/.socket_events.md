Declares the `getSocketEventsSyscalls` utility function for retrieving the set of system call identifiers related to socket events within the osquery framework.

## Key Components

- **`getSocketEventsSyscalls()`** — Returns a `std::set<int>` containing the syscall numbers that correspond to socket-related kernel events (e.g., `connect`, `bind`, `accept`). Used to configure event subscriptions or filters for network socket monitoring.

## Usage Example

```c
#include "socket_events.h"

// Retrieve all socket-related syscall IDs
std::set<int> syscalls = osquery::getSocketEventsSyscalls();

for (int syscall_id : syscalls) {
    // Register or filter events for each syscall
    registerSyscallFilter(syscall_id);
}
```
