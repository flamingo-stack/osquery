Singleton factory class for managing the lifecycle of event publishers, subscribers, and subscriptions within the osquery eventing framework.

## Key Components

### `EventFactory` (Singleton Class)
The central coordinator for osquery's event-driven architecture. Manages registration, dispatch, and teardown of all event-related components.

**Static Management Methods**
- `getInstance()` — Returns the singleton `EventFactory` instance
- `registerEventPublisher(pub)` — Registers an `EventPublisher` plugin with the factory
- `registerEventSubscriber<T>()` / `registerEventSubscriber(sub)` — Registers an `EventSubscriber` by type or instance
- `deregisterEventPublisher(pub/type_id)` — Halts and removes an `EventPublisher` by reference or name
- `deregisterEventSubscriber(sub)` — Removes an `EventSubscriber` by name

**Subscription Methods**
- `addSubscription(type_id, name_id, sc, cb)` — Creates and attaches a `Subscription` to a publisher using a context and callback
- `addSubscription(type_id, subscription)` — Attaches a pre-built `Subscription` instance
- `numSubscriptions(type_id)` — Returns subscription count for a given publisher

**Lookup & Introspection**
- `getEventPublisher(pub)` — Returns a reference to a registered publisher
- `getEventSubscriber(sub)` — Returns a reference to a registered subscriber
- `exists(sub)` — Checks if a subscriber is registered
- `publisherTypes()` / `subscriberNames()` — Lists all registered publisher or subscriber names

**Runtime Control**
- `run(type_id)` — Entry point for a publisher's event thread
- `delay()` — Spawns all publisher run loops
- `end(join)` — Stops all publishers and optionally joins their threads
- `fire<PUB>(ec)` — Fires an event context into a publisher's subscriber callbacks
- `getType<PUB>()` — Resolves the registry plugin name for a publisher type

**Event Forwarding**
- `addForwarder(logger)` — Registers a logger plugin to receive forwarded events
- `forwardEvent(event)` — Sends an event string to all registered loggers
- `configUpdate()` — Notifies the factory of configuration changes

## Usage Example

```cpp
// Register a custom publisher and subscriber
EventFactory::registerEventPublisher(std::make_shared<MyEventPublisher>());
EventFactory::registerEventSubscriber<MyEventSubscriber>();

// Add a subscription with a context and callback
auto sc = std::make_shared<MySubscriptionContext>();
EventFactory::addSubscription("my_publisher", "my_subscriber", sc,
  [](const EventContextRef& ec, const SubscriptionContextRef& sc) {
    // handle event
    return Status::success();
  });

// Start all publisher run loops
EventFactory::delay();

// Fire an event from a static publisher callback
EventFactory::fire<MyEventPublisher>(event_context);

// Shut down all publishers
EventFactory::end(true /* join threads */);
```
