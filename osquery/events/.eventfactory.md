Singleton factory that manages the full lifecycle of event publishers and subscribers in osquery's eventing system — handling registration, subscription wiring, run loop dispatch, and teardown.

## Key Components

### `EventFactory` (Singleton Class)
The central coordinator for all osquery event infrastructure. Accessed via `EventFactory::getInstance()`.

**Publisher Management**
- `registerEventPublisher(pub)` — registers an `EventPublisher` plugin instance
- `deregisterEventPublisher(pub/type_id)` — halts the run loop and cleans up
- `getEventPublisher(pub)` — retrieves a registered publisher by name
- `numEventPublishers()` — returns count of registered publishers
- `publisherTypes()` — returns all registered publisher registry names

**Subscriber Management**
- `registerEventSubscriber<T>()` — template registration; creates and registers a typed subscriber
- `registerEventSubscriber(sub)` — registration by plugin instance
- `deregisterEventSubscriber(sub)` — removes a subscriber by name
- `getEventSubscriber(sub)` — retrieves a registered subscriber
- `subscriberNames()` — returns all subscriber registry names
- `exists(sub)` — checks if a subscriber is registered

**Subscription Wiring**
- `addSubscription(type_id, name_id, sc, cb)` — creates and attaches a `Subscription` to a publisher
- `addSubscription(type_id, subscription)` — attaches a pre-built `Subscription` instance
- `numSubscriptions(type_id)` — counts subscriptions for a given publisher

**Run Loop Control**
- `delay()` — spawns all publisher run loop threads
- `run(type_id)` — entry point for a single publisher's dispatch thread
- `end(join)` — shuts down all publishers; optionally joins threads
- `fire<PUB>(ec)` — fires an `EventContext` into a publisher from a static callback

**Utilities**
- `getType<PUB>()` — returns the registry name for a publisher type
- `configUpdate()` — notifies the factory of configuration changes
- `addForwarder(logger)` / `forwardEvent(event)` — routes events to logger plugins

## Usage Example

```cpp
// Register a publisher and subscriber
EventFactory::registerEventPublisher(pub_plugin_ref);
EventFactory::registerEventSubscriber<MyEventSubscriber>();

// Wire a subscription with a callback
auto sc = std::make_shared<MySubscriptionContext>();
EventFactory::addSubscription(
    "my_publisher",
    "my_subscriber",
    sc,
    [](const EventContextRef& ec, const SubscriptionContextRef& sc) {
        // handle event
        return Status::success();
    }
);

// Start all publisher run loops
EventFactory::delay();

// Fire an event from a static publisher callback
EventFactory::fire<MyEventPublisher>(event_context);

// Shutdown
EventFactory::end(true /* join threads */);
```
