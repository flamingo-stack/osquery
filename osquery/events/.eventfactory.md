Singleton factory that manages the lifecycle of event publishers, subscribers, and subscriptions within the osquery eventing framework.

## Key Components

### `EventFactory` (Singleton Class)

A non-copyable singleton that arbitrates all event publisher/subscriber registration and lifecycle management.

**Publisher Management**
- `registerEventPublisher(pub)` — Register an `EventPublisher` plugin instance
- `deregisterEventPublisher(pub/type_id)` — Halt and remove a publisher's run loop
- `getEventPublisher(pub)` — Retrieve a registered publisher by name
- `numEventPublishers()` — Count active publishers
- `publisherTypes()` — List all registered publisher registry names

**Subscriber Management**
- `registerEventSubscriber<T>()` — Template registration for typed subscribers
- `registerEventSubscriber(sub)` — Register by plugin instance
- `deregisterEventSubscriber(sub)` — Remove a subscriber by name
- `getEventSubscriber(sub)` — Retrieve a registered subscriber
- `subscriberNames()` — List all registered subscriber names
- `exists(sub)` — Check whether a subscriber is registered

**Subscription Wiring**
- `addSubscription(type_id, name_id, sc, cb)` — Create and attach a `Subscription` to a publisher
- `numSubscriptions(type_id)` — Count subscriptions for a given publisher

**Run Loop Control**
- `run(type_id)` — Entry point for a single publisher's dispatch thread
- `delay()` — Spawn all publisher run loops
- `end(join)` — Tear down all publishers; optionally join threads

**Utilities**
- `fire<PUB>(ec)` — Fire an `EventContext` into a typed publisher
- `getType<PUB>()` — Resolve a publisher's registry name from its type
- `configUpdate()` — Notify factory of configuration changes
- `addForwarder(logger)` / `forwardEvent(event)` — Route events to logger plugins

## Usage Example

```c
// Register a publisher and subscriber, then wire a subscription
EventFactory::registerEventPublisher(myPublisherPlugin);
EventFactory::registerEventSubscriber<MyEventSubscriber>();

auto sc = std::make_shared<MySubscriptionContext>();
EventFactory::addSubscription("my_publisher", "my_subscriber", sc,
  [](const EventContextRef& ec, const SubscriptionContextRef& sc) {
    // Handle event
    return Status::success();
  });

// Start all publisher run loops
EventFactory::delay();

// Shutdown cleanly
EventFactory::end(true);
```
