Brief header defining the lifecycle state machine for osquery's event pub/sub system. It provides the `EventState` enum and `Eventer` base class used by both `EventSubscriber` and `EventPublisher` types.

## Key Components

### `EventState` Enum
Represents the lifecycle states of an event subscriber or publisher:

| Value | Meaning |
|-------|---------|
| `EVENT_NONE` | Default/uninitialized state |
| `EVENT_SETUP` | Attached and setup has run |
| `EVENT_RUNNING` | Ready to accept events |
| `EVENT_PAUSED` | Initialized but not accepting events |
| `EVENT_FAILED` | Failed to initialize or offline |

### `Eventer` Class
Minimal base class that tracks runtime state for event participants.

- **`state() const`** — Public getter returning the current `EventState`
- **`state(EventState)`** — Protected setter, accessible to subclasses
- **`state_`** — Private member defaulting to `EVENT_NONE`
- `EventFactory` is declared a `friend`, allowing it to directly manage subscriber states during initialization and teardown

## Usage Example

```c
// Typical subclass pattern (EventSubscriber inherits Eventer)
class MySubscriber : public EventSubscriber<MyPublisher>, public Eventer {
  Status init() override {
    // After successful setup, state transitions to EVENT_RUNNING
    // On failure, EventFactory may observe EVENT_FAILED
    return Status::success();
  }
};

// Checking state externally (e.g., in EventFactory)
if (subscriber->state() == EventState::EVENT_RUNNING) {
  // Safe to deliver events
}
```
