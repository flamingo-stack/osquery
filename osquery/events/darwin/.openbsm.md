Provides the OpenBSM audit event publisher interface for osquery, enabling subscription-based monitoring of macOS/BSD kernel audit events via the OpenBSM framework.

## Key Components

### Structs

- **`OpenBSMSubscriptionContext`** — Subscription config holding the target `event_id` (e.g., `23` for `execve`) to filter audit events
- **`OpenBSMEventContext`** — Event payload containing the matched `event_id`, a vector of parsed `tokenstr_t` tokens, and a managed `shared_ptr` to the raw OpenBSM buffer

### Type Aliases

- **`OpenBSMEventContextRef`** — `std::shared_ptr<OpenBSMEventContext>`
- **`OpenBSMSubscriptionContextRef`** — `std::shared_ptr<OpenBSMSubscriptionContext>`

### Classes

- **`OpenBSMEventPublisher`** — Core event publisher that polls the audit pipe, parses BSM records, and dispatches events to matching subscribers. Key methods:
  - `setUp()` — Initializes the audit pipe connection
  - `configure()` — Rebuilds the set of subscribed event IDs
  - `run()` — Main polling loop; reads from the audit descriptor
  - `tearDown()` — Closes the audit pipe
  - `shouldFire()` — Filters events against active subscription contexts
  - `acquireMessages()` — Dequeues raw audit records from the pipe
  - `configureAuditPipe()` — Opens and configures the BSM audit pipe

## Usage Example

```cpp
// Define a subscriber for execve events (event_id = 23)
class MySubscriber : public EventSubscriber<OpenBSMEventPublisher> {
  Status init() override {
    auto sc = createSubscriptionContext();
    sc->event_id = 23; // AUE_EXECVE
    subscribe(&MySubscriber::eventCallback, sc);
    return Status::success();
  }

  Status eventCallback(const OpenBSMEventContextRef& ec,
                       const OpenBSMSubscriptionContextRef& sc) {
    for (const auto& token : ec->tokens) {
      // Process parsed BSM tokens
    }
    return Status::success();
  }
};
```

> **Note:** `OpenBSMEventPublisher` is thread-safe; the audit pipe and event ID set are each protected by a dedicated `Mutex`. The publisher runs as a dispatched service via `OpenBSMConsumerRunner`.
