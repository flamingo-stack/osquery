Declares the IOKit event publisher and supporting types for macOS hardware device monitoring via Apple's IOKit framework.

## Key Components

### Structs

- **`IOKitSubscriptionContext`** — Subscriber filter context; supports filtering by `model_id`, `vendor_id`, and bus `type` (e.g., `"USB"`).
- **`IOKitEventContext`** — Event payload emitted on device changes; carries `action` (`DEVICE_ATTACH` / `DEVICE_DETACH`), device metadata (`vendor`, `model`, `path`, `driver`, `version`, `serial`), and IDs.

### Type Aliases

- **`IOKitEventContextRef`** — `std::shared_ptr<IOKitEventContext>`
- **`IOKitSubscriptionContextRef`** — `std::shared_ptr<IOKitSubscriptionContext>`

### Class: `IOKitEventPublisher`

Extends `EventPublisher<IOKitSubscriptionContext, IOKitEventContext>` and manages a `CFRunLoop` to listen for IOKit device notifications.

| Method | Description |
|---|---|
| `run()` | Starts the CoreFoundation run loop and registers device notifications |
| `tearDown()` | Releases IOKit resources on shutdown |
| `shouldFire()` | Filters events against subscriber context (vendor/model/type) |
| `deviceAttach()` (static) | Callback invoked when a device connects |
| `deviceDetach()` (static) | Callback invoked when a device disconnects |
| `newEvent()` | Constructs and fires an `IOKitEventContext` from a raw `io_service_t` |
| `restart()` / `stop()` | Internal run loop lifecycle management |

## Usage Example

```c
// Subscribe to USB device attach/detach events
auto sc = std::make_shared<IOKitSubscriptionContext>();
sc->type = "USB";
sc->vendor_id = "05ac"; // Apple vendor ID

subscribe(&MySubscriber::Callback, sc);
```

> **Platform note:** This publisher is macOS-only and requires linking against `IOKit.framework` and `CoreServices.framework`.
