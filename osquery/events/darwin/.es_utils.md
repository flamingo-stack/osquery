Utility header providing helper functions for extracting and formatting data from Apple's Endpoint Security framework (`es_*`) types within the osquery event system.

## Key Components

| Function | Description |
|----------|-------------|
| `getEsNewClientErrorMessage` | Converts an `es_new_client_result_t` error code into a human-readable string |
| `getPath` | Extracts the executable path from an `es_process_t` pointer |
| `getSigningId` | Retrieves the code-signing identifier from a process |
| `getTeamId` | Retrieves the Apple Developer Team ID from a process |
| `getStringFromToken` | Converts an `es_string_token_t` (mutable or const) to a `std::string` |
| `getCwdPathFromPid` | Looks up the current working directory for a given PID |
| `getCDHash` | Extracts the CDHash (code directory hash) from a process |
| `getProcessProperties` | Populates an `EndpointSecurityEventContextRef` with properties from a process |
| `appendQuotedString` | Appends a delimiter-quoted string to an output stream |

## Usage Example

```c
#include <osquery/events/darwin/es_utils.h>

// Inside an ES event handler
void handleExecEvent(const es_message_t* msg) {
    const es_process_t* proc = msg->event.exec.target;

    std::string path      = osquery::getPath(proc);
    std::string signingId = osquery::getSigningId(proc);
    std::string teamId    = osquery::getTeamId(proc);
    std::string cdHash    = osquery::getCDHash(proc);
    std::string cwd       = osquery::getCwdPathFromPid(proc->audit_token.val[5]);

    osquery::getProcessProperties(proc, eventContext);
}
```

## Notes

- All functions operate within the `osquery` namespace.
- Designed exclusively for **macOS** — depends on the Endpoint Security framework (`es_process_t`, `es_string_token_t`).
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/darwin/es_utils.h)
