macOS Endpoint Security event publisher and subscriber interface for osquery, providing process and file system event monitoring via Apple's EndpointSecurity framework (requires macOS 10.15+).

## Key Components

### Structs

| Struct | Description |
|--------|-------------|
| `EndpointSecuritySubscriptionContext` | Subscription context for process events; holds ES event type subscriptions and row accumulator |
| `EndpointSecurityEventContext` | Rich event context capturing process metadata (PID, UID, signing info, exec args, fork/exit data) |
| `EndpointSecurityFileSubscriptionContext` | Subscription context for file integrity monitoring (FIM) events |
| `EndpointSecurityFileEventContext` | Extends process event context with file-specific fields (`filename`, `dest_filename`) |

### Classes

| Class | Description |
|-------|-------------|
| `EndpointSecurityPublisher` | Event publisher (`"endpointsecurity"`) managing an `es_client_s*` for process lifecycle events |
| `EndpointSecurityFileEventPublisher` | Event publisher (`"endpointsecurity_fim"`) for file events; supports muted path literals/prefixes and configurable include/exclude path lists |
| `ESProcessEventSubscriber` | Subscriber (`"es_process_events"`) consuming process events from `EndpointSecurityPublisher` |
| `ESProcessFileEventSubscriber` | Subscriber (`"es_process_file_events"`) consuming file events from `EndpointSecurityFileEventPublisher` |

## Usage Example

```cpp
// Subscribing to process events
auto sc = std::make_shared<EndpointSecuritySubscriptionContext>();
sc->es_event_subscriptions_ = {ES_EVENT_TYPE_NOTIFY_EXEC,
                                ES_EVENT_TYPE_NOTIFY_FORK,
                                ES_EVENT_TYPE_NOTIFY_EXIT};

// Subscribing to file events
auto fsc = std::make_shared<EndpointSecurityFileSubscriptionContext>();
fsc->es_file_event_subscriptions_ = {ES_EVENT_TYPE_NOTIFY_CREATE,
                                      ES_EVENT_TYPE_NOTIFY_RENAME};

// Accessing event context fields in a callback
Status ESProcessEventSubscriber::Callback(
    const EndpointSecurityEventContextRef& ec,
    const EndpointSecuritySubscriptionContextRef& sc) {
  Row r;
  r["pid"]        = INTEGER(ec->pid);
  r["path"]       = ec->path;
  r["signing_id"] = ec->signing_id;
  r["args"]       = ec->args;
  addRow(r, sc);
  return Status::success();
}
```

> **Note:** All publisher/subscriber methods are gated with `API_AVAILABLE(macos(10.15))`. The FIM publisher mutes high-noise system processes (e.g., `WindowServer`, `tccd`, `securityd`) by default via `default_muted_path_literals_`.
