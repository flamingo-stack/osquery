Defines the macOS FSEvents-based filesystem event publisher for osquery, wrapping Apple's CoreServices FSEvents API to monitor filesystem changes and deliver them to subscribers.

## Key Components

### `FSEventsSubscriptionContext`
Subscription configuration struct holding:
- `path` — filesystem path to watch
- `mask` — optional `FSEventStreamEventFlags` filter
- `recursive` — whether the watch is recursive
- `category` — config-originated category label
- `requireAction()` — appends an action filter to the subscription

### `FSEventsEventContext`
Event data struct populated on each filesystem event:
- `fsevent_stream`, `fsevent_flags`, `transaction_id` — raw FSEvents metadata
- `path`, `action` — resolved filesystem path and action string

### `FSEventsEventPublisher`
Core publisher class inheriting `EventPublisher<FSEventsSubscriptionContext, FSEventsEventContext>`:

| Method | Description |
|--------|-------------|
| `configure()` | Rebuilds watch paths and exclude sets on config load/update |
| `run()` | Starts the CFRunLoop event loop |
| `tearDown()` | Gracefully stops the stream and loop |
| `Callback()` | Static FSEvents client callback invoked by the kernel |
| `shouldFire()` | Filters events against subscription context before delivery |
| `transformSubscription()` | Resolves globs and recursive paths at configure time |
| `buildExcludePathsSet()` | Populates `ExcludePathSet` of suppressed paths |

**Type aliases:**
- `FSEventsEventContextRef` — `std::shared_ptr<FSEventsEventContext>`
- `FSEventsSubscriptionContextRef` — `std::shared_ptr<FSEventsSubscriptionContext>`
- `ExcludePathSet` — `PathSet<patternedPath>` for exclusion matching

## Usage Example

```cpp
// Register a subscription to watch /etc recursively
auto sc = std::make_shared<FSEventsSubscriptionContext>();
sc->path      = "/etc";
sc->recursive = true;
sc->category  = "fim";

// The publisher resolves globs and starts the FSEvents stream internally.
// Events are delivered via shouldFire() -> subscriber callback.
EventFactory::addSubscription("fsevents", sc, myCallback);
```
