Defines the macOS FSEvents-based filesystem event publisher for osquery, wrapping Apple's `CoreServices` FSEvents API to deliver real-time filesystem change notifications to subscribers.

## Key Components

### `FSEventsSubscriptionContext`
Holds per-subscription configuration:
- `path` — filesystem path to watch
- `mask` — optional `FSEventStreamEventFlags` filter
- `recursive` — whether the watch is recursive (double-wildcard)
- `category` — originating config category
- `requireAction()` — appends a required action filter
- Private `discovered_` / `recursive_match` — resolved at configure-time for efficient re-matching

### `FSEventsEventContext`
Carries per-event data fired to subscribers:
- `fsevent_stream`, `fsevent_flags`, `transaction_id` — raw FSEvents metadata
- `path`, `action` — normalized path and action string

### `FSEventsEventPublisher`
Core publisher class inheriting `EventPublisher<FSEventsSubscriptionContext, FSEventsEventContext>`:

| Member | Purpose |
|---|---|
| `configure()` | Rebuilds watched path set on config load/update |
| `run()` | Enters the `CFRunLoop` event loop |
| `tearDown()` / `stop()` | Gracefully halts stream and run loop |
| `Callback()` | Static FSEvents client callback; dispatches events |
| `shouldFire()` | Filters events against subscription context |
| `transformSubscription()` | Resolves globs/wildcards at configure time |
| `buildExcludePathsSet()` | Populates `ExcludePathSet` for suppressed paths |
| `flush()` | Forces kernel-buffered events to drain |

## Usage Example

```cpp
// Subscribe to all changes under /etc recursively
auto sc = std::make_shared<FSEventsSubscriptionContext>();
sc->path = "/etc/";
sc->recursive = true;
sc->requireAction("UPDATED");

// Publisher is registered automatically via DECLARE_PUBLISHER("fsevents")
// Subscribers receive FSEventsEventContext on match:
void eventCallback(const FSEventsEventContextRef& ec) {
  std::cout << ec->action << ": " << ec->path << "\n";
}
```
