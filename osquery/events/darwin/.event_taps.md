Provides the macOS event tap publisher interface for capturing system-level input events (keyboard, mouse, etc.) via the CoreGraphics event tap API within the osquery event framework.

## Key Components

### Structs
- **`EventTappingSubscriptionContext`** — Subscription context for event tap subscribers (currently empty, inherits from `SubscriptionContext`)
- **`EventTappingEventContext`** — Event context passed to subscribers when an event fires (inherits from `EventContext`)

### Type Aliases
- **`EventTappingEventContextRef`** — `shared_ptr` to `EventTappingEventContext`
- **`EventTappingSubscriptionContextRef`** — `shared_ptr` to `EventTappingSubscriptionContext`

### Class: `EventTappingEventPublisher`
macOS-specific event publisher using CoreGraphics event taps. Key members:

| Member | Description |
|--------|-------------|
| `setUp()` | Installs the CGEvent tap and configures the run loop source |
| `tearDown()` | Releases CoreGraphics resources |
| `stop()` | Stops the publisher's CFRunLoop |
| `run()` | Enters the run loop to process tapped events |
| `restart()` | Tears down and re-initializes the event tap |
| `eventCallback(...)` | Static CGEvent tap callback; routes events into the osquery pipeline |
| `shouldFire(...)` | Filters events against subscriber context |

**Private state:** `CFRunLoopRef`, `CFRunLoopSourceRef`, `CFMachPortRef`, and a `Mutex` guard for run loop operations.

## Usage Example

```cpp
// Subscribing to event tap events
class MySubscriber
    : public EventSubscriber<EventTappingEventPublisher> {
 public:
  Status init() override {
    auto sc = createSubscriptionContext();
    subscribe(&MySubscriber::handleEvent, sc);
    return Status::success();
  }

  Status handleEvent(const EventTappingEventContextRef& ec,
                     const EventTappingSubscriptionContextRef& sc) {
    // Process captured macOS input event
    return Status::success();
  }
};
```

> **Platform note:** This publisher is macOS-only and requires `ApplicationServices` framework linkage. Source: [`osquery/events/darwin/event_taps.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/darwin/event_taps.h)
