Defines the `SCNetworkEventPublisher`, an osquery event publisher that wraps Apple's `SCNetworkReachability` API to monitor network reachability changes on macOS.

## Key Components

### Enums & Types
- **`SCNetworkSubscriptionType`** — Distinguishes between `ADDRESS_TARGET` (IP-based) and `NAME_TARGET` (hostname-based) monitoring targets.
- **`SCNetworkSubscriptionContext`** — Subscription configuration holding the target type, hostname/address string, address family, and a reachability flags mask for filtering.
- **`SCNetworkEventContext`** — Event payload carrying the originating subscription context and the reported `SCNetworkReachabilityFlags`.

### Class: `SCNetworkEventPublisher`
A macOS-only `EventPublisher` templated on `SCNetworkSubscriptionContext` / `SCNetworkEventContext`.

| Method | Description |
|--------|-------------|
| `configure()` | Registers reachability targets and starts monitoring |
| `setUp()` | Returns a non-success status; publisher is callback-driven, not polled |
| `tearDown()` / `stop()` | Stops the CF run loop and cleans up targets |
| `run()` | Enters the `CFRunLoop` blocking loop |
| `Callback()` (static) | Apple SCNetwork callback invoked on reachability changes |
| `shouldFire()` | Filters events against the subscription's flag mask |
| `addHostname()` / `addAddress()` | Register name- or address-based reachability targets |
| `clearAll()` | Releases all registered `SCNetworkReachabilityRef` targets |

## Usage Example

```cpp
// Subscribe to hostname reachability changes
auto sc = std::make_shared<SCNetworkSubscriptionContext>();
sc->type = SCNetworkSubscriptionType::NAME_TARGET;
sc->target = "example.com";
sc->mask = kSCNetworkReachabilityFlagsReachable;

auto sub = EventFactory::addSubscription("scnetwork", sc);
```

## Notes

- **macOS only** — depends on `SystemConfiguration/SCNetworkReachability.h`.
- Uses a `CFRunLoop` rather than a poll loop; network events are delivered via the static `Callback`.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
