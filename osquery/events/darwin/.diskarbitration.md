Provides the macOS Disk Arbitration event publisher interface for osquery, enabling subscription to disk appearance and disappearance events on macOS systems.

## Key Components

### Macros
- `kIOPropertyProtocolCharacteristicsKey_` — IOKit key for protocol characteristics lookup
- `kVirtualInterfaceLocation_` — Key identifying virtual interface location paths (DMG detection)
- `kDAAppearanceTime_` — Key for disk appearance timestamp

### Structs
- **`DiskArbitrationSubscriptionContext`** — Extends `SubscriptionContext`; includes `physical_disks` flag to filter events to physical-only or virtual (DMG) disks
- **`DiskArbitrationEventContext`** — Extends `EventContext`; carries disk metadata: `action`, `path`, `device`, `uuid`, `size`, `filesystem`, `vendor`, `checksum`, and more

### Type Aliases
- `DiskArbitrationEventContextRef` — `shared_ptr` to `DiskArbitrationEventContext`
- `DiskArbitrationSubscriptionContextRef` — `shared_ptr` to `DiskArbitrationSubscriptionContext`

### Class: `DiskArbitrationEventPublisher`
Registered as publisher `"diskarbitration"`. Key members:

| Member | Description |
|--------|-------------|
| `run()` | Main event loop using `CFRunLoopRef` and a `DASessionRef` |
| `tearDown()` / `stop()` | Cleanup for session and run loop |
| `shouldFire()` | Filters events against subscription context |
| `DiskAppearedCallback()` | Static DA callback on disk mount |
| `DiskDisappearedCallback()` | Static DA callback on disk unmount |
| `getProperty()` | Extracts string values from `CFDictionaryRef` |
| `extractUdifChecksum()` | Computes checksum for UDIF (DMG) disk images |
| `fire()` | Populates and fires event context |

## Usage Example

```cpp
// Subscribe to physical disk events only
auto sc = std::make_shared<DiskArbitrationSubscriptionContext>();
sc->physical_disks = true;

EventFactory::addSubscription(
    "diskarbitration",
    Subscription::create("my_subscriber", sc, myCallback)
);

// Access event data in callback
void myCallback(const DiskArbitrationEventContextRef& ec,
                const DiskArbitrationSubscriptionContextRef& sc) {
    LOG(INFO) << "Disk " << ec->action
              << ": " << ec->path
              << " [" << ec->filesystem << "]";
}
```

> **Platform note:** This publisher is macOS-only, requiring `DiskArbitration.framework` and `IOKit.framework`.
