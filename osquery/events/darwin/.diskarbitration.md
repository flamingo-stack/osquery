Defines the `DiskArbitrationEventPublisher` for monitoring macOS disk mount/unmount events using the DiskArbitration framework within the osquery event system.

## Key Components

### Macros
- `kIOPropertyProtocolCharacteristicsKey_` — IOKit key for protocol characteristics lookup
- `kVirtualInterfaceLocation_` — Key identifying virtual disk interface location paths
- `kDAAppearanceTime_` — Key for disk appearance timestamp

### Structs
- **`DiskArbitrationSubscriptionContext`** — Subscription config; `physical_disks` flag filters events to physical disks only (default: `false`, virtual/DMG only)
- **`DiskArbitrationEventContext`** — Event payload carrying disk metadata: `action`, `path`, `device_path`, `name`, `uuid`, `size`, `filesystem`, `vendor`, `checksum`, and mount flags (`ejectable`, `mountable`, `writable`)

### Type Aliases
- `DiskArbitrationEventContextRef` — `shared_ptr<DiskArbitrationEventContext>`
- `DiskArbitrationSubscriptionContextRef` — `shared_ptr<DiskArbitrationSubscriptionContext>`

### Class: `DiskArbitrationEventPublisher`
Extends `EventPublisher<DiskArbitrationSubscriptionContext, DiskArbitrationEventContext>`.

| Member | Description |
|--------|-------------|
| `run()` | Starts the DA session and CFRunLoop |
| `tearDown()` / `stop()` | Cleans up session and run loop |
| `shouldFire()` | Filters events per subscription context |
| `DiskAppearedCallback()` | Static DA callback on disk mount |
| `DiskDisappearedCallback()` | Static DA callback on disk unmount |
| `getProperty()` | Extracts a string value from a `CFDictionaryRef` |
| `extractUdifChecksum()` | Computes checksum for UDIF (DMG) disk images |
| `fire()` | Builds and dispatches the event context |

## Usage Example

```cpp
auto sub_ctx = std::make_shared<DiskArbitrationSubscriptionContext>();
sub_ctx->physical_disks = true; // Subscribe to physical disk events only

// In an EventSubscriber:
subscribe(&MySubscriber::handleDiskEvent, sub_ctx);

Status MySubscriber::handleDiskEvent(
    const DiskArbitrationEventContextRef& ec,
    const DiskArbitrationSubscriptionContextRef& sc) {
  LOG(INFO) << "Disk action: " << ec->action
            << " path: "       << ec->path
            << " filesystem: " << ec->filesystem;
  return Status::success();
}
```
