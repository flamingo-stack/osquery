Declares two utility functions for managing osquery's event publisher system, including publisher initialization and query denylist enforcement.

## Key Components

| Function | Description |
|----------|-------------|
| `attachEvents()` | Iterates the event publisher registry and creates run loops for each publisher via the event factory |
| `enforceEventsDenylist(const std::string& query)` | Returns `true` if a query operates exclusively on event-based tables and should be denylisted |

## Usage Example

```c
#include "events.h"

// Initialize all registered event publishers at startup
osquery::attachEvents();

// Before executing a query, check if it should be blocked
std::string incoming_query = "SELECT * FROM process_events";
if (osquery::enforceEventsDenylist(incoming_query)) {
    // Query targets only event-based tables — skip or reject
}
```

## Notes

- Both functions live in the `osquery` namespace
- `attachEvents()` is typically called once during daemon startup to spin up publisher run loops
- `enforceEventsDenylist` is a guard used to prevent excessive load from queries that continuously poll event-based tables
