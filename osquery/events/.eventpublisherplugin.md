Plugin interface for osquery event publishers, defining the lifecycle and subscription management API for event-driven data collection.

## Key Components

### `EventPublisherPlugin` Class
Inherits from `Plugin`, `InterruptibleRunnable`, and `Eventer`. Provides the base class for all osquery event publishers.

**Lifecycle Methods**
- `setUp()` — Called before the run loop starts; opens handles and registers OS API callbacks
- `configure()` — Called when subscriptions change; allows optimization (e.g., deduplicating `inotify` paths)
- `run()` — Single step of the publisher's run loop; returning `FAILED` exits the loop
- `tearDown()` — Cleans up handles and resources on shutdown; may be called multiple times
- `stop()` — Signals the run loop to terminate via `isEnding`

**Subscription Management**
- `addSubscription(subscription)` — Registers a new `SubscriptionRef` with this publisher
- `removeSubscriptions(subscriber)` — Removes all subscriptions for a named subscriber
- `numSubscriptions()` — Returns the active subscription count

**State Inspection**
- `isEnding()` / `hasStarted()` / `restartCount()` — Query run loop lifecycle state
- `numEvents()` — Returns total `EventContextID` count fired

**Protected Internals**
- `fire(ec, time)` — Enumerates subscriptions and dispatches event callbacks
- `fireCallback(sub, ec)` — Pure virtual; implemented by typed publishers to invoke subscriber callbacks
- `subscriptions_` / `subscription_lock_` — Thread-safe subscription storage

## Usage Example

```cpp
class MyPublisher : public EventPublisherPlugin {
 public:
  Status setUp() override {
    // Register OS-level event source
    return Status::success();
  }

  Status run() override {
    auto ec = createEventContext();
    // Populate ec with event data
    fire(ec);
    return Status::success();
  }

 protected:
  void fireCallback(const SubscriptionRef& sub,
                    const EventContextRef& ec) const override {
    // Invoke subscriber-specific callback
  }
};
```

> **Note:** `interrupted()` is deprecated — use `isEnding()` to check publisher termination state. Copy construction and assignment are explicitly deleted.
