Defines the `EventPublisherPlugin` abstract base class for osquery's event publishing framework, providing the interface for implementing OS-level event sources that deliver events to registered subscribers.

## Key Components

### Class: `EventPublisherPlugin`
Inherits from `Plugin`, `InterruptibleRunnable`, and `Eventer`. Serves as the base class for all event publishers (e.g., inotify, audit, FSEvents).

**Lifecycle Methods**
- `setUp()` — Called before the run loop starts; use for handle opening and OS API registration
- `configure()` — Called when subscriptions change; allows optimization (e.g., deduplicating watched paths)
- `tearDown()` — Called after the run loop exits; performs cleanup and resource release
- `run()` — Implements a single step of the publisher's run loop; returning `FAILED` exits the loop
- `stop()` — Signals the run loop to terminate

**Subscription Management**
- `addSubscription(const SubscriptionRef&)` — Registers a new subscriber
- `removeSubscriptions(const std::string&)` — Removes all subscriptions from a named subscriber
- `numSubscriptions()` — Returns the current subscriber count

**State & Diagnostics**
- `isEnding()` / `hasStarted()` — Query or set publisher lifecycle state
- `numEvents()` — Returns the total count of fired events
- `restartCount()` — Returns the number of run loop restarts

**Protected**
- `fire(const EventContextRef&, EventTime)` — Dispatches an event context to matching subscribers
- `fireCallback(const SubscriptionRef&, const EventContextRef&)` — **Pure virtual**; must be implemented by concrete publishers
- `subscriptions_` / `subscription_lock_` — Thread-safe subscription storage

## Usage Example

```cpp
class MyPublisher : public EventPublisherPlugin {
 public:
  Status setUp() override {
    // Open OS handle or register API callback
    return Status::success();
  }

  Status run() override {
    // Poll or block for events, then fire
    auto ec = createEventContext();
    fire(ec);
    return Status::success();
  }

  void fireCallback(const SubscriptionRef& sub,
                    const EventContextRef& ec) const override {
    // Invoke subscriber callback with typed context
  }

  void tearDown() override {
    // Close handles and clean up
  }
};
```

## Notes

- `fire()` should not be overridden; override `fireCallback()` instead
- Copy construction and assignment are explicitly deleted
- `interrupted()` is deprecated; use `isEnding()` instead
