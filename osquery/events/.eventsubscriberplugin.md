Defines the `EventSubscriberPlugin` class, the base interface for osquery event subscribers that receive, store, and expose event data as queryable table rows via a backing database store.

## Key Components

### Class: `EventSubscriberPlugin`
Inherits from `Plugin` and `Eventer`. Manages event subscription lifecycle, backing store persistence, and time-indexed row generation.

**Core Methods**

| Method | Description |
|--------|-------------|
| `init()` | Entry point for registering subscriptions after publisher setup |
| `addBatch(row_list)` | Persists a batch of event rows to the backing store (preferred) |
| `add(r)` | *(Deprecated)* Persists a single event row; use `addBatch()` instead |
| `genTable(yield, ctx)` | Entrypoint for table generation; retrieves time-windowed events |
| `generateRows(...)` | Static method returning events within a `[start_time, end_time]` range |
| `generateEventDataIndex(...)` | Rebuilds the event data index by scanning the database |
| `getEventID()` | Returns a unique monotonic event identifier for backing storage |
| `getEventsExpiry()` | Returns the TTL for stored events (defaults to `FLAGS_events_expiry`) |
| `getEventBatchesMax()` | Returns max stored batches (defaults to `FLAGS_events_max`) |

**Static Utilities**

| Method | Description |
|--------|-------------|
| `setOptimizeData` / `getOptimizeData` | Persist/retrieve query optimization watermarks |
| `removeOverflowingEventBatches` | Trims oldest batches when count exceeds maximum |
| `expireEventBatches` | Removes batches older than the expiry window |
| `setDatabaseNamespace` | Sets the publisher/subscriber-scoped storage prefix |
| `databaseKeyForEventId` | Returns the database key for a given event ID |
| `toIndex` | Converts a `uint64_t` to a zero-padded index string |

**Inner Types**

- `Context` — holds the database namespace, event index, last query time, and last event ID
- `GenerateRowsResult` — returns iteration state (`isEnd`, `last_time`, `last_id`) from `generateRows`

## Usage Example

```cpp
class MySubscriber : public EventSubscriber<MyPublisher> {
 public:
  Status init() override {
    auto sub = createSubscription();
    return subscribe(&MySubscriber::onEvent, sub);
  }

  Status onEvent(const MyEventContextRef& ec, const MySubscriptionContextRef& sc) {
    Row r;
    r["action"] = ec->action;
    r["path"]   = ec->path;

    std::vector<Row> rows = {r};
    return addBatch(rows);  // Preferred over deprecated add()
  }
};
```
