Defines the `EventSubscriberPlugin` class, the base plugin interface for osquery event subscribers that receive, store, and expose event data as queryable table rows via a backing store.

## Key Components

### Class: `EventSubscriberPlugin`
Inherits from `Plugin` and `Eventer`. Provides the full lifecycle for event subscription, storage, indexing, expiration, and table generation.

### Core Virtual Methods
- **`init()`** — Override to register `Subscription`s with an `EventPublisher`
- **`genTable(yield, ctx)`** — Entrypoint for table generation; retrieves stored events within a query time window
- **`getType()`** — Pure virtual; returns the associated publisher type name
- **`getEventsExpiry()`** / **`getEventBatchesMax()`** — Override to customize retention per subscriber

### Storage Methods
- **`addBatch(row_list)`** — Stores a batch of event rows into the backing database (preferred over deprecated `add()`)
- **`add(row)`** — *(Deprecated)* Single-row storage; migrate to `addBatch()`

### Static Utilities
- **`generateRows(context, db, callback, start, end, last_eid)`** — Retrieves events within a time range from the backing store
- **`expireEventBatches()`** / **`removeOverflowingEventBatches()`** — Manage event retention and overflow
- **`generateEventDataIndex()`** — Rebuilds the time-based event index from the database
- **`setOptimizeData()`** / **`getOptimizeData()`** — Read/write optimization cursors for incremental queries

### `Context` struct
Holds per-subscriber state: `database_namespace`, `event_index`, `last_query_time`, and `last_event_id`.

## Usage Example

```cpp
class MySubscriber : public EventSubscriber<MyPublisher> {
 public:
  Status init() override {
    auto sub = createSubscription<MySubscriptionContext>();
    return subscribe(&MySubscriber::eventCallback, sub);
  }

  Status eventCallback(const ECRef& ec, const SCRef& sc) {
    std::vector<Row> rows;
    Row r;
    r["action"] = ec->action;
    r["time"]   = std::to_string(ec->time);
    rows.push_back(r);
    return addBatch(rows);  // preferred over deprecated add()
  }
};

REGISTER(MySubscriber, "event_subscriber", "my_subscriber");
```
