Utility header for managing and validating file and socket descriptors within BPF process contexts on Linux, used primarily in osquery's event testing infrastructure.

## Key Components

### File Descriptor Functions

| Function | Description |
|----------|-------------|
| `setFileDescriptor(ProcessContext&, ...)` | Assigns a file descriptor with path and `close_on_exec` flag to a single process context |
| `setFileDescriptor(ProcessContextMap&, pid_t, ...)` | Same as above, but targets a specific PID within a process context map |
| `validateFileDescriptor(const ProcessContext&, ...)` | Verifies a file descriptor entry matches the expected path and flags in a process context |
| `validateFileDescriptor(const ProcessContextMap&, pid_t, ...)` | Same validation against a specific PID in a context map |

### Socket Descriptor Functions

| Function | Description |
|----------|-------------|
| `setSocketDescriptor(ProcessContext&, ...)` | Registers a socket descriptor with full network metadata (domain, type, protocol, addresses, ports) |
| `setSocketDescriptor(ProcessContextMap&, pid_t, ...)` | Same, targeting a specific PID in a process context map |
| `validateSocketDescriptor(const ProcessContext&, ...)` | Verifies socket descriptor properties match expected network metadata |
| `validateSocketDescriptor(const ProcessContextMap&, pid_t, ...)` | Same validation against a specific PID in a context map |

## Usage Example

```cpp
#include "utils.h"

osquery::ProcessContext ctx;

// Register a file descriptor
osquery::setFileDescriptor(ctx, 3, false, "/etc/hosts");

// Validate it was set correctly
bool ok = osquery::validateFileDescriptor(ctx, 3, false, "/etc/hosts");

// Register a socket descriptor
osquery::setSocketDescriptor(
    ctx, 4, false, AF_INET, SOCK_STREAM, IPPROTO_TCP,
    "127.0.0.1", 8080, "10.0.0.1", 443);

// Validate socket
bool sockOk = osquery::validateSocketDescriptor(
    ctx, 4, false, AF_INET, SOCK_STREAM, IPPROTO_TCP,
    "127.0.0.1", 8080, "10.0.0.1", 443);
```
