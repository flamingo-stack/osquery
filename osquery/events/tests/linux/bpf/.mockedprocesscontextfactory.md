Mock implementation of `IProcessContextFactory` for use in BPF event subsystem unit tests, providing controllable process context capture behavior.

## Key Components

### `MockedProcessContextFactory`
A `final` class implementing `IProcessContextFactory` with test-oriented controls:

| Member | Description |
|--------|-------------|
| `invocationCount()` | Returns how many times capture methods have been called |
| `failNextRequest()` | Causes the next capture call to return `false` (simulates failure) |
| `captureSingleProcess()` | Mocked override; captures context for a single PID |
| `captureAllProcesses()` | Mocked override; captures context for all processes |

**Private state:**
- `fail_next_request` — flag that triggers a controlled failure on the next capture call
- `invocation_count` — tracks total calls for assertion in tests; both are `mutable` to allow mutation from `const` overrides

## Usage Example

```cpp
#include <osquery/events/linux/bpf/mockedprocesscontextfactory.h>

// Basic capture
MockedProcessContextFactory factory;
ProcessContext ctx;
bool ok = factory.captureSingleProcess(ctx, 1234);
assert(ok);
assert(factory.invocationCount() == 1);

// Simulate a capture failure
factory.failNextRequest();
bool failed = factory.captureSingleProcess(ctx, 5678);
assert(!failed);

// Capture all processes
ProcessContextMap map;
factory.captureAllProcesses(map);
```
