Mock implementation of `IProcessContextFactory` for use in unit tests within the osquery Linux BPF event system.

## Key Components

- **`MockedProcessContextFactory`** — Concrete test double implementing `IProcessContextFactory`, providing controllable behavior for process context capture operations
- **`invocationCount()`** — Returns the number of times capture methods have been called, enabling call-count assertions in tests
- **`failNextRequest()`** — Arms the mock to return a failure on the next capture call, allowing error-path testing
- **`captureSingleProcess()`** — Mock override that captures context for a single process by PID
- **`captureAllProcesses()`** — Mock override that captures context for all running processes into a `ProcessContextMap`

## Private State

| Member | Type | Purpose |
|--------|------|---------|
| `fail_next_request` | `mutable bool` | Flags the next call to return failure |
| `invocation_count` | `mutable std::size_t` | Tracks total capture invocations |

## Usage Example

```cpp
#include "mockedprocesscontextfactory.h"

// Basic invocation tracking
MockedProcessContextFactory factory;
ProcessContext ctx;
factory.captureSingleProcess(ctx, 1234);
assert(factory.invocationCount() == 1);

// Test failure handling in your component
factory.failNextRequest();
bool result = factory.captureSingleProcess(ctx, 1234);
assert(result == false); // next call returns failure

// Verify all-process capture
ProcessContextMap process_map;
factory.captureAllProcesses(process_map);
assert(factory.invocationCount() == 2);
```

> **Note:** Both private fields are marked `mutable`, allowing state updates from `const`-qualified methods (`captureSingleProcess` and `captureAllProcesses` are `const` overrides).
