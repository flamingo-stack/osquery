A test double implementing the `IFilesystem` interface for use in unit tests, providing a mockable filesystem abstraction within the osquery BPF event subsystem.

## Key Components

### `MockedFilesystem`
A `final` class inheriting from `IFilesystem` that overrides all filesystem operations, enabling controlled, isolated testing without real filesystem access.

| Method | Description |
|--------|-------------|
| `open` | Mocked file open by path and flags |
| `openAt` | Mocked file open relative to a directory fd |
| `readLinkAt` | Mocked symbolic link resolution |
| `read` | Mocked file content read into a buffer |
| `enumFiles` | Mocked directory file enumeration via callback |
| `fileExists` | Mocked file existence check |

## Usage Example

```c
#include <osquery/events/linux/bpf/mockedfilesystem.h>

// Instantiate the mock in a test fixture
osquery::MockedFilesystem fs;

// Use in place of a real IFilesystem implementation
tob::utils::UniqueFd fd;
bool result = fs.open(fd, "/proc/self/status", O_RDONLY);

// Pass to components under test that depend on IFilesystem
MyBpfProcessor processor(fs);
processor.run();
```
