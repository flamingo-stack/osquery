A mock implementation of the `IDatabaseInterface` for use in unit tests, providing an in-memory key-value store backed by a `std::map`.

## Key Components

### `MockedOsqueryDatabase`
A `final` class implementing `IDatabaseInterface` with all database operations performed against an in-memory `std::map<std::string, std::string>`.

| Member | Description |
|--------|-------------|
| `key_map` | Mutable in-memory store holding all key-value pairs |
| `generateEvents()` | Seeds the mock with event data for a given publisher and event name |
| `getDatabaseValue()` | Retrieves a string or int value by domain/key |
| `setDatabaseValue()` | Stores a string or int value by domain/key |
| `setDatabaseBatch()` | Stores multiple string values in a single call |
| `deleteDatabaseValue()` | Removes a single key from the store |
| `deleteDatabaseRange()` | Removes all keys within a lexicographic range |
| `scanDatabaseKeys()` | Lists keys in a domain, optionally filtered by prefix and bounded by max count |

## Usage Example

```cpp
#include "mockedosquerydatabase.h"

// Instantiate the mock in a test
osquery::MockedOsqueryDatabase db;

// Write a value
db.setDatabaseValue("test_domain", "my_key", std::string("my_value"));

// Read it back
std::string result;
auto status = db.getDatabaseValue("test_domain", "my_key", result);
assert(status.ok());
assert(result == "my_value");

// Inspect raw store directly (useful for assertions)
assert(db.key_map.count("test_domain.my_key") > 0);

// Seed event data for event-related tests
db.generateEvents("my_publisher", "my_event");
```

## Notes

- Intended exclusively for **testing**; not suitable for production use.
- The `key_map` member is `mutable`, allowing reads to modify state (e.g., lazy initialization) even through `const` method signatures.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
