Defines the `Subscription` struct used to bind event callbacks to publisher-specific contexts within the osquery event framework.

## Key Components

- **`EventCallback`** — Type alias for a `std::function` accepting a `EventContextRef` and `SubscriptionContextRef`, returning a `Status`. This is the callback fired when a matching event occurs.
- **`SubscriptionRef`** — `std::shared_ptr<Subscription>` alias for shared ownership of subscriptions.
- **`SubscriptionVector`** — `std::vector<SubscriptionRef>` used by `EventPublisher` instances to track all registered subscriptions.
- **`Subscription`** (struct, non-copyable) — Core struct holding:
  - `subscriber_name` — Name of the owning `EventSubscriber`.
  - `context` — Publisher-specific `SubscriptionContextRef` defining event scope/filters.
  - `callback` — The `EventCallback` invoked on matching events.
  - `create()` — Static factory methods for constructing `SubscriptionRef` instances.

## Usage Example

```cpp
// Create a subscription with context and callback
auto ctx = std::make_shared<MySubscriptionContext>();
ctx->path = "/etc/passwd";

auto sub = Subscription::create(
    "MyEventSubscriber",
    ctx,
    [](const EventContextRef& ec, const SubscriptionContextRef& sc) -> Status {
        // Handle the event
        return Status::success();
    }
);

// Register via EventFactory
EventFactory::addSubscription("MyEventPublisher", sub);
```

## Notes

- `Subscription` inherits from `boost::noncopyable` — always managed via `SubscriptionRef` (shared pointer).
- The default constructor is explicitly deleted; use the `create()` static factory methods.
- See source: [`osquery/events/subscription.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/subscription.h)
