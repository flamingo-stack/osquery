Defines the `Subscription` struct used to configure an `EventPublisher` and bind a callback to a `SubscriptionContext` within the osquery event framework.

## Key Components

**Type Aliases**
- `EventCallback` — `std::function<Status(const EventContextRef&, const SubscriptionContextRef&)>` callback signature fired when a matching event occurs
- `SubscriptionRef` — `std::shared_ptr<Subscription>` smart pointer alias
- `SubscriptionVector` — `std::vector<SubscriptionRef>` for tracking multiple subscriptions per publisher

**`Subscription` struct** *(non-copyable)*
| Member | Type | Description |
|---|---|---|
| `subscriber_name` | `std::string` | Owning `EventSubscriber` name |
| `context` | `SubscriptionContextRef` | Publisher-specific filter/scope context |
| `callback` | `EventCallback` | Fired when a matching event is dispatched |

**Static Factory Methods**
- `create(name)` — Creates a bare subscription with no context or callback
- `create(name, context, callback)` — Creates a fully configured subscription ready for registration

## Usage Example

```cpp
#include <osquery/events/subscription.h>

// Define a callback
EventCallback my_callback = [](const EventContextRef& ec,
                               const SubscriptionContextRef& sc) -> Status {
  // Handle event
  return Status::success();
};

// Create a subscription context (publisher-specific)
auto ctx = std::make_shared<MySubscriptionContext>();
ctx->path = "/etc/passwd";

// Create and register the subscription
auto sub = Subscription::create("my_subscriber", ctx, my_callback);

EventFactory::addSubscription("MyEventPublisher", sub);
```

> **Note:** The default constructor is deleted — subscriptions must always be created via the named `create()` factory methods to ensure a valid `subscriber_name` is assigned.
