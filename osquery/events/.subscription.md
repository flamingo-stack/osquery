Defines the `Subscription` struct and related type aliases used to configure event publishers and bind callbacks within osquery's event framework.

## Key Components

- **`EventCallback`** — Type alias for `std::function<Status(const EventContextRef&, const SubscriptionContextRef&)>`; the callback signature fired when a matching event occurs.
- **`SubscriptionRef`** — `std::shared_ptr<Subscription>` for safe shared ownership.
- **`SubscriptionVector`** — `std::vector<SubscriptionRef>` used by publishers to track all active subscriptions.
- **`Subscription`** (struct) — Core non-copyable struct holding:
  - `subscriber_name` — Name of the owning `EventSubscriber`.
  - `context` — Publisher-specific `SubscriptionContextRef` defining event scope/filters.
  - `callback` — The `EventCallback` to invoke on matching events.
  - `create()` (static, x2) — Factory methods to construct a `SubscriptionRef`, with or without a context and callback.

## Usage Example

```cpp
#include <osquery/events/subscription.h>

// Define a callback
EventCallback my_callback = [](const EventContextRef& ec,
                                const SubscriptionContextRef& sc) -> Status {
  // Handle event
  return Status::success();
};

// Create a subscription context (publisher-specific)
auto ctx = std::make_shared<MySubscriptionContext>();
ctx->path = "/etc/passwd";

// Create the subscription
auto sub = Subscription::create("my_subscriber", ctx, my_callback);

// Register with the event publisher via EventFactory
EventFactory::addSubscription("MyEventPublisher", sub);
```

> **Note:** `Subscription` is non-copyable (`boost::noncopyable`). Always use `SubscriptionRef` (shared pointer) when passing or storing subscriptions. The default constructor is deleted — use the `create()` factory methods.
