Defines the distributed query system for osquery, providing data structures, serialization utilities, and plugin/manager classes for fetching, executing, and reporting remote queries.

## Key Components

### Structs
- **`DistributedQueryRequest`** — Holds a query string and its associated ID for a distributed query task
- **`DistributedQueryResult`** — Holds the results, column names, status, and message from an executed distributed query

### Free Functions
| Function | Description |
|---|---|
| `serializeDistributedQueryRequest[JSON]` | Serializes a request to a property tree or JSON string |
| `deserializeDistributedQueryRequest[JSON]` | Deserializes a request from a property tree or JSON string |
| `serializeDistributedQueryResult[JSON]` | Serializes a result to a property tree or JSON string |
| `deserializeDistributedQueryResult[JSON]` | Deserializes a result from a property tree or JSON string |
| `hashQuery` | Returns the SHA-256 hex digest of a query string |
| `denylistDuration` | Returns the configured denylist duration for distributed queries |
| `denylistedQueryTimestampExpired` | Checks whether a denylisted query's timeout has elapsed |

### Classes
- **`DistributedPlugin`** — Abstract plugin base class; implementations must define `getQueries()` and `writeResults()` for server communication
- **`Distributed`** — Orchestrates the full distributed query lifecycle: pulling work, executing queries, tracking denylist state, recording performance, and flushing results

## Usage Example

```cpp
#include <osquery/distributed/distributed.h>

// Typical poll-and-execute loop
auto dist = osquery::Distributed();
while (true) {
    dist.pullUpdates();
    if (dist.getPendingQueryCount() > 0) {
        dist.runQueries();
    }
}

// Serializing a request to JSON
osquery::DistributedQueryRequest req;
req.id    = "query-001";
req.query = "SELECT * FROM osquery_info";

std::string json;
auto status = osquery::serializeDistributedQueryRequestJSON(req, json);
if (!status.ok()) {
    // handle error
}
```
