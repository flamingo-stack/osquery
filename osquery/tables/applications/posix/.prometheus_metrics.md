Declares the interface for scraping and parsing Prometheus metrics endpoints within the osquery tables framework.

## Key Components

### Constants
| Constant | Value | Description |
|----------|-------|-------------|
| `kColTargetName` | `"target_name"` | Column name for the scraped target URL |
| `kColMetric` | `"metric_name"` | Column name for the metric identifier |
| `kColValue` | `"metric_value"` | Column name for the metric value |
| `kColTimeStamp` | `"timestamp_ms"` | Column name for the scrape timestamp |

### `PrometheusResponseData`
A struct holding the raw HTTP response body (`content`) and the scrape timestamp (`timestampMS`) for a single Prometheus target.

### `scrapeTargets()`
Performs HTTP scraping against one or more Prometheus `/metrics` endpoints. Accepts a map of target URLs to `PrometheusResponseData` structs (written in-place) and an optional timeout (default: 1 second).

### `parseScrapeResults()`
Converts the raw scrape map into osquery `QueryData` rows, populating the four standard columns defined by the constants above.

## Usage Example

```c
#include "prometheus_metrics.h"

using namespace osquery::tables;

// Define targets to scrape
std::map<std::string, PrometheusResponseData> results = {
    {"http://localhost:9090/metrics", {}},
    {"http://localhost:9100/metrics", {}},
};

// Scrape with a 3-second timeout
scrapeTargets(results, 3);

// Parse into osquery QueryData rows
QueryData rows;
parseScrapeResults(results, rows);

// rows now contains entries with columns:
// target_name, metric_name, metric_value, timestamp_ms
```

## Notes

- Both functions live in the `osquery::tables` namespace.
- `scrapeTargets` modifies `scrapeResults` in-place; initialize target URL keys before calling.
- Defined in [`osquery/tables/networking/prometheus_metrics.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/networking/prometheus_metrics.h).
