Defines the interface for scraping and parsing Prometheus metrics endpoints within the osquery tables subsystem.

## Key Components

**Constants**
- `kColTargetName` — Column name for the scraped target URL
- `kColMetric` — Column name for the metric name
- `kColValue` — Column name for the metric value
- `kColTimeStamp` — Column name for the timestamp in milliseconds

**Struct**
- `PrometheusResponseData` — Holds raw scrape response content (`std::string content`) and the scrape timestamp (`std::chrono::milliseconds timestampMS`)

**Functions**
- `parseScrapeResults()` — Parses raw Prometheus exposition-format payloads from a map of target URLs to `PrometheusResponseData`, writing structured rows into `QueryData`
- `scrapeTargets()` — HTTP-scrapes one or more Prometheus targets, populating a `PrometheusResponseData` map with response content and timestamps; accepts an optional timeout in seconds (default: `1`)

## Usage Example

```c
#include "prometheus_metrics.h"

// Define targets to scrape
std::map<std::string, osquery::tables::PrometheusResponseData> scrapeResults = {
    {"http://localhost:9090/metrics", {}},
    {"http://localhost:9100/metrics", {}},
};

// Scrape all targets with a 5-second timeout
osquery::tables::scrapeTargets(scrapeResults, 5);

// Parse scraped payloads into osquery QueryData rows
osquery::QueryData rows;
osquery::tables::parseScrapeResults(scrapeResults, rows);

// Each row contains: target_name, metric_name, metric_value, timestamp_ms
for (const auto& row : rows) {
    std::cout << row.at("target_name") << " | "
              << row.at("metric_name")  << " = "
              << row.at("metric_value") << std::endl;
}
```
