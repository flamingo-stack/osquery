Defines shared constants and utilities for the `jetbrains_plugins` osquery table, mapping JetBrains IDE product types to their per-OS plugin directory paths.

## Key Components

- **`JetBrainsProductType`** — Enum class enumerating all supported JetBrains products (CLion, DataGrip, GoLand, IntelliJ IDEA, PhpStorm, PyCharm, ReSharper, Rider, RubyMine, RustRover, WebStorm).
- **`ProductPathMap`** — Type alias for a vector of `(JetBrainsProductType, path_string)` tuples used to associate products with filesystem paths.
- **`kWindowsPathList`** — Constant path map resolving plugin directories under `AppData\Roaming\JetBrains\<Product>%\plugins` for each product.
- **`kMacOsPathList`** — Constant path map resolving plugin directories under `Library/Application Support/JetBrains/<Product>%/plugins`.
- **`kLinuxPathList`** — Constant path map resolving plugin directories under `.local/share/JetBrains/<Product>%`.
- **`kProductTypeToString`** — Maps each `JetBrainsProductType` enum value to a normalized lowercase string identifier (e.g., `"intellij_idea"`).
- **`getProductName()`** — Returns the string name for a given `JetBrainsProductType`.
- **`putMoreLikelyPluginJarsFirst()`** — Reorders a list of files within a plugin's `lib` directory so the most likely main JARs appear first.
- **`fileNameIsLikeVersionedLibraryName()`** — Predicate that checks whether a filename matches the pattern of a versioned library JAR.

## Usage Example

```cpp
#include "jetbrains_plugins.h"

using namespace osquery::tables;

// Look up the plugin directory paths for Windows
for (const auto& [product, path] : kWindowsPathList) {
  std::string name = getProductName(product);
  // path contains e.g. "AppData\\Roaming\\JetBrains\\CLion%\\plugins"
}

// Get the normalized product identifier
auto it = kProductTypeToString.find(JetBrainsProductType::PyCharm);
// it->second == "pycharm"
```

> **Source:** [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery) — The `%` wildcard in path strings is used at runtime to glob across installed product versions.
