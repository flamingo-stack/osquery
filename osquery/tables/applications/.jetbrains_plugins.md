Defines constants and utilities for locating and identifying JetBrains IDE plugin directories across Windows, macOS, and Linux platforms within the osquery tables namespace.

## Key Components

- **`JetBrainsProductType`** — Enum class enumerating 13 supported JetBrains IDEs: CLion, DataGrip, GoLand, IntelliJIdea, IntelliJIdeaCommunityEdition, PhpStorm, PyCharm, PyCharmCommunityEdition, ReSharper, Rider, RubyMine, RustRover, WebStorm.

- **`ProductPathMap`** — Type alias for `std::vector<std::tuple<JetBrainsProductType, std::string>>` mapping product types to relative plugin path patterns. The `%` wildcard in paths matches versioned directory suffixes (e.g., `CLion2024.1`).

- **`kWindowsPathList`** — Path map targeting `AppData\Roaming\JetBrains\<Product>%\plugins`.

- **`kMacOsPathList`** — Path map targeting `Library/Application Support/JetBrains/<Product>%/plugins`.

- **`kLinuxPathList`** — Path map targeting `.local/share/JetBrains/<Product>%`.

- **`kProductTypeToString`** — Maps `JetBrainsProductType` enum values to lowercase string identifiers (e.g., `intellij_idea`, `pycharm_community_edition`) used in osquery table output.

- **`getProductName()`** — Returns the string name for a given `JetBrainsProductType`.

- **`putMoreLikelyPluginJarsFirst()`** — Reorders a list of JAR files so the most likely plugin JARs appear first.

- **`fileNameIsLikeVersionedLibraryName()`** — Checks whether a filename matches the pattern of a versioned library name.

## Usage Example

```c
// Iterate plugin paths on macOS to discover installed plugins
for (const auto& [product, path] : osquery::tables::kMacOsPathList) {
    std::string name = osquery::tables::getProductName(product);
    // Expand % wildcard and enumerate plugins under resolved path
    std::cout << name << " -> " << path << std::endl;
}

// Reorder discovered JARs so primary plugin JARs come first
std::vector<std::string> jars = getFilesInLibDir(pluginDir);
osquery::tables::putMoreLikelyPluginJarsFirst(pluginDir, jars);
```
