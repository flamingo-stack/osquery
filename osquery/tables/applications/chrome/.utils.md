Utility header for Chrome-based browser extension and profile parsing within osquery's table generation system.

## Key Components

### Enums
- **`ChromeBrowserType`** — Enumerates supported Chromium-based browsers: Google Chrome (stable/beta/dev/canary), Brave, Chromium, Yandex, Opera, Edge, EdgeBeta, Vivaldi, and Arc

### Data Structures
- **`ChromeProfileSnapshot`** — Raw file snapshot of a Chrome profile, including `Preferences`, `Secure Preferences`, and maps of referenced/unreferenced extensions
- **`ChromeProfile`** — Parsed representation of a Chrome profile with a list of fully resolved `Extension` objects containing properties, manifest data, and content script matches
- **`ContentScriptsEntry`** — A `script`/`match` pair from a manifest's `content_scripts` block

### Key Functions

| Function | Description |
|---|---|
| `getChromeProfiles()` | Entry point — returns all Chrome-based browser profiles for a query context |
| `getChromeProfilesFromSnapshotList()` | Converts raw snapshots into parsed `ChromeProfile` objects |
| `getExtensionFromSnapshot()` | Parses a single extension from its raw snapshot |
| `computeExtensionIdentifier()` | Derives the extension ID from its `key` property |
| `webkitTimeToUnixTimestamp()` | Converts WebKit timestamps to Unix epoch format |
| `getExtensionProperty()` | Safely retrieves a named property from an extension |
| `getStringLocalization()` | Resolves a localized string from parsed `_locales` data |

## Usage Example

```cpp
#include "utils.h"

// Retrieve all Chrome profiles in an osquery table generator
osquery::tables::ChromeProfileList profiles =
    osquery::tables::getChromeProfiles(context);

for (const auto& profile : profiles) {
    for (const auto& ext : profile.extension_list) {
        std::string name = osquery::tables::getExtensionProperty(
            ext, "name", /*optional=*/false, "unknown");

        auto id = osquery::tables::computeExtensionIdentifier(ext);
        if (id.isValue()) {
            // use id.get()
        }
    }
}
```
