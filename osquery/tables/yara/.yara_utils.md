Utility header for YARA integration within osquery, providing rule compilation, scanning callbacks, file handling, and configuration parsing for YARA-based threat detection.

## Key Components

### `YaraRulesHandle`
RAII wrapper around `YR_RULES*` that automatically calls `yr_rules_destroy()` on destruction. Move-only (copy disabled) to ensure single ownership of compiled rule sets.

### `YaraCompilerResult`
Type alias: `Expected<YaraRulesHandle, YaraCompilerError>` — used as the return type for all compilation functions.

### Free Functions

| Function | Description |
|---|---|
| `yaraInitialize()` / `yaraFinalize()` | Lifecycle wrappers around the YARA library |
| `compileSingleFile(file)` | Compiles a YARA rule from a file path |
| `compileFromString(buffer)` | Compiles a YARA rule from an in-memory string |
| `handleRuleFiles(category, rule_files, rules)` | Processes a ptree of rule file paths into a named rules map |
| `yaraShouldSkipFile(path, st_mode)` | Guards against scanning files that may hang (e.g., special device files) |
| `YARACallback(...)` | Scan result callback passed to `yr_rules_scan_*` |
| `YARACompilerCallback(...)` | Compiler diagnostic callback for error/warning reporting |

### `YARAConfigParserPlugin`
A `ConfigParserPlugin` that registers the `"yara"` top-level config key and maintains a map of compiled rule groups (`category → YaraRulesHandle`) plus a URL allow-set for remote rule sources.

## Usage Example

```cpp
// Initialize YARA and compile rules from a file
yaraInitialize();

auto result = compileSingleFile("/etc/osquery/yara/malware.yar");
if (result) {
    YaraRulesHandle handle = std::move(result.get());
    yr_rules_scan_file(handle.get(), "/tmp/suspect", 0, YARACallback, &row, 0);
}

// Access parsed config rules via the plugin
auto parser = Config::getParser("yara");
auto& rules = parser->rules(); // map<string, YaraRulesHandle>

yaraFinalize();
```
