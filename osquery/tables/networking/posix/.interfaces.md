Declares the `genInterfaceDetails` table generation function for querying network interface details within the osquery tables subsystem.

## Key Components

- **`genInterfaceDetails(QueryContext& context)`** — Generates and returns a `QueryData` result set containing detailed information about network interfaces (e.g., name, address, flags, MTU). Registered as an osquery virtual table.

## Usage Example

```c
#include <osquery/tables/networking/interfaces.h>

namespace osquery {
namespace tables {

// Called internally by the osquery table dispatcher
QueryData genInterfaceDetails(QueryContext& context) {
    QueryData results;
    // Platform-specific implementation populates rows
    return results;
}

} // namespace tables
} // namespace osquery
```

## Notes

- Defined under the `osquery::tables` namespace.
- The implementation is platform-specific (Linux, macOS, Windows) and lives in corresponding `.cpp` files.
- Consumers interact with this indirectly via osquery SQL: `SELECT * FROM interface_details;`
- Source: [`osquery/tables/networking/interfaces.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/networking/interfaces.h)
