Utility header for network interface address formatting within the `osquery::tables` namespace.

## Key Components

- **`AF_INTERFACE` macro** — Platform-agnostic alias for interface address family (`AF_PACKET` on Linux, `AF_LINK` on BSD/macOS)
- **`ipAsString(const struct sockaddr *)`** — Converts a generic socket address to a human-readable IPv4/IPv6 string
- **`ipAsString(const struct in_addr *)`** — Overload for converting an `in_addr` struct directly to an IP string
- **`macAsString(const struct ifaddrs *)`** — Extracts and formats a MAC address from an `ifaddrs` interface entry
- **`macAsString(const char *)`** — Overload accepting a raw byte buffer representing a MAC address
- **`netmaskFromIP(const struct sockaddr *)`** — Returns the CIDR prefix length derived from a netmask socket address

## Usage Example

```c
#include "utils.h"
#include <ifaddrs.h>

struct ifaddrs *ifap;
getifaddrs(&ifap);

for (struct ifaddrs *ifa = ifap; ifa != nullptr; ifa = ifa->ifa_next) {
    if (ifa->ifa_addr == nullptr) continue;

    if (ifa->ifa_addr->sa_family == AF_INET) {
        std::string ip  = osquery::tables::ipAsString(ifa->ifa_addr);
        int prefix      = osquery::tables::netmaskFromIP(ifa->ifa_netmask);
        // e.g. ip = "192.168.1.10", prefix = 24
    }

    if (ifa->ifa_addr->sa_family == AF_INTERFACE) {
        std::string mac = osquery::tables::macAsString(ifa);
        // e.g. mac = "aa:bb:cc:dd:ee:ff"
    }
}

freeifaddrs(ifap);
```
