Utility header for network interface address formatting within the `osquery::tables` namespace.

## Key Components

- **`AF_INTERFACE`** — Cross-platform macro aliasing `AF_PACKET` (Linux) or `AF_LINK` (BSD/macOS) for interface-level address family detection.
- **`ipAsString(const struct sockaddr *)`** — Converts an IPv4 or IPv6 `sockaddr` struct to a human-readable string.
- **`ipAsString(const struct in_addr *)`** — Overload for converting an `in_addr` struct directly to a string.
- **`macAsString(const struct ifaddrs *)`** — Extracts and formats a MAC address from an `ifaddrs` entry.
- **`macAsString(const char *)`** — Overload for formatting a raw MAC address byte buffer.
- **`netmaskFromIP(const struct sockaddr *)`** — Derives the CIDR prefix length (netmask bit count) from a `sockaddr`.

## Usage Example

```c
#include "utils.h"
#include <ifaddrs.h>

struct ifaddrs *ifap;
getifaddrs(&ifap);

for (struct ifaddrs *ifa = ifap; ifa != nullptr; ifa = ifa->ifa_next) {
    if (ifa->ifa_addr == nullptr) continue;

    if (ifa->ifa_addr->sa_family == AF_INET) {
        // Print IPv4 address and its netmask prefix length
        std::string ip  = osquery::tables::ipAsString(ifa->ifa_addr);
        int prefix      = osquery::tables::netmaskFromIP(ifa->ifa_netmask);
        printf("%s/%d\n", ip.c_str(), prefix);
    }

    if (ifa->ifa_addr->sa_family == AF_INTERFACE) {
        // Print MAC address
        std::string mac = osquery::tables::macAsString(ifa);
        printf("MAC: %s\n", mac.c_str());
    }
}

freeifaddrs(ifap);
```
