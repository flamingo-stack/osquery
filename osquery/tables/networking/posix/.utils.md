Utility header for network interface address formatting within the osquery tables layer, providing cross-platform helpers to convert raw socket/address structures into human-readable strings.

## Key Components

| Symbol | Description |
|--------|-------------|
| `AF_INTERFACE` | Platform macro aliasing `AF_PACKET` (Linux) or `AF_LINK` (macOS/BSD) for interface-level address family detection |
| `ipAsString(sockaddr*)` | Converts an IPv4 or IPv6 `sockaddr` struct to a dotted-decimal or colon-hex string |
| `ipAsString(in_addr*)` | Overload accepting a raw `in_addr` struct for IPv4-only conversion |
| `macAsString(ifaddrs*)` | Extracts and formats a MAC address from an `ifaddrs` entry |
| `macAsString(char*)` | Overload accepting a raw byte pointer to a MAC address |
| `netmaskFromIP(sockaddr*)` | Returns the CIDR prefix length derived from a `sockaddr` netmask |

## Usage Example

```c
#include "utils.h"
#include <ifaddrs.h>

struct ifaddrs *ifap, *ifa;
getifaddrs(&ifap);

for (ifa = ifap; ifa != nullptr; ifa = ifa->ifa_next) {
    if (ifa->ifa_addr == nullptr) continue;

    int family = ifa->ifa_addr->sa_family;

    if (family == AF_INET || family == AF_INET6) {
        std::string ip  = osquery::tables::ipAsString(ifa->ifa_addr);
        int prefix      = osquery::tables::netmaskFromIP(ifa->ifa_netmask);
        // e.g. ip = "192.168.1.5", prefix = 24
    }

    if (family == AF_INTERFACE) {
        std::string mac = osquery::tables::macAsString(ifa);
        // e.g. mac = "aa:bb:cc:dd:ee:ff"
    }
}

freeifaddrs(ifap);
```

## Notes

- Defined under the `osquery::tables` namespace.
- `AF_INTERFACE` normalizes platform differences — no `#ifdef` needed in consumer code.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
