Defines the data structures and interface for querying Windows Firewall rules within osquery's table implementation, wrapping the Windows Firewall COM API (`netfw.h`).

## Key Components

### `WindowsFirewallError` (enum class)
Enumerates all possible error states when interacting with the Windows Firewall COM API, covering policy retrieval, rule enumeration, and individual rule property extraction failures.

### `WindowsFirewallRule` (struct)
Represents a single Windows Firewall rule with the following fields:

| Field | Type | Default |
|-------|------|---------|
| `name` | `std::string` | — |
| `appName` | `std::string` | — |
| `action` | `NET_FW_ACTION` | `NET_FW_ACTION_BLOCK` |
| `enabled` | `bool` | `false` |
| `grouping` | `std::string` | — |
| `direction` | `NET_FW_RULE_DIRECTION` | `NET_FW_RULE_DIR_IN` |
| `protocol` | `long` | `0` |
| `localAddresses` / `remoteAddresses` | `std::string` | — |
| `localPorts` / `remotePorts` | `std::string` | — |
| `icmpTypesCodes` | `std::string` | — |
| `profileBitmask` | `long` | `0` |
| `serviceName` | `std::string` | — |

### `WindowsFirewallRules` (type alias)
A `std::vector<WindowsFirewallRule>` used to pass collections of rules between components.

### `renderWindowsFirewallRules()`
Converts a `WindowsFirewallRules` collection into osquery `QueryData` for table output.

## Usage Example

```cpp
#include "windows_firewall_rules.h"

using namespace osquery::tables;

// Populate rules (typically from COM API enumeration)
WindowsFirewallRules rules;
WindowsFirewallRule rule;
rule.name       = "Allow HTTP";
rule.action     = NET_FW_ACTION_ALLOW;
rule.enabled    = true;
rule.direction  = NET_FW_RULE_DIR_IN;
rule.localPorts = "80";
rules.push_back(rule);

// Render into osquery table rows
QueryData rows = renderWindowsFirewallRules(rules);
```
