Declares the `genInterfaceDetails` function for querying network interface details as an osquery table.

## Key Components

- **`genInterfaceDetails(QueryContext& context)`** — Table generator function that retrieves network interface details and returns them as `QueryData`.

## Usage Example

```c
#include <osquery/tables/networking/interfaces.h>

namespace osquery {
namespace tables {

QueryData genInterfaceDetails(QueryContext& context) {
    QueryData results;
    // Enumerate network interfaces and populate rows
    return results;
}

} // namespace tables
} // namespace osquery
```

## Notes

- Resides in the `osquery::tables` namespace.
- Depends on [`osquery/core/core.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/core/core.h) and [`osquery/core/tables.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/core/tables.h).
- The implementation is platform-specific (Linux, macOS, Windows) and lives in corresponding `.cpp` files.
