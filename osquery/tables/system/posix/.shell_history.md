Declares internal helper functions for shell history table generation within osquery's `tables` namespace, supporting both standard user history parsing and macOS Bash Sessions.

## Key Components

- **`genShellHistoryFromBashSessions`** — Parses shell history from macOS Bash Sessions for a given user (`uid`) and home `directory`. Accepts a predicate callback to process each resulting `DynamicTableRowHolder`, enabling testable, injectable row handling.

- **`genShellHistoryForUser`** — Parses standard shell history files for a given user (`uid`, `gid`, `directory`). Also accepts a predicate callback for row processing, decoupling data generation from table population logic.

Both functions are designed with testability in mind — the predicate pattern allows unit tests to inject custom row consumers without requiring a live osquery table context.

## Usage Example

```c
#include "shell_history.h"

// Collect shell history rows for a specific user
osquery::tables::genShellHistoryForUser(
    "1000",       // uid
    "1000",       // gid
    "/home/alice", // home directory
    [](osquery::DynamicTableRowHolder& row) {
        // Process or assert on each history row
        row["username"] = "alice";
    }
);

// Collect history from macOS Bash Sessions
osquery::tables::genShellHistoryFromBashSessions(
    "501",
    "/Users/alice",
    [](osquery::DynamicTableRowHolder& row) {
        // Handle each session history entry
    }
);
```
