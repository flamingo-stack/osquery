Declares internal helper functions for generating shell history table rows within the `osquery::tables` namespace, used to support the `shell_history` virtual table implementation.

## Key Components

### Functions

- **`genShellHistoryFromBashSessions`** — Scans a user's directory for Bash session history files and emits rows via a predicate callback. Accepts `uid` and `directory` parameters.

- **`genShellHistoryForUser`** — Generates shell history rows for a specific user, accepting `uid`, `gid`, and `directory`. Handles standard shell history file parsing (e.g., `.bash_history`, `.zsh_history`).

Both functions accept a `std::function<void(DynamicTableRowHolder&)>` predicate, allowing callers (including unit tests) to intercept and inspect each emitted row without requiring a live osquery table context.

## Usage Example

```cpp
#include "shell_history.h"

osquery::tables::genShellHistoryForUser(
    "1000",           // uid
    "1000",           // gid
    "/home/alice",    // home directory
    [](osquery::DynamicTableRowHolder& row) {
        // Inspect or collect each history row
        auto command = row["command"];
    }
);

osquery::tables::genShellHistoryFromBashSessions(
    "1000",
    "/home/alice",
    [](osquery::DynamicTableRowHolder& row) {
        // Process Bash session-specific history entries
    }
);
```

## Notes

- Defined under `osquery::tables` — not part of the public osquery SDK.
- The predicate-based design decouples row emission from table registration, making both functions directly testable without mocking the full table engine.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
