Declares internal helper functions for generating shell history table rows from user shell history files and bash sessions.

## Key Components

- **`genShellHistoryFromBashSessions`** — Parses shell history entries from Bash session files within a given directory for a specified user ID. Accepts a predicate callback to process each resulting `DynamicTableRowHolder`.

- **`genShellHistoryForUser`** — Parses shell history entries for a specific user (by UID/GID) from a home directory. Also accepts a predicate callback for row handling.

Both functions are designed with testability in mind — the predicate parameter allows callers to inject custom row-handling logic without depending on a live query context.

## Usage Example

```cpp
#include "shell_history.h"

// Collect all shell history rows for a user
osquery::QueryData results;

osquery::tables::genShellHistoryForUser(
    "1000",       // uid
    "1000",       // gid
    "/home/alice", // home directory
    [&results](osquery::DynamicTableRowHolder& row) {
        results.push_back(row->get());
    }
);

// Collect history from active bash sessions
osquery::tables::genShellHistoryFromBashSessions(
    "1000",
    "/home/alice",
    [&results](osquery::DynamicTableRowHolder& row) {
        results.push_back(row->get());
    }
);
```

Both functions live in the `osquery::tables` namespace and integrate with the osquery virtual table framework via `DynamicTableRowHolder` from `osquery/sql/dynamic_table_row.h`.
