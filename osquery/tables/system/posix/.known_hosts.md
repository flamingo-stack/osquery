Declares the interface for querying SSH `known_hosts` files and extracting host key entries as osquery table data.

## Key Components

- **`getKnownHostsKeys(QueryContext& context)`** — Primary table generation function that retrieves all SSH known host key records, called by the osquery table plugin framework.
- **`impl::genSSHkeysForHosts(...)`** — Internal helper that parses a `known_hosts` file within a given user's directory, appending extracted key entries to the provided `QueryData` result set.

## Usage Example

```c
// Calling the top-level table function (invoked by osquery internally)
osquery::QueryContext context;
osquery::QueryData results = osquery::tables::getKnownHostsKeys(context);

// Using the impl helper directly (e.g., for a specific user's SSH directory)
osquery::QueryData results;
osquery::tables::impl::genSSHkeysForHosts(
    "1000",               // uid
    "1000",               // gid
    "/home/alice/.ssh",   // directory containing known_hosts
    results
);
```

## Notes

- Both functions operate within the `osquery::tables` namespace, following standard osquery table plugin conventions.
- `genSSHkeysForHosts` is scoped under `impl` to signal it is an internal implementation detail not intended for direct external use.
- The corresponding `.cpp` implementation handles actual file I/O and parsing of the `known_hosts` format.
