Header file declaring OpenSSL utility functions for extracting and parsing X.509 certificate attributes within the `osquery::tables` namespace.

## Key Components

All functions accept an `X509*` pointer and return `boost::optional<std::string>` (or `std::time_t`) — returning empty on failure.

| Function | Description |
|---|---|
| `generateCertificateSHA1Digest` | Computes SHA-1 fingerprint of a certificate |
| `getCertificateAttributes` | Extracts CA and self-signed boolean flags |
| `getCertificateKeyUsage` | Returns key usage extension string |
| `getCertificateSerialNumber` | Returns certificate serial number |
| `getCertificateAuthorityKeyID` | Returns Authority Key Identifier extension |
| `getCertificateSubjectKeyID` | Returns Subject Key Identifier extension |
| `getCertificateIssuerName` | Returns issuer distinguished name |
| `getCertificateSubjectName` | Returns subject distinguished name |
| `getCertificateCommonName` | Returns the CN field from the subject |
| `getCertificateSigningAlgorithm` | Returns the signature algorithm (e.g. `sha256WithRSAEncryption`) |
| `getCertificateKeyAlgorithm` | Returns the public key algorithm |
| `getCertificateKeyStregth` | Returns key strength/size in bits *(note: typo in symbol name)* |
| `getCertificateNotValidBefore` | Returns certificate start validity timestamp |
| `getCertificateNotValidAfter` | Returns certificate expiry timestamp |

## Usage Example

```cpp
#include "openssl_utils.h"
#include <openssl/pem.h>

// Assuming cert is a loaded X509*
X509* cert = /* ... load from file or store ... */;

bool is_ca = false, is_self_signed = false;
osquery::tables::getCertificateAttributes(cert, is_ca, is_self_signed);

auto sha1 = osquery::tables::generateCertificateSHA1Digest(cert);
if (sha1) {
    std::cout << "Fingerprint: " << *sha1 << "\n";
}

auto expiry = osquery::tables::getCertificateNotValidAfter(cert);
if (expiry) {
    std::cout << "Expires: " << std::ctime(&(*expiry));
}
```

## Notes

- `getCertificateIssuerName` and `getCertificateSubjectName` accept a `use_deprecated_output` flag to control legacy vs. RFC-compliant DN formatting.
- `getCertificateKeyStregth` contains a typo (`Stregth` vs `Strength`) — match the exact symbol name when calling.
