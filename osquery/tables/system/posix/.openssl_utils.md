Utility header for extracting metadata and attributes from OpenSSL X.509 certificate objects within the osquery tables framework.

## Key Components

All functions reside in the `osquery::tables` namespace and accept an `X509*` pointer, returning `boost::optional` values (empty on failure).

| Function | Returns | Description |
|----------|---------|-------------|
| `generateCertificateSHA1Digest` | `optional<string>` | SHA1 fingerprint of the certificate |
| `getCertificateAttributes` | `void` (out params) | Sets `is_ca` and `is_self_signed` flags |
| `getCertificateKeyUsage` | `optional<string>` | Comma-separated key usage extensions |
| `getCertificateSerialNumber` | `optional<string>` | Hex-encoded serial number |
| `getCertificateAuthorityKeyID` | `optional<string>` | Authority Key Identifier extension |
| `getCertificateSubjectKeyID` | `optional<string>` | Subject Key Identifier extension |
| `getCertificateIssuerName` | `optional<string>` | Issuer DN (with legacy format toggle) |
| `getCertificateSubjectName` | `optional<string>` | Subject DN (with legacy format toggle) |
| `getCertificateCommonName` | `optional<string>` | CN field from subject |
| `getCertificateSigningAlgorithm` | `optional<string>` | Signature algorithm (e.g. `sha256WithRSAEncryption`) |
| `getCertificateKeyAlgorithm` | `optional<string>` | Public key algorithm |
| `getCertificateKeyStregth` | `optional<string>` | Key size in bits *(note: typo in symbol name)* |
| `getCertificateNotValidBefore` | `optional<time_t>` | Certificate validity start timestamp |
| `getCertificateNotValidAfter` | `optional<time_t>` | Certificate validity end timestamp |

## Usage Example

```cpp
#include "openssl_utils.h"
#include <openssl/pem.h>

// Assuming `cert` is a loaded X509* object
if (auto sha1 = osquery::tables::generateCertificateSHA1Digest(cert)) {
    std::cout << "Fingerprint: " << *sha1 << "\n";
}

bool is_ca = false, is_self_signed = false;
osquery::tables::getCertificateAttributes(cert, is_ca, is_self_signed);

if (auto expiry = osquery::tables::getCertificateNotValidAfter(cert)) {
    // Compare *expiry against std::time(nullptr) to detect expired certs
}
```

> **Note:** `getCertificateKeyStregth` contains a typo in the original symbol name (`Stregth` vs `Strength`) — match exactly when calling.
