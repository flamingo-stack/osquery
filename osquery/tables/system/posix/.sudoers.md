Declares the interface for parsing and querying sudoers configuration files within the osquery tables subsystem.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `genSudoersFile` | Function | Parses a single sudoers file and appends discovered rules to `results`. Supports recursive includes via the `level` depth parameter. |
| `genSudoers` | Function | osquery table generator entry point; collects all sudoers data and returns a `QueryData` result set. |

Both symbols reside in the `osquery::tables` namespace.

## Usage Example

```c
#include "sudoers.h"

using namespace osquery;
using namespace osquery::tables;

// Directly parse a specific sudoers file (e.g., a drop-in include)
QueryData results;
genSudoersFile("/etc/sudoers", 0, results);

// Or invoke through the standard osquery table interface
QueryContext ctx;
QueryData rows = genSudoers(ctx);

for (const auto& row : rows) {
    // Each row contains sudoers rule fields (header, rule, source, etc.)
}
```

## Notes

- `level` in `genSudoersFile` guards against infinite recursion when sudoers files use `#include` or `@include` directives pointing to other files or directories.
- `genSudoers` is the canonical entry point registered with the osquery table registry; `genSudoersFile` is a lower-level helper used internally.
- See the full implementation at [`osquery/tables/system/posix/sudoers.cpp`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/system/posix/sudoers.cpp).
