Declares the interface for parsing and querying `sudoers` configuration files within the osquery tables framework.

## Key Components

### Functions

- **`genSudoersFile`** — Parses a single sudoers file (or included fragment) at a given include depth `level`, appending discovered rules into `results`. Handles recursive `#include` / `@include` directives via the `level` counter.
- **`genSudoers`** — Primary osquery table generator; accepts a `QueryContext` and returns a `QueryData` set representing all sudoers entries found on the system.

## Usage Example

```cpp
#include "sudoers.h"

// Direct file parsing
osquery::QueryData results;
osquery::tables::genSudoersFile("/etc/sudoers", 0, results);

// Via osquery table context
osquery::QueryContext ctx;
osquery::QueryData rows = osquery::tables::genSudoers(ctx);

for (const auto& row : rows) {
    // Each row contains sudoers rule fields
    // e.g., row.at("header"), row.at("source"), row.at("rule")
}
```

## Notes

- Both functions live under the `osquery::tables` namespace.
- The `level` parameter in `genSudoersFile` guards against infinite recursion from circular sudoers includes.
- `genSudoers` is the entry point registered with the osquery table registry; `genSudoersFile` is a lower-level helper intended for internal use.
