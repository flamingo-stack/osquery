Declares the interface for parsing SSH `authorized_keys` files and generating query results per user within the osquery tables subsystem.

## Key Components

### Functions

- **`genSSHkeysForUser`** — Parses the `authorized_keys` file for a specific user, populating a `QueryData` result set. Accepts the user's UID, GID, home directory path, a results container, and a logger instance.
- **`getAuthorizedKeys`** — Entry point for the osquery virtual table query; accepts a `QueryContext` and returns all authorized SSH keys across users as `QueryData`.

### Namespaces

- `osquery::tables` — Scopes both functions within the osquery tables module.

## Usage Example

```cpp
#include "authorized_keys.h"

namespace osquery {
namespace tables {

// Called by osquery's table dispatcher
QueryData getAuthorizedKeys(QueryContext& context) {
  QueryData results;
  GlogLogger logger;

  // Generate keys for a specific user
  genSSHkeysForUser("1001", "1001", "/home/alice", results, logger);

  return results;
}

} // namespace tables
} // namespace osquery
```

## Notes

- Defined under `osquery::tables` — implementations live in the corresponding `.cpp` file.
- `genSSHkeysForUser` is designed to be called per-user (e.g., iterated over `/etc/passwd` entries).
- Logging is abstracted via the `Logger` interface, with `GlogLogger` as the concrete implementation used in production.
