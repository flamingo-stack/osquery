Declares the interface for parsing SSH `authorized_keys` files within the osquery tables subsystem, exposing functions to enumerate authorized public keys per user.

## Key Components

- **`genSSHkeysForUser`** — Parses the `authorized_keys` file for a specific user (identified by `uid`, `gid`, and home `directory`), appending discovered key rows to the provided `QueryData` result set using the supplied `Logger`.
- **`getAuthorizedKeys`** — Primary osquery table query handler; accepts a `QueryContext` and returns a `QueryData` set of all authorized SSH keys found across users on the system.

## Usage Example

```cpp
#include "authorized_keys.h"

// Enumerate SSH keys for a single known user
osquery::QueryData results;
osquery::GlogLogger logger;

osquery::tables::genSSHkeysForUser(
    "1001",               // uid
    "1001",               // gid
    "/home/alice",        // home directory
    results,
    logger
);

// Or invoke the full table query via osquery context
osquery::QueryContext ctx;
osquery::QueryData allKeys = osquery::tables::getAuthorizedKeys(ctx);

for (const auto& row : allKeys) {
    // Each row contains fields: uid, key, key_file, type, comment, etc.
}
```
