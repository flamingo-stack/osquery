Declares the interface for the `last` table implementation, which queries historical login and session records from the system's `utmpx` database.

## Key Components

| Symbol | Description |
|--------|-------------|
| `genLastAccess(QueryContext&)` | Primary table generator; returns login/logout session rows from `utmpx` |
| `impl::genLastAccessForRow(const utmpx&, QueryData&)` | Internal helper that parses a single `utmpx` entry and appends a row to results |

## Usage Example

```c
#include "last.h"

// Invoke the table generator within the osquery table registration context
QueryContext context;
QueryData results = osquery::tables::genLastAccess(context);

// Process individual utmpx entries via the impl helper
utmpx entry;
// ... populate entry from system call ...
QueryData rows;
osquery::tables::impl::genLastAccessForRow(entry, rows);
```

## Notes

- Depends on `<utmpx.h>` (POSIX), so this implementation is **Unix/macOS-only**
- The `impl` namespace separates the per-row parsing logic, enabling targeted unit testing of individual `utmpx` record handling without invoking the full table scan
- Integrates with osquery's standard `QueryData` / `QueryContext` pipeline defined in [`osquery/core/tables.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/core/tables.h)
