Utility header providing context-aware helpers for resolving users and process IDs within osquery table implementations.

## Key Components

| Symbol | Description |
|--------|-------------|
| `usersFromContext` | Returns a set of user rows based on query context; defaults to current user if none specified |
| `pidsFromContext` | Returns a set of process rows based on query context; defaults to all PIDs if none specified |

Both functions live in the `osquery::tables` namespace and return `QueryData` (a collection of table rows).

## Usage Example

```c
#include "system_utils.h"

namespace osquery {
namespace tables {

QueryData genMyTable(QueryContext& context) {
  // Resolve users from query constraints, or fall back to current user
  QueryData users = usersFromContext(context);

  // Resolve PIDs from query constraints, or return all PIDs
  QueryData pids = pidsFromContext(context);

  QueryData results;
  for (const auto& user : users) {
    Row r;
    r["username"] = user.at("username");
    results.push_back(r);
  }
  return results;
}

} // namespace tables
} // namespace osquery
```

## Parameters

| Function | Parameter | Default | Behavior |
|----------|-----------|---------|----------|
| `usersFromContext` | `all` | `false` | When `true`, ignores context constraints and returns all users |
| `pidsFromContext` | `all` | `true` | When `true`, ignores context constraints and returns all PIDs |
