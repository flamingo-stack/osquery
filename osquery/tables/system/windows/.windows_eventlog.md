Header file declaring two helper functions for querying and parsing Windows Event Log data within the osquery tables framework.

## Key Components

### `parseWelXml`
```text
Status parseWelXml(QueryContext& context, std::wstring& xml_event, Row& row)
```
Parses a Windows Event Log entry rendered in XML format into an osquery `Row` for table output. Takes a query context, the wide-string XML event payload, and populates the result row.

### `genXfilterFromConstraints`
```text
void genXfilterFromConstraints(QueryContext& context, std::string& xfilter)
```
Generates an XPath filter string from query constraints that can be passed directly to the Windows `EvtQuery` API, enabling selective event filtering at the source.

## Usage Example

```c
#include <osquery/tables/events/windows_eventlog.h>

namespace osquery {
namespace tables {

QueryData genWindowsEventLog(QueryContext& context) {
  QueryData results;
  std::string xfilter;

  // Build XPath filter from SQL WHERE constraints
  genXfilterFromConstraints(context, xfilter);

  // ... query events using EvtQuery with xfilter ...

  std::wstring xml_event = /* retrieved XML event payload */;
  Row row;

  Status status = parseWelXml(context, xml_event, row);
  if (status.ok()) {
    results.push_back(row);
  }

  return results;
}

} // namespace tables
} // namespace osquery
```

## Notes

- Both functions reside in the `osquery::tables` namespace.
- `parseWelXml` uses `std::wstring` to correctly handle the wide-character encoding used by the Windows Event Log API.
- The generated `xfilter` string follows XPath syntax compatible with the Windows `EvtQuery` function.
