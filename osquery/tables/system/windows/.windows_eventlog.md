Header file declaring two helper utilities for querying and parsing Windows Event Log data within the osquery tables framework.

## Key Components

### `parseWelXml`
```text
Status parseWelXml(QueryContext& context, std::wstring& xml_event, Row& row)
```
Parses a Windows Event Log entry rendered in XML format (`xml_event`) and populates an osquery table `Row`. Returns a `Status` indicating parse success or failure.

### `genXfilterFromConstraints`
```text
void genXfilterFromConstraints(QueryContext& context, std::string& xfilter)
```
Derives an XPath filter string (`xfilter`) from the active `QueryContext` constraints. The resulting string is compatible with the Windows `EvtQuery` API for selective event filtering.

## Usage Example

```c
#include <osquery/tables/system/windows/windows_eventlog.h>

namespace osquery {
namespace tables {

QueryData genWindowsEventLog(QueryContext& context) {
  QueryData results;

  // Build XPath filter from query constraints (e.g., WHERE channel='System')
  std::string xfilter;
  genXfilterFromConstraints(context, xfilter);

  // ... open event log handle using xfilter with EvtQuery ...

  // For each raw XML event string retrieved:
  std::wstring xml_event = /* result from EvtRender */;
  Row row;
  Status s = parseWelXml(context, xml_event, row);
  if (s.ok()) {
    results.push_back(row);
  }

  return results;
}

} // namespace tables
} // namespace osquery
```

## Notes

- Both functions operate within the `osquery::tables` namespace.
- `parseWelXml` accepts a **wide string** (`std::wstring`) reflecting the UTF-16 encoding used by the Windows Event Log API.
- `xfilter` output from `genXfilterFromConstraints` is intended for direct use with `EvtQuery` from the Windows `winevt.h` API.
