Declares types and interfaces for querying Windows Update installation history via the Windows Update Agent (WUA) API, used by the osquery `windows_update_history` table implementation.

## Key Components

### Enum: `WindowsUpdateHistoryError`
Enumerates error states that may occur when querying update history, covering failures at each stage of the WUA query pipeline (e.g., `UpdateSearcherError`, `QueryError`, `EntryError`, `TitleError`, `UpdateIDError`).

### Struct: `WindowsUpdateHistoryEntry`
Represents a single Windows Update history record with fields populated from the WUA API:

| Field | Type | Description |
|---|---|---|
| `clientAppID` | `std::string` | Application that triggered the update |
| `date` | `LONGLONG` | Installation timestamp |
| `description` | `std::string` | Update description |
| `hresult` | `LONG` | Win32 result code |
| `updateOp` | `UpdateOperation` | Install or uninstall operation |
| `resultCode` | `OperationResultCode` | Outcome of the operation |
| `serverSelection` | `ServerSelection` | Source server (e.g., WSUS, Microsoft Update) |
| `serviceID` | `std::string` | GUID of the update service |
| `supportUrl` | `std::string` | Support URL for the update |
| `title` | `std::string` | Update display name |
| `updateID` | `std::string` | Unique update identifier |
| `updateRevision` | `LONG` | Update revision number |

### Type Alias: `WindowsUpdateHistory`
```c
using WindowsUpdateHistory = std::vector<WindowsUpdateHistoryEntry>;
```
A collection of update history entries.

### Function: `renderWindowsUpdateHistory`
```c
QueryData renderWindowsUpdateHistory(const WindowsUpdateHistory& history);
```
Converts a `WindowsUpdateHistory` vector into osquery `QueryData` rows for table output.

## Usage Example

```c
WindowsUpdateHistory history = fetchUpdateHistory(); // populated via WUA COM API
QueryData rows = renderWindowsUpdateHistory(history);
// rows is returned as the osquery table result
```
