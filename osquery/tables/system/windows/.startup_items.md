Declares a utility function for parsing macOS startup item path entries within the osquery tables subsystem.

## Key Components

### `parseStartupPath`

```text
bool parseStartupPath(const std::string& entry, Row& r)
```

Parses a raw startup entry string, extracting the executable path and any arguments, storing them in the provided `Row` as `path` and `args` fields respectively.

| Parameter | Type | Description |
|-----------|------|-------------|
| `entry` | `const std::string&` | Raw startup path string to parse |
| `r` | `Row&` | Output row where `path` and `args` are written |
| **returns** | `bool` | `true` on success, `false` if parsing fails |

## Usage Example

```c
#include "startup_items.h"

osquery::Row row;
std::string entry = "/usr/bin/myapp --flag1 --flag2";

if (osquery::tables::parseStartupPath(entry, row)) {
    // row["path"] == "/usr/bin/myapp"
    // row["args"] == "--flag1 --flag2"
} else {
    // Handle malformed entry
}
```

## Notes

- Defined under the `osquery::tables` namespace, consistent with other osquery table helpers
- Used internally by the `startup_items` table implementation to normalize entries sourced from macOS startup plist files
- Source: [`startup_items.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/system/darwin/startup_items.h)
