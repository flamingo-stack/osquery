Header file declaring a Windows MSI registry GUID decoding utility within the osquery tables namespace.

## Key Components

- **`decodeMsiRegistryGuid(const std::string& encoded)`** — Converts a registry-encoded GUID (32-char compact format) into a standard formatted GUID string.

## Usage Example

```c
#include "programs.h"

// Encoded registry GUID (32 chars, no hyphens/braces)
std::string encoded = "0D8797326E7E4114DAECB3B66B9CD045";

std::string guid = osquery::tables::decodeMsiRegistryGuid(encoded);
// Returns: "{237978D0-E7E6-4114-ADCE-3B6BB6C90D54}"

// Invalid input returns empty string
std::string invalid = osquery::tables::decodeMsiRegistryGuid("short");
// Returns: ""
```

## Notes

- Input must be exactly **32 characters** long; shorter or longer strings return an empty string.
- Used internally by the `programs` table to decode MSI product GUIDs stored in the Windows registry under paths like `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Installer\UserData`.
