Header file declaring a Windows MSI GUID decoding utility used within osquery's table generation framework.

## Key Components

### `decodeMsiRegistryGuid`
```text
Namespace: osquery::tables
Signature: std::string decodeMsiRegistryGuid(const std::string& encoded)
```

Converts a registry-encoded MSI GUID (32-character packed format) into a standard human-readable GUID string.

- **Input:** 32-character encoded string (e.g., `"0D8797326E7E4114DAECB3B66B9CD045"`)
- **Output:** Standard GUID format (e.g., `"{237978D0-E7E6-4114-ADCE-3B6BB6C90D54}"`)
- **On invalid input:** Returns an empty string (input must be exactly 32 characters)

## Usage Example

```c
#include "programs.h"

// Registry stores MSI GUIDs in a packed, reordered format
std::string encoded = "0D8797326E7E4114DAECB3B66B9CD045";
std::string guid = osquery::tables::decodeMsiRegistryGuid(encoded);

if (!guid.empty()) {
    // guid == "{237978D0-E7E6-4114-ADCE-3B6BB6C90D54}"
    // Use guid for installed programs table lookup
}
```

## Notes

- Declared within the `osquery::tables` namespace, consistent with osquery's table plugin conventions
- Depends on `osquery/core/core.h` and `osquery/core/tables.h`
- Primarily used when enumerating installed Windows programs from the MSI registry hive
