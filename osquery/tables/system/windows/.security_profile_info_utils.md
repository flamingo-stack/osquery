Utility header providing Windows Security Configuration Engine (SCE) RPC client access for retrieving system security profile information via `scecli.dll`.

## Key Components

### `SceClientHelper` (Singleton Class)
Manages dynamic linking to `scecli.dll` and exposes the undocumented SCE RPC client API.

| Member | Description |
|--------|-------------|
| `SceProfileInfo` | Struct mapping the SCE RPC protocol response — password policy, audit settings, account lockout, and log configuration |
| `instance()` | Returns the global singleton instance |
| `getSceSecurityProfileInfo()` | Calls `SceGetSecurityProfileInfo()` from `scecli.dll` to fetch system security profile |
| `releaseSceProfileData()` | Calls `SceFreeMemory()` from `scecli.dll` to free profile memory |
| `isWow64Process()` | Detects WoW64 (32-bit process on 64-bit Windows) via `IsWow64Process()` |
| `initialize()` | Performs run-time dynamic linking to resolve `scecli.dll` exports |

### `SceProfileData` (RAII Wrapper Struct)
Scoped manager for the memory returned by the SCE RPC server.

| Member | Description |
|--------|-------------|
| `getProfileInfo()` | Returns a typed pointer to the underlying `SceProfileInfo` data |
| `~SceProfileData()` | Destructor automatically calls `SceFreeMemory()` on scope exit |
| `getNormalizedInt()` | Normalizes `DWORD -1` (max value sentinel used in SCE protocol) to signed `-1` |

## Usage Example

```c
// Acquire SCE profile data with automatic memory management
osquery::tables::SceProfileData profileData;

auto& sce = osquery::tables::SceClientHelper::instance();
PVOID rawData = nullptr;

Status status = sce.getSceSecurityProfileInfo(rawData);
if (!status.ok()) {
    // handle error
}

// Access typed profile fields
const auto* info = profileData.getProfileInfo();
if (info != nullptr) {
    int minAge = SceProfileData::getNormalizedInt(info->MinPasswdAge);
    int maxAge = SceProfileData::getNormalizedInt(info->MaxPasswdAge);
    // Memory freed automatically when profileData goes out of scope
}
```

> **Platform note:** This header is Windows-only. It targets `scecli.dll` exports (`SceGetSecurityProfileInfo`, `SceFreeMemory`) that have been stable since Windows 7 but are undocumented.
