Windows certificate store parsing utilities for osquery's certificates table implementation.

## Key Components

### Type Aliases

- **`ServiceNameMap`** — `std::unordered_map<std::string, std::string>` used to cache service name-to-SID mappings, avoiding redundant lookups.

### Constants

| Constant | Value | Description |
|---|---|---|
| `kLocalSystem` | `S-1-5-18` | SID for the Local System account |
| `kLocalService` | `S-1-5-19` | SID for the Local Service account |
| `kNetworkService` | `S-1-5-20` | SID for the Network Service account |

### Functions

- **`parseSystemStoreString`** — Parses a Windows system certificate store path (`LPCWSTR`) into its constituent parts: store location, service name or user ID, SID, and store name. Uses a `ServiceNameMap` cache to optimize repeated service name resolutions.

## Usage Example

```c
#include "certificates.h"

// Initialize the service-to-SID cache
osquery::tables::ServiceNameMap serviceCache;

std::string storeLocation = "LocalMachine";
std::string serviceNameOrUserId;
std::string sid;
std::string storeName;

LPCWSTR systemStore = L"MY"; // Example store path

osquery::tables::parseSystemStoreString(
    systemStore,
    storeLocation,
    serviceCache,
    serviceNameOrUserId,
    sid,
    storeName
);

// sid may match kLocalSystem, kLocalService, or kNetworkService
// storeName will contain the parsed certificate store name
```

## Notes

- Windows-only header; relies on `LPCWSTR` (Windows wide-string type).
- Part of the `osquery::tables` namespace within the broader osquery framework.
