Windows certificate store parsing utilities for the osquery tables subsystem.

## Key Components

**Type Alias**
- `ServiceNameMap` — `std::unordered_map<std::string, std::string>` mapping service names to SIDs

**Constants**

| Name | Value | Description |
|------|-------|-------------|
| `kLocalSystem` | `S-1-5-18` | Well-known SID for Local System account |
| `kLocalService` | `S-1-5-19` | Well-known SID for Local Service account |
| `kNetworkService` | `S-1-5-20` | Well-known SID for Network Service account |

**Function**
- `parseSystemStoreString` — Parses a Windows certificate system store path (`LPCWSTR`) into its constituent parts: store location, service name or user ID, SID, and store name. Uses a cache (`service2sidCache`) to avoid redundant service-to-SID lookups.

## Usage Example

```cpp
#include "certificates.h"

osquery::tables::ServiceNameMap sidCache;
std::string serviceNameOrUserId;
std::string sid;
std::string storeName;

osquery::tables::parseSystemStoreString(
    L"LocalService\\My",
    "LocalService",
    sidCache,
    serviceNameOrUserId,
    sid,
    storeName
);

// sid     => "S-1-5-19"
// storeName => "My"
```

## Notes

- Windows-only header (uses `LPCWSTR`)
- Intended for internal use within the `osquery::tables` namespace to enumerate and populate certificate table data
- The `service2sidCache` parameter is mutated in-place to cache resolved SID lookups across multiple calls
