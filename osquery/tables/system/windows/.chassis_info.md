Queries Windows WMI (`Win32_SystemEnclosure`) to retrieve physical chassis/enclosure hardware information and exposes it as an osquery table.

## Key Components

- **`genChassisInfo(QueryContext&)`** — Main table generation function that executes a WMI query, maps raw SMBIOS chassis type codes to human-readable strings, and returns structured `QueryData`.
- **`enclosureTypes`** — SMBIOS DSP0134-compliant lookup map translating chassis type hex codes (`0x01`–`0x24`) to descriptive strings (e.g., `"Laptop"`, `"Blade"`, `"IoT Gateway"`).
- **`securityBreachStatus`** — Lookup map translating WMI `SecurityBreach` numeric codes to status strings (e.g., `"No Breach"`, `"Breach Successful"`).

## Usage Example

```cpp
// Called internally by osquery's table registry.
// Query via osquery shell or SDK:
//   SELECT * FROM chassis_info;
//
// Example result:
//   manufacturer = "Dell Inc."
//   chassis_types = "Notebook"
//   security_breach = "No Breach"
//   lock = "True"
//   serial = "ABC1234"

QueryData results = genChassisInfo(context);
```

> **Note:** Multiple chassis types are concatenated as a comma-separated string. Unknown type codes are represented as `"Unknown (N)"` where `N` is the raw numeric value. Returns an empty result with a `WARNING` log if WMI is unavailable.
