Header defining Windows Registry query utilities for osquery's table implementation, providing helpers for key enumeration, glob expansion, and COM class resolution.

## Key Components

**Constants**
- `kRegSep` — Registry path separator (`\`)
- `kDefaultRegName` — Default key name string `(Default)`
- `kRegMaxRecursiveDepth` — Maximum recursion depth for registry traversal (`32`)

**Functions**

| Function | Description |
|---|---|
| `queryKey` | Queries a single registry key path and returns results |
| `queryMultipleRegistryKeys` | Batch-queries multiple keys with LIKE pattern support |
| `queryMultipleRegistryPaths` | Batch-queries multiple full registry paths |
| `getClassName` | Resolves a CLSID (e.g. `{0000002F-...}`) to a human-readable class name |
| `getClassExecutables` | Returns executables (`.dll`, `.exe`) associated with a CLSID |
| `expandRegistryGlobs` | Expands SQL glob patterns (e.g. `HKEY_LOCAL_MACHINE\%\Microsoft`) into matching key sets |
| `explodeRegistryPath` | Splits a full path into HIVE and KEY components |
| `getUsernameFromKey` | Extracts a username from an `HKEY_USERS\<SID>\...` path |
| `populateSubkeys` | Expands a key set with discovered subkeys |

## Usage Example

```cpp
#include <osquery/tables/system/windows/registry.h>

using namespace osquery::tables;

// Query a single key
QueryData results;
auto status = queryKey("HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft", results);

// Expand a glob pattern then batch query
std::set<std::string> keys;
expandRegistryGlobs("HKEY_LOCAL_MACHINE\\%\\Run", keys);
queryMultipleRegistryKeys({keys.begin(), keys.end()}, results);

// Split a path into hive + key
std::string hive, key;
explodeRegistryPath("HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft", hive, key);
// hive = "HKEY_LOCAL_MACHINE", key = "SOFTWARE\\Microsoft"

// Resolve a CLSID to executables
std::vector<std::string> execs;
getClassExecutables("{0000002F-0000-0000-C000-000000000046}", execs);
```
