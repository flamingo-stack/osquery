Utility header providing Windows Registry query and traversal helpers for osquery's registry table implementation.

## Key Components

### Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `kRegSep` | `"\\"` | Registry path separator |
| `kDefaultRegName` | `"(Default)"` | Default registry key name |
| `kRegMaxRecursiveDepth` | `32` | Maximum recursion depth for registry traversal |

### Functions

- **`queryKey`** — Queries a single registry key path and appends results to `QueryData`
- **`queryMultipleRegistryKeys`** — Batch-queries multiple registry keys using LIKE matching
- **`queryMultipleRegistryPaths`** — Batch-queries multiple registry paths using LIKE matching
- **`getClassName`** — Resolves a COM Class ID (CLSID) to its human-readable class name
- **`getClassExecutables`** — Returns all executables (`.dll`, `.exe`, etc.) associated with a CLSID across all hives
- **`expandRegistryGlobs`** — Expands SQL glob patterns (e.g., `HKEY_LOCAL_MACHINE\%\Microsoft`) into a concrete set of matching registry keys
- **`explodeRegistryPath`** — Splits a full registry path into its HIVE and KEY components
- **`getUsernameFromKey`** — Extracts a username from an `HKEY_USERS\<SID>\...` path
- **`populateSubkeys`** — Expands a set of registry keys to include their immediate subkeys

## Usage Example

```c
#include <osquery/tables/system/windows/registry.h>

// Query a single key
QueryData results;
auto status = queryKey("HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft", results);

// Expand a glob pattern into matching keys
std::set<std::string> keys;
expandRegistryGlobs("HKEY_LOCAL_MACHINE\\%\\Microsoft", keys);

// Split a path into hive and key
std::string hive, key;
explodeRegistryPath("HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft", hive, key);
// hive = "HKEY_LOCAL_MACHINE", key = "SOFTWARE\\Microsoft"

// Resolve a username from HKEY_USERS
std::string username;
getUsernameFromKey("HKEY_USERS\\S-1-5-19\\Software", username);
// username = "LOCAL SERVICE"
```
