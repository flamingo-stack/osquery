Queries Linux EFI variable files to determine Secure Boot and Setup Mode status for the `secureboot` osquery table.

## Key Components

- **`kEfiVarsDirectory`** — Path constant pointing to `/sys/firmware/efi/efivars`, the world-readable EFI variables interface
- **`readBoolEfiVar()`** — Internal helper that reads a 5-byte EFI variable file, skipping the 4-byte attribute prefix and interpreting the 5th byte as a boolean (`0`, `1`, or `-1` for unknown)
- **`genSecureBoot()`** — Main table generation function; validates UEFI firmware presence, then populates `secure_boot` and `setup_mode` columns

## Behavior Notes

- Returns an empty result set if the firmware type cannot be determined or is not UEFI
- Silently skips EFI variable reads that fail (e.g., kernel lacks EFI var support, or EFI vars not mounted)
- Uses `/sys/firmware/efi/efivars` (world-readable single-file interface) over `/sys/firmware/efi/vars` (root-only) to avoid privilege requirements
- Kernel enforces a 100 reads/second rate limit on non-root EFI reads — noted but not mitigated

## Usage Example

```cpp
// Invoked internally by the osquery table registry
QueryData result = genSecureBoot(context);

// Resulting row contains:
// result[0]["secure_boot"] => "0" | "1" | "-1"
// result[0]["setup_mode"]  => "0" | "1" | "-1"
```

```bash
# Query via osquery CLI
osqueryi "SELECT secure_boot, setup_mode FROM secureboot;"
```
