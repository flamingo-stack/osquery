Header file defining data structures and interfaces for querying Linux MD (Multiple Device) RAID array information within the osquery tables framework.

## Key Components

### Data Structures

| Struct | Purpose |
|--------|---------|
| `MDDrive` | Represents a single drive in an MD array (name, position) |
| `MDAction` | Tracks ongoing array operations (progress, finish time, speed) |
| `MDBitmap` | Holds bitmap metadata (memory usage, chunk size, external file) |
| `MDDevice` | Complete MD array descriptor including drives, status, RAID level, and active operations |
| `MDStat` | Top-level container for parsed `/proc/mdstat` data (personalities, devices, unused) |

### Classes

- **`MDInterface`** — Abstract base class defining the contract for MD driver interaction and mdstat parsing. Enables dependency injection and testability.
- **`MD`** — Concrete implementation of `MDInterface` that performs actual ioctl calls and filesystem reads.

### Free Function

- **`getDrivesForArray`** — Populates `QueryData` with drive-level details for a named MD array using a provided `MDInterface` instance.

### Virtual Methods on `MDInterface`

| Method | Description |
|--------|-------------|
| `getDiskInfo` | Retrieves disk info via MD ioctl |
| `getArrayInfo` | Retrieves array info via MD ioctl |
| `parseMDStat` | Parses `/proc/mdstat` lines into `MDStat` |
| `getPathByDevName` | Resolves device path from short name (e.g., `md0`) |
| `getDevName` | Resolves device name from major/minor numbers |
| `getSuperblkVersion` | Returns the superblock version of an array |

## Usage Example

```c
// Instantiate the concrete MD implementation
osquery::tables::MD md;
osquery::tables::MDStat stat;

// Parse /proc/mdstat lines
std::vector<std::string> lines = readMdstatLines();
md.parseMDStat(lines, stat);

// Fetch drive details for a specific array
osquery::QueryData results;
osquery::tables::getDrivesForArray("md0", md, results);
```
