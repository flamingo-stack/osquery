Defines data structures and a database class for parsing and querying PCI device information from the system `pci.ids` file, along with utility functions for extracting PCI attributes into osquery table rows.

## Key Components

### Structs

- **`PciModel`** — Holds a PCI device model's ID, description, and a map of subsystem information keyed by `"<subsystem_vendor_id> <subsystem_model_id>"`.
- **`PciVendor`** — Holds a vendor's ID, name, and a map of `PciModel` entries keyed by device ID.

### Class: `PciDB`

Parses a `pci.ids` filestream and provides lookup methods:

| Method | Description |
|---|---|
| `PciDB(std::istream&)` | Constructor; parses the `pci.ids` stream |
| `getVendorName()` | Looks up a vendor name by vendor ID |
| `getModel()` | Looks up a model description by vendor + model ID |
| `getSubsystemInfo()` | Looks up subsystem description by vendor, model, and subsystem IDs |

Private parsing helpers (`parseLine`, `parseVendor`, `parseModel`, `parseSubsystem`) handle line-by-line processing of the `pci.ids` format.

### Free Functions

- **`extractVendorModelFromPciDBIfPresent()`** — Populates an osquery `Row` with vendor/model data from sysfs device and subsystem ID attributes using a `PciDB` instance.
- **`extractPCIClassIDAttrs()`** — Populates an osquery `Row` with PCI class identifier fields parsed from a sysfs class attribute string.

## Usage Example

```cpp
#include <fstream>
#include "pci_devices.h"

// Parse the system pci.ids file
std::ifstream pci_ids("/usr/share/hwdata/pci.ids");
osquery::tables::PciDB pcidb(pci_ids);

// Look up vendor and model info
std::string vendor, model;
pcidb.getVendorName("8086", vendor);  // e.g., "Intel Corporation"
pcidb.getModel("8086", "1234", model);

// Populate an osquery row from sysfs attributes
osquery::Row row;
osquery::tables::extractVendorModelFromPciDBIfPresent(
    row, "0x80861234", "0x80861234", pcidb);
```
