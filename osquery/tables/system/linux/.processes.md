Declares a utility function for parsing Linux process cgroup information within the osquery tables namespace.

## Key Components

- **`parseProcCGroup(const std::string& content)`** — Parses the raw string content of a process's cgroup file (e.g., `/proc/<pid>/cgroup`) and returns a normalized string representation.

## Usage Example

```c
#include "processes.h"

std::string cgroupContent = "12:cpu:/user.slice\n11:memory:/system.slice";
std::string parsed = osquery::tables::parseProcCGroup(cgroupContent);
// parsed contains the normalized cgroup information
```

## Notes

- Resides in the `osquery::tables` namespace
- Typically used internally by osquery's process-related table implementations on Linux
- Input is expected to be the raw text content read from the `/proc` filesystem cgroup entries
