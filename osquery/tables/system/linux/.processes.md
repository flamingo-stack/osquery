Declares a utility function for parsing Linux process cgroup information within the osquery tables namespace.

## Key Components

- **`parseProcCGroup(const std::string& content)`** — Parses raw `/proc/<pid>/cgroup` file content and returns a structured string representation of the cgroup data.

## Usage Example

```c
#include "processes.h"

std::string cgroupContent = "12:cpuset:/\n11:memory:/system.slice\n";
std::string parsed = osquery::tables::parseProcCGroup(cgroupContent);
```

## Notes

- Lives under the `osquery::tables` namespace, consistent with other osquery table implementations.
- Intended for internal use by process-related table implementations on Linux.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
