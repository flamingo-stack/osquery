Provides a RAII wrapper for managing D-Bus connection lifecycle, ensuring automatic allocation and cleanup of `DBusConnection` resources in the osquery Linux system tables layer.

## Key Components

### `UniqueDbusConnectionAllocator`
An allocator policy class that implements the resource management strategy for `DBusConnection*` pointers:

- **`allocate(ResourceType& connection, bool system)`** — Opens a D-Bus connection; the `bool` parameter selects between the system bus (`true`) or session bus (`false`).
- **`deallocate(ResourceType& connection)`** — Releases and cleans up the `DBusConnection*` resource safely.

### `UniqueDbusConnection`
A type alias instantiating `UniqueResource<UniqueDbusConnectionAllocator, bool>` — a RAII handle that automatically deallocates the D-Bus connection when it goes out of scope.

## Usage Example

```c
#include <osquery/tables/system/linux/dbus/uniquedbusconnection.h>

namespace osquery {

void queryDbusProperty() {
    // Acquire a system bus connection (true = system bus)
    UniqueDbusConnection connection(true);

    if (!connection.isValid()) {
        // Handle allocation failure
        return;
    }

    // Use connection.get() to access the raw DBusConnection*
    DBusConnection* raw = connection.get();

    // Connection is automatically released when 'connection' goes out of scope
}

} // namespace osquery
```

## Notes

- Depends on `uniqueresource.h` for the generic `UniqueResource` RAII template and `dbus/dbus.h` for the D-Bus C API types.
- Scoped to the `osquery` namespace.
- Linux-specific; lives under the `tables/system/linux/dbus/` path.
