Defines the D-Bus method handler for querying systemd's `ListUnits` RPC, mapping the response into structured `Unit` objects for osquery's Linux system tables.

## Key Components

**`ListUnitsMethodHandler`** — Core handler class implementing the D-Bus `org.freedesktop.systemd1.Manager.ListUnits` method.

| Member | Description |
|--------|-------------|
| `kDestination` | D-Bus service name: `org.freedesktop.systemd1` |
| `kInterface` | Target interface: `org.freedesktop.systemd1.Manager` |
| `kMethod` | Method name: `ListUnits` |
| `Unit` | POD struct holding a single systemd unit's metadata |
| `Output` | Type alias for `std::vector<Unit>` |
| `parseReply()` | Deserializes a raw `DBusMessage` reply into an `Output` vector |
| `readUnitInformation()` | Reads a single unit's fields from a `DBusMessageIter` |

**`ListUnitsMethod`** — Convenience alias combining the handler with the generic `DbusMethod<>` template for dispatch.

**`Unit` struct fields:**

```text
id, description, load_state, active_state,
sub_state, following, path, job_id, job_type, job_path
```

## Usage Example

```c
// Instantiate and invoke the method via the type alias
osquery::ListUnitsMethod method;
osquery::ListUnitsMethodHandler::Output units;

auto conn = /* acquire DBusConnection */;
auto status = method.call(conn, units);

if (status.ok()) {
    for (const auto& unit : units) {
        printf("Unit: %s | State: %s\n",
               unit.id.c_str(),
               unit.active_state.c_str());
    }
}
```

> `ListUnitsMethod` is the primary entry point; direct use of `ListUnitsMethodHandler` is discouraged as its constructor is `protected`.
