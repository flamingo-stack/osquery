Defines the D-Bus method handler for querying systemd unit information via the `org.freedesktop.systemd1.Manager.ListUnits` interface on Linux.

## Key Components

### `ListUnitsMethodHandler`
Core handler class that implements the D-Bus call to enumerate all systemd units.

**Constants**
- `kDestination` — D-Bus service name: `org.freedesktop.systemd1`
- `kInterface` — Target interface: `org.freedesktop.systemd1.Manager`
- `kMethod` — Method name: `ListUnits`

**`Unit` struct**
Represents a single systemd unit with the following fields:

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Unit identifier |
| `description` | `string` | Human-readable description |
| `load_state` | `string` | Load state (e.g., `loaded`) |
| `active_state` | `string` | Active state (e.g., `active`) |
| `sub_state` | `string` | Sub-state detail |
| `following` | `string` | Unit being followed, if any |
| `path` | `string` | D-Bus object path |
| `job_id` | `uint32_t` | Associated job ID |
| `job_type` | `string` | Job type |
| `job_path` | `string` | Job D-Bus object path |

**Methods**
- `parseReply()` — Parses the raw D-Bus reply into a vector of `Unit` structs
- `readUnitInformation()` — (protected) Deserializes a single unit from a `DBusMessageIter`

### `ListUnitsMethod`
Type alias composing the handler with the generic `DbusMethod` template:
```c
using ListUnitsMethod = DbusMethod<ListUnitsMethodHandler>;
```

## Usage Example

```c
#include <osquery/tables/system/linux/dbus/methods/listunitsmethodhandler.h>

osquery::ListUnitsMethod method;
osquery::ListUnitsMethodHandler::Output units;

auto status = method.call(connection, units);
if (status.ok()) {
    for (const auto& unit : units) {
        // Access unit.id, unit.active_state, etc.
    }
}
```

> **Note:** This handler is Linux-only and depends on a running systemd D-Bus interface. It is used internally by osquery's `systemd_units` table implementation.
