Defines a D-Bus method handler for retrieving a single string property from a systemd D-Bus interface using the `org.freedesktop.DBus.Properties.Get` method.

## Key Components

- **`GetStringPropertyMethodHandler`** — Handler class implementing the D-Bus property fetch logic. Targets the `org.freedesktop.systemd1` destination via the `org.freedesktop.DBus.Properties` interface, calling the `Get` method. Exposes:
  - `kDestination`, `kInterface`, `kMethod` — compile-time constants identifying the D-Bus endpoint
  - `Output` — type alias for `std::string`, representing the fetched property value
  - `parseReply()` — parses a raw `UniqueDbusMessage` reply and populates the output string

- **`GetStringPropertyMethod`** — Type alias composing `GetStringPropertyMethodHandler` into a fully typed `DbusMethod` template, accepting two `const std::string&` parameters (interface name and property name)

## Usage Example

```cpp
#include <osquery/tables/system/linux/dbus/methods/getstringproperty.h>

// Instantiate and call the method with interface and property name arguments
GetStringPropertyMethod method;
GetStringPropertyMethodHandler::Output result;

auto status = method.call(
    connection,
    "/org/freedesktop/systemd1/unit/sshd_2eservice",
    "org.freedesktop.systemd1.Unit",
    "ActiveState"
);

if (status.ok()) {
    std::cout << "Property value: " << result << std::endl;
}
```

## Notes

- Protected constructor/destructor enforce use via the `DbusMethod` template rather than direct instantiation
- Part of the osquery Linux D-Bus subsystem under `osquery/tables/system/linux/dbus/methods/`
