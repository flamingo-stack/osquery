Defines a D-Bus method handler for retrieving a single string property from a D-Bus object, targeting the systemd1 interface via `org.freedesktop.DBus.Properties`.

## Key Components

- **`GetStringPropertyMethodHandler`** — Base handler class for the D-Bus `Get` property call. Hardcodes the destination (`org.freedesktop.systemd1`), interface (`org.freedesktop.DBus.Properties`), and method (`Get`). Exposes `parseReply()` to extract a `std::string` from the raw D-Bus reply message.

- **`GetStringPropertyMethod`** — A fully composed D-Bus method type alias built from `DbusMethod<>`, parameterized with two `const std::string&` arguments (interface name and property name).

## Usage Example

```c
// Instantiate and call the composed method type
GetStringPropertyMethod method;

std::string value;
auto status = method.call(
    connection,
    "/org/freedesktop/systemd1/unit/ssh_2eservice",
    "org.freedesktop.systemd1.Unit",
    "ActiveState"
);

if (status.ok()) {
    // 'value' now holds the retrieved property string
}
```

## Notes

- The handler constructor and destructor are `protected`, enforcing use through `DbusMethod<>` composition rather than direct instantiation.
- The two template string arguments to `GetStringPropertyMethod` correspond to the D-Bus **interface** and **property name** passed at call time.
- Part of osquery's Linux system tables D-Bus abstraction layer.
