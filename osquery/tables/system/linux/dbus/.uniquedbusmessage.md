RAII wrapper for managing `DBusMessage*` lifecycle within the osquery D-Bus infrastructure on Linux.

## Key Components

### `UniqueDbusMessageAllocator`
A protected allocator class that implements the allocate/deallocate interface required by `UniqueResource`:

- **`allocate()`** — Creates a new `DBusMessage*` for a method call, parameterized by destination, path, interface, and method name.
- **`deallocate()`** — Releases the underlying `DBusMessage*` resource.

### `UniqueDbusMessage` (type alias)
A `UniqueResource` specialization that combines `UniqueDbusMessageAllocator` with four `const std::string&` constructor arguments:

```text
UniqueResource<UniqueDbusMessageAllocator,
               const std::string& destination,
               const std::string& path,
               const std::string& iface,
               const std::string& method>
```

## Usage Example

```cpp
#include <osquery/tables/system/linux/dbus/uniquedbusmessage.h>

// Create a RAII-managed DBus method call message.
// The message is automatically released when 'msg' goes out of scope.
UniqueDbusMessage msg;
auto status = msg.allocate(
    "org.freedesktop.NetworkManager",          // destination
    "/org/freedesktop/NetworkManager",         // path
    "org.freedesktop.NetworkManager",          // interface
    "GetDevices"                               // method
);

if (!status.ok()) {
    // handle allocation failure
}

DBusMessage* raw = msg.get(); // access raw pointer if needed
```

## Notes

- Defined in `namespace osquery`.
- Depends on `UniqueResource<>` from [`uniqueresource.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/tables/system/linux/dbus/uniqueresource.h) and the system `<dbus/dbus.h>` header.
- Linux-only — part of the D-Bus table infrastructure used for querying system services.
