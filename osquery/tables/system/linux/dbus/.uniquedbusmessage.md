RAII wrapper for managing `DBusMessage*` lifetimes within the osquery D-Bus abstraction layer, ensuring automatic allocation and deallocation of D-Bus method call messages.

## Key Components

- **`UniqueDbusMessageAllocator`** — Policy class defining allocation/deallocation strategies for `DBusMessage*` resources:
  - `allocate()` — Creates a new D-Bus method call message targeting a destination, object path, interface, and method name
  - `deallocate()` — Releases the underlying `DBusMessage*` resource
- **`UniqueDbusMessage`** — Type alias instantiating `UniqueResource<>` with `UniqueDbusMessageAllocator` and four `const std::string&` constructor parameters, providing scope-bound ownership of a D-Bus message

## Usage Example

```cpp
#include <osquery/tables/system/linux/dbus/uniquedbusmessage.h>

// Automatically allocates a DBusMessage* for the given D-Bus target.
// The message is freed when 'msg' goes out of scope.
UniqueDbusMessage msg;

auto status = msg.get(
    "org.freedesktop.NetworkManager",          // destination
    "/org/freedesktop/NetworkManager",         // object path
    "org.freedesktop.NetworkManager",          // interface
    "GetDevices"                               // method
);

if (!status.ok()) {
    LOG(ERROR) << "Failed to allocate D-Bus message: " << status.getMessage();
    return;
}

DBusMessage* raw = msg.resource(); // access the raw pointer when needed
```

## Notes

- Follows the same allocator-policy pattern used across osquery's D-Bus wrappers (see `uniqueresource.h`)
- The destructor is virtual to support potential subclassing of the allocator policy
- Part of osquery's Linux-specific D-Bus table infrastructure
