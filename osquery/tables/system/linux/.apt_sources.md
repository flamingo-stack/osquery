Defines data structures and parsing utilities for APT package source entries used by the `apt_sources` osquery table implementation.

## Key Components

### `AptSource` Struct
Represents a single APT repository source with the following fields:
- `base_uri` — The repository URI (e.g., `http://archive.ubuntu.com/ubuntu`)
- `name` — The distribution/suite name (e.g., `focal main`)
- `cache_file` — Vector of filename components used to locate the local APT cache file

### Functions

| Function | Description |
|----------|-------------|
| `parseAptSourceLine()` | Parses a single line from a traditional `/etc/apt/sources.list` file into an `AptSource` |
| `parseDeb822Block()` | Parses a multi-line Deb822-format block (used in `.sources` files) into a vector of `AptSource` entries |
| `getCacheFilename()` | Reconstructs the APT cache filename from the `cache_file` components vector |

## Usage Example

```c
#include "apt_sources.h"

using namespace osquery::tables;

// Parse a traditional sources.list line
AptSource source;
Status s = parseAptSourceLine(
    "deb http://archive.ubuntu.com/ubuntu focal main restricted",
    source
);

if (s.ok()) {
    std::string cache = getCacheFilename(source.cache_file);
    // cache -> e.g. "archive.ubuntu.com_ubuntu_dists_focal_main_..."
}

// Parse a Deb822-format block
std::vector<AptSource> sources;
Status s2 = parseDeb822Block(deb822_block_string, sources);
```

## Notes

- Both traditional `sources.list` and modern Deb822 `.sources` formats are supported
- Declared within the `osquery::tables` namespace
