Utility header for bridging macOS Apple System Log (ASL) API with osquery's table query infrastructure, including compatibility shims for older ASL API versions.

## Key Components

### Compatibility Shims (`OLD_ASL_API`)
Inline wrappers defined when `ASL_API_VERSION` is not present, normalizing the legacy ASL API:
- `asl_release(aslmsg)` — wraps `asl_free()`
- `asl_release(aslresponse)` — wraps `aslresponse_free()`
- `asl_next(aslresponse)` — wraps `aslresponse_next()`

### Functions

| Function | Description |
|---|---|
| `addQueryOp()` | Appends a constraint operation (ANDed) to an ASL query, converting osquery operators to ASL equivalents |
| `createAslQuery()` | Builds a full ASL query object from an osquery `QueryContext` |
| `readAslRow()` | Reads a single ASL message row into an osquery `Row` |
| `convertLikeRegex()` | Converts a SQL `LIKE`-style pattern string into a regex |

## Usage Example

```c
#include "asl_utils.h"

namespace osquery {
namespace tables {

QueryData queryAslLogs(QueryContext& context) {
  QueryData results;

  // Build an ASL query from the osquery context
  aslmsg query = createAslQuery(context);

  asl_object_t client = asl_open(nullptr, "com.example", 0);
  aslresponse resp = asl_search(client, query);

  aslmsg row;
  while ((row = asl_next(resp)) != nullptr) {
    Row r;
    readAslRow(row, r);
    results.push_back(r);
  }

  asl_release(resp);
  asl_release(query);
  asl_close(client);

  return results;
}

} // namespace tables
} // namespace osquery
```

## Notes

- macOS only — depends on `<asl.h>`, which is not available on other platforms.
