Implements a macOS FSEvents-based file system event subscriber for osquery, tracking file creation, modification, and other changes across configured paths.

## Key Components

### `FileEventSubscriber`
An `EventSubscriber` subclass registered under the `"file_events"` plugin name. Listens to `FSEventsEventPublisher` events and records file activity into osquery's event table.

| Method | Description |
|---|---|
| `init()` | Minimal initialization; returns success immediately |
| `configure()` | Clears existing subscriptions and re-registers paths from the osquery config |
| `Callback(ec, sc)` | Handles incoming FSEvents, builds result rows, and adds them to the event table |

### Registration
```cpp
REGISTER(FileEventSubscriber, "event_subscriber", "file_events");
```
Registers the subscriber into the osquery plugin registry so it is auto-initialized at startup.

## Key Behaviors

- **Dynamic reconfiguration** — `configure()` calls `removeSubscriptions()` then iterates `Config::get().files()` to create fresh subscriptions per path/category.
- **Mount point handling** — When an `kFSEventStreamEventFlagMount` flag is detected, a new subscription for `<mount_path>/*` is spawned asynchronously via `std::packaged_task` on a detached thread.
- **Row decoration** — `decorateFileEvent()` enriches each row with file hash and stat metadata when the action is `CREATED` or `UPDATED`.

## Usage Example

```cpp
// Rows emitted to the file_events table contain:
Row r;
r["action"]         = ec->action;         // e.g., "CREATED", "UPDATED"
r["target_path"]    = ec->path;           // Absolute path of the changed file
r["category"]       = sc->category;       // Config category label
r["transaction_id"] = INTEGER(ec->transaction_id); // FSEvents transaction ID
// + hash/stat fields added by decorateFileEvent()
```

Configure monitored paths via the osquery `file_paths` config key; the subscriber picks them up automatically on each `configure()` call.
