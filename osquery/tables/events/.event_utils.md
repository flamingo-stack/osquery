Utility header providing shared helpers for file event handling across osquery's platform-specific `file_events` table implementations.

## Key Components

**`kCommonFileColumns`** — Extern constant defining the set of column names shared across all platform file event implementations.

**`decorateFileEvent(path, hash, r)`** — Decorates a table row with common file metadata by:
- Populating columns sourced from the `file` virtual table
- Optionally reading and hashing the target file at `path` when `hash` is `true`
- Writing results into the output `Row` reference `r`

## Usage Example

```c
#include <osquery/events/event_utils.h>

// Inside a file event subscriber callback:
Row r;
r["action"] = "CREATED";
r["target_path"] = event->path;

// Decorate with common file columns and compute hash
decorateFileEvent(event->path, /* hash= */ true, r);

results.push_back(r);
```

## Notes

- Defined inside the `osquery` namespace
- Designed to be called from each platform's file event subscriber (Linux inotify, macOS FSEvents, Windows USN journal) to ensure consistent column output
- The `hash` parameter controls a potentially expensive disk read — pass `false` for high-frequency events where hashing is unnecessary
