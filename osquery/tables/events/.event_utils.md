Utility header providing shared helpers for cross-platform file event handling in osquery's eventing system.

## Key Components

- **`kCommonFileColumns`** — A constant set of column names shared across file event tables on all platforms, ensuring consistent schema decoration.
- **`decorateFileEvent(path, hash, r)`** — Populates a `Row` with common file metadata (path info, optional hash) sourced from the `file` table, abstracting platform-specific `file_events` implementations.

## Usage Example

```cpp
#include "event_utils.h"

void handleFileEvent(const std::string& filePath, Row& eventRow) {
    // Decorate the row with common file columns, including hash
    decorateFileEvent(filePath, /* hash= */ true, eventRow);

    // eventRow now contains hashed file metadata
    // and all columns defined in kCommonFileColumns
}
```

## Notes

- `hash` parameter controls whether the file at `path` is read and checksummed; pass `false` for performance-sensitive paths where hashing is unnecessary.
- Intended to be called from each platform's `file_events` publisher (Linux inotify, macOS FSEvents, Windows USN journal) to normalize output rows before emission.
- Depends on `osquery/core/tables.h` for the `Row` type.
