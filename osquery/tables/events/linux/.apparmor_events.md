Brief description of the file's purpose: Declares the `AppArmorEventSubscriber` class, which subscribes to Linux audit events related to AppArmor policy enforcement within the osquery eventing framework.

## Key Components

- **`AppArmorEventSubscriber`** — Final class inheriting from `EventSubscriber<AuditEventPublisher>`. Listens for AppArmor-related audit events from the Linux kernel.

  | Method | Description |
  |--------|-------------|
  | `init()` | Registers the subscriber and declares the audit event type subscription |
  | `callback(ec, sc)` | Invoked when a matching kernel audit event fires; receives event and subscription context refs |
  | `processEvents(emitted_row_list, event_list)` | Static helper that transforms raw `AuditEvent` objects into `QueryData` rows; marked `noexcept` |
  | `getEventSet()` | Static method returning the set of audit event type integers this subscriber handles |

## Usage Example

```c
// Typical osquery subscriber wiring — framework calls these automatically.
// Manual usage for testing processEvents:

std::vector<AuditEvent> raw_events = /* ... populated by audit publisher ... */;
QueryData rows;

Status s = AppArmorEventSubscriber::processEvents(rows, raw_events);
if (s.ok()) {
    for (const auto& row : rows) {
        // Each row maps column names to values for the apparmor_events table
    }
}

// Retrieve handled audit event codes:
const std::set<int>& handled = AppArmorEventSubscriber::getEventSet();
```

## Notes

- Located in the `osquery` namespace.
- Depends on Linux-specific headers (`linux/audit.h`) — only compiled on Linux.
- Integrates with `AuditEventPublisher` defined in [`osquery/events/linux/auditeventpublisher.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/linux/auditeventpublisher.h).
