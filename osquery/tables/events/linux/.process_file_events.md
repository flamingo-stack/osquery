Defines the data structures and subscriber class for Linux audit-based File Integrity Monitoring (FIM), tracking file system operations through kernel syscall events via the audit subsystem.

## Key Components

### Structs & Descriptors

| Type | Purpose |
|------|---------|
| `AuditdFimInodeDescriptor` | Maps an inode to a file/folder path with a `Type` enum (`File`, `Folder`) |
| `AuditdFimFdDescriptor` | Tracks a file descriptor's inode and last operation (`Open`, `Read`, `Write`, etc.) |
| `AuditdFimPathRecordItem` | Aggregates individual `AUDIT_PATH` records (index, inode, path) |
| `AuditdFimSrcDestData` | Source/destination paths for two-path syscalls (`rename`, `link`) |
| `AuditdFimIOData` | Target path and operation type for I/O syscalls (`Open`, `Read`, `Write`, `Unlink`, etc.) |
| `AuditdFimSyscallContext` | Full context of a syscall event including PIDs, UIDs, GIDs, path records, and return value |
| `AuditdFimContext` | Top-level FIM state: monitored paths, process map, and inode map |

### Map Classes

- **`AuditdFimInodeMap`** — Global inode-to-path registry with `getReference`, `takeAndRemove`, `save`, and `remove` operations.
- **`AuditdFimFdMap`** — Per-process file descriptor map supporting `duplicate` (for `dup`/`dup2`/`dup3`) and suppressed warning logging.
- **`AuditdFimProcessMap`** — Multi-process fd tracking with `clone` support (for `fork`/`vfork`) and per-pid fd delegation.

### Subscriber

**`ProcessFileEventSubscriber`** — Extends `EventSubscriber<AuditEventPublisher>` to consume Linux audit events:

- `init()` / `configure()` — Lifecycle and configuration hooks
- `Callback()` — Invoked per audit event batch
- `ProcessEvents()` — Static method that updates `AuditdFimContext` and emits `Row` entries
- `GetSyscallSet()` — Returns the set of handled syscall numbers

## Usage Example

```cpp
// Static processing of audit events
std::vector<Row> emitted_rows;
AuditdFimContext fim_context;
fim_context.included_path_list = {"/etc", "/usr/bin"};

auto status = ProcessFileEventSubscriber::ProcessEvents(
    emitted_rows,
    fim_context,
    event_list  // std::vector<AuditEvent> from publisher
);

// Inspect handled syscalls
const auto& syscalls = ProcessFileEventSubscriber::GetSyscallSet();
```
