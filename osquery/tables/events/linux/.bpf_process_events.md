Defines the `BPFProcessEventSubscriber` class, which subscribes to BPF-based process events on Linux and transforms raw kernel event data into osquery table rows.

## Key Components

### `BPFProcessEventSubscriber`
An `EventSubscriber` implementation bound to `BPFEventPublisher` that handles process lifecycle events captured via eBPF.

| Method | Description |
|--------|-------------|
| `init()` | Registers subscriptions with the BPF event publisher |
| `eventCallback(...)` | Invoked per event; routes data to row generation |
| `generateRow(row, event)` | Converts a single `ISystemStateTracker::Event` into an osquery `Row` |
| `generateRowList(event_list)` | Batch-converts a list of events into multiple `Row` entries |
| `generateCmdlineColumn(argv)` | Formats an argv vector as a space-joined command-line string |
| `generateJsonCmdlineColumn(argv)` | Formats an argv vector as a JSON array string |

## Usage Example

```cpp
// Row generation from a single BPF process event
Row row;
ISystemStateTracker::Event event = /* populated by BPF publisher */;

if (BPFProcessEventSubscriber::generateRow(row, event)) {
    // row now contains process fields: pid, path, cmdline, etc.
}

// Batch processing
auto rows = BPFProcessEventSubscriber::generateRowList(event_list);

// Cmdline column formatting
std::vector<std::string> argv = {"/usr/bin/curl", "-s", "https://example.com"};
std::string cmdline      = BPFProcessEventSubscriber::generateCmdlineColumn(argv);
// → "/usr/bin/curl -s https://example.com"

std::string json_cmdline = BPFProcessEventSubscriber::generateJsonCmdlineColumn(argv);
// → ["/usr/bin/curl","-s","https://example.com"]
```

## Notes

- Linux-only; depends on `BPFEventPublisher` which requires kernel eBPF support.
- The static helper methods are independently testable without a running event loop.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
