Header defining the `BPFProcessEventSubscriber` class, which subscribes to BPF-based process events on Linux and transforms them into osquery table rows.

## Key Components

- **`BPFProcessEventSubscriber`** — Final class extending `EventSubscriber<BPFEventPublisher>`; handles lifecycle and event processing for BPF process events
- **`init()`** — Initializes the subscriber and registers it with the BPF event publisher
- **`eventCallback()`** — Invoked per event; receives event and subscription contexts for real-time processing
- **`generateRow()`** — Converts a single `ISystemStateTracker::Event` into an osquery `Row`
- **`generateRowList()`** — Batch-converts an `EventList` into a `std::vector<Row>`
- **`generateCmdlineColumn()`** — Serializes an `argv` vector into a plain space-separated command-line string
- **`generateJsonCmdlineColumn()`** — Serializes an `argv` vector into a JSON-formatted command-line string

## Usage Example

```c
// Subscriber is registered automatically via osquery's event framework.
// Static helpers can be used independently for row generation:

ISystemStateTracker::Event event = /* ... */;
Row row;

if (BPFProcessEventSubscriber::generateRow(row, event)) {
    // row now contains columns: pid, path, cmdline, etc.
}

// Build command-line columns from argv
std::vector<std::string> argv = {"/usr/bin/curl", "-s", "https://example.com"};

std::string cmdline      = BPFProcessEventSubscriber::generateCmdlineColumn(argv);
// → "/usr/bin/curl -s https://example.com"

std::string jsonCmdline  = BPFProcessEventSubscriber::generateJsonCmdlineColumn(argv);
// → ["/usr/bin/curl", "-s", "https://example.com"]
```

> **Platform note:** This subscriber is Linux-only and requires BPF support in the kernel. It feeds the `bpf_process_events` virtual table in osquery.
