Defines the `SELinuxEventSubscriber` class for capturing and processing SELinux audit events on Linux systems via the osquery audit event framework.

## Key Components

**`SELinuxEventSubscriber`** — Final class inheriting from `EventSubscriber<AuditEventPublisher>` that subscribes to Linux kernel audit events related to SELinux.

| Method | Description |
|--------|-------------|
| `init()` | Registers the subscriber and declares the audit event type subscription |
| `Callback(ec, sc)` | Invoked by the kernel audit framework when a matching event fires |
| `ProcessEvents(emitted_row_list, event_list)` | Static method that transforms raw `AuditEvent` objects into osquery `Row` entries |
| `GetEventSet()` | Static method returning the set of audit event type IDs this subscriber handles |

## Usage Example

```cpp
#include <osquery/events/linux/selinux_events.h>

// Retrieve the handled audit event type IDs
const std::set<int>& handled_events = SELinuxEventSubscriber::GetEventSet();

// Process a batch of audit events into rows
std::vector<Row> rows;
std::vector<AuditEvent> events = /* ... populated by AuditEventPublisher ... */;

Status status = SELinuxEventSubscriber::ProcessEvents(rows, events);
if (status.ok()) {
    for (const auto& row : rows) {
        // Each row maps to an SELinux audit log entry
    }
}
```

## Notes

- Linux-only; depends on `AuditEventPublisher` from the osquery Linux audit subsystem
- `ProcessEvents` and `GetEventSet` are `static` and `noexcept`, making them safe to call without an instance and suitable for unit testing in isolation
- Source: [`osquery/events/linux/selinux_events.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/linux/selinux_events.h)
