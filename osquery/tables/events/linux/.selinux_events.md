Defines the `SELinuxEventSubscriber` class for capturing and processing SELinux-related audit events on Linux systems via the osquery audit event framework.

## Key Components

### `SELinuxEventSubscriber`
Inherits from `EventSubscriber<AuditEventPublisher>`. Subscribes to Linux kernel audit events related to SELinux enforcement actions.

| Method | Description |
|--------|-------------|
| `init()` | Registers the subscriber's audit event type subscription at startup |
| `Callback(ec, sc)` | Invoked when a matching kernel audit event fires; receives event and subscription context refs |
| `ProcessEvents(emitted_row_list, event_list)` | Static method that transforms raw `AuditEvent` objects into osquery `Row` entries; `noexcept` |
| `GetEventSet()` | Static method returning the set of audit event type integers this subscriber handles; `noexcept` |

## Usage Example

```cpp
// Subscriber is auto-registered via osquery's EventFactory.
// Manual ProcessEvents usage (e.g., in unit tests):

std::vector<Row> rows;
std::vector<AuditEvent> raw_events = GetTestAuditEvents();

Status s = SELinuxEventSubscriber::ProcessEvents(rows, raw_events);
if (s.ok()) {
    for (const auto& row : rows) {
        // Each row contains SELinux audit fields (e.g., avc, syscall, context)
    }
}

// Retrieve handled event type codes:
const auto& event_types = SELinuxEventSubscriber::GetEventSet();
```

## Notes

- Depends on `AuditEventPublisher` — Linux-only, requires audit subsystem access
- `ProcessEvents` and `GetEventSet` are static to allow isolated unit testing without a running event loop
- Part of the `osquery` namespace; registration with `EventFactory` is handled by the osquery core infrastructure
