Header defining the `BPFSocketEventSubscriber` class, which subscribes to BPF-based socket events on Linux and converts raw kernel events into osquery table rows.

## Key Components

### `BPFSocketEventSubscriber`
An `EventSubscriber` specialization that consumes events from `BPFEventPublisher` and processes socket-level activity captured via eBPF.

| Member | Description |
|--------|-------------|
| `init()` | Initializes the subscriber and registers subscriptions |
| `eventCallback(ECRef, SCRef)` | Invoked per-event; handles incoming BPF socket events |
| `generateRow(Row&, Event&)` | Static helper that populates a single osquery `Row` from a system state event |
| `generateRowList(EventList&)` | Static helper that converts a list of events into multiple `Row` entries |

## Usage Example

```c
// Subscriber registration happens automatically via osquery's event framework.
// To manually generate rows from a BPF event list:

ISystemStateTracker::EventList events = tracker.getSocketEvents();

// Single row
Row r;
if (BPFSocketEventSubscriber::generateRow(r, events[0])) {
    // r is now populated with socket event fields
}

// Batch conversion
std::vector<Row> rows =
    BPFSocketEventSubscriber::generateRowList(events);
```

## Notes

- Linux-only; depends on `BPFEventPublisher` which requires eBPF kernel support
- Part of osquery's publisher/subscriber event system — the subscriber is auto-registered at startup, not instantiated manually
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/linux/bpf/bpf_socket_events.h)
