Defines the `SocketEventSubscriber` class, an osquery event subscriber that monitors Linux socket-related system calls via the audit event publisher.

## Key Components

- **`SocketEventSubscriber`** — Final class inheriting from `EventSubscriber<AuditEventPublisher>` that subscribes to kernel-level socket audit events
- **`init()`** — Registers the subscriber and declares the audit event type subscription
- **`Callback()`** — Handles incoming kernel audit events matching the subscribed socket syscalls
- **`ProcessEvents()`** — Static method that transforms raw `AuditEvent` objects into `Row` entries; accepts filtering flags for failed events, UNIX sockets, null accept events, and null accept socket events
- **`GetSyscallSet()`** — Returns the set of Linux syscall numbers this subscriber monitors (e.g., `connect`, `accept`, `bind`)
- **`parseSockAddr()`** — Parses the `saddr` field from an `AUDIT_SOCKADDR` record, populating a result `Row` and flagging whether the address is a UNIX domain socket

## Usage Example

```cpp
// ProcessEvents is the primary testable interface
std::vector<Row> rows;
std::vector<AuditEvent> events = getAuditEvents();

Status status = SocketEventSubscriber::ProcessEvents(
    rows,
    events,
    /*allow_failed_socket_events=*/false,
    /*allow_unix_socket_events=*/true,
    /*allow_null_accept_events=*/false,
    /*allow_null_accept_socket_events=*/false
);

// Inspect supported syscalls
const auto& syscalls = SocketEventSubscriber::GetSyscallSet();

// Parse a raw saddr field
Row row;
bool is_unix = false;
bool ok = SocketEventSubscriber::parseSockAddr("0200...", row, is_unix);
```
