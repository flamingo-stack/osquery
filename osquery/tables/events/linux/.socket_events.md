Defines the `SocketEventSubscriber` class, an osquery event subscriber that listens to Linux audit events related to socket activity.

## Key Components

**`SocketEventSubscriber`** — Subscribes to `AuditEventPublisher` events and processes socket-related kernel audit records.

| Member | Description |
|--------|-------------|
| `init()` | Registers the subscriber with the audit event publisher |
| `Callback()` | Invoked when a matching kernel audit event fires |
| `ProcessEvents()` | Transforms raw `AuditEvent` list into osquery `Row` results; accepts filter flags for failed, UNIX, and null-accept socket events |
| `GetSyscallSet()` | Returns the set of syscall IDs this subscriber handles (e.g., `connect`, `accept`) |
| `parseSockAddr()` | Parses the `saddr` field from an `AUDIT_SOCKADDR` record into structured row fields; sets `unix_socket` flag |

## Usage Example

```cpp
#include <osquery/events/linux/socket_events.h>

// During event processing, transform audit events into rows
std::vector<Row> rows;
std::vector<AuditEvent> events = /* ... received from publisher ... */;

Status s = SocketEventSubscriber::ProcessEvents(
    rows,
    events,
    /*allow_failed_socket_events=*/false,
    /*allow_unix_socket_events=*/true,
    /*allow_null_accept_events=*/false,
    /*allow_null_accept_socket_events=*/false
);

// Parse a raw saddr string from an AUDIT_SOCKADDR record
Row row;
bool is_unix = false;
bool ok = SocketEventSubscriber::parseSockAddr("02001F90...", row, is_unix);
```

## Notes

- Declared `final` — not intended for subclassing.
- `ProcessEvents` and `GetSyscallSet` are `static` and `noexcept`, making them safe to call without a subscriber instance.
