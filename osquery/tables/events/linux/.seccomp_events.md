Header file defining the `SeccompEventSubscriber` class, which subscribes to Linux audit events related to seccomp (secure computing mode) syscall filtering and translates raw kernel events into structured osquery rows.

## Key Components

### Compatibility Macros

Backfill constants introduced in kernel 4.14 if missing from the system's `seccomp.h`:

| Macro | Value | Meaning |
|-------|-------|---------|
| `SECCOMP_RET_KILL_PROCESS` | `0x80000000U` | Kill the entire process |
| `SECCOMP_RET_KILL_THREAD` | `SECCOMP_RET_KILL` | Kill only the offending thread |
| `SECCOMP_RET_LOG` | `0x7ffc0000U` | Allow syscall after logging |

### `SeccompEventSubscriber`

Extends `EventSubscriber<AuditEventPublisher>` within the `osquery` namespace.

**Static Lookup Tables**

- `seccomp_actions_map` — maps seccomp action codes to human-readable names (e.g., `KILL`, `ALLOW`)
- `arch_codes_map` — maps Linux audit architecture codes to architecture name strings
- `syscall_x86_64_map` — maps x86_64 syscall numbers to syscall name strings

**Methods**

- `init()` — registers the subscriber's audit event type subscription
- `Callback(ec, sc)` — invoked when a matching kernel audit event fires
- `processEvents(emitted_row_list, event_list)` — static method that translates a batch of `AuditEvent` objects into `QueryData` rows; `noexcept`
- `parseEvent(event, parsed_event)` — static helper that parses a single `AuditEvent` into a `Row`; `noexcept`

## Usage Example

```c
// osquery wires this up automatically via the subscriber registration system.
// To query captured seccomp events from the osquery shell:

SELECT action, arch, syscall, pid, exe
FROM seccomp_events;
```
