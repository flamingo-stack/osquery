Declares the `AuditProcessEventSubscriber` class, which subscribes to Linux audit events to monitor and process system calls related to process lifecycle (exec, fork, clone).

## Key Components

**`AuditProcessEventSubscriber`** — Final class inheriting from `EventSubscriber<AuditEventPublisher>` with the following members:

| Method | Description |
|--------|-------------|
| `init()` | Registers the audit event type subscription on startup |
| `Callback(ec, sc)` | Fired when kernel events match the subscribed audit event type |
| `ProcessEvents(emitted_row_list, event_list)` | Transforms raw `AuditEvent` entries into osquery `Row` objects |
| `ProcessExecveEventData(row, event)` | Parses `execve`/`execveat` syscall data into a row |
| `GetProcessIDs(ppid, pid, syscall_nr, record)` | Extracts parent PID and PID from a syscall audit record |
| `IsThreadClone(is_thread_clone, syscall_nr, record)` | Detects if a `clone()` call used the `CLONE_THREAD` flag |
| `GetSyscallName(name, syscall_nr)` | Resolves a syscall number to its string name |
| `GetSyscallNameMap()` | Returns the static syscall number-to-name lookup map |

## Usage Example

```cpp
#include <osquery/events/linux/process_events.h>

// Static utility: resolve a syscall number to its name
std::string name;
if (osquery::AuditProcessEventSubscriber::GetSyscallName(name, 59)) {
    // name == "execve"
}

// Static utility: check if a clone() call spawned a thread vs. a process
bool is_thread = false;
osquery::AuditProcessEventSubscriber::IsThreadClone(
    is_thread, syscall_nr, syscall_record);

if (is_thread) {
    // Handle thread creation separately from process fork
}
```

## Notes

- All static methods are marked `noexcept` — callers do not need exception handling.
- Depends on [`AuditEventPublisher`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/linux/auditeventpublisher.h) for the underlying Linux audit netlink transport.
- Part of the `osquery` namespace; registered automatically via the subscriber framework.
