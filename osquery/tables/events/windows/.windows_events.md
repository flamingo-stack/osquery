Defines the `WindowsEventSubscriber` class, an osquery event subscriber that listens to Windows Event Log events and maps them into queryable table rows.

## Key Components

- **`WindowsEventSubscriber`** — Inherits from `EventSubscriber<WindowsEventLogPublisher>`; subscribes to Windows Event Log publisher events.
- **`init()`** — Initializes the subscriber and registers subscriptions with the publisher.
- **`Callback()`** — Invoked per event; receives an event reference (`ECRef`) and subscription context (`SCRef`) for processing.
- **`generateRow()`** — Static utility that populates an osquery `Row` from a `WELEvent` struct, transforming raw Windows event data into a table-compatible format.

## Usage Example

```cpp
// Subscriber is auto-registered via osquery's event framework.
// generateRow can be used independently to convert a WELEvent:

Row row;
WELEvent wel_event = /* populated by WindowsEventLogParser */;
WindowsEventSubscriber::generateRow(row, wel_event);

// row now contains mapped fields (e.g., event_id, source, message)
// ready for osquery table emission.
```

> **Note:** Direct instantiation is not typical. osquery's event subsystem handles lifecycle management — `init()` and `Callback()` are invoked automatically when the subscriber is registered and events are published by `WindowsEventLogPublisher`.
