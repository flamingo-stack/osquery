Defines the `WindowsEventSubscriber` class, which subscribes to Windows Event Log events published by `WindowsEventLogPublisher` within the osquery eventing framework.

## Key Components

### `WindowsEventSubscriber`
Extends `EventSubscriber<WindowsEventLogPublisher>` to consume and process Windows Event Log entries.

| Member | Description |
|--------|-------------|
| `init()` | Initializes the subscriber and registers event subscriptions |
| `~WindowsEventSubscriber()` | Virtual destructor for proper cleanup |
| `Callback(ECRef, SCRef)` | Invoked for each matching event; processes event data |
| `generateRow(Row&, WELEvent&)` | Static helper that maps a `WELEvent` into an osquery `Row` for table output |

## Usage Example

```cpp
#include "windows_events.h"

namespace osquery {

Status WindowsEventSubscriber::init() {
  auto subscription = createSubscriptionContext();
  // Configure channels or filters on subscription
  return subscribe(&WindowsEventSubscriber::Callback, subscription);
}

Status WindowsEventSubscriber::Callback(const ECRef& event,
                                         const SCRef& subscription) {
  Row row;
  generateRow(row, event->windows_event);
  addRow(row);
  return Status::success();
}

void WindowsEventSubscriber::generateRow(Row& row,
                                          const WELEvent& windows_event) {
  row["channel"]  = windows_event.channel;
  row["datetime"] = windows_event.datetime;
  row["eventid"]  = INTEGER(windows_event.event_id);
  // ... additional field mappings
}

} // namespace osquery
```

## Notes

- Part of the osquery Windows eventing subsystem; relies on `WindowsEventLogPublisher` for raw event delivery and `WindowsEventLogParser` for event parsing.
- `generateRow` is static, making it usable independently for testing or reuse without a subscriber instance.
- Source: [`osquery/events/windows/`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/windows/)
