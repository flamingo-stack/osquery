Header file defining the `PowershellEventSubscriber` class, which subscribes to Windows Event Log events to capture and process PowerShell script block logging data for osquery.

## Key Components

### `PowershellEventSubscriber`
Extends `EventSubscriber<WindowsEventLogPublisher>` to consume PowerShell-related Windows Event Log entries.

- **`init()`** — Registers subscriptions with the Windows Event Log publisher.
- **`Callback()`** — Invoked per event; delegates to processing logic.

### `Context`
Internal state container holding accumulated event data across calls:

| Member | Purpose |
|---|---|
| `script_state_map` | Groups partial `ScriptMessage` fragments by `ScriptBlockID` |
| `character_frequency_map` | Frequency analysis vector used for obfuscation detection |
| `row_list` | Completed rows pending table insertion |
| `last_event_expiration_time` | Tracks when stale events were last flushed |
| `invalid_event_count` / `expired_event_count` | Diagnostic counters |

### `ScriptMessage`
Represents a single PowerShell script block log fragment, including ordering metadata (`expected_message_count`, `message_number`), the raw `message` body, timestamps, and script path/name.

### Static Helpers

- **`parseScriptMessageEvent()`** — Deserializes a `ptree` event into a `ScriptMessage`.
- **`processEventObject()`** — Merges a parsed event into the shared `Context`.
- **`processEventExpiration()`** — Evicts stale incomplete script blocks from `script_state_map`.
- **`generateRow()`** — Assembles a complete osquery `Row` from a reassembled script block.

## Usage Example

```cpp
// Subscriber is registered automatically via osquery's plugin system.
// Manual interaction with static helpers for unit testing:

boost::optional<PowershellEventSubscriber::Context::ScriptMessage> msg;
PowershellEventSubscriber::parseScriptMessageEvent(msg, event_ptree);

if (msg) {
    PowershellEventSubscriber::Context ctx;
    PowershellEventSubscriber::processEventObject(ctx, event_ptree);
    PowershellEventSubscriber::processEventExpiration(ctx);
}
```
