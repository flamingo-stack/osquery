Defines the `PowershellEventSubscriber` class for capturing and processing PowerShell script block execution events on Windows via the `WindowsEventLogPublisher` event pipeline.

## Key Components

### `PowershellEventSubscriber`
An `EventSubscriber` that subscribes to Windows Event Log entries related to PowerShell script block logging (ETW/EVTX events).

- **`init()`** — Registers subscriptions with the Windows Event Log publisher.
- **`Callback()`** — Invoked per event; routes events into context processing.

### `Context`
Internal state struct tracking in-flight and completed script block events:

| Member | Purpose |
|---|---|
| `script_state_map` | Maps script block IDs to their partial message fragments |
| `character_frequency_map` | Frequency analysis vector for script content scoring |
| `row_list` | Accumulated rows ready for osquery table output |
| `last_event_expiration_time` | Timestamp for expiring stale incomplete events |
| `invalid_event_count` / `expired_event_count` | Diagnostic counters |

### `ScriptMessage`
Holds a single parsed fragment of a (potentially multi-part) PowerShell script block event, including metadata such as `script_path`, `script_name`, `event_time`, and message ordering fields.

### Static Utility Methods

- **`generateRow()`** — Assembles a complete osquery `Row` from a list of `ScriptMessage` fragments and the frequency map.
- **`parseScriptMessageEvent()`** — Parses a raw `ptree` event into a `ScriptMessage` optional.
- **`processEventObject()`** — Merges a parsed event into the running `Context`.
- **`processEventExpiration()`** — Evicts stale/incomplete script block entries from `Context`.

## Usage Example

```cpp
// Subscriber is auto-registered via osquery's event framework.
// Manual interaction example for testing:

PowershellEventSubscriber subscriber;
subscriber.init();

PowershellEventSubscriber::Context ctx;
boost::property_tree::ptree raw_event; // populated from Windows Event Log

auto status = PowershellEventSubscriber::processEventObject(ctx, raw_event);
if (status.ok() && !ctx.row_list.empty()) {
    for (const auto& row : ctx.row_list) {
        // emit row to osquery table results
    }
}
```
