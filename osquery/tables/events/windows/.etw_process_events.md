Defines the `EtwProcessEventSubscriber` class, which subscribes to Windows ETW (Event Tracing for Windows) process events published by `EtwPublisherProcesses`.

## Key Components

- **`EtwProcessEventSubscriber`** — A final `EventSubscriber` specialization that hooks into the `EtwPublisherProcesses` publisher to receive and handle process lifecycle events on Windows.
  - **`init()`** — Initializes the subscriber and registers its subscriptions with the ETW publisher.
  - **`eventCallback()`** — Invoked by the event framework when a matching process event is dispatched; receives the event context (`ECRef`) and subscription context (`SCRef`) for processing.

## Usage Example

```cpp
// Subscribers are registered automatically via the osquery plugin system.
// The framework calls init() on startup and routes matching ETW process
// events to eventCallback() at runtime.

Status EtwProcessEventSubscriber::init() {
    auto subscription = createSubscriptionContext();
    subscribe(&EtwProcessEventSubscriber::eventCallback, subscription);
    return Status::success();
}

Status EtwProcessEventSubscriber::eventCallback(
    const ECRef& event_context,
    const SCRef& subscription_context) {
    // Process event data from event_context (e.g., PID, process name, image path)
    // and emit rows to the osquery table layer.
    return Status::success();
}
```

## Notes

- Windows-only; depends on the ETW infrastructure in `etw_publisher_processes.h`.
- Follows the standard osquery `EventSubscriber<Publisher>` pattern — the framework handles event dispatch and thread safety.
- Source: [`flamingo-stack/osquery`](https://github.com/flamingo-stack/osquery)
