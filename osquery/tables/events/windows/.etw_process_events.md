Defines the ETW (Event Tracing for Windows) process event subscriber that listens to process-related events published by `EtwPublisherProcesses`.

## Key Components

- **`EtwProcessEventSubscriber`** — Final class inheriting from `EventSubscriber<EtwPublisherProcesses>`. Subscribes to Windows ETW process events and handles their processing via a callback.

| Member | Description |
|--------|-------------|
| `init()` | Initializes the subscriber and registers subscriptions |
| `eventCallback(ECRef, SCRef)` | Invoked when a process event is received; handles event data processing |

## Usage Example

```cpp
// Subscriber is registered automatically via osquery's event framework.
// Typical interaction pattern:

namespace osquery {

Status EtwProcessEventSubscriber::init() {
  // Register subscription context filters (e.g., process create/terminate)
  auto subscription_context = createSubscriptionContext();
  subscribe(&EtwProcessEventSubscriber::eventCallback, subscription_context);
  return Status::success();
}

Status EtwProcessEventSubscriber::eventCallback(
    const ECRef& event_context,
    const SCRef& subscription_context) {
  // Process incoming ETW process event data
  // e.g., log process creation, extract PID, image path, etc.
  return Status::success();
}

} // namespace osquery
```

> The subscriber follows osquery's pub/sub event model — `EtwPublisherProcesses` captures raw ETW events from the Windows kernel, while this subscriber consumes and transforms them into queryable table rows.
