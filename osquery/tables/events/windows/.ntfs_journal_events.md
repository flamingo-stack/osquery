Declares the `NTFSEventSubscriber` class and supporting utilities for subscribing to NTFS file system change events on Windows within the osquery event framework.

## Key Components

- **`NTFSEventSubscriber`** — Event subscriber class (extends `EventSubscriber<NTFSEventPublisher>`) that receives, filters, and records NTFS file change events
  - `shouldEmit()` — Filters events based on subscription context before emission
  - `generateRowFromEvent()` — Converts a raw `NTFSEventRecord` into a queryable `Row`
  - `init()` — One-time initialization routine
  - `configure()` — Configuration callback, may be invoked multiple times on config changes
  - `Callback()` — Primary handler invoked by the publisher when events arrive

- **`StringList`** — Type alias for `std::vector<std::string>`, used for path collections

- **`processConfiguration()`** — Parses subscriber configuration, populating include/exclude path lists and access category filters from a given `NTFSEventSubscriptionContextRef`

## Usage Example

```c
// Typical osquery subscriber registration and callback flow
NTFSEventSubscriber subscriber;
subscriber.init();
subscriber.configure();

// Called automatically by the event publisher on each NTFS event
Status result = subscriber.Callback(ec, sc);

// Standalone configuration processing
StringList include_paths, exclude_paths;
StringList access_categories = {"writes", "deletes"};
processConfiguration(context, access_categories, include_paths, exclude_paths);
```

> **Note:** This header is Windows-only and depends on `ntfs_event_publisher.h`. The subscriber integrates with osquery's eventing pipeline — direct instantiation outside the framework is not typical in production use.
