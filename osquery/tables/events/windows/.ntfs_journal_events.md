Header defining the `NTFSEventSubscriber` class and supporting utilities for subscribing to NTFS file system change events on Windows via the osquery event framework.

## Key Components

### `NTFSEventSubscriber`
An `EventSubscriber` subclass that listens to events from `NTFSEventPublisher`.

| Member | Description |
|---|---|
| `NTFSEventSubscriber()` | Constructor |
| `~NTFSEventSubscriber()` | Destructor |
| `init()` | One-time initialization routine |
| `configure()` | Configuration callback; may be called multiple times |
| `Callback(ec, sc)` | Receives raw NTFS events from the publisher |
| `shouldEmit(sc, event)` | Filters events based on subscription context |
| `generateRowFromEvent(event)` | Converts an `NTFSEventRecord` into an osquery `Row` |

### `StringList`
A type alias for `std::vector<std::string>`, used for path lists.

### `processConfiguration()`
Parses subscriber configuration, populating include/exclude path lists and access categories from the given `NTFSEventSubscriptionContextRef`.

## Usage Example

```c
// Typical osquery subscriber pattern — registration is automatic via the
// REGISTER macro in the corresponding .cpp file.

// The subscriber is initialized and configured by the osquery event framework:
//   init()      → called once at startup
//   configure() → called on each config update

// Path filtering is handled internally via processConfiguration():
StringList access_categories = {"write", "delete"};
StringList include_paths, exclude_paths;

processConfiguration(context, access_categories, include_paths, exclude_paths);

// Events flow through Callback() and are filtered by shouldEmit()
// before being converted to rows via generateRowFromEvent()
```

## Notes

- Windows-only; depends on [`ntfs_event_publisher.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/events/windows/ntfs_event_publisher.h)
- `configure()` may be invoked multiple times as the osquery configuration changes
- Path filtering (include/exclude) is applied before row emission to minimize overhead
