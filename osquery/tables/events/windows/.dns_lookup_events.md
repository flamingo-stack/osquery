Declares the `EtwDNSEventSubscriber` class, an ETW-based event subscriber that captures Windows DNS lookup events via the `EtwPublisherDNS` publisher.

## Key Components

- **`EtwDNSEventSubscriber`** — Final class inheriting from `EventSubscriber<EtwPublisherDNS>`; subscribes to ETW DNS events on Windows
  - **`init()`** — Initializes the subscriber and registers the event subscription
  - **`eventCallback()`** — Callback invoked when a DNS event fires; receives the event context (`ECRef`) and subscription context (`SCRef`) for processing

## Usage Example

```c
// Subscriber is auto-registered via osquery's event framework.
// Typical interaction is through the osquery eventing pipeline:

namespace osquery {

Status EtwDNSEventSubscriber::init() {
  // Register subscription with the ETW DNS publisher
  auto subscription = createSubscriptionContext();
  subscribe(&EtwDNSEventSubscriber::eventCallback, subscription);
  return Status::success();
}

Status EtwDNSEventSubscriber::eventCallback(const ECRef& event_context,
                                             const SCRef& subscription_context) {
  // Process incoming DNS lookup event data
  // e.g., extract queried hostname, response IPs, process ID
  return Status::success();
}

} // namespace osquery
```

> **Note:** This subscriber is Windows-only and relies on the ETW (Event Tracing for Windows) infrastructure. It integrates with osquery's eventing framework and is not instantiated directly — the framework handles lifecycle management automatically.
