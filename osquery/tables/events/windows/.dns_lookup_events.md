Event subscriber header for capturing Windows DNS lookup events via ETW (Event Tracing for Windows).

## Key Components

- **`EtwDNSEventSubscriber`** — Final class inheriting from `EventSubscriber<EtwPublisherDNS>`. Subscribes to DNS events published by the ETW DNS publisher and processes them through a callback pattern.

| Method | Description |
|--------|-------------|
| `init()` | Initializes the subscriber and registers subscriptions |
| `eventCallback(...)` | Handles incoming DNS event data from the ETW publisher |

## Usage Example

```c
// The subscriber is registered automatically via osquery's event framework.
// Interaction is typically through the osquery table infrastructure:

namespace osquery {

Status EtwDNSEventSubscriber::init() {
  // Register subscription context with the ETW DNS publisher
  auto subscription = createSubscriptionContext();
  subscribe(&EtwDNSEventSubscriber::eventCallback, subscription);
  return Status::success();
}
```

## Notes

- Windows-only component; relies on `etw_publisher_dns.h` for the underlying ETW plumbing
- Populates the `dns_lookup_events` osquery virtual table, queryable via SQL
- Follows the standard osquery publisher/subscriber event model defined in `eventsubscriber.h`
