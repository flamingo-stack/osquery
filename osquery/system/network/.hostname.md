A header defining the `HostIdentity` data structure used to represent a host's network identity within osquery, including its fully qualified domain name and UUID.

## Key Components

- **`HostIdentity`** — A final class encapsulating host identification data with two public fields:
  - `fqdn` — The fully qualified domain name of the host
  - `uuid` — A unique identifier for the host
- **`HostIdentity::localhost()`** — Static factory method that constructs a `HostIdentity` instance populated with the local machine's identity information
- **`discloseSchema()`** — Templated schema disclosure method integrating with osquery's `schemer` serialization framework, registering `fqdn` and `uuid` fields

## Usage Example

```c
#include <osquery/utils/hostname.h>

// Retrieve the local host's identity
osquery::HostIdentity identity = osquery::HostIdentity::localhost();

// Access identity fields
std::string fqdn = identity.fqdn;
std::string uuid = identity.uuid;

// Schema serialization is handled automatically via schemer
// when used with osquery's archive/serialization pipeline
```

## Notes

- The class is marked `final`, preventing inheritance
- Schema registration via `discloseSchema` enables JSON/other format serialization through the [`schemer`](https://github.com/flamingo-stack/osquery/blob/main/osquery/utils/schemer/schemer.h) utility
- Lives within the `osquery` namespace
