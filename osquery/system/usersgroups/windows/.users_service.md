Background service that populates and maintains a Windows user cache by enumerating local accounts and roaming profiles.

## Key Components

### `UsersService` (class)
Extends `InternalRunnable` to run as a background dispatcher thread. Responsible for discovering Windows users and populating a shared `UsersCache` instance.

**Constructor**
```c
UsersService(std::promise<void> users_cache_promise,
             std::shared_ptr<UsersCache> users_cache);
```
Accepts a promise (signaled when the initial cache population completes) and a shared pointer to the cache being populated.

**Protected Methods**
- `start()` — Entry point called by the dispatcher when the service thread begins execution.

**Private Methods**
| Method | Description |
|--------|-------------|
| `processLocalAccounts()` | Enumerates local Windows accounts, tracks processed SIDs, and invokes the update callback per user |
| `processRoamingProfiles()` | Processes roaming profile users not already covered by local account enumeration |

**Private Members**
- `users_cache_promise_` — Signals cache readiness to waiting callers
- `users_cache_` — Shared reference to the `UsersCache` being built

## Usage Example

```cpp
#include <osquery/system/usersgroups/windows/users_service.h>

// Create shared cache and readiness promise
auto users_cache = std::make_shared<osquery::UsersCache>();
std::promise<void> cache_ready;
auto cache_future = cache_ready.get_future();

// Instantiate and dispatch the service
auto service = std::make_shared<osquery::UsersService>(
    std::move(cache_ready), users_cache);

osquery::Dispatcher::addService(service);

// Block until initial population is complete
cache_future.wait();
```

## Notes
- Windows-only; lives under the `windows/` path and depends on `users_groups_cache.h`
- The `UpdateUserFunc` alias (`void(User user)`) is passed as a callback to both processing methods, decoupling enumeration logic from cache-update logic
