Thread-safe in-memory cache for Windows user and group account data within the `osquery` namespace, supporting generation-based expiry to detect accounts removed from the system.

## Key Components

### Structs

| Struct | Fields | Description |
|--------|--------|-------------|
| `User` | `uid`, `gid`, `sid`, `username`, `description`, `type`, `directory`, `generation` | Represents a Windows user account |
| `Group` | `gid`, `sid`, `groupname`, `comment`, `generation` | Represents a Windows group account |

Both structs implement `operator==` (excludes `generation` from comparison).

### Type Aliases

- `UidCacheIndex` / `GidCacheIndex` — `unordered_multimap<DWORD, size_t>` for numeric ID lookups
- `SidCacheIndex` — `unordered_map<string, size_t>` for SID-based lookups
- `GroupnameCacheIndex` — `unordered_map<string, size_t>` for name-based lookups

### `UsersCache`

| Method | Description |
|--------|-------------|
| `initializeCache(users)` | Bulk-loads initial user set |
| `updateUser(user)` | Inserts or updates a user by SID, bumping its generation |
| `increaseGeneration()` | Advances the cache generation counter |
| `cleanupExpiredUsers()` | Removes users whose generation is behind the current counter |
| `getUsersByUid(uid)` | Returns all users matching a UID |
| `getUserBySid(sid)` | Returns a single user by SID |
| `getAllUsers()` | Returns the full cached user list |
| `clear()` | Resets cache state (for testing) |

### `GroupsCache`

Mirrors `UsersCache` with equivalent methods, adding `getGroupByName(name)` for name-based lookup.

## Usage Example

```cpp
// Populate and maintain a users cache
osquery::UsersCache users_cache;
users_cache.initializeCache(fetchAllSystemUsers());

// On periodic refresh
for (auto& user : fetchAllSystemUsers()) {
    users_cache.updateUser(user);
}
users_cache.increaseGeneration();
users_cache.cleanupExpiredUsers(); // removes accounts no longer on the system

// Lookup
auto user = users_cache.getUserBySid("S-1-5-21-...");
if (user.has_value()) {
    std::cout << user->username << "\n";
}

// Groups cache
osquery::GroupsCache groups_cache;
groups_cache.initializeCache(fetchAllSystemGroups());
auto group = groups_cache.getGroupByName("Administrators");
```

> **Thread safety:** Both caches use `std::mutex` (under `mutable`) to guard all reads and writes, making them safe for concurrent access from multiple threads.
