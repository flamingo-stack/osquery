Declares the `GroupsService` class, a background service that enumerates and caches local Windows groups for use in osquery table queries.

## Key Components

- **`GroupsService`** — Extends `InternalRunnable` to run as a background dispatcher thread; responsible for populating and updating a `GroupsCache` with local group data
- **`GroupsService(promise, cache)`** — Constructor accepting a `std::promise<void>` (signals cache readiness) and a shared `GroupsCache` instance
- **`start()`** — Override of `InternalRunnable::start()`; entry point for the background thread execution
- **`processLocalGroups(update_group_func)`** — Enumerates local Windows groups and invokes the provided callback for each discovered `Group`
- **`UpdateGroupFunc`** — Type alias for the group update callback signature: `void(Group)`

## Usage Example

```cpp
#include <osquery/system/usersgroups/windows/groups_service.h>

// Create shared cache and promise/future pair
auto groups_cache = std::make_shared<osquery::GroupsCache>();
std::promise<void> cache_ready_promise;
auto cache_ready_future = cache_ready_promise.get_future();

// Instantiate and dispatch the service
auto groups_svc = std::make_shared<osquery::GroupsService>(
    std::move(cache_ready_promise),
    groups_cache
);

// Wait for initial cache population before querying
cache_ready_future.wait();

// groups_cache is now populated with local Windows groups
```

## Notes

- Windows-only — located under the `windows/` path and depends on `users_groups_cache.h`
- The `std::promise<void>` pattern allows callers to block until the initial group enumeration completes, preventing queries against an empty cache
