Background service that populates and maintains the Windows groups cache by enumerating local groups and updating shared cache state.

## Key Components

### `GroupsService` (class)
Extends `InternalRunnable` to run as a background dispatcher thread. Responsible for enumerating local Windows groups and populating a shared `GroupsCache` instance.

| Member | Description |
|--------|-------------|
| `GroupsService(...)` | Constructor accepting a `std::promise<void>` (signals cache readiness) and a shared `GroupsCache` pointer |
| `start()` | Override of `InternalRunnable::start()`; entry point for the background thread |
| `processLocalGroups(...)` | Iterates local groups and invokes a callback for each `Group` entry |
| `groups_cache_promise_` | Fulfilled when initial cache population completes, unblocking dependent callers |
| `groups_cache_` | Shared pointer to the `GroupsCache` populated by this service |

## Usage Example

```cpp
#include "groups_service.h"

// Create the shared cache
auto groups_cache = std::make_shared<osquery::GroupsCache>();

// Set up a promise/future pair to wait for initial population
std::promise<void> groups_promise;
auto groups_future = groups_promise.get_future();

// Instantiate and dispatch the service
auto service = std::make_shared<osquery::GroupsService>(
    std::move(groups_promise), groups_cache);

Dispatcher::addService(service);

// Block until the cache is fully populated
groups_future.wait();

// groups_cache is now ready for use
```

## Notes

- Windows-only: depends on `users_groups_cache.h` under the `windows` path.
- The `std::promise` pattern provides a one-shot signal — callers `wait()` on the corresponding `std::future` before consuming cache data.
- Registered with the osquery `Dispatcher` via `InternalRunnable`, following the standard osquery service lifecycle.
