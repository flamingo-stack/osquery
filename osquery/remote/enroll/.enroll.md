Declares the enrollment plugin interface and utility functions for osquery node authentication and secret management with remote config/logger backends.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `FLAGS_disable_enrollment` | Flag (`bool`) | Runtime flag to disable all enrollment features |
| `kEnrollHostDetails` | `const std::set<std::string>` | Table names used to populate host identification details sent during enrollment |
| `EnrollPlugin` | Abstract class | Superclass for enrollment plugins; routes `call()` requests and provides host detail generation |
| `EnrollPlugin::enroll()` | Pure virtual method | Implemented by subclasses to perform the actual enrollment and return a node secret/key |
| `EnrollPlugin::genHostDetails()` | Protected method | Queries `kEnrollHostDetails` tables and populates a `JSON` object with the first row of each |
| `getNodeKey()` | Free function | Returns a cached node key from RocksDB or triggers enrollment via the named plugin |
| `clearNodeKey()` | Free function | Removes the persisted node key from backing storage |
| `getEnrollSecret()` | Free function | Reads and returns a trimmed enrollment secret from the path specified by `FLAGS_enroll_secret_path` |

## Usage Example

```cpp
#include <osquery/enrollment/enroll.h>

// Implementing a custom enroll plugin
class MyEnrollPlugin : public osquery::EnrollPlugin {
 protected:
  std::string enroll() override {
    // Contact your enrollment endpoint and return node key
    return "my-secret-node-key-from-backend";
  }
};

REGISTER(MyEnrollPlugin, "enroll", "my_enroll");

// Retrieving a node key (cached or fresh enrollment)
std::string node_key = osquery::getNodeKey("my_enroll");

// Reading a pre-shared enrollment secret from disk
const std::string secret = osquery::getEnrollSecret();

// Clearing a stored node key (e.g., on re-enrollment)
osquery::Status status = osquery::clearNodeKey();
if (!status.ok()) {
  LOG(ERROR) << "Failed to clear node key: " << status.getMessage();
}
```

## Notes

- Enrollment plugins are best deployed as a **suite** alongside matching config and logger plugins.
- `getNodeKey()` caches results in RocksDB; `clearNodeKey()` forces re-enrollment on next request.
