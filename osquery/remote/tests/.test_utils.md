Provides a singleton TLS server runner utility for managing a local TLS test server process during osquery integration tests.

## Key Components

### `TLSServerRunner` (class)
A non-copyable singleton class that manages the lifecycle of a TLS server subprocess used in testing client-side TLS functionality.

| Member | Description |
|--------|-------------|
| `instance()` | Returns the singleton `TLSServerRunner` instance |
| `start(server_cert, verify_client_cert)` | Launches the TLS server process; returns `false` on failure |
| `stop()` | Terminates the server process on exit |
| `port()` | Returns the TCP port the server is listening on |
| `setClientConfig()` | Configures osquery flags for TLS client testing |
| `unsetClientConfig()` | Restores osquery flags to pre-test state |
| `getListeningPortPid()` | Resolves the PID of a process bound to a given port |
| `startAndSetScript()` | Spawns the TLS server subprocess and assigns `server_` |

**Private state:**
- `server_` — shared handle to the running `PlatformProcess`
- `port_` — bound TCP port string
- Saved flag values: `tls_hostname_`, `enroll_tls_endpoint_`, `tls_server_certs_`, `enroll_secret_path_`

## Usage Example

```cpp
#include "test_utils.h"

// Start the TLS server before tests
bool ok = osquery::TLSServerRunner::start("/path/to/server.crt", false);
if (!ok) {
  // handle startup failure
}

// Configure client flags to point at the test server
osquery::TLSServerRunner::setClientConfig();

// Access the listening port
std::string port = osquery::TLSServerRunner::port();

// Run TLS-dependent tests...

// Restore flags and shut down after tests
osquery::TLSServerRunner::unsetClientConfig();
osquery::TLSServerRunner::stop();
```

## Notes
- Inherits `boost::noncopyable` — copy/move construction is disabled by design.
- The server process is lazily started; calling `start()` multiple times is safe.
- Source: [`test_utils.h`](https://github.com/flamingo-stack/osquery/blob/main/test_utils.h)
