URI parsing utility class for the `osquery` namespace, derived from folly/uri, that parses and provides structured access to individual components of a URI string.

## Key Components

### `Uri` class

| Member | Description |
|--------|-------------|
| `Uri(const std::string& str)` | Constructor — parses a URI string; throws `std::invalid_argument` on failure |
| `scheme()` | Returns the lowercased scheme (e.g., `"http"`) |
| `username()` / `password()` | Returns auth credentials if present |
| `host()` | Returns host, with brackets for IPv6 (e.g., `"[::1]"`) |
| `hostname()` | Returns host without brackets — suitable for `getaddrinfo()` and similar APIs |
| `port()` | Returns port as `uint16_t` |
| `path()` | Returns the URI path component |
| `query()` | Returns the raw query string |
| `fragment()` | Returns the fragment/anchor |
| `authority()` | Returns the combined authority component |
| `setPort(uint16_t)` | Overrides the port and marks authority as present |
| `getQueryParams()` | Parses query string into key-value pairs; **not thread-safe on first call** |

> **Note:** Component parts are **not** percent-decoded. Callers must decode values manually using `uriUnescape()` as appropriate.

## Usage Example

```cpp
#include "uri.h"

try {
    osquery::Uri uri("http://user:pass@www.example.com:8080/foo/bar?key=val#anchor");

    std::string scheme   = uri.scheme();    // "http"
    std::string host     = uri.hostname();  // "www.example.com"
    uint16_t    port     = uri.port();      // 8080
    std::string path     = uri.path();      // "/foo/bar"
    std::string fragment = uri.fragment();  // "anchor"

    // Iterate query parameters
    for (const auto& [key, value] : uri.getQueryParams()) {
        // key="key", value="val"
    }
} catch (const std::invalid_argument& e) {
    // Handle malformed URI
}
```
