A URI parsing utility class (adapted from folly/uri) that parses and provides structured access to URI components within the `osquery` namespace.

## Key Components

### `Uri` class
- **Constructor** — `Uri(const std::string& str)`: Parses a URI string; throws `std::invalid_argument` on failure
- **`scheme()`** — Returns the lowercased scheme (e.g., `"http"`)
- **`host()`** — Returns host, including brackets for IPv6 (e.g., `"[::1]"`)
- **`hostname()`** — Returns host without IPv6 brackets; suitable for `getaddrinfo()` and similar APIs
- **`port()`** — Returns the port as `uint16_t`
- **`path()`** — Returns the URI path (e.g., `"/foo/bar"`)
- **`query()`** — Returns the raw query string (e.g., `"key=foo"`)
- **`fragment()`** — Returns the fragment/anchor (e.g., `"anchor"`)
- **`authority()`** — Returns the combined authority (host + port)
- **`getQueryParams()`** — Parses and returns query string as `vector<pair<string,string>>`; lazy, not thread-safe on first call
- **`setPort(uint16_t)`** — Overrides the port value

> **Note:** Component parts are **not** percent-decoded. Call `uriUnescape()` separately as needed.

## Usage Example

```cpp
#include "uri.h"

try {
    osquery::Uri uri("http://www.example.com:8080/foo/bar?key=foo#anchor");

    uri.scheme();    // "http"
    uri.hostname();  // "www.example.com"
    uri.port();      // 8080
    uri.path();      // "/foo/bar"
    uri.query();     // "key=foo"
    uri.fragment();  // "anchor"

    // Parse query parameters
    for (const auto& [key, value] : uri.getQueryParams()) {
        // key="key", value="foo"
    }
} catch (const std::invalid_argument& e) {
    // Handle malformed URI
}
```
