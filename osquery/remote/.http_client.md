HTTP client interface for osquery's remote communication layer, providing HTTP/HTTPS request functionality built on Boost.Beast and OpenSSL.

## Key Components

### `Client`
The primary HTTP client class supporting GET, POST, PUT, HEAD, and DELETE methods over both plain and TLS-encrypted connections.

**Key methods:**
- `get(Request&)` / `head(Request&)` / `delete_(Request&)` — Simple HTTP methods
- `post(Request& req, string body, string content_type)` — HTTP POST
- `put(Request& req, string body, string content_type)` — HTTP PUT
- `setOptions(Options const&)` — Reconfigure client behavior

### `Client::Options`
Fluent builder for configuring client behavior. Returns `*this` on each setter for chaining.

| Option | Description |
|--------|-------------|
| `ssl_connection(bool)` | Enable TLS wrapping |
| `timeout(int)` | Request timeout in seconds |
| `always_verify_peer(bool)` | Enforce peer certificate verification |
| `follow_redirects(bool)` | Auto-follow HTTP redirects |
| `proxy_hostname(string)` | Route through proxy |
| `openssl_certificate(string)` | Server certificate for verification |
| `openssl_private_key_file(string)` | Client private key |

### `HTTP_Request<T>` / `HTTP_Response<T>`
Template wrappers around Boost.Beast request/response types, adding URI parsing via `osquery::Uri`.

**Key methods on `HTTP_Request`:**
- `remoteHost()`, `remotePort()`, `remotePath()`, `protocol()` — URI component accessors

### Type Aliases
```c
typedef HTTP_Request<beast_http_request>  Request;
typedef HTTP_Response<beast_http_response> Response;
```

### Constants
- `kInstanceMetadataAuthority` — `"169.254.169.254"` (cloud metadata endpoint)

## Usage Example

```cpp
#include <osquery/remote/http_client.h>

osquery::http::Client::Options opts;
opts.ssl_connection(true)
    .timeout(10)
    .always_verify_peer(true)
    .openssl_certificate("/etc/ssl/certs/ca-bundle.crt");

osquery::http::Client client(opts);

osquery::http::Request req("https://example.com/api/data");
osquery::http::Response resp = client.get(req);
```
