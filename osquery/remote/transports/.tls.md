HTTPS/TLS transport layer implementation for osquery remote communication, providing secure client-server connections with configurable certificate management and cipher suite enforcement.

## Key Components

### Constants & Flags
- **`kTLSCiphers`** — Restrictive cipher suite string enforcing strong encryption (ECDH/DH/RSA with AES/3DES, excluding weak options)
- **`tls_client_key`** — Flag for optional PEM client private key path
- **`tls_client_cert`** — Flag for optional PEM client certificate path
- **`tls_hostname`** — Flag for TLS server hostname

### Enums
- **`HTTPVerb`** — Supported HTTP methods: `HTTP_POST` (0), `HTTP_PUT` (1)

### Class: `TLSTransport`
Extends `Transport` to implement HTTPS communication:

| Method | Description |
|---|---|
| `sendRequest()` | Sends a parameterless request; returns status code 1 (connectivity) or 2 (TLS error) |
| `sendRequest(params, compress)` | Sends a request with serialized parameters, optional compression |
| `getInternalOptions()` | Returns restrictive cipher suite options for osquery infrastructure |
| `getOptions()` | Returns general-purpose options for AWS/generic endpoints |
| `decorateRequest(r)` | Applies base modifications to an HTTP request object |
| `setClientCertificate(...)` | Configures client-side TLS authentication |
| `setPeerCertificate(...)` | Configures server certificate pinning |
| `disableVerifyPeer()` | Disables peer verification (test use only) |

## Usage Example

```cpp
#include <osquery/remote/transports/tls.h>

// Create and configure a TLS transport
auto transport = std::make_shared<osquery::TLSTransport>();

// Use restrictive options for osquery internal infrastructure
auto options = transport->getInternalOptions();

// Send a request with serialized parameters
std::string params = R"({"node_key": "abc123"})";
osquery::Status status = transport->sendRequest(params, /* compress= */ false);

if (!status.ok()) {
  // status.getCode() == 1: connectivity issue
  // status.getCode() == 2: TLS-specific error
  LOG(ERROR) << status.getMessage();
}
```

> **Note:** `disableVerifyPeer()` and `FRIEND_TEST` declarations are reserved for unit testing via `TLSTransportsTests`. Do not use in production code.
