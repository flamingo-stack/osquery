Defines the `TLSTransport` class and supporting declarations for HTTPS communication within the osquery remote transport layer, including cipher suite configuration, client/server certificate handling, and OpenFrame authorization integration.

## Key Components

- **`kTLSCiphers`** — Hardcoded restrictive cipher suite string enforcing best-practice TLS encryption (excludes `aNULL`, `MD5`, `CBC`, `SHA`)
- **`HTTPVerb`** — Enum defining supported HTTP methods (`HTTP_POST`, `HTTP_PUT`)
- **`TLSTransport`** — Primary class extending `Transport`; handles HTTPS request dispatch with optional compression, client-auth certificates, server pinning, and peer verification
  - `sendRequest()` — Sends a parameterless HTTPS request
  - `sendRequest(params, compress)` — Sends a serialized parameter payload, optionally gzip-compressed
  - `getInternalOptions()` — Returns hardened TLS options (restricted ciphers + client certs) for osquery infrastructure
  - `getOptions()` — Returns general-purpose TLS options for AWS or public endpoints
  - `decorateRequest(r)` — Applies base headers/modifications to an outgoing request
  - `disableVerifyPeer()` — Testing-only method to skip peer certificate validation

**Flags declared:**
- `tls_client_key` — Path to PEM private key for client auth
- `tls_client_cert` — Path to PEM certificate for client auth
- `tls_hostname` — Target TLS server hostname

## Usage Example

```cpp
#include "tls.h"

osquery::TLSTransport transport;

// For osquery infrastructure (strict ciphers, client cert)
auto opts = transport.getInternalOptions();

// For general HTTPS endpoints (e.g., AWS)
auto genericOpts = transport.getOptions();

// Send a request with JSON params
osquery::Status status = transport.sendRequest("{\"key\":\"value\"}", true);
if (!status.ok()) {
  // status.getCode(): 1 = connectivity error, 2 = TLS-specific error
}
```
