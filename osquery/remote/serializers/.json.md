A JSON serializer implementation for osquery's remote request system, providing serialization and deserialization of JSON data for HTTP communication.

## Key Components

### `JSONSerializer` (class)
Extends the base `Serializer` class to handle JSON encoding/decoding for remote requests.

| Method | Description |
|--------|-------------|
| `serialize(const JSON&, std::string&)` | Converts a `JSON` object into a serialized string |
| `deserialize(const std::string&, JSON&)` | Parses a serialized string back into a `JSON` object |
| `getContentType()` | Returns `"application/json"` for HTTP `Content-Type` headers |

## Usage Example

```c
#include <osquery/remote/serializers/json.h>

osquery::JSONSerializer serializer;

// Serialize JSON to string
osquery::JSON json;
std::string output;
auto status = serializer.serialize(json, output);

// Deserialize string to JSON
std::string raw = R"({"key": "value"})";
osquery::JSON result;
auto status = serializer.deserialize(raw, result);

// Get content type for HTTP headers
std::string contentType = serializer.getContentType();
// Returns: "application/json"
```

## Notes

- Inherits from the `Serializer` base class defined in [`osquery/remote/requests.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/remote/requests.h)
- Used internally by the osquery remote transport layer when communicating with TLS/HTTP endpoints
- All methods return a `Status` object for error handling
