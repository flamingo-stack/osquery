Defines the `JSONSerializer` class for serializing and deserializing JSON data in osquery's remote request infrastructure.

## Key Components

- **`JSONSerializer`** — Concrete implementation of the `Serializer` interface that handles JSON-formatted data for remote communications.
  - `serialize(const JSON& json, std::string& serialized)` — Converts a `JSON` object into a string representation.
  - `deserialize(const std::string& serialized, JSON& json)` — Parses a JSON string back into a `JSON` object.
  - `getContentType()` — Returns `"application/json"` as the MIME content type.

## Usage Example

```cpp
#include <osquery/remote/serializers/json.h>

osquery::JSONSerializer serializer;

// Serialize
osquery::JSON json;
std::string output;
osquery::Status status = serializer.serialize(json, output);

// Deserialize
osquery::JSON parsed;
osquery::Status status = serializer.deserialize(output, parsed);

// Content-Type header value
std::string contentType = serializer.getContentType();
// "application/json"
```
