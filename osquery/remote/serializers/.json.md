Defines the `JSONSerializer` class for serializing and deserializing JSON data in osquery's remote request pipeline.

## Key Components

- **`JSONSerializer`** — Concrete implementation of the `Serializer` interface that handles JSON encoding/decoding for remote communications.
  - `serialize(const JSON& json, std::string& serialized)` — Converts a `JSON` object into a string representation.
  - `deserialize(const std::string& serialized, JSON& json)` — Parses a JSON string back into a `JSON` object.
  - `getContentType()` — Returns `"application/json"` as the MIME content type.

## Usage Example

```cpp
#include <osquery/remote/serializers/json.h>

osquery::JSONSerializer serializer;

// Serialize
osquery::JSON jsonObj;
std::string output;
auto status = serializer.serialize(jsonObj, output);
if (!status.ok()) {
  LOG(ERROR) << "Serialization failed: " << status.getMessage();
}

// Deserialize
osquery::JSON parsed;
auto status2 = serializer.deserialize(output, parsed);

// Content type for HTTP headers
std::string contentType = serializer.getContentType();
// => "application/json"
```
