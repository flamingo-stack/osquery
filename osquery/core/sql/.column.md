Defines column metadata types used throughout the osquery table plugin system, including column option flags, data types, and type aliases for describing table schemas.

## Key Components

### `ColumnOptions` (enum class)
Bitmask flags controlling column behavior in SQL queries:

| Flag | Value | Description |
|------|-------|-------------|
| `DEFAULT` | 0 | No special behavior |
| `INDEX` | 1 | Treat as primary key |
| `REQUIRED` | 2 | Must appear in `WHERE` clause |
| `ADDITIONAL` | 4 | Expands result scope when in predicate |
| `OPTIMIZED` | 8 | Enables query-level optimization |
| `HIDDEN` | 16 | Excluded from `SELECT *` results |
| `COLLATE*` | 32–2048 | Custom collation sequences |

Supports bitwise `|` and `&` operators for combining and testing flags.

### `ColumnType` (enum)
Represents SQLite-compatible column data types: `TEXT_TYPE`, `INTEGER_TYPE`, `BIGINT_TYPE`, `UNSIGNED_BIGINT_TYPE`, `DOUBLE_TYPE`, `BLOB_TYPE`, and `UNKNOWN_TYPE`.

### Type Aliases
- **`TableName`** — `std::string` alias for table plugin names
- **`TableColumns`** — Ordered vector of `(name, ColumnType, ColumnOptions)` tuples describing a table schema
- **`ColumnAliasSet`** — Map from column name to a set of alias strings

### `kColumnTypeNames`
External map translating `ColumnType` constants to their SQLite string representations.

## Usage Example

```c
#include <osquery/core/tables.h>
#include "column.h"

using namespace osquery;

// Define columns for a custom table
TableColumns getColumns() {
  return {
    {"uid",      INTEGER_TYPE, ColumnOptions::INDEX},
    {"path",     TEXT_TYPE,    ColumnOptions::REQUIRED | ColumnOptions::OPTIMIZED},
    {"checksum", TEXT_TYPE,    ColumnOptions::HIDDEN},
    {"size",     BIGINT_TYPE,  ColumnOptions::DEFAULT},
  };
}

// Test if a column has a specific option
ColumnOptions opts = ColumnOptions::INDEX | ColumnOptions::HIDDEN;
bool isHidden = (opts & ColumnOptions::HIDDEN) != 0; // true
```
