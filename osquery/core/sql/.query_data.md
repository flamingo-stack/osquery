Defines the core result-set types and serialization utilities for representing and converting osquery SQL query results.

## Key Components

### Type Aliases

| Type | Definition | Purpose |
|------|-----------|---------|
| `QueryData` | `std::vector<Row>` | Standard (untyped) SQL result set |
| `QueryDataTyped` | `std::vector<RowTyped>` | Typed SQL result set |
| `QueryDataSet` | `std::multiset<RowTyped>` | Multiset for fast row lookup |

### Serialization Functions

- **`serializeQueryData`** — Converts `QueryData` or `QueryDataTyped` into a `rapidjson::Document` array; accepts optional column ordering and numeric serialization flag
- **`serializeQueryDataJSON`** — Overloads for serializing `QueryData` or `QueryDataTyped` directly to a `JSON` document or `std::string`

### Deserialization Functions

- **`deserializeQueryData`** — Converts a `rapidjson::Value` array back into `QueryData`, `QueryDataTyped`, or `QueryDataSet`
- **`deserializeQueryDataJSON`** — Parses a JSON document or string back into `QueryData` or `QueryDataSet`

### Utility

- **`addUniqueRowToQueryData`** — Appends a `RowTyped` to a `QueryDataTyped` only if it is not already present (linear scan)

## Usage Example

```cpp
#include <osquery/core/sql/query_data.h>

// Serialize query results to JSON string
osquery::QueryData results = runSomeQuery();
std::string json;
auto status = osquery::serializeQueryDataJSON(results, json);
if (!status.ok()) {
  LOG(ERROR) << status.getMessage();
}

// Deserialize JSON back to QueryData
osquery::QueryData restored;
osquery::deserializeQueryDataJSON(json, restored);

// Deduplicated insert into typed result set
osquery::QueryDataTyped typed;
osquery::RowTyped row = {{"col", osquery::INTEGER(42)}};
osquery::addUniqueRowToQueryData(typed, row);
```

## Notes

- `QueryDataSet` uses `std::multiset`, making it suited for duplicate-aware fast lookups rather than uniqueness enforcement
- `addUniqueRowToQueryData` performs a linear scan — avoid for large result sets in hot paths
