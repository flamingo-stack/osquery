Defines the `DiffResults` structure and associated utilities for computing and serializing the difference between two osquery query result sets.

## Key Components

### `DiffResults` struct
A move-only data structure holding the delta between two `QueryDataTyped` result sets:

| Member | Type | Description |
|--------|------|-------------|
| `added` | `QueryDataTyped` | Rows present in the new result but not the old |
| `removed` | `QueryDataTyped` | Rows present in the old result but not the new |

**Methods:**
- `hasNoResults()` — Returns `true` if both `added` and `removed` are empty
- `operator==` / `operator!=` — Equality comparison between two `DiffResults`

### Free Functions

| Function | Description |
|----------|-------------|
| `diff(old_, new_)` | Computes the delta between a `QueryDataSet` and a `QueryDataTyped`, returning a `DiffResults` |
| `serializeDiffResults(...)` | Serializes a `DiffResults` into a `rapidjson::Document` object with `added`/`removed` keys |
| `serializeDiffResultsJSON(...)` | Serializes a `DiffResults` directly into a JSON string |

## Usage Example

```cpp
#include <osquery/core/sql/diff_results.h>

// Compute diff between old and new query results
QueryDataSet oldResults = getOldResults();
QueryDataTyped newResults = getNewResults();

DiffResults delta = osquery::diff(oldResults, newResults);

if (!delta.hasNoResults()) {
    std::string json;
    Status s = osquery::serializeDiffResultsJSON(delta, json, /*asNumeric=*/false);
    if (s.ok()) {
        LOG(INFO) << "Changes detected: " << json;
    }
}
```

## Notes
- `DiffResults` inherits from `only_movable` — copy construction and assignment are disabled; use `std::move` when transferring ownership.
- The `asNumeric` flag in serialization functions controls whether numeric column values are emitted as JSON numbers rather than strings.
