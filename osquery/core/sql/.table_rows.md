Defines the `TableRows` type alias and declares serialization/deserialization utilities for converting collections of table rows to and from JSON.

## Key Components

- **`TableRows`** — Type alias for `std::vector<TableRowHolder>`, representing a collection of query result rows.
- **`serializeTableRows`** — Serializes a `TableRows` object into a `rapidjson::Document` JSON array.
- **`serializeTableRowsJSON`** — Serializes a `TableRows` object directly into a JSON-formatted `std::string`.
- **`deserializeTableRows`** — Deserializes a `rapidjson::Value` JSON array back into a `TableRows` object.
- **`deserializeTableRowsJSON`** — Deserializes a JSON string back into a `TableRows` object.

All functions return a `Status` indicating success or failure.

## Usage Example

```c
#include "table_rows.h"

// Serialize to JSON string
osquery::TableRows rows = getQueryResults();
std::string json;
osquery::Status s = osquery::serializeTableRowsJSON(rows, json);
if (s.ok()) {
    // use json string
}

// Deserialize from JSON string
osquery::TableRows restored;
osquery::Status s2 = osquery::deserializeTableRowsJSON(json, restored);

// Serialize to JSON document array
osquery::JSON doc;
rapidjson::Document arr;
osquery::Status s3 = osquery::serializeTableRows(rows, doc, arr);
```
