Defines the `TableRows` type alias and declares serialization/deserialization utilities for converting collections of table rows to and from JSON.

## Key Components

- **`TableRows`** — Type alias for `std::vector<TableRowHolder>`, representing a collection of query result rows.
- **`serializeTableRows()`** — Serializes a `TableRows` object into a `rapidjson::Document` JSON array.
- **`serializeTableRowsJSON()`** — Serializes a `TableRows` object directly into a JSON-formatted `std::string`.
- **`deserializeTableRows()`** — Converts a `rapidjson::Value` JSON array back into a `TableRows` object.
- **`deserializeTableRowsJSON()`** — Converts a raw JSON string back into a `TableRows` object.

## Usage Example

```c
#include "table_rows.h"

osquery::TableRows rows;
// ... populate rows from a query ...

// Serialize to JSON string
std::string json_output;
osquery::Status status = osquery::serializeTableRowsJSON(rows, json_output);
if (status.ok()) {
    // json_output now contains the serialized rows
}

// Deserialize back from JSON string
osquery::TableRows restored_rows;
osquery::Status ds = osquery::deserializeTableRowsJSON(json_output, restored_rows);
if (!ds.ok()) {
    // handle error
}
```

All four functions return an `osquery::Status` object — check `.ok()` to confirm success or retrieve an error message via `.getMessage()`.
