Defines the `ScheduledQuery` struct representing a single scheduled query's configuration within the osqueryd daemon.

## Key Components

### `ScheduledQuery` (struct)
A move-only data structure (inherits `only_movable`) encapsulating all attributes of a scheduled query:

| Field | Type | Description |
|-------|------|-------------|
| `pack_name` | `std::string` | Parent pack name |
| `name` | `std::string` | Query identifier |
| `query` | `std::string` | SQL query string |
| `oncall` | `std::string` | Query owner |
| `interval` | `uint64_t` | Execution frequency in seconds |
| `splayed_interval` | `uint64_t` | Temporary splayed interval |
| `startup_priority` | `uint64_t` | Startup execution priority (`UINT64_MAX` = disabled) |
| `denylisted` | `bool` | Whether query is currently denylisted |
| `options` | `std::map<std::string, bool>` | Key/value query option flags |

**Methods:**
- `isSnapshotQuery()` — Returns `true` if the `"snapshot"` option is enabled
- `reportRemovedRows()` — Returns `true` if removed rows should be reported (defaults to `true` when option is absent)
- `operator==` / `operator!=` — Equality based on `query` and `interval` fields

## Usage Example

```c
#include <osquery/config/scheduled_query.h>

// Construct with pack, name, and SQL
osquery::ScheduledQuery sq("pack_default", "users_query", "SELECT * FROM users;");
sq.interval = 60;
sq.options["snapshot"] = false;
sq.options["removed"] = true;

// Check query behavior
if (sq.isSnapshotQuery()) {
    // handle snapshot mode
}

if (sq.reportRemovedRows()) {
    // include removed rows in results
}

// Move semantics only — copy construction is deleted
osquery::ScheduledQuery sq2 = std::move(sq);
```

> **Note:** `ScheduledQuery` is move-only. Copy construction and copy assignment are disabled via `only_movable`. Equality comparison checks only `query` and `interval` — other fields (e.g., `options`, `denylisted`) are ignored in comparisons.
