Defines the `ScheduledQuery` struct used within osqueryd to represent all relevant attributes of a scheduled SQL query, including execution interval, ownership, and runtime options.

## Key Components

### `ScheduledQuery` (struct, `osquery` namespace)
A move-only data structure (inherits `only_movable`) holding the configuration and state of a scheduled query.

**Fields:**

| Field | Type | Description |
|---|---|---|
| `pack_name` | `string` | Name of the containing pack |
| `name` | `string` | Query identifier |
| `query` | `string` | The SQL query string |
| `oncall` | `string` | Owner/responsible team |
| `interval` | `uint64_t` | Execution frequency in seconds |
| `splayed_interval` | `uint64_t` | Temporary splayed interval value |
| `startup_priority` | `uint64_t` | Startup execution priority (`UINT64_MAX` = disabled) |
| `denylisted` | `bool` | Whether the query is denylisted |
| `options` | `map<string, bool>` | Runtime option flags (e.g. `snapshot`, `removed`) |

**Methods:**

- `isSnapshotQuery()` — Returns `true` if the `snapshot` option is set
- `reportRemovedRows()` — Returns `true` if the `removed` option is set or absent (defaults to reporting)
- `operator==` / `operator!=` — Equality based on `query` and `interval` only

## Usage Example

```cpp
#include <osquery/config/scheduled_query.h>

// Construct with pack, name, and SQL
osquery::ScheduledQuery sq("my_pack", "running_procs", "SELECT * FROM processes;");
sq.interval = 60;
sq.options["snapshot"] = false;
sq.options["removed"] = true;

if (!sq.isSnapshotQuery() && sq.reportRemovedRows()) {
    // Differential query — schedule for execution
}

// Move semantics only; copy construction is deleted
osquery::ScheduledQuery sq2 = std::move(sq);
```
