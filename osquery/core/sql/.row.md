Defines the core data structures and serialization utilities for representing individual database query rows in osquery, supporting both untyped string-based and SQLite type-affinity-aware typed variants.

## Key Components

### Type Aliases
| Alias | Underlying Type | Description |
|-------|----------------|-------------|
| `RowData` | `std::string` | Base column value type |
| `RowDataTyped` | `boost::variant<long long, double, std::string>` | Typed column value (maps to SQLite affinities) |
| `Row` | `std::map<std::string, RowData>` | Untyped row as column-name → string |
| `RowTyped` | `std::map<std::string, RowDataTyped>` | Typed row as column-name → variant |
| `ColumnNames` | `std::vector<std::string>` | Ordered list of column names from a query |

### Serialization Functions
- **`serializeRow`** — Serializes a `Row` or `RowTyped` into a `rapidjson::Value` object within a managed `JSON` document
- **`serializeRowJSON`** — Serializes a `Row` or `RowTyped` directly to a JSON string; typed variant accepts `asNumeric` flag to preserve numeric types

### Deserialization Functions
- **`deserializeRow`** — Populates a `Row` or `RowTyped` from a `rapidjson::Value` object
- **`deserializeRowJSON`** — Populates a `Row` or `RowTyped` from a raw JSON string

All functions return an osquery `Status` indicating success or failure.

## Usage Example

```c
#include <osquery/core/tables.h>
#include <osquery/utils/db/row.h>

// Build a simple untyped row
osquery::Row r;
r["pid"]  = "1234";
r["name"] = "my_process";

// Serialize to JSON string
std::string json;
auto status = osquery::serializeRowJSON(r, json);
if (status.ok()) {
    // json => {"pid":"1234","name":"my_process"}
}

// Deserialize back
osquery::Row r2;
osquery::deserializeRowJSON(json, r2);

// Typed row — numeric values preserved when asNumeric=true
osquery::RowTyped rt;
rt["pid"]  = (long long)1234;
rt["load"] = 0.75;
rt["name"] = std::string("my_process");

std::string typedJson;
osquery::serializeRowJSON(rt, typedJson, /*asNumeric=*/true);
// typedJson => {"pid":1234,"load":0.75,"name":"my_process"}
```
