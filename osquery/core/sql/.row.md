Defines the core data structures and serialization utilities for representing and manipulating single database query rows within the osquery framework.

## Key Components

### Type Aliases
| Type | Definition |
|------|------------|
| `RowData` | `std::string` — raw column value |
| `RowDataTyped` | `boost::variant<long long, double, std::string>` — typed column value |
| `Row` | `std::map<std::string, RowData>` — untyped row (column → string) |
| `RowTyped` | `std::map<std::string, RowDataTyped>` — typed row (column → variant) |
| `ColumnNames` | `std::vector<std::string>` — ordered column name list |

### Serialization Functions
- **`serializeRow`** — Serializes a `Row` or `RowTyped` into a `rapidjson::Value` object within a managed `JSON` document
- **`serializeRowJSON`** — Serializes a `Row` or `RowTyped` directly to a JSON string; supports optional numeric type preservation via `asNumeric`

### Deserialization Functions
- **`deserializeRow`** — Deserializes a `rapidjson::Value` object into a `Row` or `RowTyped`
- **`deserializeRowJSON`** — Deserializes a raw JSON string into a `Row` or `RowTyped`

All functions return an osquery `Status` object indicating success or failure.

## Usage Example

```c
#include <osquery/core/tables.h>
#include <osquery/utils/db/row.h>

// Build a simple row
osquery::Row r;
r["pid"]  = "1234";
r["name"] = "my_process";

// Serialize to JSON string
std::string json;
auto status = osquery::serializeRowJSON(r, json);
if (status.ok()) {
  // json == {"pid":"1234","name":"my_process"}
}

// Deserialize back from JSON
osquery::Row r2;
osquery::deserializeRowJSON(json, r2);

// Typed row with numeric preservation
osquery::RowTyped rt;
rt["pid"]  = 1234LL;
rt["load"] = 0.75;
rt["name"] = std::string("my_process");

std::string typedJson;
osquery::serializeRowJSON(rt, typedJson, /*asNumeric=*/true);
```
