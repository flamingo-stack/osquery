Defines the core data types and serialization utilities for representing a single database query row in osquery, supporting both string-based and typed (variant) row formats.

## Key Components

### Type Aliases

| Type | Definition |
|------|-----------|
| `RowData` | `std::string` — raw column value |
| `RowDataTyped` | `boost::variant<long long, double, std::string>` — typed column value |
| `Row` | `std::map<std::string, RowData>` — untyped row |
| `RowTyped` | `std::map<std::string, RowDataTyped>` — type-aware row |
| `ColumnNames` | `std::vector<std::string>` — ordered column names |

### Serialization Functions

- **`serializeRow(Row, ColumnNames, JSON, Value)`** — serializes an untyped `Row` into a JSON object, respecting column order
- **`serializeRow(RowTyped, JSON, Value, bool)`** — serializes a typed row; `asNumeric` controls whether numeric types emit as numbers or strings
- **`serializeRowJSON(Row, string&)`** — convenience wrapper producing a JSON string from a `Row`
- **`serializeRowJSON(RowTyped, string&, bool)`** — convenience wrapper for `RowTyped`

### Deserialization Functions

- **`deserializeRow(Value, Row&)`** — parses a `rapidjson::Value` object into a `Row`
- **`deserializeRow(Value, RowTyped&)`** — parses a `rapidjson::Value` into a `RowTyped`
- **`deserializeRowJSON(string, Row&)`** — parses a JSON string into a `Row`
- **`deserializeRowJSON(string, RowTyped&)`** — parses a JSON string into a `RowTyped`

## Usage Example

```c
#include <osquery/core/sql/row.h>

// Build a simple untyped row
osquery::Row r;
r["pid"] = "1234";
r["name"] = "launchd";

// Serialize to JSON string
std::string json;
osquery::Status s = osquery::serializeRowJSON(r, json);
// json => {"pid":"1234","name":"launchd"}

// Round-trip: deserialize back
osquery::Row restored;
osquery::deserializeRowJSON(json, restored);

// Typed row with numeric serialization
osquery::RowTyped rt;
rt["pid"] = (long long)1234;
rt["load"] = 0.75;

std::string typedJson;
osquery::serializeRowJSON(rt, typedJson, /*asNumeric=*/true);
// typedJson => {"pid":1234,"load":0.75}
```
