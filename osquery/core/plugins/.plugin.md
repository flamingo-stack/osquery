Defines the core `Plugin` base class and associated types for the osquery plugin/registry system, establishing the interface all registry items must implement.

## Key Components

- **`PluginRequest`** — `std::map<std::string, std::string>` alias representing the input to a plugin call, typically containing an `"action"` key
- **`PluginResponse`** — `std::vector<PluginRequest>` alias representing the output returned from a plugin call
- **`Plugin`** — Abstract base class (non-copyable) that all registry plugins must extend:
  - `setUp()` / `tearDown()` — Optional lifecycle hooks
  - `configure()` — Called on configuration updates
  - `routeInfo()` — Publishes plugin routing metadata
  - `call()` — **Pure virtual**; the primary entry point every plugin must implement
  - `getName()` / `setName()` — Plugin identity accessors (`setName` is `final`)
  - `addExternal()` / `removeExternal()` — Static hooks for external (extension) plugin registration
- **`PluginRef`** — `std::shared_ptr<Plugin>` convenience alias
- **`tableRowsToPluginResponse()`** — Free function converting `TableRows` into a `PluginResponse`

## Usage Example

```cpp
#include <osquery/registry/plugin.h>

class MyPlugin : public osquery::Plugin {
 public:
  osquery::Status setUp() override {
    // Optional initialization
    return osquery::Status::success();
  }

  osquery::Status call(const osquery::PluginRequest& request,
                       osquery::PluginResponse& response) override {
    auto action = request.find("action");
    if (action == request.end()) {
      return osquery::Status::failure("No action specified");
    }

    if (action->second == "query") {
      response.push_back({{"result", "some_value"}});
    }

    return osquery::Status::success();
  }
};
```

Plugins are invoked via `Registry::call`, passing a `PluginRequest` and receiving a `PluginResponse`. See [`osquery/registry/`](https://github.com/flamingo-stack/osquery/blob/main/osquery/registry/) for registry integration details.
