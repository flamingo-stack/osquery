Defines the `Initializer` class and core system utility functions for bootstrapping, managing, and tearing down an osquery process across daemon, shell, worker, and watcher execution modes.

## Key Components

### `Initializer` Class
The primary lifecycle manager for any osquery process. Non-copyable by design.

| Method | Description |
|--------|-------------|
| `Initializer(argc, argv, tool, init_glog)` | Bootstraps process state; call from `main()` |
| `initDaemon()` | Configures process as a long-running daemon |
| `initShell()` | Configures process as a lightweight interactive shell |
| `initWorkerWatcher(name)` | Spawns and monitors child worker processes with CPU/memory bounds |
| `start()` | Begins active work after initialization |
| `shutdown(retcode)` | Stops all services/threads cleanly; returns most appropriate exit code |
| `requestShutdown(retcode)` | Static; signals shutdown from any context |
| `shutdownNow(retcode)` | Static; immediate exit without dispatcher coordination |
| `isWorker()` / `isWatcher()` | Static; detect process role via environment variables |
| `resourceLimitHit()` | Static; signals that a resource limit has been exceeded |

### UUID & Identity Utilities

| Function | Description |
|----------|-------------|
| `generateNewUUID()` | Returns a new random UUID string |
| `getInstanceUUID(ident)` | Persistent per-instance UUID |
| `getEphemeralUUID(ident)` | Session-scoped UUID |
| `getHostUUID(ident)` | Hardware-derived host UUID |
| `getHostIdentifier()` | Configured unique machine identifier |
| `isPlaceholderHardwareUUID(uuid)` | Detects known invalid/placeholder UUIDs |

### System Helpers

| Function | Description |
|----------|-------------|
| `isUserAdmin()` | Returns `true` if running with admin privileges |
| `setThreadName(name)` | Sets OS-level thread name |
| `getStartTime()` / `setStartTime(st)` | Tool start time tracking |
| `platformSetup()` / `platformTeardown()` | Platform-specific init/cleanup (e.g., COM on Windows) |
| `checkPlatform(platform)` | Validates platform compatibility string |

## Usage Example

```cpp
#include <osquery/core/system.h>

int main(int argc, char* argv[]) {
  // Bootstrap osquery as a daemon
  osquery::Initializer runner(argc, argv, osquery::ToolType::DAEMON);

  runner.initDaemon();

  // Spawn and monitor worker processes
  runner.initWorkerWatcher("osqueryd");

  // Workers proceed past initWorkerWatcher; begin processing
  runner.start();

  // Block until shutdown is requested
  runner.waitForShutdown();

  return runner.shutdown(EXIT_SUCCESS);
}
```
