Provides the core initialization, lifecycle management, and system identity utilities for osquery processes, defining the `Initializer` class and related helper functions used across daemon, shell, worker, and watcher process types.

## Key Components

**`Initializer` class** — Primary entry point for osquery process setup (non-copyable):
- `Initializer(argc, argv, tool, init_glog)` — Bootstraps process state; call from `main()`
- `initDaemon()` — Configures process as an osquery daemon with mutex and config validation
- `initShell()` — Lightweight shell mode initialization
- `initWorkerWatcher(name)` — Spawns and monitors worker child processes with CPU/memory bounds
- `start()` — Begins active work after initialization
- `shutdown(retcode)` — Stops all services/threads cleanly; returns most appropriate exit code
- `requestShutdown(retcode)` / `shutdownNow(retcode)` — Static shutdown triggers
- `isWorker()` / `isWatcher()` — Detect current process role via environment variable

**UUID & Identity helpers:**
- `generateNewUUID()` — Creates a random UUID string
- `getInstanceUUID()` / `getEphemeralUUID()` / `getHostUUID()` — Scoped UUID getters returning `Status`
- `getHardwareUUID()` / `getHostIdentifier()` — Machine-level identification
- `isPlaceholderHardwareUUID(uuid)` — Filters known invalid/placeholder UUIDs

**System utilities:**
- `isUserAdmin()` — Checks if the process runs with admin privileges
- `setThreadName(name)` — Platform-aware thread naming
- `getStartTime()` / `setStartTime(st)` — Tool start timestamp accessors
- `platformSetup()` / `platformTeardown()` — Platform-specific init/teardown (e.g., COM on Windows)

## Usage Example

```c
int main(int argc, char* argv[]) {
    osquery::Initializer runner(argc, argv, osquery::ToolType::DAEMON);

    runner.initDaemon();

    // Watcher forks workers; only workers return here
    runner.initWorkerWatcher("osqueryd");

    runner.start();

    return runner.shutdown(EXIT_SUCCESS);
}
```
