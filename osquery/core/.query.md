Brief description of the file's purpose: Defines the `Query` class and `QueryLogItem` struct for managing scheduled query execution history, result diffing, and JSON serialization within osquery's persistent storage layer.

## Key Components

### `QueryLogItem` (struct)
Holds metadata and results for a single query execution log entry, supporting both differential and snapshot result modes. Fields include:
- `isSnapshot`, `results` (`DiffResults`), `snapshot_results` — result data
- `name`, `identifier`, `time`, `epoch`, `counter`, `calendar_time` — execution metadata
- `decorations` — additional key-value fields emitted with log lines
- `operator==` / `operator!=` — comparison by results and name

### Serialization Functions
| Function | Description |
|---|---|
| `serializeQueryLogItem` | Serializes a `QueryLogItem` to a JSON document |
| `serializeQueryLogItemJSON` | Serializes a `QueryLogItem` to a JSON string |
| `serializeQueryLogItemAsEvents` | Serializes as an events list (actions) to a JSON document |
| `serializeQueryLogItemAsEventsJSON` | Serializes as events to a vector of JSON strings |

### `Query` (class)
Manages persistent RocksDB-backed history for a named scheduled query.

| Method | Description |
|---|---|
| `getPreviousQueryResults` | Retrieves prior results as a `QueryDataSet` |
| `saveQueryResults` | Persists serialized JSON results and epoch |
| `getPreviousEpoch` | Returns epoch of last stored results |
| `getQueryCounter` | Returns/resets invocation counter |
| `isQueryNameInDatabase` | Checks if query name exists in storage |
| `isNewQuerySql` | Detects if query SQL has changed |
| `getQueryStatus` | Determines if results are fresh or query is new |
| `addNewResults` | Stores results and computes differential |
| `addNewEvents` | Variant of `addNewResults` for event-based queries |
| `getCurrentResults` | Retrieves the most recent result set |
| `getStoredQueryNames` *(static)* | Lists all query names stored in RocksDB |

## Usage Example

```c
// Construct a Query object for a scheduled query
ScheduledQuery sq;
sq.query = "SELECT * FROM processes;";
osquery::Query q("process_monitor", sq);

// Check if query is new or has changed SQL
bool fresh, is_new;
q.getQueryStatus(current_epoch, fresh, is_new);

// Execute and store results, retrieving differential
osquery::DiffResults diff;
uint64_t counter = 0;
osquery::QueryDataTyped results = /* run query */;
q.addNewResults(std::move(results), current_epoch, counter, diff);

// Serialize the log item for upstream logging
osquery::QueryLogItem item;
item.name = "process_monitor";
item.results = diff;
item.epoch = current_epoch;
item.counter = counter;

std::string json_output;
osquery::serializeQueryLogItemJSON(item, json_output);
```
