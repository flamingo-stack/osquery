Declares the `Flag` singleton class and supporting macros that wrap gflags to provide osquery-specific flag registration, categorization, and runtime management.

## Key Components

### Data Structures
- **`FlagDetail`** — Metadata for a flag: description, and boolean attributes (`shell`, `external`, `cli`, `hidden`)
- **`FlagInfo`** — Full flag snapshot including type, description, default value, current value, and its `FlagDetail`

### `Flag` Class (Singleton)
| Method | Description |
|--------|-------------|
| `create()` | Registers a new named flag with its detail metadata |
| `createAlias()` | Creates a gflags alias backed by `getValue()` |
| `flags()` | Returns all registered flags as a `map<string, FlagInfo>` |
| `getValue()` / `getInt32Value()` | Reads the current flag value |
| `getDefaultValue()` | Retrieves the compiled-in default |
| `updateValue()` | Overrides a flag's value at runtime |
| `isDefault()` | Checks whether a flag still holds its default |
| `isCLIOnlyFlag()` | Returns true if the flag cannot be set via configuration |
| `printFlags()` | Prints help output, optionally filtered by shell/external/cli |
| `resetCustomFlags()` | Clears custom flags (used by fuzzer targets) |

### Registration Macros
| Macro | Behavior |
|-------|----------|
| `FLAG(t, n, v, d)` | Standard flag — settable via flagfile, CLI, or config options |
| `SHELL_FLAG(t, n, v, d)` | osqueryi (shell) only |
| `EXTENSION_FLAG(t, n, v, d)` | Extensions only |
| `CLI_FLAG(t, n, v, d)` | CLI/flagfile only; not settable in config `options` |
| `HIDDEN_FLAG(t, n, v, d)` | Excluded from `--help` output |

## Usage Example

```c
// Declare a standard flag
FLAG(string, config_path, "/etc/osquery/osquery.conf", "Path to config file");

// Declare a CLI-only flag
CLI_FLAG(bool, disable_extensions, false, "Disable extension manager");

// Read and update at runtime
std::string val = Flag::getValue("config_path");
Flag::updateValue("config_path", "/custom/path.conf");

// Check if still at default
if (Flag::isDefault("config_path")) {
  // user has not overridden it
}
```
