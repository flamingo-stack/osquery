Defines the core data structures and type system for osquery's virtual table infrastructure, including SQLite type affinity macros, constraint operators, and the `ConstraintList` used to filter table query results.

## Key Components

- **`__sqliteField` / Type Macros** — Overloaded template functions and macros (`SQL_TEXT`, `INTEGER`, `BIGINT`, `DOUBLE`, etc.) that convert native C++ types to SQLite-compatible string representations
- **`ConstraintOperator`** — Enum defining SQL predicate operators (`EQUALS`, `GREATER_THAN`, `LIKE`, `GLOB`, `REGEXP`, etc.)
- **`Constraint`** — Struct pairing an operator with a string expression, representing a single WHERE clause condition
- **`TableAttributes`** — Flags enum describing table behavior (`CACHEABLE`, `EVENT_BASED`, `USER_BASED`, `PENDING`, etc.)
- **`ConstraintList`** — Core struct holding all constraints for a single column, with methods for matching, existence checks, and serialization
- **Type Aliases** — `TableColumns`, `ConstraintMap`, `ConstraintSet`, `UsedColumns`, `UsedColumnsBitset` for query context plumbing

## Usage Example

```c
// Check if a query constrains a column to a specific value
ConstraintList cl;
cl.affinity = TEXT_TYPE;
cl.add(Constraint(EQUALS, "chrome"));

// In table generation logic:
if (cl.exists(EQUALS)) {
    for (const auto& val : cl.getAll(EQUALS)) {
        // val == "chrome" — use to filter rows
    }
}

// Match a candidate value against all constraints
std::string candidate = "chrome";
if (cl.matches(candidate)) {
    // Row passes the predicate — include in results
}

// Convert native types to SQLite text fields
std::string row_pid   = INTEGER(1234);
std::string row_name  = SQL_TEXT("osqueryd");
std::string row_bytes = BIGINT(9876543210LL);
```
