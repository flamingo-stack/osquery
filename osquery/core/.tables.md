Defines core data structures and types for osquery's virtual table system, providing the foundational abstractions for SQL query constraint handling, column type affinities, and table attribute management used by all osquery table implementations.

## Key Components

- **`__sqliteField()`** — Overloaded inline helpers that convert various C/C++ types (primitives, char arrays, strings) into `std::string` for SQLite storage
- **Type Affinity Macros** — `SQL_TEXT`, `INTEGER`, `BIGINT`, `UNSIGNED_BIGINT`, `DOUBLE` for column value conversion; `TEXT_LITERAL`, `INTEGER_LITERAL`, etc. for C++ type aliases
- **`ConstraintOperator`** — Enum of SQL predicate operators (`EQUALS`, `GREATER_THAN`, `LIKE`, `GLOB`, `REGEXP`, etc.)
- **`Constraint`** — POD struct pairing an operator with its expression string
- **`ConstraintList`** — Non-copyable collection of `Constraint` objects for a single column; provides `matches()`, `exists()`, `existsAndMatches()`, `notExistsOrMatches()`, and `getAll()` query helpers
- **`TableAttributes`** — Bitmask enum flagging table behaviors (`CACHEABLE`, `EVENT_BASED`, `USER_BASED`, `PENDING`, etc.)
- **Type Aliases** — `TableColumns`, `ConstraintMap`, `ConstraintSet`, `UsedColumns`, `UsedColumnsBitset`, `ColumnAliasSet`, `AliasColumnMap`

## Usage Example

```cpp
// Checking constraints in a table generator
void MyTablePlugin::generate(QueryContext& context) {
    auto& uid_constraints = context.constraints["uid"];

    // Only filter if a constraint was provided
    if (uid_constraints.exists(EQUALS)) {
        for (const auto& uid : uid_constraints.getAll(EQUALS)) {
            // fetch rows matching uid
        }
    }

    // Build a row using type affinity macros
    Row r;
    r["uid"]  = INTEGER(1000);
    r["name"] = SQL_TEXT("alice");
    r["size"] = BIGINT(file_size);
}
```
