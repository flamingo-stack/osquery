Thread-safe singleton providing lazy, future-backed access to globally cached Windows user and group data, coordinated with the osquery initialization lifecycle.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `GlobalUsersGroupsCache` | Class | Singleton cache accessor for Windows users and groups |
| `getUsersCache()` | Static method | Blocks until `UsersCache` is ready, then returns a const reference |
| `getGroupsCache()` | Static method | Blocks until `GroupsCache` is ready, then returns a const reference |
| `global_users_cache_future_` | Private field | `shared_future<void>` signaling users cache initialization |
| `global_groups_cache_future_` | Private field | `shared_future<void>` signaling groups cache initialization |
| `Initializer` | Friend class | Permitted to wire up the cache lifecycle |
| `initUsersAndGroupsServices` | Friend function | Populates and signals the cache futures on startup |
| `deinitUsersAndGroupsServices` | Friend function | Tears down cache resources on shutdown |

## Usage Example

```cpp
#include <osquery/system/usersgroups/windows/global_users_groups_cache.h>

// Retrieve cached users - blocks until initialization is complete
const osquery::UsersCache& users = osquery::GlobalUsersGroupsCache::getUsersCache();

// Retrieve cached groups - blocks until initialization is complete
const osquery::GroupsCache& groups = osquery::GlobalUsersGroupsCache::getGroupsCache();

// Iterate over cached users
for (const auto& user : users) {
  // process user entry
}
```

## Notes

- **Windows-only**: Depends on `users_groups_cache.h` under the `windows/` path.
- **Blocking semantics**: Both getters block the calling thread via `shared_future::get()` until the background service completes initialization — safe to call from table query threads.
- **Lifecycle ownership**: Construction and destruction of the underlying cache instances are exclusively controlled by `Initializer`, `initUsersAndGroupsServices`, and `deinitUsersAndGroupsServices` via `friend` access.
