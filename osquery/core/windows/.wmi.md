Windows Management Instrumentation (WMI) abstraction layer for osquery, providing a clean C++ interface for executing WMI queries and retrieving typed results on Windows systems.

## Key Components

### `WmiMethodArgs`
Helper class for constructing WMI method call arguments. Supports a templated `Put<T>()` method to add named parameters and `GetArguments()` to retrieve the argument map (`WmiMethodArgsMap`).

### `WmiResultItem`
Wraps a single `IWbemClassObject` result. Provides typed getter methods for extracting WMI property values:

| Method | Return Type |
|---|---|
| `GetBool` | `bool` |
| `GetString` | `std::string` / `std::wstring` |
| `GetLong` / `GetLongLong` | `long` / `long long` |
| `GetUnsignedInt32` / `GetUnsignedLong` / `GetUnsignedLongLong` | unsigned variants |
| `GetUChar` / `GetUnsignedShort` | `unsigned char` / `unsigned short` |
| `GetDateTime` | `FILETIME` |
| `GetVectorOfStrings` / `GetVectorOfLongs` | `vector<string>` / `vector<long>` |

All getters return an osquery `Status` indicating success or failure.

### `WmiRequest`
Main query class. Created via the static factory `CreateWmiRequest()` returning `Expected<WmiRequest, WmiError>`. Executes WQL queries against a configurable WMI namespace (default: `ROOT\CIMV2`) and exposes results via `results()`. Supports `ExecMethod()` for invoking WMI methods on result objects.

### `impl::WmiObjectDeleter`
Internal RAII deleter for COM `IUnknown` pointers, used with `std::unique_ptr` throughout to ensure proper `Release()` calls.

## Usage Example

```cpp
#include <osquery/utils/system/windows/wmi.h>

// Execute a WMI query
auto request = osquery::WmiRequest::CreateWmiRequest(
    "SELECT Name, ProcessId FROM Win32_Process");

if (!request) {
  // Handle construction error
  return;
}

for (const auto& item : request->results()) {
  std::string name;
  unsigned int pid = 0;

  item.GetString("Name", name);
  item.GetUnsignedInt32("ProcessId", pid);

  // Use name and pid...
}

// Execute a WMI method with arguments
osquery::WmiMethodArgs args;
args.Put<std::string>("InputParam", "value");

osquery::WmiResultItem out;
request->ExecMethod(someResultItem, "MethodName", args, out);
```
