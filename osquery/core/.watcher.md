Defines the watchdog infrastructure for osquery, providing classes and structures to spawn, monitor, and enforce performance limits on worker processes and autoloaded extension processes.

## Key Components

### Enums & Structs

- **`WatchdogLimitType`** — Categorizes performance limits: `MEMORY_LIMIT`, `UTILIZATION_LIMIT`, `RESPAWN_LIMIT`, `RESPAWN_DELAY`, `LATENCY_LIMIT`, `INTERVAL`
- **`PerformanceState`** — Snapshot struct tracking CPU time, memory footprint, sustained latency, and last respawn time for a monitored process
- **`ExtensionMap`** — Type alias (`std::map<std::string, std::shared_ptr<PlatformProcess>>`) mapping extension paths to their managed processes

### Classes

- **`Watcher`** — Thread-safe, non-copyable singleton managing state for the worker process and autoloaded extensions. Tracks performance states, restart counts, and process handles. Exposes `bindFates()`, `hasManagedExtensions()`, `loadExtensions()`, and `getWorkerStatus()`
- **`WatcherRunner`** — `InternalRunnable` thread that spawns and polls worker/extension processes. Enforces performance limits via `isChildSane()`, handles respawning via `createWorker()` / `createExtension()`, and can gracefully stop children via `stopChild()`
- **`WatcherWatcherRunner`** — Inverse watchdog spawned inside the worker process to detect if the parent watcher dies

### Free Function

- **`getWorkerLimit(WatchdogLimitType)`** — Returns a numeric performance threshold for a given limit category and watchdog level

## Usage Example

```cpp
// Construct and start the watcher runner in the dispatcher
auto watcher = std::make_shared<Watcher>();
watcher->loadExtensions();

auto runner = std::make_shared<WatcherRunner>(argc, argv, /*use_worker=*/true, watcher);
Dispatcher::addService(runner);

// Query a performance limit
uint64_t memLimit = getWorkerLimit(WatchdogLimitType::MEMORY_LIMIT);
```
