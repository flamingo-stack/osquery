Declares the `osquery` shutdown coordination API, providing functions to request, monitor, and wait for application shutdown across multi-threaded osquery components.

## Key Components

| Function | Description |
|---|---|
| `requestShutdown(retcode, system_log)` | Primary shutdown trigger; signals all dispatched services to stop gracefully |
| `waitForShutdown()` | Blocks the calling thread until a shutdown is requested |
| `waitTimeoutOrShutdown(timeout)` | Interruptible sleep — returns early if shutdown is requested |
| `shutdownRequested()` | Non-blocking check for shutdown state (intended for shell tools) |
| `getShutdownExitCode()` / `setShutdownExitCode()` | Get/set the process exit code |
| `resetShutdown()` | Resets shutdown state — for internal use and testing only |

## Usage Example

```cpp
#include <osquery/core/shutdown.h>

// In a signal handler or failure path:
void onFatalError() {
    osquery::requestShutdown(EXIT_FAILURE, "Unrecoverable config error");
}

// In main(), block until shutdown is signaled:
int main() {
    // ... initialize services ...

    osquery::waitForShutdown();

    // ... teardown ...
    return osquery::getShutdownExitCode();
}

// In a retry loop, sleep interruptibly:
bool enrollWithRetry() {
    while (true) {
        if (tryEnroll()) return true;

        // Wait 30s, but exit early if shutdown is requested
        bool shutdown = osquery::waitTimeoutOrShutdown(
            std::chrono::milliseconds(30000)
        );
        if (shutdown) return false;
    }
}
```

> **Note:** Prefer `requestShutdown()` over `stdlib exit()` in all osquery components to ensure graceful teardown of event threads and Thrift service pools.
