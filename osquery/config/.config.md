Programmatic representation of osquery's runtime configuration, providing a singleton `Config` class that manages query schedules, file watches, config source hashing, performance tracking, and plugin-driven config parsing.

## Key Components

- **`Config`** — Singleton class (non-copyable) encapsulating all configuration state
- **`Config::get()`** — Static singleton accessor
- **`Config::update()`** — Applies new config data from a source map
- **`Config::recordQueryPerformance()`** — Records pre/post execution metrics for scheduled queries
- **`Config::recordQueryStart()`** — Marks a query as "dirty" (in-flight) in the backing store
- **`Config::genHash()` / `hashSource()`** — SHA1 hashing of config content per source
- **`Config::scheduledQueries()`** — Iterates scheduled queries via a predicate callback
- **`Config::packs()`** — Iterates registered query packs via a predicate callback
- **`Config::files()`** — Iterates watched file categories via a predicate callback
- **`Config::getParser()`** — Retrieves a named `ConfigParserPlugin` from the registry
- **`Config::validateConfig()`** — Validates JSON document structure and depth
- **`Config::restoreConfigBackup()`** — Retrieves config persisted in the database
- **`kExecutingQuery`** — Global string holding the currently executing query name

## Usage Example

```cpp
// Access the singleton
auto& c = Config::get();

// Load and apply config from a plugin source
c.load();

// Iterate all scheduled queries
c.scheduledQueries([](std::string name, const ScheduledQuery& query) {
  LOG(INFO) << "Scheduled query: " << name;
});

// Retrieve performance stats for a specific query
Config::getPerformanceStats("my_query", [](const QueryPerformance& perf) {
  LOG(INFO) << "Executions: " << perf.executions;
});

// Iterate watched file categories
c.files([](const std::string& category,
           const std::vector<std::string>& paths) {
  LOG(INFO) << "Category: " << category;
});
```
