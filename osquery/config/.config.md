Programmatic representation of osquery's runtime configuration, providing a singleton `Config` class that manages query schedules, packs, file categories, performance tracking, and config plugin integration.

## Key Components

- **`Config` (singleton class)** — Core configuration manager; non-copyable, accessed via `Config::get()`
- **`update()`** — Applies new config data from a map of namespace → JSON string sources
- **`restoreConfigBackup()`** — Retrieves persisted config from the database via `Expected<>`
- **`recordQueryPerformance()`** — Captures before/after process metrics for scheduled queries
- **`recordQueryStart()`** — Marks a query as "dirty" (running) to detect prior aborts on restart
- **`genHash()` / `hashSource()`** — SHA1-based change detection per config source
- **`scheduledQueries()`** — Iterates scheduled queries via a predicate function
- **`files()`** — Iterates configured filesystem glob categories via a predicate
- **`getPerformanceStats()`** — Retrieves `QueryPerformance` stats by query name
- **`getParser()`** — Retrieves a `ConfigParserPlugin` instance from the registry
- **`validateConfig()`** — Verifies JSON root is an object within max depth limits
- **`kExecutingQuery`** — Global string holding the currently executing query name

## Usage Example

```cpp
// Access the singleton
auto& cfg = Config::get();

// Iterate all scheduled queries
cfg.scheduledQueries([](std::string name, const ScheduledQuery& query) {
  std::cout << "Query: " << name << std::endl;
});

// Iterate configured file categories
cfg.files([](const std::string& category,
             const std::vector<std::string>& files) {
  for (const auto& f : files) {
    std::cout << category << ": " << f << std::endl;
  }
});

// Retrieve performance stats for a query
Config::getPerformanceStats("my_query", [](const QueryPerformance& perf) {
  std::cout << "Executions: " << perf.executions << std::endl;
});
```
