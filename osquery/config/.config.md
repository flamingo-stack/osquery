Programmatic representation of osquery's configuration system, providing a singleton interface for loading, updating, validating, and querying configuration data including scheduled queries, packs, file categories, and performance metrics.

## Key Components

### `Config` (Singleton Class)
The core configuration manager. Access via `Config::get()`.

**Public Methods:**
- `update()` — Apply new config data from a source map
- `restoreConfigBackup()` — Retrieve persisted config from the database
- `recordQueryPerformance()` — Store pre/post query process metrics
- `recordQueryStart()` — Mark a query as dirty/initialized before execution
- `genHash()` / `getHash()` / `hashSource()` — SHA1 hashing per source
- `scheduledQueries()` — Iterate scheduled queries via predicate
- `packs()` — Iterate registered packs via predicate
- `files()` — Iterate file categories via predicate
- `getPerformanceStats()` — Access `QueryPerformance` data by query name
- `getParser()` — Retrieve a `ConfigParserPlugin` by name
- `validateConfig()` — Verify JSON document structure and depth
- `addPack()` / `removePack()` — Manage query packs
- `addFile()` / `removeFiles()` — Manage monitored file paths

**Protected Methods:**
- `refresh()` / `load()` — Trigger config reload from plugin
- `updateSource()` — Process a single source update
- `applyParsers()` — Dispatch JSON keys to registered `ConfigParserPlugin` instances
- `genPack()` — Resolve a pack resource via `ConfigPlugin`
- `purge()` / `reset()` — Cleanup and test utilities

### `kExecutingQuery`
Global string tracking the currently executing scheduled query name.

## Usage Example

```cpp
// Access the singleton
auto& config = Config::get();

// Iterate scheduled queries
config.scheduledQueries([](std::string name, const ScheduledQuery& query) {
  std::cout << "Query: " << name << std::endl;
});

// Retrieve performance stats
Config::getPerformanceStats("my_query", [](const QueryPerformance& perf) {
  std::cout << "Executions: " << perf.executions << std::endl;
});

// Update config from a source map
Status s = config.update({{"filesystem", "{\"schedule\": {}}"}});
```
