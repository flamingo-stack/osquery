Utility header providing test infrastructure helpers for osquery configuration and pack testing, exposing directory accessors and fixture data generators.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `getTestConfigDirectory()` | Function | Returns path to the test configuration directory |
| `getTestHelperScriptsDirectory()` | Function | Returns path to the test helper scripts directory |
| `getTestConfigMap()` | Function | Builds a config map from a file, mapping source name to JSON content |
| `getExamplePacksConfig()` | Function | Returns a `JSON` object representing a sample packs configuration |
| `getUnrestrictedPack()` | Function | Returns a `JSON` pack with no platform/version restrictions |
| `getRestrictedPack()` | Function | Returns a `JSON` pack with platform/version restrictions applied |
| `getPackWithDiscovery()` | Function | Returns a `JSON` pack containing discovery queries |
| `getPackWithValidDiscovery()` | Function | Returns a `JSON` pack with a valid, passing discovery query |
| `getPackWithFakeVersion()` | Function | Returns a `JSON` pack referencing a non-existent osquery version |

## Usage Example

```c
#include "test_utils.h"

// Access test fixture directories
auto config_dir = osquery::getTestConfigDirectory();
auto scripts_dir = osquery::getTestHelperScriptsDirectory();

// Load a config map from a test file
auto config_map = osquery::getTestConfigMap("test_config.json");

// Retrieve fixture pack configurations for unit tests
osquery::JSON unrestricted = osquery::getUnrestrictedPack();
osquery::JSON restricted   = osquery::getRestrictedPack();
osquery::JSON discovery    = osquery::getPackWithDiscovery();
```

## Notes

- All functions live in the `osquery` namespace.
- Depends on `osquery/utils/json/json.h` for the `JSON` type and `boost::filesystem::path` for cross-platform path handling.
- Intended for use in test targets only — not part of the production library surface.
