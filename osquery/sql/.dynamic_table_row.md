Defines `DynamicTableRow` and `DynamicTableRowHolder`, providing a string-map-backed implementation of the `TableRow` interface for use in osquery's virtual table system.

## Key Components

### `DynamicTableRow`
Concrete `TableRow` subclass backed by a `Row` (string-to-string map). Key methods:
- **Constructors** — default, move from `Row`, and initializer-list forms
- `get_rowid()` — resolves the SQLite row ID, falling back to a default
- `get_column()` — binds a column value into a `sqlite3_context`
- `serialize()` — writes the row into a JSON document
- `clone()` — returns a deep copy wrapped in a `TableRowHolder`
- `operator[]` / `count()` — map-style access to column values

### `DynamicTableRowHolder`
RAII wrapper around a heap-allocated `DynamicTableRow` plus its `TableRowHolder`. Simplifies working with dynamic rows before strongly-typed rows are ubiquitous. Implicitly converts to `TableRowHolder&&` for insertion into result sets.

### Free Functions
- `make_table_row()` — creates an empty `DynamicTableRowHolder`
- `make_table_row(init)` — creates a `DynamicTableRowHolder` from an initializer list
- `tableRowsFromQueryData(QueryData&&)` — converts legacy `QueryData` to `TableRows` (generated-code use only)
- `deserializeRow(doc, r)` — populates a `DynamicTableRowHolder` from a JSON object

## Usage Example

```cpp
#include <osquery/core/sql/dynamic_table_row.h>

// Inline construction
auto row = make_table_row({
    {"pid",  "1234"},
    {"name", "osqueryd"},
    {"path", "/usr/bin/osqueryd"},
});

// Value access
std::string& name = row["name"];

// Convert to TableRowHolder for result set insertion
TableRows results;
results.push_back(std::move((TableRowHolder&&)row));
```
