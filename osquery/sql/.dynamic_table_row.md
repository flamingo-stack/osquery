Defines the `DynamicTableRow` and `DynamicTableRowHolder` classes, providing a string-map-backed implementation of the `TableRow` interface for use in osquery's virtual table system.

## Key Components

**`DynamicTableRow`** — Concrete `TableRow` backed by a `Row` (string map):
- `get_rowid()` — returns the row's SQLite row ID
- `get_column()` — populates a `sqlite3_context` with column data
- `serialize()` — writes the row into a RapidJSON object
- `clone()` — returns a heap-allocated copy wrapped in `TableRowHolder`
- `operator[]` / `count()` — direct map-style access to row fields

**`DynamicTableRowHolder`** — RAII wrapper pairing a raw `DynamicTableRow*` with its owning `TableRowHolder`, simplifying usage before strongly-typed rows are universally adopted. Implicitly converts to `TableRowHolder&&`.

**Free functions:**
- `make_table_row()` — factory returning an empty `DynamicTableRowHolder`
- `make_table_row(init)` — factory from an initializer list of key-value pairs
- `tableRowsFromQueryData()` — converts a `QueryData` struct to `TableRows` (intended for generated code)
- `deserializeRow()` — populates a `DynamicTableRowHolder` from a RapidJSON value

## Usage Example

```c
// Create a row with initial values
auto row = make_table_row({
    {"pid",  "1234"},
    {"name", "osqueryd"},
    {"path", "/usr/bin/osqueryd"}
});

// Access or mutate fields
row["status"] = "running";

// Convert to TableRowHolder for use in a TableRows result
TableRows results;
results.push_back(std::move(row));

// Deserialize from JSON
DynamicTableRowHolder out;
Status s = deserializeRow(jsonValue, out);
```
