Defines the SQLite virtual table interface for osquery, providing the core structures and functions needed to attach osquery table plugins as SQLite virtual tables in an in-memory database.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `kAttachMutex` | `RecursiveMutex` | Global mutex protecting concurrent table attach operations |
| `BaseCursor` | `struct` | SQLite cursor state — holds rows, position, and optional coroutine generator |
| `VirtualTable` | `struct` | SQLite vtab wrapper — links the plugin's `VirtualTableContent` metadata and the active `SQLiteDBInstance` |
| `attachTableInternal()` | Function | Attaches a named table plugin to a given SQLite DB instance |
| `detachTableInternal()` | Function | Drops (detaches) a named table from a SQLite DB instance |
| `attachFunctionInternal()` | Function | Registers a custom scalar function into SQLite |
| `attachVirtualTables()` | Function | Bulk-attaches all registered table plugins to a DB instance |
| `registerForeignTables()` | Function | Registers cross-platform schema plugins from the generated amalgamation (non-external builds only) |

## Usage Example

```cpp
#include <osquery/sql/virtual_table.h>

// Attach a single table plugin to a new SQLite instance
auto instance = SQLiteDBManager::getUnique();
Status s = attachTableInternal("users", instance, false);
if (!s.ok()) {
    LOG(ERROR) << "Failed to attach table: " << s.getMessage();
}

// Attach all registered tables at DB init time
attachVirtualTables(instance);

// Register a custom SQLite scalar function
attachFunctionInternal("my_func", [](sqlite3_context* ctx, int argc, sqlite3_value** argv) {
    sqlite3_result_int(ctx, 42);
});
```

> Both `BaseCursor` and `VirtualTable` are non-copyable and intended exclusively for use inside SQLite virtual table module callbacks — do not instantiate them directly outside of vtab method implementations.
