Defines the core SQL query interface for osquery, providing both a high-level `SQL` class and lower-level free functions for executing SQLite-backed queries against osquery's virtual table system.

## Key Components

### `SQL` Class
The primary interface for executing osquery SQL queries. Wraps query execution and exposes results, column metadata, and status in a structured way.

| Member | Description |
|--------|-------------|
| `SQL(query, use_cache)` | Constructor — executes query immediately |
| `rows()` | Returns `QueryData` (const and mutable overloads) |
| `columns()` | Returns `ColumnNames` with column order |
| `ok()` | Returns `true` if query succeeded |
| `getStatus()` | Returns the underlying `Status` object |
| `getMessageString()` | Returns human-readable status message |
| `selectAllFrom(table)` | Static helper — `SELECT * FROM <table>` |
| `selectAllFrom(table, column, op, expr)` | Static helper — `SELECT * FROM <table> WHERE <column> <op> <expr>` |
| `selectFrom(columns, table, column, op, expr)` | Static helper — `SELECT <columns> FROM <table> WHERE ...` |

### Free Functions

| Function | Description |
|----------|-------------|
| `query(q, results, use_cache)` | Low-level query execution; populates a `QueryData` output parameter |
| `getQueryColumns(q, columns)` | Analyzes a query and returns result column names/types via SQLite |
| `getQueryTables(q, tables)` | Extracts referenced virtual table names from a query string |

## Usage Example

```cpp
// High-level SQL class usage
SQL sql("SELECT * FROM time");
if (sql.ok()) {
  for (const auto& row : sql.rows()) {
    for (const auto& col : row) {
      LOG(INFO) << col.first << " => " << col.second;
    }
  }
} else {
  LOG(ERROR) << sql.getMessageString();
}

// Static helper with constraint
QueryData results = SQL::selectAllFrom(
  "processes", "pid", EQUALS, "1234"
);

// Low-level free function
QueryData out;
Status s = query("SELECT name FROM processes;", out);

// Inspect columns without full execution
TableColumns cols;
getQueryColumns("SELECT * FROM users", cols);

// Extract referenced tables
std::vector<std::string> tables;
getQueryTables("SELECT * FROM users JOIN groups", tables);
```

> **Note:** Prefer `osquery::SQL` over the lower-level `query()` free function for most use cases. The `SQL` class is move-only (`only_movable`) and not copyable.
