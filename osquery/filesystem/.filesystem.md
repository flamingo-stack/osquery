Provides filesystem abstraction utilities for osquery, including file I/O, directory traversal, glob pattern resolution, permission checks, and Linux `/proc` filesystem helpers.

## Key Components

### Enums & Constants
- **`GlobLimits`** — Bitmask enum controlling glob traversal: `GLOB_FILES`, `GLOB_FOLDERS`, `GLOB_ALL`, `GLOB_NO_CANON`
- **`kSQLGlobWildcard`** / **`kSQLGlobRecursive`** — SQL-style wildcard tokens (`%`, `%%`) used in path pattern matching

### File I/O
- **`readFile(path, content)`** — Reads a file into a string; size-bounded by the `read_max` flag; handles special files (FIFOs, named pipes) safely
- **`readFile(path, predicate)`** — Chunk-based variant that invokes a callback per chunk
- **`writeTextFile(path, content, permissions, mode)`** — Writes text to disk with configurable permissions and open mode
- **`parseJSON(path, tree)`** — Parses a JSON file into a Boost property tree

### Path & Permission Utilities
- **`pathExists`** / **`isDirectory`** / **`isReadable`** / **`isWritable`** — Path introspection helpers
- **`safePermissions(dir, path, executable)`** — Validates file ownership/permissions against `/tmp`-style directory risks
- **`resolveFilePattern(pattern, results [, setting])`** — Expands SQL/glob patterns to matching filesystem paths
- **`replaceGlobWildcards(pattern, limits)`** — Converts SQL `%` wildcards to filesystem `*` globs with optional canonicalization

### Directory Operations
- **`listFilesInDirectory`** / **`listDirectoriesInDirectory`** — List contents, optionally recursive
- **`createDirectory`** — Creates directories, with optional `recursive` and `ignore_existence` flags
- **`removePath`** / **`movePath`** — Delete or move files and directories
- **`getHomeDirectories`** — Returns all system home directory paths
- **`osqueryHomeDirectory`** — Returns the osquery-specific home/storage path

### Linux `/proc` Helpers *(Linux only)*
- **`procProcesses`** — Lists all running PIDs from `/proc`
- **`procDescriptors`** — Lists open file descriptors for a given PID
- **`procReadDescriptor`** — Resolves a descriptor's virtual path via symlink

## Usage Example

```c
#include <osquery/filesystem/filesystem.h>

// Read a file
std::string content;
auto status = osquery::readFile("/etc/os-release", content);
if (!status.ok()) {
  LOG(ERROR) << status.getMessage();
}

// Chunk-based read
osquery::readFile("/var/log/syslog", [](std::string_view chunk) {
  // process chunk
});

// Glob pattern resolution (files only)
std::vector<std::string> results;
osquery::resolveFilePattern("/home/%/.ssh/%", results, osquery::GLOB_FILES);

// Write a file
osquery::writeTextFile("/tmp/out.txt", "hello\n", 0640);

// Linux: enumerate processes
#ifdef __linux__
std::set<std::string> pids;
osquery::procProcesses(pids);
#endif
```
