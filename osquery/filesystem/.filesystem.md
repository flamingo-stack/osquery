Filesystem utility header for osquery providing cross-platform file I/O, directory traversal, glob pattern resolution, and Linux `/proc` introspection primitives.

## Key Components

### Enums & Constants
- **`GlobLimits`** — Bitmask flags controlling glob traversal: `GLOB_FILES`, `GLOB_FOLDERS`, `GLOB_ALL`, `GLOB_NO_CANON`
- **`kSQLGlobWildcard`** / **`kSQLGlobRecursive`** — SQL-style `%` and `%%` wildcard constants

### File I/O
- **`readFile()`** — Read file contents into a string or stream via chunk callback; non-blocking, respects `read_max` flag
- **`writeTextFile()`** — Write string content to disk with configurable permissions and open mode
- **`isWritable()` / `isReadable()`** — Permission checks with optional effective-UID semantics
- **`pathExists()`** — Disk existence check returning coded `Status`

### Directory Operations
- **`listFilesInDirectory()` / `listDirectoriesInDirectory()`** — Enumerate entries, optionally recursive
- **`resolveFilePattern()`** — Expand SQL/glob wildcard patterns into matching path lists
- **`replaceGlobWildcards()`** — Translate SQL `%` wildcards to filesystem `*`, with path canonicalization
- **`createDirectory()` / `removePath()` / `movePath()`** — Directory lifecycle helpers
- **`isDirectory()`** — Type check for a given path
- **`getHomeDirectories()`** — Returns all system home directory paths

### Security & Permissions
- **`safePermissions()`** — Validates file is not in a world-writable `/tmp`-like directory and is root/process-owned
- **`lsperms()`** — Converts a numeric mode to an `ls`-style permission string

### Utilities
- **`osqueryHomeDirectory()`** — Returns the osquery local storage home path
- **`parseJSON()`** — Deserializes a JSON file into a Boost property tree
- **`initializeFilesystemAPILocale()`** — Windows-only locale initialization

### Linux `/proc` (ifdef `__linux__`)
- **`procProcesses()`** — Lists all PIDs from `/proc`
- **`procDescriptors()`** — Lists open file descriptors for a process
- **`procReadDescriptor()`** — Resolves a descriptor's symlink target
- **`readRawMemory()`** *(partial)* — Physical memory reads via `/dev/mem`

## Usage Example

```c
#include <osquery/filesystem/filesystem.h>

// Read a file
std::string content;
auto status = osquery::readFile("/etc/os-release", content);
if (status.ok()) {
  LOG(INFO) << content;
}

// Glob-resolve all .conf files under /etc
std::vector<std::string> results;
osquery::resolveFilePattern("/etc/%.conf", results, osquery::GLOB_FILES);
for (const auto& path : results) {
  LOG(INFO) << path;
}

// Linux: list running PIDs
#ifdef __linux__
std::set<std::string> pids;
osquery::procProcesses(pids);
#endif
```
