Provides cross-platform filesystem abstraction utilities for osquery, including file I/O, directory traversal, glob pattern resolution, permission checks, and Linux-specific `/proc` filesystem helpers.

## Key Components

### Enums & Constants
- **`GlobLimits`** — Bitmask enum controlling glob traversal: `GLOB_FILES`, `GLOB_FOLDERS`, `GLOB_ALL`, `GLOB_NO_CANON`
- **`kSQLGlobWildcard`** / **`kSQLGlobRecursive`** — SQL-style `%` and `%%` glob tokens

### File I/O
- **`readFile(path, content)`** — Non-blocking file read, respects `read_max` flag; handles special files (FIFOs, Named Pipes)
- **`readFile(path, predicate)`** — Chunked file read with callback
- **`writeTextFile(path, content, permissions, mode)`** — Write text to disk with configurable permissions
- **`parseJSON(path, tree)`** — Parse a JSON file into a Boost property tree

### Path & Directory Utilities
- **`pathExists(path)`** — Check if a path exists on disk
- **`isDirectory(path)`** — Check if a path is a directory
- **`isReadable(path)`** / **`isWritable(path)`** — Permission checks (supports effective UID)
- **`listFilesInDirectory(path, results)`** — List files, optionally recursive
- **`listDirectoriesInDirectory(path, results)`** — List subdirectories, optionally recursive
- **`createDirectory(path)`** — Create directory with optional recursive and ignore-exists flags
- **`removePath(path)`** / **`movePath(from, to)`** — Remove or move files/directories
- **`getHomeDirectories()`** — Returns all system home directory paths

### Glob Resolution
- **`resolveFilePattern(pattern, results)`** — Resolve SQL-style glob patterns to matching paths
- **`replaceGlobWildcards(pattern)`** — Convert SQL `%` wildcards to filesystem `*` globs, with path canonicalization

### Security & Misc
- **`safePermissions(dir, path)`** — Validate file ownership/permissions against `/tmp`-style attack vectors
- **`osqueryHomeDirectory()`** — Returns osquery's protected home directory path
- **`lsperms(mode)`** — Convert numeric permission bitmask to `ls`-style string

### Linux-Only (`#ifdef __linux__`)
- **`procProcesses(processes)`** — List all PIDs from `/proc`
- **`procDescriptors(process, descriptors)`** — List open file descriptors for a PID
- **`procReadDescriptor(process, descriptor, result)`** — Resolve a descriptor's virtual path

## Usage Example

```c
#include <osquery/filesystem/filesystem.h>

// Read a file
std::string content;
auto status = osquery::readFile("/etc/os-release", content);
if (status.ok()) {
    // use content
}

// Glob resolve with SQL-style wildcard
std::vector<std::string> results;
osquery::resolveFilePattern("/etc/cron.d/%", results, osquery::GLOB_FILES);

// Chunked read with callback
osquery::readFile("/var/log/syslog", [](std::string_view chunk) {
    // process chunk
});

// Linux: iterate /proc processes
std::set<std::string> pids;
osquery::procProcesses(pids);
```
