Utility header for creating a temporary mock directory structure used in osquery unit tests.

## Key Components

- **`kTopLevelMockFolderName`** — Extern constant holding the name of the top-level mock folder.
- **`createMockFileStructure()`** — Creates a small temporary directory tree on disk and returns the path to its root.

## Usage Example

```c
#include "mock_file_structure.h"

using namespace osquery;

void myTest() {
    // Create a temporary mock directory structure for testing
    boost::filesystem::path mockRoot = createMockFileStructure();

    // Use mockRoot as the base path for file system test assertions
    boost::filesystem::path testFile = mockRoot / kTopLevelMockFolderName / "somefile.txt";
}
```

## Notes

- Intended for **test environments only** — not for production use.
- The returned path points to the generated directory tree root.
- Depends on `boost::filesystem` for cross-platform path handling.
