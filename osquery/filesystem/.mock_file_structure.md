Utility header for creating a temporary mock directory structure used in osquery unit tests.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `kTopLevelMockFolderName` | `extern const std::string` | Name of the top-level temporary folder created for tests |
| `createMockFileStructure()` | `boost::filesystem::path` | Generates a small directory tree for use in filesystem-related tests |

## Usage Example

```c
#include "mock_file_structure.h"

using namespace osquery;

void myTest() {
    // Create a temporary directory structure
    boost::filesystem::path mockRoot = createMockFileStructure();

    // Use mockRoot in your test
    // e.g., verify file enumeration, path resolution, etc.

    // Clean up after test completes
    boost::filesystem::remove_all(mockRoot);
}
```

## Notes

- Intended exclusively for **test environments** — do not use in production code
- Returns the root path of the generated mock tree, allowing tests to reference files within it
- Defined within the `osquery` namespace
- Source: [`mock_file_structure.h`](https://github.com/flamingo-stack/osquery/blob/main/mock_file_structure.h)
