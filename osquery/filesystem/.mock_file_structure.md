Provides a test utility for generating a temporary mock directory structure used in osquery filesystem-related unit tests.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `kTopLevelMockFolderName` | `extern const std::string` | Name constant for the top-level mock folder |
| `createMockFileStructure()` | `boost::filesystem::path` | Creates a small temporary directory tree for testing |

## Usage Example

```c
#include "mock_file_structure.h"
#include <boost/filesystem.hpp>

namespace osquery {

void myFilesystemTest() {
  // Create a temporary mock directory tree
  boost::filesystem::path mockRoot = createMockFileStructure();

  // Use mockRoot in test assertions
  // e.g., verify files exist under kTopLevelMockFolderName
  boost::filesystem::path topLevel = mockRoot / kTopLevelMockFolderName;

  // Clean up after test
  boost::filesystem::remove_all(mockRoot);
}

} // namespace osquery
```

> **Note:** This header is intended exclusively for test environments. Do not use `createMockFileStructure()` in production code paths, as it generates temporary filesystem artifacts on the host.
