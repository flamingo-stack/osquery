Provides declarations for reading POSIX extended attributes (xattrs) from files, including error types, result aliases, and core retrieval functions used within the osquery framework.

## Key Components

### Error Enumerations
- **`XAttrFileError`** — Errors when listing attribute names (`NoLength`, `List`, `SizeChanged`)
- **`XAttrValueError`** — Errors when reading an attribute value (`NoLength`, `Get`, `SizeChanged`)
- **`XAttrGetError`** — Top-level retrieval errors (`GenericError`, `NoFile`)

### Type Aliases
- **`ExtendedAttributeValue`** — Raw attribute data as `std::vector<uint8_t>`
- **`ExtendedAttributeMap`** — Map of attribute name → value (`unordered_map<string, ExtendedAttributeValue>`)
- **`XAttrGetResult`** — `Expected<ExtendedAttributeMap, XAttrGetError>`
- **`XAttrNameListResult`** — `Expected<vector<string>, XAttrFileError>`
- **`XAttrValueResult`** — `Expected<ExtendedAttributeValue, XAttrValueError>`

### Functions
| Function | Description |
|---|---|
| `getExtendedAttributes(path)` | Retrieves all xattrs for a file by path |
| `getExtendedAttributesNames(fd)` | Lists all xattr names for an open file descriptor |
| `getExtendedAttributeValue(fd, name)` | Reads a single xattr value by name from an open fd |
| `xAttrFileErrorToString(error, path)` | Converts a `XAttrFileError` to a human-readable string |
| `xAttrValueErrorToString(error, path, name)` | Converts a `XAttrValueError` to a human-readable string |

## Usage Example

```c
#include "xattrs.h"

// Retrieve all extended attributes for a file path
auto result = osquery::getExtendedAttributes("/etc/myfile.conf");
if (result.isValue()) {
    const auto& attrs = result.get();
    for (const auto& [name, value] : attrs) {
        // process each attribute name/value pair
    }
} else {
    // handle XAttrGetError
}

// Read a single attribute from an open file descriptor
auto valueResult = osquery::getExtendedAttributeValue(fd, "user.checksum");
if (valueResult.isValue()) {
    const auto& bytes = valueResult.get(); // std::vector<uint8_t>
}
```
