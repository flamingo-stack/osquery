Header file defining the interface for reading extended attributes (xattrs) from files on Unix-like systems within the osquery framework.

## Key Components

### Error Enumerations

- **`XAttrFileError`** — Errors when listing attribute names (`NoLength`, `List`, `SizeChanged`)
- **`XAttrValueError`** — Errors when reading attribute values (`NoLength`, `Get`, `SizeChanged`)
- **`XAttrGetError`** — High-level retrieval errors (`GenericError`, `NoFile`)

### Type Aliases

| Type | Definition |
|------|-----------|
| `ExtendedAttributeValue` | `std::vector<std::uint8_t>` — raw byte buffer for an xattr value |
| `ExtendedAttributeMap` | `std::unordered_map<std::string, ExtendedAttributeValue>` — name-to-value mapping |
| `XAttrGetResult` | `Expected<ExtendedAttributeMap, XAttrGetError>` |
| `XAttrNameListResult` | `Expected<std::vector<std::string>, XAttrFileError>` |
| `XAttrValueResult` | `Expected<ExtendedAttributeValue, XAttrValueError>` |

### Functions

- **`xAttrFileErrorToString`** — Converts an `XAttrFileError` to a human-readable string with path context
- **`xAttrValueErrorToString`** — Converts an `XAttrValueError` to a human-readable string with path and attribute name context
- **`getExtendedAttributesNames(int fd)`** — Lists all xattr names for an open file descriptor
- **`getExtendedAttributeValue(int fd, const std::string& name)`** — Reads a single xattr value by name from an open file descriptor
- **`getExtendedAttributes(const std::string& path)`** — Retrieves all xattr names and values for a file path

## Usage Example

```c
#include "xattrs.h"

auto result = osquery::getExtendedAttributes("/path/to/file");
if (result.isError()) {
    // Handle XAttrGetError::NoFile or GenericError
    return;
}

for (const auto& [name, value] : result.get()) {
    // name  -> std::string (e.g. "com.apple.quarantine")
    // value -> std::vector<uint8_t> (raw bytes)
}
```
