Utility header for reading extended file attributes (xattrs) on Unix-like systems, providing typed error handling and result types for listing and retrieving xattr names and values.

## Key Components

### Error Enums
- **`XAttrFileError`** — Errors when listing attribute names (`NoLength`, `List`, `SizeChanged`)
- **`XAttrValueError`** — Errors when reading attribute values (`NoLength`, `Get`, `SizeChanged`)
- **`XAttrGetError`** — Top-level errors for full attribute retrieval (`GenericError`, `NoFile`)

### Type Aliases
- **`ExtendedAttributeValue`** — Raw xattr value as `std::vector<uint8_t>`
- **`ExtendedAttributeMap`** — Map of attribute name → value (`unordered_map<string, ExtendedAttributeValue>`)
- **`XAttrGetResult`** — `Expected<ExtendedAttributeMap, XAttrGetError>`
- **`XAttrNameListResult`** — `Expected<vector<string>, XAttrFileError>`
- **`XAttrValueResult`** — `Expected<ExtendedAttributeValue, XAttrValueError>`

### Functions
- **`xAttrFileErrorToString`** — Human-readable message for a file listing error
- **`xAttrValueErrorToString`** — Human-readable message for a value retrieval error
- **`getExtendedAttributesNames(fd)`** — Lists all xattr names for an open file descriptor
- **`getExtendedAttributeValue(fd, name)`** — Reads a single xattr value by name from a file descriptor
- **`getExtendedAttributes(path)`** — Retrieves all xattr name/value pairs for a file path

## Usage Example

```cpp
#include "xattrs.h"

auto result = osquery::getExtendedAttributes("/path/to/file");
if (result.isValue()) {
    for (const auto& [name, value] : result.get()) {
        // process each attribute name and its raw byte value
    }
} else {
    auto error = result.getError();
    // handle XAttrGetError::NoFile or XAttrGetError::GenericError
}

// Per-descriptor usage
int fd = open("/path/to/file", O_RDONLY);
auto names = osquery::getExtendedAttributesNames(fd);
if (names.isValue()) {
    for (const auto& name : names.get()) {
        auto val = osquery::getExtendedAttributeValue(fd, name);
    }
}
```
