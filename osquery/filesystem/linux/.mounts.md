Declares data structures and a utility function for querying mounted filesystem information within the osquery framework.

## Key Components

### Structs

- **`MountInformation::StatFsInfo`** — Nested struct holding low-level `statfs` metrics:
  - `block_size` — Optimal transfer block size (`f_bsize`)
  - `block_count` — Total data blocks (`f_blocks`)
  - `free_block_count` — Free blocks (`f_bfree`)
  - `unprivileged_free_block_count` — Free blocks available to unprivileged users (`f_bavail`)
  - `inode_count` — Total inodes (`f_files`)
  - `free_inode_count` — Free inodes (`f_ffree`)

- **`MountInformation`** — Describes a single mounted filesystem:
  - `type` — Filesystem type (e.g., `ext4`, `tmpfs`)
  - `device` — Raw device path
  - `device_alias` — Canonicalized device path
  - `path` — Mount point
  - `flags` — Mount options
  - `optional_statfs_info` — Optional `StatFsInfo`; absent if `statfs` failed

### Type Aliases

- **`MountedFilesystems`** — `std::vector<MountInformation>` representing all active mounts

### Functions

- **`getMountedFilesystems(MountedFilesystems&)`** — Populates the provided vector with information about all currently mounted filesystems; returns an osquery `Status`

## Usage Example

```c
#include "mounts.h"

osquery::MountedFilesystems mounts;
auto status = osquery::getMountedFilesystems(mounts);

if (status.ok()) {
  for (const auto& mount : mounts) {
    std::cout << mount.path << " -> " << mount.device
              << " [" << mount.type << "]\n";

    if (mount.optional_statfs_info) {
      auto& fs = *mount.optional_statfs_info;
      std::cout << "  Blocks: " << fs.block_count
                << ", Free: "   << fs.free_block_count << "\n";
    }
  }
}
```
