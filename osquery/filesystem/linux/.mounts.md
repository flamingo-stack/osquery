Header defining data structures and interfaces for querying mounted filesystem information within the osquery framework.

## Key Components

### `MountInformation::StatFsInfo` (struct)
Nested struct holding low-level filesystem statistics sourced from `statfs`:

| Field | Description |
|-------|-------------|
| `block_size` | Optimal transfer block size (`f_bsize`) |
| `block_count` | Total data blocks (`f_blocks`) |
| `free_block_count` | Free blocks (`f_bfree`) |
| `unprivileged_free_block_count` | Free blocks for unprivileged users (`f_bavail`) |
| `inode_count` | Total inodes (`f_files`) |
| `free_inode_count` | Free inodes (`f_ffree`) |

### `MountInformation` (struct)
Top-level struct representing a single mounted filesystem entry:
- `type` — Filesystem type (e.g., `ext4`, `tmpfs`)
- `device` — Raw device path
- `device_alias` — Canonicalized device path
- `path` — Mount point path
- `flags` — Mount options string
- `optional_statfs_info` — `boost::optional<StatFsInfo>`; absent if `statfs` failed

### `MountedFilesystems` (type alias)
```c
using MountedFilesystems = std::vector<MountInformation>;
```
Collection type for all mounted filesystem entries.

### `getMountedFilesystems()`
```c
Status getMountedFilesystems(MountedFilesystems& mounted_fs_info);
```
Populates `mounted_fs_info` with data for all currently mounted filesystems. Returns an osquery `Status` indicating success or failure.

## Usage Example

```cpp
#include "mounts.h"

osquery::MountedFilesystems mounts;
auto status = osquery::getMountedFilesystems(mounts);

if (status.ok()) {
  for (const auto& mount : mounts) {
    std::cout << mount.path << " (" << mount.type << ")\n";

    if (mount.optional_statfs_info.has_value()) {
      const auto& fs = mount.optional_statfs_info.value();
      std::cout << "  Free blocks: " << fs.free_block_count << "\n";
    }
  }
}
```

> **Note:** `optional_statfs_info` may be unset if the underlying `statfs` call failed for a given mount. Always check `has_value()` before accessing it.
