Declares data structures and a query function for retrieving mounted filesystem information within the osquery framework.

## Key Components

### `MountInformation`
A struct describing a single mounted filesystem, containing:
- **`StatFsInfo`** — Nested struct wrapping `statfs` metrics:
  - `block_size` — Optimal transfer block size
  - `block_count` — Total data blocks
  - `free_block_count` — Free blocks in filesystem
  - `unprivileged_free_block_count` — Free blocks available to unprivileged users
  - `inode_count` — Total file nodes
  - `free_inode_count` — Free file nodes
- `type` — Filesystem type string
- `device` — Raw device path
- `device_alias` — Canonicalized device path
- `path` — Mount point path
- `flags` — Mount option flags
- `optional_statfs_info` — `boost::optional<StatFsInfo>` (absent if `statfs` call failed)

### `MountedFilesystems`
Type alias for `std::vector<MountInformation>` — a collection of all active mount entries.

### `getMountedFilesystems()`
```c
Status getMountedFilesystems(MountedFilesystems& mounted_fs_info);
```
Populates `mounted_fs_info` with all currently mounted filesystems. Returns an osquery `Status` indicating success or failure.

## Usage Example

```c
#include "mounts.h"

osquery::MountedFilesystems mounts;
auto status = osquery::getMountedFilesystems(mounts);

if (status.ok()) {
  for (const auto& mount : mounts) {
    std::cout << "Device: " << mount.device
              << " -> Path: " << mount.path
              << " Type: " << mount.type << "\n";

    if (mount.optional_statfs_info) {
      const auto& fs = *mount.optional_statfs_info;
      std::cout << "  Blocks: " << fs.block_count
                << " Free: "   << fs.free_block_count << "\n";
    }
  }
}
```
