Linux `/proc` filesystem utilities for enumerating processes, file descriptors, and network socket information within the osquery framework.

## Key Components

### Data Structures

- **`SocketInfo`** — Holds socket metadata: family, protocol, local/remote address and port, state, and network namespace inode
- **`SocketProcessInfo`** — Maps a socket inode to its owning process ID and file descriptor
- **`ProcessNamespaceList`** — Maps namespace names to their inode numbers

### Constants

- `kLinuxProcPath` — Base path `/proc`
- `kLinuxProtocolNames` — Maps protocol numbers (`IPPROTO_TCP`, etc.) to `/proc/net` file names
- `tcp_states` — Ordered list of TCP state strings indexed by Linux kernel state codes

### Functions

| Function | Description |
|---|---|
| `procEnumerateProcesses` | Template; iterates all PIDs under `/proc`, invoking a callback per process |
| `procEnumerateProcessDescriptors` | Template; iterates all file descriptors under `/proc/<pid>/fd`, invoking a callback per descriptor |
| `procGetSocketList` | Builds a `SocketInfoList` from `/proc/<pid>/net` for a given family/protocol |
| `procGetSocketListPacket` | Parses `/proc/net/packet` content into a `SocketInfoList` |
| `procGetSocketInodeToProcessInfoMap` | Maps socket inodes to owning process info via `/proc/<pid>/fd` |
| `procGetProcessNamespaces` | Reads Linux namespace inodes for a given PID |
| `procDecodeAddressFromHex` | Decodes a hex-encoded `/proc/net` address for `AF_INET` or `AF_INET6` |
| `procDecodePortFromHex` | Decodes a hex-encoded port number |
| `getProcRSS` | Returns resident set size for a process |

## Usage Example

```cpp
#include "proc.h"

// Enumerate all running processes
struct MyData { std::vector<std::string> pids; };
MyData data;

osquery::procEnumerateProcesses(data,
  [](const std::string& pid, MyData& d) -> bool {
    d.pids.push_back(pid);
    return true; // continue iteration
  });

// Collect socket info for a specific PID
osquery::SocketInfoList sockets;
osquery::procGetSocketList(AF_INET, IPPROTO_TCP, 0, "1234", sockets);

for (const auto& s : sockets) {
  std::cout << s.local_address << ":" << s.local_port
            << " -> " << s.state << "\n";
}
```

> **Note:** No locking is performed during enumeration. Race conditions (e.g., a process exiting mid-iteration) are handled gracefully by skipping failed entries and logging via `VLOG(1)`.
