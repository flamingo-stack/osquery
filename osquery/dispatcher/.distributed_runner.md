Defines the `DistributedRunner` service thread responsible for executing distributed queries within the osquery dispatcher framework.

## Key Components

- **`DistributedRunner`** — A `InternalRunnable` subclass that runs as a managed Dispatcher service thread. Implements the distributed query polling/execution loop via `start()`.
- **`startDistributed()`** — Factory/launch function that initializes and registers the `DistributedRunner` with the Dispatcher, returning a `Status` indicating success or failure.

## Usage Example

```c
#include <osquery/distributed/distributed_runner.h>

// Start the distributed query service (typically called during daemon init)
Status s = osquery::startDistributed();
if (!s.ok()) {
  LOG(ERROR) << "Failed to start distributed runner: " << s.getMessage();
}
```

The `DistributedRunner` thread is managed by the `Dispatcher` — it should not be instantiated directly in most cases. Use `startDistributed()` to register it properly within the service lifecycle.
