Defines the `DistributedRunner` class, a Dispatcher service thread responsible for running the distributed query service within osquery.

## Key Components

- **`DistributedRunner`** — Inherits from `InternalRunnable`; implements the background thread that drives distributed query execution. Registered with the osquery Dispatcher.
  - `start()` — Thread entry point override; contains the main execution loop for processing distributed queries.

- **`startDistributed()`** — Free function that initializes and launches the distributed query runner service, returning a `Status` indicating success or failure.

## Usage Example

```c
// Start the distributed query runner service
Status s = osquery::startDistributed();
if (!s.ok()) {
    LOG(ERROR) << "Failed to start distributed runner: " << s.getMessage();
}

// Alternatively, instantiate and dispatch manually
auto runner = std::make_shared<osquery::DistributedRunner>();
osquery::Dispatcher::addService(runner);
```

## Notes

- Relies on `osquery/dispatcher/dispatcher.h` for the `InternalRunnable` base class and Dispatcher integration.
- The constructor registers the thread name as `"DistributedRunner"` for identification in dispatcher logs.
- See the full implementation at [`osquery/distributed/distributed_runner.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/distributed/distributed_runner.h).
