Defines the thread management and concurrency primitives for osquery's async task execution system, providing a singleton `Dispatcher` and base runnable classes for managed service threads.

## Key Components

### `InterruptibleRunnable`
Abstract base class for any runnable that supports cooperative interruption.

| Member | Description |
|--------|-------------|
| `interrupt()` | Signals the runnable to stop; triggers `condition_` wake-up |
| `interrupted()` | Checks if an interrupt has been requested |
| `pause(milliseconds)` | Interruptible sleep; wakes early on interrupt signal |
| `stop()` | Pure virtual; subclasses define their shutdown logic |
| `runnable_name_` | Thread name exposed via `name()` |

### `InternalRunnable`
Extends `InterruptibleRunnable` (non-copyable) as the concrete base for osquery service threads.

| Member | Description |
|--------|-------------|
| `run()` | Thread entrypoint called by `Dispatcher`; sets `run_` flag |
| `start()` | Pure virtual; subclasses define their work loop |
| `hasRun()` | Returns whether the thread entrypoint has executed |

### Type Aliases
```c
using InternalRunnableRef = std::shared_ptr<InternalRunnable>;
using InternalThreadRef   = std::unique_ptr<std::thread>;
```

### `Dispatcher` (Singleton)
Manages lifecycle of all osquery background service threads.

| Method | Description |
|--------|-------------|
| `instance()` | Returns the singleton `Dispatcher` |
| `addService(ref)` | Spawns a new thread for the given runnable |
| `joinServices()` | Blocks until all service threads complete |
| `stopServices()` | Signals all services to interrupt and stops them |
| `serviceCount()` | Returns number of active services |

## Usage Example

```c
// Define a custom service
class MyService : public osquery::InternalRunnable {
 public:
  MyService() : InternalRunnable("MyService") {}

 protected:
  void start() override {
    while (!interrupted()) {
      // do work
      pause(std::chrono::milliseconds(1000));
    }
  }

  void stop() override {
    // cleanup on interrupt
  }
};

// Register and launch the service
auto svc = std::make_shared<MyService>();
osquery::Dispatcher::addService(svc);

// Teardown
osquery::Dispatcher::stopServices();
osquery::Dispatcher::joinServices();
```

> **Note:** `Dispatcher` is a singleton and non-copyable. Services register themselves and are automatically removed upon completion via `removeService()`.
