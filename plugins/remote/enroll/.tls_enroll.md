Declares the `TLSEnrollPlugin` class, which implements TLS-based node enrollment for osquery by requesting and caching enrollment keys from a remote TLS endpoint.

## Key Components

### `TLSEnrollPlugin` (class)
Extends `EnrollPlugin` to provide TLS enrollment functionality within the `osquery` namespace.

| Member | Description |
|--------|-------------|
| `enroll()` | Returns a cached enrollment key if available; otherwise triggers a new key request |
| `requestKey(uri, node_key)` | Sends an enrollment request to the specified TLS endpoint URI and populates `node_key` on success |
| `TLSEnrollTests` | Declared as a `friend` class to allow unit test access to private members |

## Usage Example

```c
// Plugin is registered and invoked via the osquery plugin system.

namespace osquery {

Status TLSEnrollPlugin::requestKey(const std::string& uri,
                                    std::string& node_key) {
  // Sends enrollment request to uri,
  // populates node_key on success.
}

// Subsequent calls return the cached key without re-enrolling.

} // namespace osquery
```

## Notes

- Depends on [`osquery/remote/enroll/enroll.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/remote/enroll/enroll.h) for the base `EnrollPlugin` interface.
- Key caching behavior in `enroll()` avoids redundant TLS requests across repeated calls.
- Part of the osquery remote configuration and enrollment subsystem.
