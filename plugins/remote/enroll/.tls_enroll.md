Declares the `TLSEnrollPlugin` class, which implements TLS-based node enrollment for osquery's remote configuration system by requesting and caching enrollment keys from a TLS endpoint.

## Key Components

### `TLSEnrollPlugin` (extends `EnrollPlugin`)
| Member | Description |
|--------|-------------|
| `enroll()` | Returns a cached enrollment key or triggers a new key request if none is cached |
| `requestKey(uri, node_key)` | Performs the HTTP/TLS request to the enrollment endpoint and populates the node key |
| `TLSEnrollTests` | Declared as a `friend` class to allow unit test access to private members |

## Usage Example

```cpp
// TLSEnrollPlugin is typically registered as an osquery plugin
// and invoked through the enrollment subsystem, not directly.

#include <osquery/remote/enroll/tls_enroll.h>

namespace osquery {

// Registration example (typically in a plugin init block)
REGISTER(TLSEnrollPlugin, "enroll", "tls");

} // namespace osquery

// Once registered, the enrollment system calls enroll() automatically
// when a node_key is required for authenticating distributed/config TLS requests.
// The plugin handles key caching internally, only contacting the TLS
// endpoint (--enroll_secret_path / --tls_enroll_uri) when no key is stored.
```

> **Note:** `requestKey` returns a `Status` object — callers should check `Status::ok()` to confirm successful enrollment before using the returned `node_key`.
