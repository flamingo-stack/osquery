Declares the `TLSEnrollPlugin` class, which implements TLS-based node enrollment for osquery's remote enrollment system by requesting and caching enrollment keys from a TLS endpoint.

## Key Components

- **`TLSEnrollPlugin`** — Extends `EnrollPlugin` to provide TLS-specific enrollment logic.
  - **`enroll()`** — Returns a cached enrollment key if available; otherwise triggers a new key request.
  - **`requestKey(uri, node_key)`** — Performs the actual HTTP/TLS call to the enrollment endpoint and populates the returned node key.
  - **`TLSEnrollTests`** — Declared as a `friend` class to allow direct unit test access to private members.

## Usage Example

```cpp
#include <osquery/remote/enroll/tls_enroll.h>

// Register the plugin with the osquery registry
REGISTER(TLSEnrollPlugin, "enroll", "tls");

// The plugin is invoked internally by the enrollment system.
// On first call, enroll() contacts the TLS endpoint:
//   POST https://<tls_hostname>/enroll
// On subsequent calls, the cached node_key is returned directly.
```

The plugin integrates with osquery's plugin registry under the `"enroll"` category. The `requestKey()` method handles the network round-trip, while `enroll()` acts as the cache-aware entry point — minimizing redundant enrollment requests across the agent lifecycle.
