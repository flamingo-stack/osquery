A filesystem-based plugin for osquery's numeric monitoring system that writes monitoring data points to a log file.

## Key Components

### `NumericMonitoringFilesystemPlugin`
Extends `NumericMonitoringPlugin` to persist numeric monitoring data to disk via a configurable log file path.

| Member | Description |
|--------|-------------|
| `NumericMonitoringFilesystemPlugin()` | Default constructor using built-in log file path |
| `NumericMonitoringFilesystemPlugin(path)` | Constructor accepting a custom `boost::filesystem::path` for the log file |
| `call(request, response)` | Handles plugin dispatch — formats and writes a monitoring data point |
| `setUp()` | Initializes the output file stream; must succeed before `call()` is used |
| `isSetUp()` | Returns whether the plugin has been successfully initialized |
| `formTheLine(line, request)` | Private helper that formats a `PluginRequest` into a delimited log line |

**Private fields:**
- `line_format_` — ordered list of fields to include per line
- `separator_` — character delimiter between fields
- `log_file_path_` — target log file location
- `output_file_stream_` — file output stream
- `output_file_mutex_` — mutex ensuring thread-safe writes

## Usage Example

```cpp
#include <osquery/numeric_monitoring/plugins/filesystem.h>

// Using a custom log path
boost::filesystem::path log_path("/var/log/osquery/numeric_monitoring.log");
osquery::NumericMonitoringFilesystemPlugin plugin(log_path);

osquery::Status status = plugin.setUp();
if (status.ok() && plugin.isSetUp()) {
    osquery::PluginRequest request = {{"path", "cpu.usage"}, {"value", "42.5"}};
    osquery::PluginResponse response;
    plugin.call(request, response);
}
```
