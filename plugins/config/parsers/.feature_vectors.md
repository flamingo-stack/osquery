Declares the `FeatureVectorsConfigParserPlugin`, a lightweight `ConfigParserPlugin` that parses feature vector dictionary keys from osquery configuration sources.

## Key Components

- **`kFeatureVectorsRootKey`** — Extern constant defining the root configuration key used to locate feature vector data within the config tree.
- **`FeatureVectorsConfigParserPlugin`** — Inherits from `ConfigParserPlugin`; implements two overrides:
  - `keys()` — Returns the list of config keys this parser handles.
  - `update()` — Called when configuration is loaded or refreshed, receiving the source identifier and parsed config data.

## Usage Example

```cpp
#include "feature_vectors.h"

// The plugin is typically registered via osquery's plugin system.
// Access parsed feature vector config using the root key:
auto parser = Config::getParser(kFeatureVectorsRootKey);
if (parser != nullptr) {
    auto& doc = parser->getData();
    // Process feature vector entries from doc
}
```

## Notes

- Follows osquery's standard config parser pattern — register the plugin and osquery's `Config` subsystem will invoke `update()` automatically on config load/reload.
