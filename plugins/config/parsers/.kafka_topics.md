Defines the `KafkaTopicsConfigParserPlugin` class and associated constants for parsing Kafka topic configurations from osquery's configuration system.

## Key Components

- **`kKafkaTopicParserRootKey`** — Extern constant `std::string` defining the root key used to retrieve Kafka topic configurations from osquery config.
- **`KafkaTopicsConfigParserPlugin`** — A `ConfigParserPlugin` subclass responsible for extracting, updating, and parsing Kafka topic configurations.
  - **`keys()`** — Returns the list of configuration keys this parser handles.
  - **`update()`** — Called when configuration is updated from a given source, processes the new `ParserConfig` data.

## Usage Example

```cpp
#include "kafka_topics.h"

namespace osquery {

// Access the root key used for Kafka topic config lookup
std::cout << kKafkaTopicParserRootKey << std::endl;

// Plugin is registered via osquery's plugin system; 
// direct instantiation is typically handled by the config subsystem.
KafkaTopicsConfigParserPlugin parser;

// Retrieve keys this parser is responsible for
auto keys = parser.keys();

// Trigger a config update (called internally by osquery config machinery)
ParserConfig config;
Status s = parser.update("config_source", config);
if (!s.ok()) {
  LOG(ERROR) << "Kafka topic config update failed: " << s.getMessage();
}

} // namespace osquery
```

## Notes

- Inherits from `ConfigParserPlugin` defined in [`osquery/config/config.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/config/config.h).
- Follows osquery's plugin registration pattern — instances are typically managed by the config subsystem rather than instantiated directly.
- Part of the `osquery` namespace.
