Header file defining the Prometheus metrics configuration parser plugin for osquery, enabling dynamic discovery of Prometheus scrape targets from osquery configuration.

## Key Components

- **`kPrometheusParserRootKey`** — Extern string constant defining the root configuration key used to identify Prometheus-related entries in the osquery config.

- **`PrometheusMetricsConfigParserPlugin`** — A `ConfigParserPlugin` subclass responsible for parsing Prometheus target definitions from the osquery config. Exposes two overridden methods:
  - `keys()` — Returns the list of config keys this parser handles.
  - `update()` — Called when the configuration changes, receiving the source identifier and updated parser config map.

## Usage Example

```cpp
#include "prometheus_targets.h"

// The plugin is typically registered via the osquery plugin system.
// Access the root key used for Prometheus config lookups:
std::string rootKey = osquery::kPrometheusParserRootKey;

// The plugin is auto-invoked by osquery's config subsystem on config updates.
// Manual instantiation example:
osquery::PrometheusMetricsConfigParserPlugin parser;

// Retrieve the config keys this parser is responsible for:
auto keys = parser.keys();

// Called internally by osquery when config is refreshed:
osquery::ParserConfig cfg;
auto status = parser.update("filesystem", cfg);
if (!status.ok()) {
  // Handle parse error
}
```
