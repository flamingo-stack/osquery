Defines the decoration system for osquery, which attaches key-value metadata to log items before they are dispatched to downstream logging APIs.

## Key Components

- **`DecorationPoint`** — Enum specifying when decorators execute:
  - `DECORATE_LOAD` — once at config load
  - `DECORATE_ALWAYS` — on every query run
  - `DECORATE_INTERVAL` — on a timed interval

- **`kDecorationPointKeys`** — Constant map linking each `DecorationPoint` to its configuration key string.

- **`runDecorators()`** — Iterates all configured decorators for a given decoration point. Accepts an optional timestamp (for interval-based points) and an optional source filter to restrict execution to a specific config source.

- **`getDecorations()`** — Populates an output map with the current set of accumulated decoration column/value pairs, ready to be merged into log entries.

- **`clearDecorations()`** — Removes stored decorations for a given config source, typically called when that source is updated.

## Usage Example

```c
#include <osquery/config/decorators.h>

// Run decorators that should execute on every query
osquery::runDecorators(osquery::DECORATE_ALWAYS);

// Run interval decorators with a specific timestamp and source
osquery::runDecorators(osquery::DECORATE_INTERVAL, currentTime, "config_source");

// Retrieve accumulated decorations and merge into a log record
std::map<std::string, std::string> decorations;
osquery::getDecorations(decorations);

for (const auto& kv : decorations) {
    logRecord[kv.first] = kv.second;
}

// Clear decorations when a config source is refreshed
osquery::clearDecorations("config_source");
```
