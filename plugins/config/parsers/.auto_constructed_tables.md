Auto Table Construction (ATC) plugin header that defines classes for dynamically creating and managing osquery tables from SQLite database sources via configuration.

## Key Components

### `ATCPlugin` (extends `TablePlugin`)
A dynamically constructed table plugin that queries an external SQLite database file.

| Member | Description |
|--------|-------------|
| `tc_columns_` | Column schema for the constructed table |
| `sqlite_query_` | SQLite query used to populate table rows |
| `path_` | Path to the external SQLite database file |
| `table_attributes_` | Starts as `PENDING` to prevent race conditions during SQL (re)initialization |
| `generate()` | Executes the configured query and returns rows |
| `setActive()` | Marks the table as ready for querying, clearing the `PENDING` state |
| `attributes()` | Returns current table attributes |

### `ATCConfigParserPlugin` (extends `ConfigParserPlugin`)
Parses the `auto_table_construction` config key and manages the lifecycle of ATC tables — registering new ones and removing stale ones when config updates.

| Member | Description |
|--------|-------------|
| `kParserKey` | Config section key: `"auto_table_construction"` |
| `kDatabaseKeyPrefix` | Registry prefix: `"atc."` |
| `setUp()` | Initializes the parser and restores previously registered ATC tables |
| `update()` | Processes config changes, adding/removing ATC tables as needed |
| `removeATCTables()` | Unregisters a set of ATC tables |
| `registeredATCTables()` | Returns currently active ATC table names |

## Usage Example

```c
// ATCPlugin is constructed internally by ATCConfigParserPlugin
// when parsing osquery config such as:
// {
//   "auto_table_construction": {
//     "my_custom_table": {
//       "query": "SELECT * FROM my_data",
//       "path": "/var/db/custom.db",
//       "columns": ["id", "name", "value"]
//     }
//   }
// }

auto plugin = std::make_shared<ATCPlugin>(
    "/var/db/custom.db",
    tc_columns,
    "SELECT id, name, value FROM my_data"
);

// After registration, mark the table as queryable
plugin->setActive();
```
