Brief description of a configuration parser plugin for logger settings within the osquery framework.

## Key Components

- **`LoggerConfigParserPlugin`** — A `ConfigParserPlugin` subclass that parses logger-related configuration sections.
  - **`keys()`** — Returns the list of configuration keys this parser handles (driven by the static `kLoggerKey` constant).
  - **`update()`** — Processes configuration updates from a given source, applying parsed logger settings.
  - **`kLoggerKey`** *(private static)* — The string key identifying the logger configuration section.

## Usage Example

```c
// The plugin is registered via the osquery plugin system and invoked
// automatically during config parsing. To retrieve parsed logger config:

auto& config = Config::get();
auto parser = Config::getParser("logger"); // resolved via kLoggerKey
if (parser != nullptr) {
    const auto& data = parser->getData();
    // Access logger settings from the parsed configuration document
}
```

## Notes

- Inherits from `ConfigParserPlugin`, integrating with osquery's config subsystem.
- The `update()` method is called whenever the configuration source changes, enabling dynamic logger reconfiguration.
- Defined in the `osquery` namespace; source lives at [`osquery/logger/logger.h`](https://github.com/flamingo-stack/osquery/blob/main/osquery/logger/logger.h).
