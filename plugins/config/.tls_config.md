Declares the `TLSConfigPlugin` class, which retrieves osquery configuration over TLS from a remote endpoint.

## Key Components

### `TLSConfigPlugin`
Inherits from `ConfigPlugin` and `std::enable_shared_from_this<TLSConfigPlugin>`. Implements TLS-based remote config fetching.

| Member | Type | Description |
|--------|------|-------------|
| `setUp()` | `Status` | Initializes the plugin, validates and caches the remote TLS config URL |
| `genConfig()` | `Status` | Fetches and populates the config map from the remote TLS endpoint |
| `uri_` | `std::string` (protected) | Cached URL computed once during setup |

## Usage Example

```cpp
// Register and use TLSConfigPlugin via the osquery plugin system
auto plugin = std::make_shared<osquery::TLSConfigPlugin>();

Status s = plugin->setUp();
if (!s.ok()) {
  LOG(ERROR) << "TLS config setup failed: " << s.getMessage();
}

std::map<std::string, std::string> config;
Status result = plugin->genConfig(config);
if (result.ok()) {
  for (const auto& [source, json] : config) {
    // Process each config source JSON blob
  }
}
```

## Notes

- The `uri_` field is computed once in `setUp()` and reused across `genConfig()` calls to avoid redundant URL resolution.
- `TLSConfigTests` is declared a `friend` class for unit test access to internals.
- Typically registered via osquery's plugin registry rather than instantiated directly.
