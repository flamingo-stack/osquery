Declares the `SyslogLoggerPlugin` class, which routes osquery log output to the system syslog facility via the standard POSIX `syslog.h` interface.

## Key Components

- **`SyslogLoggerPlugin`** — Extends `LoggerPlugin` to implement syslog-based logging. Registered under the `"logger"` registry with the name `"syslog"`.
  - `usesLogStatus()` — Returns `true`, indicating this plugin handles status log lines.
  - `logString(const std::string& s)` — Writes a single log string entry to syslog.
  - `init(const std::string& name, const std::vector<StatusLogLine>& log)` — Initializes the plugin and flushes any buffered startup log lines.
  - `logStatus(const std::vector<StatusLogLine>& log)` — Writes a batch of `StatusLogLine` entries to syslog.

- **`REGISTER` macro** — Registers `SyslogLoggerPlugin` into the osquery plugin registry, making it selectable via `--logger_plugin=syslog`.

## Usage Example

Enable the syslog logger at runtime by setting the logger plugin flag:

```bash
osqueryd --logger_plugin=syslog
```

Or configure it in the osquery configuration file:

```json
{
  "options": {
    "logger_plugin": "syslog"
  }
}
```

Once active, osquery result and status logs are forwarded to the system syslog daemon (e.g., `rsyslog`, `syslog-ng`, `journald`), viewable via:

```bash
journalctl -t osqueryd
# or
tail -f /var/log/syslog
```
