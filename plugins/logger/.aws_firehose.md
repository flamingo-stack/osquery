Header defining the AWS Kinesis Firehose logger plugin and log forwarder classes for streaming osquery logs to AWS Firehose delivery streams.

## Key Components

### Type Alias
- **`IFirehoseLogForwarder`** — Specialization of the generic `AwsLogForwarder` template, binding Firehose-specific AWS SDK types (`Record`, `FirehoseClient`, `PutRecordBatchOutcome`, `PutRecordBatchResponseEntry`).

### Classes

- **`FirehoseLogForwarder`** — Concrete forwarder implementing batched log delivery to Firehose. Overrides internal lifecycle and configuration methods:
  - `internalSetup()` / `internalSend()` — Client initialization and batch dispatch.
  - `initializeRecord()` — Populates a Firehose `Record` from a byte buffer.
  - Constraint accessors: `getMaxBytesPerRecord()`, `getMaxRecordsPerBatch()`, `getMaxBytesPerBatch()`, `getMaxRetryCount()`, `getInitialRetryDelay()`.
  - `appendNewlineSeparators()` — Controls newline injection between log entries.
  - `getFailedRecordCount()` / `getResult()` — Parses batch outcomes for retry logic.

- **`FirehoseLoggerPlugin`** — `LoggerPlugin` integration point registered with the osquery plugin system. Owns a `FirehoseLogForwarder` instance and routes log strings and status lines through it.
  - `setUp()` — Initializes the plugin and forwarder.
  - `logString()` / `logStatus()` — Entry points for log data and status events.
  - `usesLogStatus()` — Returns `true`, enabling status log ingestion.

### Flag
- **`aws_firehose_period`** — Declared `uint64` gflag controlling the forwarding interval.

## Usage Example

```c
// Instantiate and set up the Firehose logger plugin (handled by osquery plugin registry)
FirehoseLoggerPlugin plugin;
Status status = plugin.setUp();

// Direct forwarder construction (e.g., in tests)
FirehoseLogForwarder forwarder(
    "my-stream",   // Firehose delivery stream name
    15,            // log_period (seconds)
    1000,          // max_lines per batch
    "",            // endpoint_override (empty = default AWS endpoint)
    region         // AWSRegion struct
);
```
