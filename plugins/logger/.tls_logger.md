TLS logger plugin and forwarder declarations for buffering and sending osquery logs to a remote TLS endpoint via a background dispatcher thread.

## Key Components

### `TLSLogForwarder`
Extends `BufferedLogForwarder` to flush database-buffered result and status logs to a TLS endpoint. Runs as a `Dispatcher` service when an enrollment key is present.

| Member | Description |
|--------|-------------|
| `configuration_mutex` | Guards concurrent reads/writes of configuration state |
| `configuration_updated` | Flag signaling pending config changes |
| `updated_uri`, `updated_log_period`, `updated_max_backoff_period`, `updated_max_log_lines` | Staged config values applied on next `applyNewConfiguration()` call |
| `send()` | Transmits a batch of log lines to the TLS endpoint |
| `applyNewConfiguration()` | Applies staged configuration updates |
| `uri_` | Active endpoint URI |

### `TLSLoggerPlugin`
Implements `LoggerPlugin` to integrate TLS-based log forwarding into osquery's plugin system.

| Method | Description |
|--------|-------------|
| `init()` | Buffers early status logs generated before logger initialization |
| `setUp()` | Registers the node key and starts the `TLSLogForwarder` dispatcher thread |
| `configure()` | Reacts to configuration updates at runtime |
| `logString()` | Forwards result/snapshot/event log strings to the forwarder |
| `logStatus()` | Forwards ERROR/WARNING/INFO status log lines to the forwarder |
| `usesLogStatus()` | Returns `true`, enabling status log consumption |

## Usage Example

```c
// Registered automatically via osquery plugin system.
// TLSLoggerPlugin::setUp() initializes the forwarder:
Status TLSLoggerPlugin::setUp() {
    forwarder_ = std::make_shared<TLSLogForwarder>();
    Dispatcher::addService(forwarder_);
    return Status::success();
}

// Staged configuration updates are applied safely:
{
    std::lock_guard<std::mutex> lock(forwarder_->configuration_mutex);
    forwarder_->updated_uri = "https://fleet.example.com/log";
    forwarder_->configuration_updated = true;
}
```
