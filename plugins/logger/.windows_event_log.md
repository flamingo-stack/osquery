Windows Event Log logger plugin interface for osquery, providing integration with the Windows Event Log system via ETW (Event Tracing for Windows).

## Key Components

### `WindowsEventLoggerPlugin`
A `LoggerPlugin` subclass that routes osquery log output to the Windows Event Log. Inherits from `osquery::LoggerPlugin` and overrides the standard logging lifecycle methods.

**Protected Methods:**
- `logString(const std::string& s)` — Logs a plain string message to the Windows Event Log
- `init(const std::string& name, const std::vector<StatusLogLine>& log)` — Initializes the plugin and registers the ETW provider handle
- `logStatus(const std::vector<StatusLogLine>& log)` — Logs structured status entries with severity levels

**Static Utility Methods:**
- `acquireHandle(REGHANDLE&)` — Registers the current process as a Windows Event Log provider via ETW
- `releaseHandle(REGHANDLE&)` — Deregisters and releases the ETW provider handle
- `emitLogRecord(REGHANDLE, message, severity, source_file_name, line)` — Writes a single structured log record to the Windows Event Log with optional severity, source file, and line metadata

**Private Members:**
- `registration_handle_` — Stores the active ETW `REGHANDLE` for the lifetime of the plugin

## Usage Example

```cpp
#include "windows_event_log.h"

osquery::WindowsEventLoggerPlugin plugin;

// Acquire an ETW provider handle
REGHANDLE handle = 0;
auto status = osquery::WindowsEventLoggerPlugin::acquireHandle(handle);

if (status.ok()) {
    // Emit a log record with INFO severity
    osquery::WindowsEventLoggerPlugin::emitLogRecord(
        handle,
        "osquery startup complete",
        osquery::O_INFO,
        __FILE__,
        __LINE__
    );

    // Release when done
    osquery::WindowsEventLoggerPlugin::releaseHandle(handle);
}
```

> **Platform Note:** This plugin is Windows-only and depends on `evntprov.h` from the Windows SDK. It is only compiled on Windows targets within the osquery build system.
