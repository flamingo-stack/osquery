Defines the `StdoutLoggerPlugin` class, an osquery logger plugin that outputs log messages and status lines to standard output.

## Key Components

- **`StdoutLoggerPlugin`** — Inherits from `LoggerPlugin`; registers itself under the `"stdout"` logger name via the `REGISTER` macro
- **`usesLogStatus()`** — Returns `true`, enabling status log forwarding to this plugin
- **`logString()`** — Handles plain string log output to stdout
- **`init()`** — Initializes the plugin with a name and any buffered status log lines
- **`logStatus()`** — Handles structured `StatusLogLine` vector output to stdout

## Usage Example

```cpp
// Register and use the stdout logger via osquery config:
// { "options": { "logger_plugin": "stdout" } }

// Or instantiate directly in a test context:
StdoutLoggerPlugin plugin;
plugin.init("stdout", {});

Status result = plugin.logString("Hello from osquery");

std::vector<StatusLogLine> statusLines = { /* ... */ };
Status statusResult = plugin.logStatus(statusLines);
```

The plugin is auto-registered at startup via:

```cpp
REGISTER(StdoutLoggerPlugin, "logger", "stdout");
```

No manual instantiation is needed in production — osquery's registry resolves it by name when `logger_plugin = stdout` is set in configuration.
