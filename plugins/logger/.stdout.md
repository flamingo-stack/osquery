Defines the `StdoutLoggerPlugin` class, a logger plugin that outputs osquery log data directly to standard output (stdout).

## Key Components

### `StdoutLoggerPlugin`
Extends `LoggerPlugin` to provide stdout-based logging. Registered under the `"logger"` registry with the name `"stdout"`.

| Member | Description |
|--------|-------------|
| `usesLogStatus()` | Returns `true`, enabling status log processing |
| `logString(s)` | Writes a string log entry to stdout |
| `init(name, log)` | Initializes the plugin with a name and initial log lines |
| `logStatus(log)` | Writes a collection of `StatusLogLine` entries to stdout |

### Plugin Registration
```c
REGISTER(StdoutLoggerPlugin, "logger", "stdout");
```
Registers the plugin with osquery's registry, making it selectable via `--logger_plugin=stdout`.

## Usage Example

Enable the stdout logger when launching osquery:

```bash
osqueryd --logger_plugin=stdout
```

Or reference programmatically via the registry:

```c
auto plugin = RegistryFactory::get().plugin("logger", "stdout");
```

Log output will stream directly to the process's stdout, useful for containerized deployments or debugging where log aggregators read from standard streams.
