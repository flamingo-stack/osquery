Provides the `BufferedLogForwarder` base class and supporting utilities for reliably buffering and forwarding osquery log data (results and statuses) to remote destinations using a background thread.

## Key Components

### `iterate()` (inline function)
Iterates over a `std::vector<std::string>`, applying a predicate to each element. Automatically sleeps the thread for 20ms every 100 iterations to prevent CPU utilization spikes.

### `BufferedLogForwarder` (class)
A thread-safe base class extending `InternalRunnable` that buffers log lines to a backing store and periodically flushes them. Subclasses must implement `send()`.

**Key methods:**

| Method | Description |
|--------|-------------|
| `setUp()` | Initializes the buffer count; **must** be called by subclass overrides |
| `start()` | Entry point for the background thread; flushes logs on a configurable interval |
| `logString()` | Buffers a result string to the backing store |
| `logStatus()` | Decorates and buffers status log lines |
| `check()` | Scans buffered logs and dispatches them via `send()` |
| `purge()` | Removes oldest logs when the buffer exceeds `buffered_log_max` |
| `send()` | **Pure virtual** — subclasses implement actual log delivery |
| `backoffTick()` | Reduces exponential backoff counters after successful sends |

## Usage Example

```cpp
class MyLogForwarder : public BufferedLogForwarder {
 public:
  MyLogForwarder()
      : BufferedLogForwarder("MyService", "mylogger",
                             std::chrono::seconds(30), 500) {}

  Status setUp() override {
    // Initialize remote client here
    return BufferedLogForwarder::setUp(); // MUST call base
  }

 protected:
  Status send(std::vector<std::string>& log_data,
              const std::string& log_type) override {
    for (auto& entry : log_data) {
      // Forward entry to remote endpoint
    }
    return Status::success();
  }
};
```
