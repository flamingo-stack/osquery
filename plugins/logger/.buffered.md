Provides a thread-safe base class and utility for buffering and periodically forwarding osquery log data (results and statuses) to a backing store before sending to remote endpoints.

## Key Components

### `iterate()` (inline function)
Iterates over a `std::vector<std::string>`, applying a predicate to each element. Automatically yields the thread with a 20ms sleep every 100 iterations to prevent CPU thrash.

### `BufferedLogForwarder` (class)
An abstract base class extending `InternalRunnable` that manages periodic, buffered log forwarding. Subclasses must implement `send()`.

**Constructors** (protected):
- `(service_name, name)` — uses default period and max log lines
- `(service_name, name, log_period)` — custom flush interval
- `(service_name, name, log_period, max_log_lines, max_backoff_period)` — full control including backoff

**Key Public Methods:**
| Method | Description |
|---|---|
| `start()` | Main run loop; waits and flushes on interval |
| `setUp()` | Initializes buffer count; **must** be called by subclasses |
| `logString()` | Buffers a result log string to the backing store |
| `logStatus()` | Decorates and buffers status log lines |

**Key Protected Methods:**
| Method | Description |
|---|---|
| `send()` | **Pure virtual** — subclasses implement actual log delivery |
| `check()` | Scans buffered logs, sorts by type, calls `send()`, then `purge()` |
| `purge()` | Removes oldest logs when buffer exceeds `buffered_log_max` |
| `backoffTick()` | Reduces exponential backoff timer each cycle |

## Usage Example

```cpp
class MyForwarder : public BufferedLogForwarder {
 public:
  MyForwarder()
      : BufferedLogForwarder("my_service", "my_logger",
                             std::chrono::seconds(30), 500) {}

  // Required: implement actual log delivery
  Status send(std::vector<std::string>& log_data,
              const std::string& log_type) override {
    for (auto& entry : log_data) {
      sendToRemote(log_type, entry);
    }
    return Status::success();
  }

  Status setUp() override {
    // Must call base setUp() first
    auto s = BufferedLogForwarder::setUp();
    if (!s.ok()) return s;
    // Custom initialization...
    return Status::success();
  }
};

// Register and start
auto forwarder = std::make_shared<MyForwarder>();
forwarder->setUp();
Dispatcher::addService(forwarder);
```
