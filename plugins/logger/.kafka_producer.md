Header defining the `KafkaProducerPlugin` class, which integrates osquery's logging system with Apache Kafka via `librdkafka`, enabling query results to be published as messages to configured Kafka brokers.

## Key Components

### Constants & Utilities
- **`kKafkaBaseTopic`** — Default Kafka topic used when a payload's name doesn't map to a configured topic
- **`getMsgName()`** — Extracts the `name` field from a log payload string

### `KafkaProducerPlugin`
Inherits from both `LoggerPlugin` and `InternalRunnable`. Key members:

| Member | Description |
|---|---|
| `logString()` | Sends a log payload string to Kafka brokers |
| `init()` | Configures the producer; registers OS hostname as `client.id` |
| `start()` | Runnable entry point; polls Kafka in a loop |
| `stop()` | Flushes remaining messages (max 3s wait) on shutdown |
| `publishMsg()` | Publishes a message to a specific `rd_kafka_topic_t*` |
| `flushMessages()` | Thread-safe wrapper around `rd_kafka_flush` |
| `pollKafka()` | Thread-safe wrapper around `rd_kafka_poll` for delivery callbacks |
| `queryToTopics_` | Maps query names to their respective Kafka topics |
| `running_` | Atomic flag indicating producer activity |

Non-copyable by design (deleted copy constructor and assignment operator).

## Usage Example

```cpp
#include "kafka_producer.h"

// Plugin is typically registered and managed by the osquery plugin system
osquery::KafkaProducerPlugin producer;

// During logger initialization
producer.init("kafka_producer", {});

// Log a result payload (called internally by osquery logger dispatch)
std::string payload = R"({"name":"pack_query","columns":{}})";
osquery::Status status = producer.logString(payload);

// Extract topic name from payload
std::string topicName = osquery::getMsgName(payload);
// topicName == "pack_query"

// Graceful shutdown
producer.stop();
```

## Notes

- Topic routing uses the `name` field extracted via `getMsgName()`, falling back to `kKafkaBaseTopic`
- `shutdownFlag_` ensures `stop()` teardown logic executes only once across threads
