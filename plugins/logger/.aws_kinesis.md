Defines the AWS Kinesis log forwarding plugin for osquery, providing classes to batch and stream log records to an Amazon Kinesis stream.

## Key Components

### Type Alias
- **`IKinesisLogForwarder`** — Specialization of the generic `AwsLogForwarder` template, parameterized with Kinesis-specific AWS SDK types (`PutRecordsRequestEntry`, `KinesisClient`, `PutRecordsOutcome`, `PutRecordsResultEntry`).

### Classes

- **`KinesisLogForwarder`** — Concrete log forwarder that implements batching and sending logic for Kinesis. Key overrides:
  - `internalSetup()` — Initializes the Kinesis client and partition key.
  - `internalSend(batch)` — Submits a batch of records via `PutRecords`.
  - `initializeRecord()` — Populates a `PutRecordsRequestEntry` with a byte buffer.
  - Batch constraint methods: `getMaxBytesPerRecord()`, `getMaxRecordsPerBatch()`, `getMaxBytesPerBatch()`, `getMaxRetryCount()`, `getInitialRetryDelay()`.
  - Holds a private `partition_key_` string (overridden by `aws_kinesis_random_partition_key` flag).

- **`KinesisLoggerPlugin`** — osquery `LoggerPlugin` that owns a `KinesisLogForwarder` instance and bridges the osquery logging API to Kinesis:
  - `setUp()` — Instantiates and configures the forwarder.
  - `logString()` — Forwards a raw log string.
  - `logStatus()` — Forwards ERROR/WARNING/INFO status log lines.
  - `usesLogStatus()` — Signals that status logs are supported.

### Flag
- **`aws_kinesis_period`** — Declared `uint64` gflag controlling the flush interval of the forwarder.

## Usage Example

```cpp
// Registration happens via osquery plugin registry; direct usage example:
KinesisLogForwarder forwarder(
    "my-stream",       // Kinesis stream name
    10,                // log_period (seconds)
    1000,              // max_lines per batch
    "",                // no endpoint override
    AWSRegion::US_EAST_1
);

Status s = forwarder.internalSetup();
if (!s.ok()) {
    LOG(ERROR) << "Kinesis setup failed: " << s.getMessage();
}
```
