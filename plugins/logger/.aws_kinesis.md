Header defining the AWS Kinesis log forwarding plugin for osquery, providing classes to batch and send log records to an Amazon Kinesis stream.

## Key Components

### Type Alias
- **`IKinesisLogForwarder`** — Specialization of the generic `AwsLogForwarder` template, parameterized with Kinesis-specific AWS SDK types (`PutRecordsRequestEntry`, `KinesisClient`, `PutRecordsOutcome`, `PutRecordsResultEntry`).

### Classes

- **`KinesisLogForwarder`** — Concrete forwarder that implements the batching and transmission logic for Kinesis. Key overrides:
  - `internalSetup()` — Initializes the Kinesis client and partition key.
  - `internalSend(batch)` — Sends a batch of records via `PutRecords`.
  - `initializeRecord()` — Populates a single `PutRecordsRequestEntry` from a byte buffer.
  - Limit methods (`getMaxBytesPerRecord`, `getMaxRecordsPerBatch`, `getMaxBytesPerBatch`, `getMaxRetryCount`, `getInitialRetryDelay`) — Enforce Kinesis API constraints.
  - `appendNewlineSeparators()`, `getFailedRecordCount()`, `getResult()` — Control serialization and error handling.
  - **Private:** `partition_key_` — Used unless `aws_kinesis_random_partition_key` flag is set.

- **`KinesisLoggerPlugin`** — osquery `LoggerPlugin` integration point. Registers with the plugin system and delegates log forwarding to `KinesisLogForwarder`.
  - `setUp()` — Initializes the forwarder.
  - `logString()` / `logStatus()` — Route string and status logs to the forwarder.
  - `usesLogStatus()` — Declares support for status-level logging.

### Flag
- **`aws_kinesis_period`** — Controls the flush interval (declared via `gflags`).

## Usage Example

```c
// KinesisLoggerPlugin is registered as an osquery logger plugin.
// Configuration is driven by gflags at startup:
//
//   --logger_plugin=aws_kinesis
//   --aws_kinesis_stream=my-stream
//   --aws_region=us-east-1
//   --aws_kinesis_period=10        // flush every 10 seconds
//   --aws_kinesis_random_partition_key=true

// The plugin is instantiated internally by osquery's plugin registry.
// Direct instantiation of KinesisLogForwarder (e.g., in tests):
auto forwarder = std::make_shared<KinesisLogForwarder>(
    "my-stream",   // stream name
    10,            // log_period (seconds)
    1000,          // max_lines per batch
    "",            // endpoint_override (empty = default AWS endpoint)
    region         // AWSRegion struct
);
```
