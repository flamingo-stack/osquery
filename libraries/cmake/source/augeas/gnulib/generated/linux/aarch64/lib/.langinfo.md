## Usage Example

```c
#include <langinfo.h>
#include <locale.h>
#include <stdio.h>

int main(void) {
    setlocale(LC_ALL, "");

    /* Query the locale's character encoding */
    printf("Codeset:        %s\n", nl_langinfo(CODESET));

    /* Query decimal separator */
    printf("Decimal point:  %s\n", nl_langinfo(DECIMAL_POINT));

    /* Query abbreviated weekday names */
    printf("Day 1 (abbrev): %s\n", nl_langinfo(ABDAY_1));

    /* Query yes/no regular expressions */
    printf("Yes expression: %s\n", nl_langinfo(YESEXPR));
    printf("No  expression: %s\n", nl_langinfo(NOEXPR));

    return 0;
}
```

> **Note:** This header is auto-generated by GNU `gnulib`. On platforms that already provide a complete `<langinfo.h>`, it delegates via `#include_next` and only fills in whichever constants are missing (e.g., `ALTMON_1`–`ALTMON_12` on macOS/BSD).
