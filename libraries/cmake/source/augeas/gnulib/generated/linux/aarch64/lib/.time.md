A gnulib-generated compatibility shim that augments the system `<time.h>` with more-standard POSIX declarations, portability fixes, and optional C++ namespace aliases via the `GNULIB_NAMESPACE` mechanism.

## Key Components

### Conditional Inclusion Guard
- `_GL_TIME_H` — prevents recursive inclusion; defers to the system header when only partial symbols (`__need_time_t`, `__need_clock_t`, `__need_timespec`) are requested
- Uses `#include_next <time.h>` to chain-include the real system header

### Function Declaration Macros
| Macro | Purpose |
|---|---|
| `_GL_FUNCDECL_RPL(func, ret, params)` | Declares a gnulib replacement as `rpl_func` |
| `_GL_FUNCDECL_SYS(func, ret, params)` | Declares the system function with correct prototype |
| `_GL_EXTERN_C` | Wraps declarations with `extern "C"` linkage in C++ |

### C++ Namespace Alias Macros
| Macro | Purpose |
|---|---|
| `_GL_CXXALIAS_RPL` | Aliases `GNULIB_NAMESPACE::func` → `rpl_func` |
| `_GL_CXXALIAS_SYS` | Aliases `GNULIB_NAMESPACE::func` → system `func` |
| `_GL_CXXALIAS_RPL_CAST_1` | Same as RPL variant but uses `reinterpret_cast` to silence type mismatch errors |
| `_GL_CXXALIAS_SYS_CAST` | Same as SYS variant with cast |
