Portable compatibility header that provides a unified `alloca` macro/function declaration for stack-based memory allocation across multiple compilers and platforms.

## Key Components

- **`alloca(N)`** macro/function — Allocates `N` bytes on the call stack, automatically reclaimed when the enclosing function returns.

### Platform Mappings

| Platform/Compiler | Resolution |
|---|---|
| GCC / MinGW | `__builtin_alloca` |
| AIX | `__alloca` |
| MSVC | `_alloca` (via `<malloc.h>`) |
| DEC/VMS | `__ALLOCA` |
| Tandem TNS/E | `_alloca` intrinsic |
| IBM MVS | `<stdlib.h>` |
| Fallback | `void *alloca(size_t)` declaration |

## Usage Example

```c
#include "alloca.h"
#include <string.h>

void process_data(size_t len) {
    /* Allocate a temporary buffer on the stack */
    char *buf = alloca(len);
    memset(buf, 0, len);
    /* buf is automatically freed when process_data() returns */
}
```

## ⚠️ Known Limitations

Avoid `alloca` in these scenarios:

- **Inside function call arguments** — undefined behaviour
- **Inside inline functions** — allocation may outlive the intended scope
- **Large allocations (`N >= 65536`)** — stack size is not guaranteed; crash risk with no recoverable error
