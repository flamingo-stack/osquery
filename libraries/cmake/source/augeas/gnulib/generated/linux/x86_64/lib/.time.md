### C/C++ Linkage Macros (`_GL_CXXDEFS_H`)
| Macro | Purpose |
|---|---|
| `_GL_EXTERN_C` | Emits `extern "C"` in C++ mode, `extern` otherwise |
| `_GL_FUNCDECL_RPL(func, ...)` | Declares a gnulib replacement function as `rpl_func` |
| `_GL_FUNCDECL_SYS(func, ...)` | Declares the system function with a portable prototype |
| `_GL_CXXALIAS_RPL(func, ...)` | Creates a `GNULIB_NAMESPACE::func` alias pointing to `rpl_func` |
| `_GL_CXXALIAS_SYS(func, ...)` | Creates a `GNULIB_NAMESPACE::func` alias pointing to the system function |
| `_GL_CXXALIAS_*_CAST` variants | Same as above but with `reinterpret_cast` to silence C++ conversion warnings |
| `_GL_BEGIN/END_NAMESPACE` | Opens/closes the `GNULIB_NAMESPACE` C++ namespace when defined |
