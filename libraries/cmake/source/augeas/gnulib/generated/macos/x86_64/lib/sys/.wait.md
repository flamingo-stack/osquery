| Macro | Purpose |

| `_GL_BEGIN_NAMESPACE` / `_GL_END_NAMESPACE` | Opens/closes `GNULIB_NAMESPACE` when defined |

| `_GL_FUNCDECL_SYS(func, ...)` | Declares the system function with a given prototype |

| `_GL_CXXALIAS_*_CAST` variants | Same as above but silences C++ type-conversion errors via `reinterpret_cast` |
