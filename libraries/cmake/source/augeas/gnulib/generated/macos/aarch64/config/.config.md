## Key Components

- `ENABLE_DEBUG` — Enables debug mode when set to `1`

### Feature Detection (`HAVE_*`)
Presence flags for system headers and functions including `alloca`, `arpa/inet.h`, `btowc`, `catgets`, `CFLocaleCopyCurrent`, and many more POSIX/libc symbols.

- `GNULIB_TEST_*` — Enable test coverage for individual gnulib portability shims (e.g., `GNULIB_TEST_REALPATH`, `GNULIB_TEST_STRERROR`)
