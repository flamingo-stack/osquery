Defines the compile-time configuration flags for the AWS C SDK, controlling optional features like custom memory management.

## Key Components

| Macro | Default | Description |
|---|---|---|
| `USE_AWS_MEMORY_MANAGEMENT` | Undefined (disabled) | Enables AWS custom memory allocator hooks when defined |

## Usage Example

```c
// Check if custom memory management is active
#include <SDKConfig.h>

#ifdef USE_AWS_MEMORY_MANAGEMENT
    // Custom allocator path
    aws_mem_acquire(allocator, size);
#else
    // Standard malloc path
```
