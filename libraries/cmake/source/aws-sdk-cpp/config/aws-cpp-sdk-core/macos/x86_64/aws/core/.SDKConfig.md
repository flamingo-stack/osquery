Compile-time configuration header for the AWS C SDK, controlling optional build-time features via preprocessor defines.

## Key Components

| Macro | Default | Description |
|---|---|---|
| `USE_AWS_MEMORY_MANAGEMENT` | Undefined | Enables custom AWS memory management hooks when defined |

## Usage Example

```c
/* Check if custom memory management is active */
#ifdef USE_AWS_MEMORY_MANAGEMENT
    /* AWS allocator overrides are in effect */
    aws_mem_acquire(allocator, size);
#else
    /* Standard malloc/free in use */
    malloc(size);
#endif
```

## Notes

- Generated by CMake at build time — do not edit manually
- To enable `USE_AWS_MEMORY_MANAGEMENT`, pass `-DUSE_AWS_MEMORY_MANAGEMENT` during the CMake configure step
- Consumed internally by the AWS C SDK; rarely referenced directly in application code
