Defines the AWS CRT C++ SDK version string as a compile-time constant, used for version identification and compatibility checks.

## Key Components

| Symbol | Type | Value |
|--------|------|-------|
| `AWS_CRT_CPP_VERSION` | `#define` macro | `"1.9.116"` |

## Usage Example

```c
#include <aws/crt/Config.h>

// Access the version string at compile time
printf("AWS CRT C++ Version: %s\n", AWS_CRT_CPP_VERSION);
```
