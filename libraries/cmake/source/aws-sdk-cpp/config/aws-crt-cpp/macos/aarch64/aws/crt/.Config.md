Defines the AWS CRT C++ SDK version string as a compile-time constant, used for version identification and compatibility checks across the SDK.

## Key Components

| Macro | Value | Description |
|---|---|---|
| `AWS_CRT_CPP_VERSION` | `"1.9.116"` | Current SDK version string |

## Usage Example

```c
#include <aws/crt/Config.h>

// Access the version string at compile time
const char* version = AWS_CRT_CPP_VERSION;
printf("AWS CRT C++ SDK Version: %s\n", version);
```
