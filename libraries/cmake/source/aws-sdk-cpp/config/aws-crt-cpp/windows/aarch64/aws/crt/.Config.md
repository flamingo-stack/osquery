Defines the AWS CRT C++ SDK version string as a compile-time constant macro.

## Key Components

| Symbol | Type | Value |
|---|---|---|
| `AWS_CRT_CPP_VERSION` | Preprocessor macro | `"1.9.116"` |

## Usage Example

```c
#include "Config.h"

// Access the version string at compile time
const char *version = AWS_CRT_CPP_VERSION;
printf("AWS CRT C++ Version: %s\n", version);
```
