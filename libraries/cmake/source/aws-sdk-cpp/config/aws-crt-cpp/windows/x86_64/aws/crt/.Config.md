Defines the AWS CRT C++ library version string as a compile-time constant.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `AWS_CRT_CPP_VERSION` | `#define` | Semantic version string for the AWS CRT C++ library |

## Usage Example

```c
#include "Config.h"

// Access the version string at compile time
const char* version = AWS_CRT_CPP_VERSION;
printf("AWS CRT C++ Version: %s\n", version);
// Output: AWS CRT C++ Version: 1.9.116
```
