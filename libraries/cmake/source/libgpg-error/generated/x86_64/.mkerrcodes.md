Auto-generated lookup table mapping numeric Linux `errno` values to their corresponding `GPG_ERR_E*` symbol name strings, produced by the `mkerrcodes.awk` script and consumed by the libgpg-error library for error code translation.

## Key Components

### `err_table[]`
A static array of anonymous structs, each containing:

| Field | Type | Description |
|-------|------|-------------|
| `err` | `int` | Numeric Linux errno value (e.g. `2` for `ENOENT`) |
| `err_sym` | `const char *` | Corresponding GPG error symbol string (e.g. `"GPG_ERR_ENOENT"`) |

## Usage Example

```c
/* Typical reverse-lookup usage pattern */
const char *find_gpg_err_sym(int errno_val) {
    size_t n = sizeof(err_table) / sizeof(err_table[0]);
    for (size_t i = 0; i < n; i++) {
        if (err_table[i].err == errno_val)
            return err_table[i].err_sym;
    }
    return NULL;
}

/* Example */
const char *sym = find_gpg_err_sym(2);
/* sym == "GPG_ERR_ENOENT" */
```
