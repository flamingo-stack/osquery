## Usage Example

```c
/* Retrieve the human-readable name for a given error source code */
#include "err-sources.h"

const char *get_source_name(int source_code) {
    /* msgidxof() converts the source code to a table index,
       accounting for sparse/non-contiguous code ranges */

    /* Use the index to look up the offset in msgstr */

}

/* Example: source code 4 → "GPG Agent" */
```
