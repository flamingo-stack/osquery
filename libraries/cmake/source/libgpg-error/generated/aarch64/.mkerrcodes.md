## Key Components

### `err_table[]`

A static array of anonymous structs, each containing:

| Field | Type | Description |
|---|---|---|
| `err` | `int` | Numeric POSIX/Linux `errno` value |
| `err_sym` | `const char *` | Corresponding GPG error symbol string |

The table covers **~130 error codes**, including:

- Standard POSIX errors (`GPG_ERR_ENOENT`, `GPG_ERR_EINVAL`, `GPG_ERR_ENOMEM`)
- Network/socket errors (`GPG_ERR_ECONNREFUSED`, `GPG_ERR_ETIMEDOUT`)
- Stream/STREAMS errors (`GPG_ERR_ENOSTR`, `GPG_ERR_ENODATA`)

> **Note:** Some numeric codes intentionally appear twice — for example, `35` maps to both `GPG_ERR_EDEADLK` and `GPG_ERR_EDEADLOCK`, and `11` maps to both `GPG_ERR_EAGAIN` and `GPG_ERR_EWOULDBLOCK`, reflecting platform aliases.

```c
/* Typical reverse-lookup pattern consumers of this table would use */
const char *find_gpg_err_sym(int errno_val) {
    size_t n = sizeof(err_table) / sizeof(err_table[0]);
    for (size_t i = 0; i < n; i++) {
        if (err_table[i].err == errno_val)

    }
    return NULL;
}
```
