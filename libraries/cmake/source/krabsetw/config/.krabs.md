Instantiates the `krabs` namespace with a default-constructed `schema_locator` object, serving as a minimal translation unit to satisfy the linker for the krabs ETW (Event Tracing for Windows) library.

## Key Components

- **`krabs::dummy`** — A global `schema_locator` instance used as a placeholder to ensure the `krabs` namespace and its associated symbols are included in the compiled output.

## Usage Example

```cpp
#include "krabs.hpp"

// The dummy schema_locator is defined globally in the krabs namespace.
// No direct usage required — this file exists to satisfy linker requirements.
// Consumers interact with the krabs ETW library through krabs.hpp:

krabs::user_trace trace;
krabs::provider<> provider(L"Microsoft-Windows-Kernel-Process");
trace.enable(provider);
trace.start();
```

> **Note:** This file contains no logic beyond the global instantiation. Its primary role is as a compilation unit anchor for the krabs ETW library, ensuring the `schema_locator` type is linked into the final binary.
