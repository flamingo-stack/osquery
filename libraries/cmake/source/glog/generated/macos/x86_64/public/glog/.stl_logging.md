Provides `std::ostream` stream output operators for standard C++ STL containers, enabling them to be used directly with glog's `LOG()` and `CHECK_EQ()` macros for diagnostic logging.

## Key Components

| Component | Description |
|---|---|
| `google::PrintSequence` | Core iterator-based printer; outputs up to 100 elements followed by `...` if truncated |
| `operator<<` for `std::pair` | Formats pair as `(first, second)` |
| `OUTPUT_TWO_ARG_CONTAINER` | Macro expanding stream operators for `vector`, `deque`, `list` |
| `OUTPUT_THREE_ARG_CONTAINER` | Macro for `set`, `multiset` |
| `OUTPUT_FOUR_ARG_CONTAINER` | Macro for `map`, `multimap`, and optionally unordered/hash sets |
| `OUTPUT_FIVE_ARG_CONTAINER` | Macro for `unordered_map`, `unordered_multimap`, and hash map variants |

### Optional Container Support (define before including)

| Macro | Enables |
|---|---|
| `GLOG_STL_LOGGING_FOR_UNORDERED` | `<unordered_map>`, `<unordered_set>` |
| `GLOG_STL_LOGGING_FOR_TR1_UNORDERED` | `<tr1/unordered_map>`, `<tr1/unordered_set>` |
| `GLOG_STL_LOGGING_FOR_EXT_HASH` | `<ext/hash_map>`, `<ext/hash_set>` |
| `GLOG_STL_LOGGING_FOR_EXT_SLIST` | `<ext/slist>` |

## Usage Example

```cpp
#define GLOG_STL_LOGGING_FOR_UNORDERED
#include <glog/stl_logging.h>
#include <glog/logging.h>

// Log STL containers directly
std::vector<int> nums = {1, 2, 3};
LOG(INFO) << "nums: " << nums;
// Output: nums: 1 2 3

std::map<std::string, int> scores = {{"alice", 10}, {"bob", 20}};
LOG(INFO) << "scores: " << scores;
// Output: scores: (alice, 10) (bob, 20)

// Use with CHECK macros
std::vector<int> v1 = {1, 2}, v2 = {1, 2};
CHECK_EQ(v1, v2);  // Streams container contents on failure
```

> **Note:** This header injects operators into `namespace std` via `using ::operator<<` to support ADL resolution when `glog/logging.h` is included first. This is acknowledged as technically undefined behavior but is intentional for correct ADL lookup.
