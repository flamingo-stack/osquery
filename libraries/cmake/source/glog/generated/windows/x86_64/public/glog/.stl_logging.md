Provides `std::ostream` stream output operators for common STL containers, enabling them to be used directly with glog's `LOG()` and `CHECK_*()` macros for diagnostic logging.

## Key Components

| Component | Description |
|---|---|
| `google::PrintSequence` | Core iterator-based printer; outputs up to 100 elements, appending `...` if truncated |
| `operator<<` for `std::pair` | Formats as `(first, second)` |
| `OUTPUT_TWO_ARG_CONTAINER` | Macro expanding `operator<<` for `vector`, `deque`, `list` |
| `OUTPUT_THREE_ARG_CONTAINER` | Macro expanding `operator<<` for `set`, `multiset` |
| `OUTPUT_FOUR_ARG_CONTAINER` | Macro expanding `operator<<` for `map`, `multimap`, and optionally unordered/hash sets |
| `OUTPUT_FIVE_ARG_CONTAINER` | Macro expanding `operator<<` for `unordered_map`, `hash_map`, and variants |

### Optional Extension Macros

| Macro | Enables |
|---|---|
| `GLOG_STL_LOGGING_FOR_UNORDERED` | `<unordered_map>` / `<unordered_set>` |
| `GLOG_STL_LOGGING_FOR_TR1_UNORDERED` | `<tr1/unordered_map>` / `<tr1/unordered_set>` |
| `GLOG_STL_LOGGING_FOR_EXT_HASH` | `<ext/hash_map>` / `<ext/hash_set>` |
| `GLOG_STL_LOGGING_FOR_EXT_SLIST` | `<ext/slist>` |

## Usage Example

```cpp
#define GLOG_STL_LOGGING_FOR_UNORDERED
#include <glog/stl_logging.h>
#include <glog/logging.h>

// Log a vector directly
std::vector<int> v = {1, 2, 3};
LOG(INFO) << "values: " << v;
// Output: values: 1 2 3

// Use CHECK_EQ with containers
std::vector<int> a = {1, 2}, b = {1, 2};
CHECK_EQ(a, b);

// Pairs are formatted as (first, second)
std::map<std::string, int> m = {{"x", 1}};
LOG(INFO) << "map: " << m;
// Output: map: (x, 1)
```

> **Note:** Elements beyond the first 100 are silently truncated with `...` — this header is intended for logging/debugging use only, not serialization.
