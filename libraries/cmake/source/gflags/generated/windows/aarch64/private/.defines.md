| `HAVE_STDINT_H` | ✅ Defined | `<stdint.h>` is available |

| `HAVE_INTTYPES_H` | ✅ Defined | `<inttypes.h>` is available |
| `HAVE_SYS_STAT_H` | ✅ Defined | `<sys/stat.h>` is available |

## Usage Example

```c
// Conditional compilation based on detected platform features
#include "defines.h"

#ifdef OS_WINDOWS
  #include <shlwapi.h>   // Safe — HAVE_SHLWAPI_H is defined
#endif

#ifdef HAVE_STDINT_H
  #include <stdint.h>
#endif

#ifndef HAVE_STRTOLL
  // Provide a fallback implementation for strtoll on this platform
  long long strtoll_fallback(const char *str, char **end, int base);
#endif
```
