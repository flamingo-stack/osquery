### Header Availability (`HAVE_*_H`)
Defines presence of system headers detected at build time. Currently **enabled**:
- `HAVE_FCNTL_H`
- `HAVE_INTTYPES_H`
- `HAVE_SIGNAL_H`
- `HAVE_STDINT_H`
- `HAVE_SYS_STAT_H`
- `HAVE_AF_UNIX_H`

Most POSIX/Unix headers (`arpa/inet.h`, `pthread.h`, `sys/socket.h`, etc.) are **disabled** — indicating a Windows-targeted build.

### Function Availability (`HAVE_*`)
All function detection macros (`gethostbyname`, `strerror_r`, `sched_get_priority_*`) are currently **undefined**.

## Usage Example

```c
#include "config.h"

/* Conditional compilation based on detected headers */
#ifdef HAVE_FCNTL_H
#include <fcntl.h>
#endif

#ifdef HAVE_AF_UNIX_H
#include <afunix.h>  /* Windows AF_UNIX socket support */
#endif

/* Version check at runtime */
const char *version = PACKAGE_VERSION;  /* "0.17.0" */
```
